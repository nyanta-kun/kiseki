# 9車の軸モデル再設計 — 診断と設計（2026-08-24）

ユーザー提起:「9車はグレード競走が中心で注目度が高い。母数は少なく、車数が多いぶん
7車より当てにくいが、点数を絞って当てれば配当が大きい。最終コーナーで3ラインになると
外からのまくりは難しくなるのではないか。**現状のモデルは全て見直しが必要なレベルと感じる。
軸1を決めるモデルと、それに連動して2・3着に来る軸2を選ぶモデルの構築を検討したい**」

本書は**読み取りのみ**の診断と、そこから導かれる設計案。本番コードは一切変更していない。
再現スクリプトは `keirin/scripts/exp_9axis/`。

## 0. まず本番が何をしているかを書き出す（CLAUDE.md「検証の作法」）

| 項目 | 実際の値（コードとDBから） |
|---|---|
| 9車の商品 | `RANK_9C`（三連複2軸流し）と `RANK_9H1`（三連単フォーメーション6点・高配当狙い） |
| 軸の選び方 | `rank_7c_select_axis` ＝ **モデル3着内率 `pp3` の上位2車**（車数に依存しない共通関数） |
| 相手 | `rank_7c_select_legs(others, p3, 0.15)`。落差カットは無い。**実測 平均4.9点／7車** |
| レース選別 | 較正後 `p3_sum_top2 >= RANK_9C_P3_SUM_MIN(1.30)` ∧ 相手3点以上 |
| 賭け金 | `tilt_stakes: True`（予測オッズでダッチング・1レース10,000円） |
| 元モデル | `lgbm_wt_eval`（66特徴・`top3_flag`・**7車と9車を混ぜて学習**・AUC 0.776） |

🔴 **9C は 二軸そろい → 的中 の転換率が 89.8%**（7Cは57.5%）。相手はほぼ総流しなので、
**9C の成否はほぼ軸だけで決まる**。ユーザーが軸に注目したのは対象の選び方として正しい。

## 1. 前提の検算

| ユーザーの見立て | 実測 | 判定 |
|---|---|---|
| グレード競走が中心 | 9車 8,264R の級班は **S級 99.8%**。開催グレードは GIII 2,929 / GI 442 / GII 234 / GP 32（2024-01以降・cup_grade 未取得 2,193 を除く） | 🟢 |
| 母数が少ない | 9車 8,264R ↔ 7車 87,036R（**8.7%**）。9車がある日は全体の 55%、その日の平均 **11.0本** | 🟢 |
| 大レースで力差が小さい | **逆**。S級同士で比べても競走得点のレース内 sd は **9車 4.65 ↔ 7車 3.91**、最大差 14.99 ↔ 11.80 | 🔴 |
| 7車より当てにくい | 二軸そろい **42.4% ↔ 53.6%**。ただし**ランダム比では9車が上**（5.09x ↔ 3.75x） | 🟢 |
| 当たれば配当が大きい | 三連複の的中配当 中央 **16.9倍 ↔ 8.6倍**、100倍以上 **9.1% ↔ 3.6%**。三連単も 中央 77.4 ↔ 35.7倍 | 🟢 |
| 3ラインだとまくりにくい | 9車の1着決まり手は **n_lines=3 で 捲 29.5%／差 56.2%**、n_lines=5 で 捲 39.2%／差 49.0%。さらに **逃は9車全体で 13.2%**（7車 25.3%） | 🟢 |

**「力差が小さいから難しい」ではない。** 9車は力差がむしろ大きく、難しさの実体は
**3枠を9人で分ける組み合わせ**と、後述の**モデルの上乗せの薄さ**にある。

**「3ラインでまくりにくい」は実測で支持される。** ライン数が少ない（＝1本が長い）ほど
まくりは決まらず番手の差しが増える。9車では**先行がそのまま残ることがほぼ無い**
（逃 13.2%）のも7車との大きな違い。

## 2. 診断 — どこで負けているのか

### 2.1 識別力の上乗せが薄い

レース内 pairwise concordance（3着内かどうかの識別）:

| | モデル `pp3` | 競走得点だけ | 上乗せ |
|---|---|---|---|
| 7車 | 0.7639 | 0.7220 | **+0.0419** |
| 9車 | 0.7478 | 0.7209 | **+0.0269** |

🔴 **9車ではモデルが競走得点に上乗せしている量が 7車の 2/3 しかない。**
「見直しが必要」という体感の実体はここにある。

### 2.2 全域で過大評価（順位ではなくゲートに効く）

レース内 Σ`pp3`（定義上 3.00 になるはず）は **9車 3.159 ↔ 7車 3.025**。
`p3_calibration` は種別（決勝・準決勝）と開催グレードのセグメントしか持たず、
**車数のセグメントが無い**。`RANK_9C_P3_SUM_MIN = 1.30` は**膨らんだ量に当てた絶対閾値**。

### 2.3 🔴🔴 最大の欠落 — 二軸の依存を周辺確率では表現できない

軸1と軸2が**そろって3着内に入る**確率を、実測と「独立と仮定した積」で比べる:

| 年 | 同ライン 実測 / 独立 / 依存 | 別ライン 実測 / 独立 / 依存 |
|---|---|---|
| 2024 | 55.66 / 50.69 / **+4.98pt** [+3.3,+6.7] | 28.51 / 33.54 / **−5.03pt** [−7.2,−2.9] |
| 2025 | 53.45 / 48.54 / **+4.91pt** [+3.7,+6.1] | 30.15 / 34.62 / **−4.47pt** [−5.8,−3.0] |
| 2026 | 52.35 / 48.27 / **+4.08pt** [+2.6,+5.6] | 25.20 / 32.46 / **−7.25pt** [−9.1,−5.4] |

**3年とも同符号・CIが0を跨がない。** 7車も同じ向きだが幅は約半分（+2.8 / −3.9pt）。

軸1が3着内に入ったときの、残り8車の3着内率（全体の押し下げ −5.2pt を控除した相対値）:

| 軸1との関係 | 実測3着内率 | 相対残差 |
|---|---|---|
| 同ライン 直後（番手） | 50.07% | **+12.0pt** |
| 同ライン +2 | 31.71% | **+9.4pt** |
| 同ライン 直前 | 53.46% | **+8.1pt** |
| 別ライン先頭 | 18.91% | −2.1pt |
| 別ライン その他 | 17.90% | −3.7pt |

🔴 **周辺確率の積で軸2を選ぶ現行方式は、この構造を原理的に表現できない。**
これがユーザーの言う「連動して2・3着に来る軸2」そのもの。

## 3. A/B — 何が効いて何が効かないか

すべて honest walk-forward（vintage 予測・学習窓と評価窓を分離）。

### 3.1 ❌ ベースモデルの作り直しは効かない

四半期9窓・9車 4,639R。腕は同じ特徴パイプライン・同じ学習器で学習データだけ変える。

| 腕 | concordance | 軸1 3着内 | 二軸そろい | Δ二軸 | Σp3 |
|---|---|---|---|---|---|
| A0 現行（全車数で学習） | 0.7485 | 70.66% | 42.70% | — | 3.161 |
| A1 車数対応特徴を追加 | 0.7487 | 70.68% | 42.64% | −0.06pt [−0.63,+0.50] | **3.080** |
| A2 **9車だけで学習** | 0.7445 | 70.17% | 41.37% | **−1.34pt** [−2.20,−0.50] | **3.017** |
| A3 9車だけ＋車数対応 | 0.7433 | 70.42% | 41.47% | **−1.23pt** [−2.07,−0.39] | 3.014 |

A1 で足した特徴: `n_entries` / `score_rank` `wr_rank` `top3r_rank` の車数正規化版 /
`frame_frac` / `is_outer` の車数対応版 / `n_senko` `n_lines` の比率版。

🔴 **「9車専用モデル」は有意に悪化する**（学習 7万行では足りない）。
🔴 **車数対応特徴を足しても順位は1ミリも動かない。** LightGBM は生の順位や
   グレードから既に車数を実質的に判別できている。**改善するのは較正だけ**
   （Σp3 3.161 → 3.080、9車専用なら 3.017）。
🔴 **軸1はどの腕でも 70.2〜70.7% で動かない。** 過去の6通りの差し替えが全滅した
   （[[keirin_9car_axis_diagnosis_2026_08_24]]）のと同じ結論に、モデル側からも到達した。

> ⚠️ したがって「現状のモデルを全て見直す」＝**ベースモデルを作り直す**という形の
> 改修は、**測った範囲では報われない**。作り直すべきは**軸2の選び方**である。

### 3.2 🟢 軸2の条件付きモデルは効く

軸1 = `pp3` 1位で固定。残り候補から `P(軸1と当該車がそろって3着内)` の最大を軸2に採る。
特徴は両車の個別特徴＋**ペア関係**（同ライン・ライン内位置差・得点差・枠差・脚質の組）
＋レース文脈（ライン数・先行人数・グレード・車数）。全レース母集団での直接対決:

| 検定窓 | 現行（p3 2位） | 新（同時確率） | Δ | 同一選択 | 同ライン率 |
|---|---|---|---|---|---|
| 2026（学習 2024-25）9車 n=1,335R | 39.93% | 42.77% | **+2.85pt** [+1.12,+4.64] | 71.2% | 54.2%→80.4% |
| 2024-25（学習 2026）9車 n=3,258R | 43.46% | 44.66% | **+1.20pt** [+0.03,+2.39] | 71.2% | 56.4%→79.4% |
| 参考 7車 2026 n=13,749R | 53.64% | 54.44% | +0.80pt [+0.28,+1.31] | 79.8% | 57.9%→75.4% |
| 参考 7車 2024-25 n=34,801R | 53.63% | 54.71% | +1.08pt [+0.78,+1.39] | 81.1% | 57.1%→71.8% |

**両方向で正・CIが0を跨がない。** 効果量は 9車 +1.2〜+2.9pt / 7車 +0.8〜+1.1pt。
（7車の +1.0pt 前後は §24 の既報 +1.05pt と整合する＝独立に再現された）

### 3.3 ⚠️ 本番の 9C の買い方へ通すと目減りする

ゲート・相手・点数をすべて本番に揃え、母集団を両腕で完全に同一にして採点:

| 検定窓 | 二軸そろい | 的中 | ROI（均等配分） |
|---|---|---|---|
| 2026 n=580R 現行 | 53.62% | 47.93% | 73.58% [62,86] |
| 2026 n=580R **新軸2** | 55.86% | 49.48% | 73.31% [63,85] |
| Δ | **+2.24pt** [+0.34,+4.31] | +1.55pt [−0.34,+3.45] | −0.3pt |
| 2024-25 n=1,502R 現行 | 55.39% | 51.13% | 83.78% [77,91] |
| 2024-25 n=1,502R **新軸2** | 56.32% | 51.93% | 86.25% [79,94] |
| Δ | +0.93pt [−0.33,+2.26] | +0.80pt [−0.47,+2.00] | +2.5pt |

🔴 **ゲートが効果を吸う。** `p3_sum_top2 >= 1.30` は「上位2車に確率が集中したレース」
＝**現行の軸選択が既に正しいレース**を選ぶので、ペアモデルの出番が残っていない。
🔴 **ROI は動かない**（73〜86%・払戻率 74.85% の前後）。9C の設計に明記されているとおり
**ROI で語る商品ではない**。この改修も**的中体験の改善であって収支の改善ではない**。

### 3.4 ❌ レース選別まで同時確率へ替えるのは**再現しない**

件数を完全に揃えた比較（[A]=いまの本番）:

| | 2026 検定（4.68件/日） | 2024-25 検定（4.99件/日） |
|---|---|---|
| [A] 現行ゲート × 現行軸2 | 二軸 53.62 / 的中 47.93 / ROI 73.58 | 55.39 / 51.13 / 83.78 |
| [B] 現行ゲート × **新軸2** | 55.86 / 49.48 / 73.31 | 56.32 / 51.93 / 86.25 |
| [C] 新ゲート × 新軸2 | **58.10 / 51.72** / 73.49 | 56.99 / 52.46 / 83.81 |
| [D] 新ゲート × 現行軸2 | 56.03 / 50.34 / 72.54 | 57.26 / 52.86 / 85.66 |

探索側（2026）では [C] が [A] に **+4.48pt / +3.79pt** と大きく見えるが、
逆向き（2024-25）では **+1.60pt / +1.33pt** まで縮む。さらに件数を絞った帯では
逆向き窓で**現行ゲートのほうが良い**（2.7件/日: 新 62.52/57.58 ↔ 現行 63.56/59.43）。

🔴 **ゲートの置き換えは主張しない。** 効果が確認できたのは **[B]（軸2だけ替える）**。

## 4. 設計案

### 採る

**① 軸2を「軸1との同時確率」で選ぶ（9C・9H1 共通）**

- 学習単位: (レース, 軸1固定, 候補車)。目的変数 `y = 1[軸1が3着内] × 1[候補が3着内]`
- **学習は 7車＋9車を混ぜる**（9車だけでは 3.1 と同じ理由で足りない）。`n_entries` を特徴に持つ
- 特徴（29列）: 両車の `pp3` `ppw`、`p3` 差と積、候補の p3 順位、**同ライン**、
  **ライン内位置差**、両車のライン規模・位置・先頭フラグ・単騎フラグ・脚質、
  得点差と相対得点、枠差、ライン数、先行人数、開催グレード、級班、車数
- 出力は**軸2の選択にだけ使う**。`pred_top3_pct` は書き換えない
  （表示・他ランク・過去データへ波及する。`p3_calibration` と同じ原則）

**② 車数セグメントを `p3_calibration` に足す**

Σp3 が 9車で 3.159 → ゲート閾値 1.30 が実質的に緩んでいる。単調変換なので順位は不変、
効くのは `RANK_9C_P3_SUM_MIN` の判定だけ。**較正を入れたら閾値を引き直すこと**
（入れっぱなしだと件数が数割動く）。

### 採らない（測って否定した）

- ❌ **9車専用のベースモデル** — 二軸そろい −1.2〜−1.3pt（有意に悪化）
- ❌ **車数対応の特徴追加によるベースモデル改修** — 順位は完全に不変（Δ−0.06pt）
- ❌ **軸1の選び直し** — モデル側からも規則側からも動かない（70.2〜70.7%）
- ❌ **レース選別を同時確率へ替える** — 逆向き窓で再現しない
- ❌ **9車の三連単購入モデル** — 別途否定済み（[[keirin_9car_and_type_scan_2026_08_24]]）。
  ただしあれは**現行の軸**を前提にした評価。軸2が改善したら再測定の価値はある（未実施）

### 保留（ユーザー判断が要る）

- **件数と質の取引**。同時確率の上位15%まで絞ると 二軸 70〜72% / 的中 65% になるが
  **1.6件/日**（現行 4.7件/日）。これは改善ではなく取引で、現行ゲートを 1.45 へ
  上げてもほぼ同じ場所に着く
- **相手（3列目）の選び直し** — 9C では否定済み（[[keirin_layer3_transfer_9c_2026_08_23]]）。
  ただし軸2が変われば相手の集合も変わるので、①の後に再測定する余地はある

## 5. 検証プロトコル（実装するなら）

1. `wf_preds9_*.pkl` / `wf_preds_*.pkl` を使う。backfill された `pred_top3_pct` は使わない
2. ペアモデルの学習・検定は**年をまたぐ独立窓**。`--swap` の逆向きを必ず両方出す
3. 一次指標は**二軸そろい**と**的中**。ROI は均等配分で出し、**本番はダッチング**と明記する
4. 母集団は腕の間で完全に同一（ゲートは現行の `p3_sum_top2` で固定して判定する）
5. 出荷実装ができたら**実験スクリプトと差分0件**を突き合わせる
   （[[keirin_tf_core_redesign_2026_08_22]] の「簡易実装で勝って出荷実装で逆転」を踏まない）
6. 入れたら翌朝の `[marquee]` ログと `netkeirin_submissions` の件数を突き合わせる

## 6. 期待値の見積もり（正直な線）

- 9C の**的中率 +0.8〜+1.6pt**（現行 48〜51% → 49〜53%）。**ROI は動かない**
- 件数は変わらない（ゲートを触らないため）
- 9H1 は `pp3` の順位で買い目を作るので**この改修の影響を受けない**。
  9H1 に効かせたいなら別設計が要る

🔴 **「9車のモデルを作り直せば当たるようになる」は成り立たない。**
効くのは**軸2の選び方を周辺確率から同時確率へ替える1点**で、期待できるのは
的中率 1pt 前後。それ以上を求めるなら**件数を捨てる**しかない。

## 8. 🔴🔴 その代わり、穴埋めの成績がどこにも記録されていない

## 10. 🔴 自己訂正 — ペアモデルは穴埋め経路に対しては有意でない

§3.2 のペアモデルを全網羅母集団へ当てると、**p3上位2車に対しては**外れ群で
的中 +3.22pt [+1.54,+4.90] と大きく出る。しかしこれは**ベースラインの取り違え**だった。

🔴 **穴埋め経路は既にライン組み替えをしている**（`submit_marquee_wt._axes()`：
上位2車のどちらかがライン先頭なら、軸2をその同ラインの指数最上位へ差し替える）。
本番の実挙動を相手に測り直すと:

| 母集団 | p3上位2車 | **本番の穴埋め（組み替え）** | ペアモデル | Δ(ペア − 本番) 的中 |
|---|---|---|---|---|
| 全網羅 4,593R | 39.2% / 75.9% | 39.7% / 76.5% | 40.5% / 76.4% | +0.85pt [−0.07,+1.74] |
| 外れ群 1,367R | 31.1% / 63.5% | **33.1% / 69.1%** | 34.3% / 68.9% | +1.24pt [−0.44,+2.93] |
| 当たり群 1,702R | 47.9% / 79.1% | 49.1% / 81.8% | 49.0% / 78.7% | −0.06pt [−1.35,+1.23] |
| 穴埋めが出る母集団 2,507R | 29.9% / 71.7% | 30.4% / 71.7% | 31.6% / 71.2% | +1.12pt [−0.40,+2.51] |

🔴 **どの群でも有意でない。** 1行の組み替えルールが同じ依存構造を既に拾っている。
外れ群の改善（的中 +2.0pt / ROI +5.6pt）は**組み替えが作っている**。

⚠️ ただし**組み替えは群によって符号が違う**。中間群では p3上位2車より悪い
（的中 36.7→35.2% / ROI 83.6→77.2%）。ペアモデルはそこを取り戻す（36.7%）。
**「組み替えを掛ける／掛けない」をレースの型で切り分ける余地はここにある**（未検証）。

## 12. `RANK_9F` — 穴埋めで売っている9車の成績記録

🔴 **軸の正本は `submit_marquee_wt._axes()` を import して使う。** 写すと片方だけ直る。

   モデルに依存するので、片方だけ別 vintage で作ると母集団の排他性が壊れる。

## 13. 「実測が無い過去レースのペーパー」＝ これで作れる

ユーザー質問「実測なくても過去レースに対しても今のモデル適用で当たるか外れるかの
ペーパーはできませんか？」——**`#9C ∪ #9F` がそれ**。

- 入稿の有無に関係なく **2024-01 以降の全9車レース**について、その月の vintage モデルで
  「買っていたら当たったか・払戻はいくらか」を採点する
- 実際に入稿したレースは `netkeirin_submissions` を join すれば分けられる
  （`report_9car_full_coverage_wt.py` の「実入稿したか」表）
- したがって **実測の蓄積を待たずに「外れているレース」の分析ができる**

⚠️ ペーパーは **model-vintage look-ahead が無い**（月次凍結モデル）が、
   **入稿の優先順位・日次上限・波の締切は再現していない**。
   「その買い方なら当たったか」であって「実際に売れたか」ではない。
