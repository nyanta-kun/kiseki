# 05 市場の動きに「波乱の予兆」はあるか — 否定（入稿時点の板には既存量への増分が無い）

**結論: 否定。** 実オッズを「読み」として使う案は、第1層（型判定への加点）・第3層（選別ゲート）
のどちらでも、**入稿時点に実在した板**では既存量（`axis_sum` / `pw_ent` / WT印一致）への
増分が無い（ΔAUC −0.004 [−0.009, +0.002]・商品KPI は無作為対照と区別がつかない）。
市場の情報は**発走 5 時間以内の板に初めて現れ、閉場（確定）で最大になる**が、
その確定オッズ（look-ahead）を使ってさえ商品に変換できるのは 表示的中 +1〜2.5pt を
件数 −33%・10万+ −67〜75% と引き換えにする程度＝**既存の軸信頼ゲートを深くしたのと同じ操作**。

| 問い | 答え |
|---|---|
| 朝の波（07:20）で板は使えるか | **実質使えない**。朝の板はモーニング／デイ開催で三連複 76% 充足（全35点は 22%）、ナイター 35%（全点 2%）、ミッドナイト 18%（全点 0%）。しかも充足していても増分ゼロ |
| 昼・夜の波に遅らせれば使えるか | 板は育つ（noon→h12 で 95%・night→h14 で 67%／h18 で 89%）が、**そこでも増分は無い**（Δ −0.023 [−0.046, +0.000]・商品KPI は対照 10〜18/20 で CI が 0 を跨ぐ） |
| 市場はいつ何かを知るのか | 軸2そろいに対して **発走 5h 以内で Δ +0.010〜+0.018（CI 下限 ≈0）**、8h 以上前は 0 以下。確定で +0.026〜+0.031（両窓・有意）。**配当（100倍+）に対しては確定オッズでも情報ゼロ** |
| 予測オッズとの乖離（残差）は荒れの予兆か | 確定オッズの残差（`ratio_top` / `pair_ratio` / KL）は そろい率を Q1→Q5 で 44→57% に分けるが増分は +0.003〜+0.013 で `mk_axis` の 1/3 以下。100倍+ には効かない。**乖離は「荒れ」ではなく「市場が軸を支持しているか」の言い換え** |
| 二重計上か | `mk_axis` は `axis_sum` と Spearman **+0.77**、`mk_ent` は `pw_ent` と +0.76・予測オッズ最安と +0.74。**予測オッズと印が市場の形をすでに運んでいる** |

触る層: **第1層（型判定に市場の加点）と第3層（昼・夜の波の選別ゲート）**。どちらも不採用。

## 2. 台と測り方

| 台 | 期間 | n | 用途 |
|---|---|--:|---|
| A `/tmp/race_type_board.npz` + `TRIO_ODDS`（**確定**三連複） | 探索 2024-07〜2025-12 / 確認 2026-01〜08 | 25,833 / 10,404 | **上限**（look-ahead）。確定オッズで増分が無ければ早期の板にも無い |
| B as-of 台（DB のみ）: `wt_odds_snapshot` × `wt_entries.pred_*`（月次 vintage）× 結果 × `type_lab_picks` paper/live | 2026-07-17〜09-10（morning 板は 08-08〜） | 3,643R / 売った行 2,052R | **入稿時点に実在した板だけ**を使う本番相当 |

市場量（三連複の板 35 点から・`mkfeat.py`）: 含意確率 q = (1/o)/Σ(1/o) → 車ごとの市場3着内率 m。
`mk_axis` = 自社の軸2車の m の和（市場の軸支持）/ `agree2` = 市場の上位2車 == 自社の軸2車 /
`mk_ent` = q のエントロピー（市場の混戦度）/ `resid_axis` = axis_sum − mk_axis（自社が市場より強気）/
`log_fav` = 板の最安 / `ratio_top` `pair_ratio` = 予測オッズ÷板（残差）/ `kl` = KL(市場‖モデル)。

増分: ロジスティック回帰・日付ブロック 5-fold OOF・レース単位 paired bootstrap 95%CI。
base は `axis_sum, pw_ent, arare, gap, log(予測オッズ最安)`（台A）/ `axis_sum, pw_ent, WT印一致`（台B）。
目的は **軸2そろい**（外れの 55% を占める軸崩壊の裏）と **三連単 100倍+**（配当）。

## 3. 実測

### 3.1 【上限】確定オッズは軸2そろいを分ける（`final_upper.py`・台A）

| 目的 | 窓 | base AUC | +全市場量 | Δ [95%CI] | 最強単体 |

| 軸2そろい | 探索 | 0.6848 | 0.7168 | **+0.0321 [+0.0283, +0.0362]** | `mk_pair` +0.0318 / `mk_axis` +0.0293 |
| 軸2そろい | 確認 | 0.6698 | 0.7005 | **+0.0307 [+0.0249, +0.0365]** | `mk_pair` +0.0317 / `mk_axis` +0.0291 |

| 100倍+ | 確認 | 0.6245 | 0.6358 | +0.0113 [+0.0049, +0.0174] | `mk_ent` +0.0071 |

閉場時の市場は軸の堅さについて自社より約 +0.03 AUC ぶん多く知っている（両窓一致・有意）。
**これが早期の板が持ちうる情報の天井。** 配当については確定オッズでも +0.01 しか無い。

残差系（予測オッズ÷板）: `ratio_top` +0.003 / `pair_ratio` +0.011〜+0.013 / `kl` +0.002〜+0.004。
記述では `ratio_top` Q1（市場が自社より嫌う）→Q5 で そろい 44.3→57.2%・100倍+ 30.3→25.0%。
**「乖離が大きい＝荒れる」ではなく「市場が軸を嫌う＝崩れる」の言い換えで、`mk_axis` の下位互換。**

二重計上（確認窓 Spearman）: `mk_axis`×`axis_sum` **+0.765**・×`log_min_po` −0.721・×印一致 +0.345 /
`mk_ent`×`pw_ent` **+0.763**・×`log_min_po` +0.737 / `log_fav`×`log_min_po` **+0.750**。
＝ **予測オッズと印が、市場の形の大半をすでにモデルへ運んでいる。** 残る +0.03 は市場固有の情報。

## 4. なぜ効かないか（機序）

1. **入稿時点に資金が無い。** 板が埋まるのは発走 3h 以内（全点 66%）で、型ラボの入稿は
   モーニング以外すべて発走 5h 以上前。ナイター・ミッドナイトは 07:20 に三連複の 65〜82% が未確定。
2. **早期に入っている金は自社と同じものを見ている。** 板が揃っている 07:20 のレースでも
   `mk_axis` は `axis_sum` と +0.39〜+0.65、`mk_ent` は `pw_ent` と −0.52〜−0.57 で相関し、
   base に足すと OOF で消える（+0.0013）。競走得点・印・ラインは公開情報で、モデルも市場も同じ入力から読む。
3. **市場固有の情報は最後の資金にある。** 確定で +0.03 AUC 効くのに 0〜1.5h 前で +0.012、
   5h 以上前で 0。`oddspred_gap_2026_08_26.md` の「残差は締切間際の資金移動」と同じ現象。
4. **市場は配当を事前に知らない。** 100倍+ は確定オッズでも Δ +0.01 で、`mk_ent` の効きは
   `pw_ent` の言い換え。「荒れる」の予兆は市場にも無い（`type_a_upset` §の「決着の型は事前予測不可」と整合）。
5. **商品に変換すると軸信頼ゲートと同じ操作になる。** 確定 `mk_axis` の下位切りが効くのは
   `axis_sum` と +0.77 で相関するから。`race_shape` は既に `axis_sum` で同じ切り方をしている。

## 5. 採否と落とし先

- (a) 型判定への加点 — **不採用**。第1層の入力は「当日朝に確定するもの」（DESIGN 第1層）で、
  板はその条件を満たさず、満たす部分（07:20 の全35点）にも増分が無い。
- (b) 昼・夜の波でだけ掛ける選別ゲート — **不採用**。h12/h14 の板で Δ −0.023 [−0.046, +0.000]・
  商品KPI は対照 10〜18/20。**波を遅らせる運用変更（現行は朝に全レースを組む）の根拠にならない。**
- (c) 高額枠の選定 — **不採用**。100倍+ に対して市場は確定でも情報ゼロ。
- 運用上の価値がある否定: **「朝の波では原理的に使えない」が数字で確定した**（§1.1）。
  今後「板を見て組み直す」系の提案が来たら、まず §3.3 の時間表を当てること。

## 6. 限界

- as-of 台は **2026-07-17〜09-10 の 3,643R（morning 板は 08-08〜の 1,083R）**。窓が 8 週間しか無く
  「両窓」は半窓分割で代用した（CI ±0.02〜0.04）。**上限（確定オッズ）だけは 36,237R・両窓で有意**なので、
  「入稿時点の板 ≤ 確定オッズの情報」という順序関係に依存した論法になっている。
- 市場量は三連複の板から作った（三連単は充足数のみ）。三連単の板固有の順序情報は測っていない。
  ただし三連単の充足は三連複と同じ時間で育つ（§1.1）ので可用性の結論は変わらない。
- 商品KPI は日次上限を掛けていない（`synth_odds_thin` §の「上限は binding」の効果は未反映）。
  上限を掛けると入稿ループ側のゲートはさらに効かなくなる方向。
- `wt_entries.pred_*` は月次 vintage の backfill 値（当月のモデルは前月末までで学習）。
  当日に配信された値と同一ではないが look-ahead ではない。
- 多重比較: 市場量 13 本 × 目的 2 × 窓 2。as-of で有意になったものが無いので過学習側の懸念は無い。
- 発走 5h 以内の +0.010〜+0.018 は本物の可能性があるが、**そこで入稿できる波が無い**
  （締切は発走 15 分前だが、波は 07:20/13:00/18:00 の 3 回だけ）。「発走 2〜3 時間前に
  組み直す第4の波」を作れば使える余地はあるが、確定の半分以下の情報で商品KPI に届くかは未測定。
