# 消しモデル（市場が見込むほど来ない選手を探す）— 事前登録 2026-10-28

> §1〜§6 は**測る前に**書いてコミットした。結果は §7 以降に追記し、ここは書き換えない。

## 1. 背景と問い

ユーザー仮説（10/28）: レース条件・出走選手・ラインの組み合わせ・調子から「限りなく来ない選手」を見分けて
消せば、残る組み合わせは市場より割安になり、同じ計画払戻のまま的中が上がる。

これが成り立つのは**消した選手を市場が過大評価しているときだけ**。だから最初に問うのは
「朝に分かる情報だけで、**最終オッズの市場**が過大評価している選手を見分けられるか」。

既知のこと:
- 市場の見込みが低い選手ほど見込みより来ない（人気-穴バイアス・`docs/upset_index/S0_RESULT_2026_10_02.md`）
- 現行モデル（p3）が市場より低く見る選手は、市場どおりに来る（同 S0）
- 選手コメントの調子は確定市場にほぼ織り込み済み（10/01）
- ライン役割×市場見込み帯の1変数集計では 0.84〜1.08（10/28・2026-06〜10 を探索に使用）

## 2. モデル（固定）

選手1人1行・7車レース。LightGBM 二値（目的 = 3着以内）。
**出発点（init_score）= logit(m3)** に固定し、木は市場からのずれだけを学習する。

- `m3` = 最終三連単オッズから作る市場の3着内確率（Σ(1/odds) で正規化した各目の確率を、その選手を含む目で足す。レース内で和3）。0.005〜0.995 に切る
- 予測 `p̂` = sigmoid(logit(m3) + 木の出力)。比 `r̂ = p̂ / m3`
- 特徴（すべて朝に分かるもの）:
  - レース: 種別・開催日目・グレード・cup_grade・距離・場・レース番号
  - 選手: 級班・期・ギア・脚質・競走得点・予想印・S/H/B 回数・逃/捲/差/マ回数・1〜3着率・決まり手率5種
  - レース内の相対: 競走得点の順位・最大との差・平均との差
  - ライン: 人数・ライン内位置・先頭か・ライン数・自ラインの得点合計と順位・最強ラインとの差・自ライン先頭の得点
  - 調子: 同じ開催の前走着順・直近3走/5走の平均着順・3着内率・前走からの日数（その日より前の走のみ）
  - 市場: logit(m3) 自体とレース内の m3 順位（人気-穴バイアスの形を学ばせる）
- 結果列（着順・`factor`・`res_*`・`final_half`）と `pred_*_pct`（後から付け直される）は使わない
- 主ハイパラ: num_leaves 31・lr 0.03・min_data_in_leaf 200・feature_fraction 0.8・bagging 0.8・lambda_l2 1.0。
  木の数は学習窓の最後の3か月（2025-10〜12）を検証にした早期停止で決め、その本数で学習窓全体を学習し直す

選手コメント版（副）: 上の特徴に、その開催の前検日コメントのタグと、その日より前の直近のレース後コメントのタグ
（調子・トラブル・疲労・自信・自己評価・向き・走り方）を足す。

## 4. 判定（第1段）

「消し」= `m3 ≥ 0.15` かつ `r̂ ≤ 0.70` の選手。確認（主）で:

1. 消し選手の 実際の3着内数 ÷ Σm3 ≤ **0.80**、かつ開催日単位ブートストラップ（2,000回）95% CI の上限 < **0.90**
2. 消し選手が1人以上いるレースが全レースの **5% 以上**

両方を満たせば第2段（その選手を含む目を消した商品を台で組み、同じ計画払戻で表示的中が上がるか）を
別途事前登録する。満たさなければ、この方向（朝の情報で最終市場の過大評価を見分ける）は不採用と記録する。

併記（判定に使わない）: `r̂` の十分位ごとの 実際/Σm3、確認（副）での同じ数字、コメント版の同じ数字、
`m3 < 0.15` の層の数字、特徴の寄与上位。

## 7. 結果（2026-10-28 実施）— 第1段 **不通過**（判定2）

スクリプト `scripts/exp_type_lab/kesi/{build,run,morning}.py`。入力 CSV は psql で書き出した（`rows_*.csv`・`form.csv`・`iv.csv`・
`morning.csv`・git 管理外）。37.9 万行 = 54,106R × 7（重複なし・各レースで Σm3 = 3 を確認）。
主モデルは早期停止 336 本。寄与上位は場 28%・レース種別 10%・logit(m3) 8%（＝人気-穴バイアスの強さが場と種別で違う）、
以下 競走得点の差・期・1〜3着率・ラインの得点合計と最強ラインとの差。

| **確認(主) 2026-01〜05** | 62人 | 0.505 [0.168, 0.871] | **0.6%** | 通過 | **不通過** |

**「市場が 15% 以上と見ているのに、その 7 割以下しか来ない選手」はほとんど作れない。** ユーザー仮説の
「限りなく来ない選手を消す」は、この閾値では不採用。第2段（消した商品の台）は事前登録どおり行わない。

### 7.2 併記（判定外）— ずれ自体はある・ただし ±1〜2割

- 対数損失（1レースあたり）: 市場 3.7559 → モデル 3.7437（Δ −0.0122 [−0.0161, −0.0084]・主）、
  副も Δ −0.0117 [−0.0155, −0.0076]。**最終市場に対して増分がある**（10/01 の選手コメント単独では無かった）
- `m3≥0.15` の r̂ 十分位（実際÷見込み）は予測どおりに並ぶ（主 / 副）:
  最下位 0.873 / 0.879（予測 0.86）… 最上位 1.146 / 1.127（予測 1.16）
- `m3<0.15` の最下位五分位は 0.72 / 0.56（穴の中の「本当に来ない穴」）。ただしもともと商品が買わない層
- コメント版は学習 4 か月で本数 46・増分 Δ −0.0071。コメントのタグは寄与上位 15 に入らない

### 7.3 探索: 朝のオッズを出発点にした場合（2026-06-08〜10-27・7,281R・一度見た期間）

`wt_odds_snapshot` の `morning`（06:05〜・入稿は 07 時台が大半）を朝の市場にした。
朝↔最終の logit 相関 0.84。主モデルの出発点を朝の m3 に替えた r̂ の十分位で、**払戻を決める最終市場に対する** 実際÷見込み:
最下位 0.930 / 第2 0.952 … 第9 1.062 / 最上位 1.081。**朝の時点でも ±7% の手掛かりが残る**（最終を出発点にした上限の約半分）。

### 7.4 まとめ

- 消す方向（来ない選手）より、**市場が過小評価している選手を拾う方向**の方が幅が大きい（上位十分位 +13〜15%・最終市場が分かっている場合の上限）
- 🔴 **朝の時点で残るのは「回収」側の手掛かりで、「的中」側ではない。** §7.3 の最上位十分位は 朝m3 0.314 → 最終 0.263 → 実際 0.285。
  朝の見込みに対しては 0.907（**朝の見込みより来ない**）で、最終に対しては 1.081。日中に市場がその選手から離れ、
  オッズが伸びるぶん払戻が増える形。朝に選んだ目は朝の見込みより当たらない。
  なお §7.3 は最終市場で学習したモデルの出発点を差し替えただけ（朝の出発点で学習し直していない）ので、目安にとどまる
- ただし幅は ±1〜2割で、三連単の控除（回収 100% に比 1.35 が要る）を越える大きさではない。
  効くとしても表示的中が数ポイント・回収が数ポイントの改善どまりの見込み
- 次に測るなら: p̂（朝の市場＋ずれ）で目を選んだ商品の台（事前登録を新たに書く。2026 は今回見たので前向きが必須）

### 7.5 事後の確認: 寄与 1 位の「場」は人工物か（`venue_check.py`）

- 場を外して学習し直しても十分位の表は保たれ（主 0.88〜1.14・副 0.87〜1.14）、対数損失の改善はむしろ大きい
  （主 −0.0122 → −0.0136・副 −0.0117 → −0.0144）。場の寄与は過学習で、ずれそのものは場の偏り（オッズの取得時刻など）ではない
- 改善は 37 場に散らばる（上位 4 場で 32%）
- 場なしの寄与上位: レース種別 9.7%・logit(m3) 9.4%・競走得点の平均との差 5.3%・最大との差 4.7%・期 4.7%・2着率・1着率・ラインの得点合計
- 未確認: 1〜3着率・決まり手率が出走表時点の値かどうか（後から更新されると小さな増分を作りうる）。場の形をしていないので強くは疑っていない
