## 1. 形（`src/type_lab.py::flat_lead_legs`・`PLANS["L_flat"]`）

1. 7車で、**軸2車の3着内率の合計 `axis_sum` が `FLAT_LEAD_AXIS_SUM_MAX`（1.327）未満**
2. 得点1位の居るラインが3車以下（単騎なら1車）
3. 得点1位の居ない2車以上のラインで、**先頭が「逃」**（先頭の得点順位は問わない＝`L_lead` との違い）
4. 買い目は **先頭→番手→3着**。3着から 第三のラインの番手以降・3着内率最下位・競走得点最下位を外す
5. **1レース1万円を均等に割る**（100円単位で切り捨て）
6. 版は `flat_lead_rule_version()`（先頭 `F`）。既存の `rule_version` / `line_lead_rule_version` は割らない

`L_lead`（得点5位以下の先頭だけ）を混戦に限って広げた形なので、**混戦のレースでは `L_lead` の行と
重なる**（`L_flat` ⊇ その日の混戦の `L_lead`）。`L_lead` の判定（2026-11-24）とは独立に判定する。

- **区切りは両窓を見ながら選んだ。** 混戦の測り方3種（1着率のエントロピー・1着率1位−2位・`axis_sum`）×

## 4. 判定（事前登録）

判定は**紙上の全行**で行う（売っていないので実売の件数は無い）。

| | 指標 | 閾値 |
|---|---|---|
| **主** | **発生倍率** = 的中数 ÷ Σ(0.75 / 確定オッズ)（買った全目・確定三連単オッズ `wt_odds`） | **≥ 1.10** |
| 副1 | 同じレースで実際に売った現行商品（`netkeirin_submissions`・決済済み）との回収率の差 | `L_flat` ≥ 現行 |
| 副2 | 上位3本を除いた回収率 | ≥ 75% |
| 参考 | 回収率・表示的中・10万円以上の的中数 | — |

主指標を回収率にしないのは、500R・的中40本では回収率の差の範囲が数十pt になり判定がつかないため
（確認窓 1,077R でも −17〜+216pt）。発生倍率は件数が少なくてもぶれが小さい（`L_lead` と同じ考え方・
`line_lead_2026_09_24.md` §3・§7）。

**判定の出し方**

- 主 ≥ 1.10 ∧ 副2 ≥ 75% → **混戦の F/E/D を `L_flat` へ置き換える実売の提案**を作る（売るかはユーザーが決める）。
  副1 は提案に添える（件数が少ないので単独では判定に使わない）
- 主 < 1.00 → 不採用。行の生成を止める
- 1.00 ≤ 主 < 1.10 → 判定保留。期間を延ばすかをユーザーと決める

集計: `scripts/flat_lead_report.py --from <開始日> --to 2026-12-02`
