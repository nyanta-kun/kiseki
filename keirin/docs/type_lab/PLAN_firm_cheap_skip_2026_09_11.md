## 2. 🔴 最初に決めること — 「三連単3倍」の定義

ユーザーの言葉は「三連単で3倍を切る」。**どの目の3倍かを先に確定させる。**
候補は3つあり、母集団が変わる:

| 定義 | 意味 | 備考 |
|---|---|---|
| **A. 指数1-2-3 の予測オッズ** | モデルの本命の並び | §1 で実測済み（6.96%） |
| B. 印 ◎-○-△ の予測オッズ | 公式印の本命の並び | `A_prediction_mark` から。印欠測の扱いが要る |
| C. 買い目の最安点の予測オッズ | 実際に買う目の下限 | 帯（`min_odds`）に支配されるので**読みの量ではない** |

🟢 **A を主、B を副で測ることを推す。** C は帯の言い換えになるので単独では使わない。
⚠️ **A と B の一致率**を先に出すこと（`mark_order` の実測では決着3車が◎○△なのは 20.32%）。

## 3.5 🔴🔴 実例（2026-09-11 四日市1R）と「割り方」の必要性

ユーザーが挙げた実例。**計画の §3 はこのケースを扱えていなかった**ので追記する。

| | |
|---|---|
| 四日市1R 一般・型C（`axis_sum` 1.615 / `arare` 1） | 売った商品 **`C_hit` 12点** |
| 指数順 `p3_order` | **5-1-7**-4-2-3-6 |
| 決着 `win_combo` | **5-1-7**＝**指数1・2・3位そのまま**（確定 **2.50倍**） |
| 平均想定払戻 | 22,266円 |

買い目（抜粋）:

    1-5-7   3,600円 / 予測 5.74倍   ← 帯下差込(underband)の1点・**決着と同じ3車の並び違い**
    5-1-4   1,100円 / 予測18.88倍
    5-1-2   1,000円 / 予測20.75倍
    …（帯15倍+の10点）
    決着 5-1-7 は **買い目に無し**

🔴 **3車は完全に当てていて、並びだけ外した。** しかも当てていても 2.50倍＝25,000円で、
他11点に 6,400円 使っているので**実質ほぼ収支トントン**。
＝ **「当てても安い」レースの典型**で、ユーザーの提案はここを指している。

### ユーザー提案の後半（当初の計画に無かった部分）

> これが**人気を集めているが一定以上外れそう**で、**それ以外に妙味がある**レースであれば
> 購入対象とすべき

＝ **「安い層を一律に落とす」ではなく「安い層の中を2つに割る」**:

| レースの型 | 扱い |
|---|---|
| 本命が安い **かつ** そのとおり決まりそう | **見送り**（当てても安い） |
| 本命が安い **が** 崩れそう／他に妙味がある | **買う**（穴側に価値がある） |

### 🔴 「崩れる側を事前に当てる」は一度失敗している

`band_and_gate_2026_09_10.md` §8: `q_m3`（◎○△で決まるモデル確率）で帯を切り替える腕は、
結果を単調に分離するのに**無作為対照20seed に両窓で符号反転**
（型E 2/20 ↔ 16/20・型C 19/20 ↔ 2/20）。

🟢 **ただし `q_m3` より良い量が後から見つかっている。**
`band_by_race_2026_09_10.md`: **`sig14`＝Σ(1/予測オッズ)**（確率上位14点・帯なし）が
決着が帯を割るかの AUC で **型C 0.660/0.675・型E 0.631/0.646** と、
`q_m3`（0.628/0.617・0.561/0.573）を**両窓で上回る**。
→ **`q_m3` では駄目だったが `sig14` なら、という余地は残っている。**

### 追加する腕（§3 の続き）

| 腕 | 内容 |
|---|---|
| ⑤ **安い層を `sig14` で2分し、上位（＝順当に決まりそう）だけ見送る** | **ユーザー提案の本体** |
| ⑥ 同・`q_m3` 版 | §8 の再現（**負けるはず**・検算用） |
| ⑦ ⑤と同数を安い層から無作為に落とす対照20seed | **必須** |

🔴 **⑦ が肝。** ⑤が⑦に勝てなければ「割り方に情報がある」とは言えず、
   ②（丸ごと見送り）と区別が付かない。
🔴 **「一定以上外れそう」を事後の決着で定義しない**（look-ahead）。
   朝に確定する量（`sig14` / `axis_sum` / `arare` / `gap` / 印の分布）だけで作ること。

## 4. 判断指標

**この操作は「表示的中を上げる施策」ではない**可能性が高い（§0.1）。
したがって**何を買って何を売るかを先に宣言してから測る**こと。

| 指標 | 役割 |
|---|---|
| 件/日 | 減る量。目安 2.8件/日（3倍・A の場合） |
| 表示的中 | **下がる想定**。どれだけ下がるか |
| **10万+/日** | 🔴 一撃商品を落とすので**直撃する**。最重要 |
| 払戻中央 | 上がる想定 |
| 投資額/日 | 減る（＝顧客の損失も減る） |
| ROI | 🔴 **採否に使わない**（±2.5pt の判別に約15.6年） |

🟢 **本件の本当の狙いは「読みと商品の一貫性」**——帯で無理に穴側を買って辻褄を合わせる
くらいなら出さない、という商品思想。**測定では決まらない店頭KPIの判断**になる可能性が高い。
その場合は「この取引条件になる」という表を出して**ユーザーに選んでもらう**。

## 7. あらかじめ予想される結末（外れてよい・書いておくのは先入観を明示するため）

- 表示的中は**下がる**（§0.1 の機序がそのまま効く）
- 10万+ は**落ちる**（一撃商品を含めて落とすため）

🔴 **もしこのとおりなら、それは「効かない」ではなく「店頭方針の選択」**。
そう報告して判断を仰ぐこと。**無理に効果を作らない。**

⚠️ **ただし ⑤（安い層を2分する）だけは別。** ここが効けば「投資額を減らしつつ
表示的中を落とさない」が成立しうる唯一の道で、②（丸ごと見送り）とは質が違う。
**⑤が⑦（無作為対照）に勝つかどうかを、本検証の合否の中心に置くこと。**
