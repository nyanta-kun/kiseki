## 1. 観察の裏取り（実データ1件）

本日 2026-09-19 の自信ありは **`20260919_38_04` の `F_sign`**
（タイトル「高額狙いの三連単｜大混戦」・`confident_ev`=1.129・status=`proposed`）。
前日 9/18 も `20260918_28_11` の `F_sign`。

`F_sign` は**設計上の表示的中が約 4.76%**（`DESIGN.md` 2.1）の看板商品。
＝ユーザーの「穴寄り」という観察はそのとおりで、**バグではなく 2026-09-02 の仕様どおり**の動作。

## 2. 原因 — EV 最大は定義上こう振る舞う

EV = Σ(確率 × 賭け金 × 予測オッズ) ÷ Σ賭け金 は**高オッズ・低確率ほど大きくなる**。
そのため合成オッズの下限をどこに置いても、選ばれるのは合成 15倍前後の一撃商品
（`C_sign` / `A_sign` / `E_big`）になる。

`confident_pick.py` の旧 docstring 自身が
「自信ありを『当たりやすい1本』から**『大きく獲る1本』へ意図的に再定義**した」
と書いており、2026-09-12 に「仕様として維持する」判断も入っていた。
今回の指示はその判断を**元に戻す**もの。

## 4. 取引条件（何を失うか）

| | EV最大（〜09-18） | Σp最大（09-19〜） |
|---|--:|--:|
| 表示的中（確認窓） | 5.88% | **29.83%** |
| 払戻中央（確認窓） | 139,125円 | 26,110円 |
| 10万+（確認窓238日） | 12件 | **0件** |
| 合成中央 | 15.18倍 | 2.83倍 |

**「大きく獲る1本」を捨てて「当たりやすい1本」を取る**取引。ROI では判別できない
（85.7 ↔ 87.2%）。ユーザーの依頼が的中信頼度なので採用。

🟢 **穴狙いアイコンとの衝突も解消する。** netkeirin の勝負アイコンは1列しかなく
`resolve_act_type` は自信ありを優先するため、一撃商品が選ばれた日はその商品の
穴狙いアイコンが消えていた（2026-09-02〜09-12 の11件中3件）。Σp 最大では
`C_hit` / `B_hit` が選ばれるのでこの上書きはほぼ起きない。

### 🔴 フロントの表示バグを同時に潰した

`ReviewClient.tsx` は `ExpectedValueBadge ev={p.confident_ev ?? p.expected_value}` と
していた。`ExpectedValueBadge` は **満尺 2.00・1.00 未満は赤**の期待値バーなので、
`confident_ev` が Σp（0〜1）になると**全件が赤の極小バー**になり表示が嘘になる。

→ 期待値バッジには板由来の `expected_value` だけを渡し、選定値は
「自信あり Σp ○○%」として別行に出す。

⚠️ **`confident_ev` という列名は互換のため据え置き**。中身は世代で変わっている
（旧EV → Σp → EV → **Σp**）ので、**日をまたいで値を比べてはいけない**。

## 5.5 🔴 段（tier）との関係 — この変更が効くのは段が止まっている間だけ

`pick()` / `_choose_confident` の分岐は**3段**ある:

    tier_day（`TIER_SELL_ENABLED` ∧ 段の商品が1件でもある）
        → `tier_confident_score`（固め `T_firm` だけ・決勝系を優先・Σp 最大）
    elif 型ラボの行がある
        → `type_lab_confident_score`  ← **本稿が変えたのはここだけ**
    else
        → `race_expected_value`（旧ランク経路）

🔴 **いま `TIER_SELL_ENABLED = False`**（`c6980a17` #583「段の販売を止め、入稿の判断を
9/14 までの規則へ戻す」・2026-09-16〜）。したがって `tier_day` は常に False で、
**型ラボ経路が現役**。本稿の実測（本日の自信ありが `F_sign` だった件を含む）は
すべてこの状態のもの。

⚠️ **段の販売を再開（`TIER_SELL_ENABLED = True`）すると、段の日は本変更が効かない**
（段の規則が優先される）。ただし段の規則も既に Σp 最大なので、**向きは同じ**
（決勝系を優先する点と、候補を固め `T_firm` に限る点だけが違う）。
段を再開するときは、型ラボ経路と段経路で「自信あり」の性格が揃っているかを
この表と突き合わせて確認すること。

## 6. 限界

- 実地窓が 23日（n=23）と短い。探索・確認（365 / 238日）が本体。
- 確認窓は既に多くの検証で消費済み。本件はユーザー指示による仕様変更であって
  探索による発見ではないが、数値の再利用時は注意。
- 既存ランク側（`pick_confident_race_wt.py` の旧 EV 経路）と**段の経路は変更していない**。
  型ラボが1件でもあれば旧 EV 経路には到達せず、段は `TIER_SELL_ENABLED=False` で止まっている。
- 9車・高額枠は自信ありの母集団に入らない（`_choose_confident` は通常商品の行だけを見る）。
