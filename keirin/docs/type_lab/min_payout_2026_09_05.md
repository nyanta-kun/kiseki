# 最低2倍保証と信頼度傾斜（2026-09-05）

ユーザー要望：

> 最低2倍を担保しながら、買い目に対しての信頼度を得点化し、
> 信頼度が高いところから払い戻しが多くなる様に傾斜配分する事はできませんか？

**できた。しかも仕組みは既にあった**（`allocate` の `conf` モード）。変えたのは床の倍率と、
それを掛けるプランの範囲だけ。**買う目は1点も変えていない。**

台: `keirin.type_lab_picks` の実生成行（本番のモデル確率と予測オッズ）+ `keirin.wt_odds`
の確定オッズ。7車・hit系6プラン・入稿ゲート通過分。窓は 探索2025 / 確認2026。

---

## 1. 仕組み

`conf` は **各点に「予算 × `floor_mult` ÷ 予測オッズ」の床を置き、残りを確率に比例して
配る**。床の分だけ「当たれば最低 `floor_mult` 倍」が保証され、残りが確率順に乗るので
**確信のある点ほど払戻が厚い**。

🟢 **「最低2倍」は入稿ゲートと同じ制約。** 床を全点に置ける条件は
`Σ(1/オッズ) <= 1/mult`。mult=2.0 は `Σ <= 0.5` で、入稿ゲート
（平均想定払戻2万円超）とまったく同じ式。**通る買い目なら必ず組める。**

変更前は `A_hit` / `F_hit` だけが `conf` で `floor_mult=1.3`、他は `dutch`（全点同額・傾斜なし）。

## 2. 実測

|---|---|---|
| ROI | 76.0 → **76.1** | 80.6 → **80.7** |
| **2万円未満の点があるレース** | **22.1% → 8.5%** | **21.9% → 8.3%** |
| 的中率・表示的中 | 不変 | 不変 |
| 10万円+ | ほぼ不変 | ほぼ不変 |
| 在庫（件数） | **不変** | **不変** |

## 3. 傾斜は実際に付く

1レース内の想定払戻のひらき（最高 ÷ 最低・確認窓）:

| プラン | 変更前 | 変更後 |
|---|---:|---:|
| B_hit | 1.18 | **1.83** |
| C_hit | 1.19 | **1.59** |
| E_hit | 1.20 | **1.87** |
| D_hit | 1.03 | 1.21 |
| A_hit | 1.45 | 1.22 |
| F_hit | 2.17 | 1.60 |

`dutch` だったプランには**傾斜が新たに付き**、元から `conf` の2つは
**床が予算を食うぶんひらきが縮む**（狙いは最低額の底上げなので想定内）。

## 4. 掛けないもの

⚠️ **`A_ana`（穴狙い）は ROI 78.6 → 65.7（−12.9pt）と大きく悪化する。**
想定払戻25万円級の商品に全点2万円の床を置くと、高配当の目への傾斜が床に食われて崩れる。
`F_sign` / `F_pay` / `A_trio` も対象外（元から「2万円未満の点」が 0.0〜1.6% でこの手当てが要らない）。

## 5. 🔴 床が置けないレースを見送りにしない

`Σ(1/予測オッズ) > 0.5` だと床が置けず `allocate` が None を返す。そのまま返すと
**商品が丸ごと消える**（実測 8.3〜8.5%）。母集団を静かに削るのが一番たちが悪いので、
その分は **変更前の配分のまま売る**（`ALLOC_BEFORE_MIN_PAYOUT` / `alloc_fallback`）。

＝ この変更で**在庫は1件も減らない**。落ちた分はそのまま「2万円未満の点があるレース」
として残る（8.3〜8.5%）。構造的に2倍が組めない買い目なので、なくすには買い目の側を変えるしかない。

## 6. 限界

- 払戻の実測は**確定オッズ**、床の判定は**予測オッズ**。予測が高めに出た分だけ
  実際の払戻は2万円に届かないことがある（既存の「計画払戻÷実際」と同じ性質）。
- ROI は動かない。これは**最低額の底上げと傾斜**であって収支の改善ではない。
- 傾斜の強さは床が食う割合で決まる。`Σ` が小さいレースほどひらきが大きくなる
  （床が予算の `mult × Σ` しか使わないため）。
