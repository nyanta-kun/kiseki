# 賭け金の傾け（市場が過小評価している選手を含む目へ寄せる）— 事前登録 2026-10-28

> §1〜§6 は**測る前に**書いてコミットした。結果は §7 以降に追記し、ここは書き換えない。

## 1. 背景と狙い

`docs/type_lab/kesi_model_2026_10_28.md`: 朝の情報で最終市場の値付けの誤りを ±1〜2割見分けられる。
朝のオッズを出発点にすると、残るのは「当たる回数」ではなく「当たったときの配当」の側（最終オッズが伸びる選手）。
ユーザー（10/28）: 的中率が下がらず配当が増えれば回収率は上がる。

→ **買い目（組番）は本番のまま変えず、賭け金の配分だけを寄せる。** 当たる・当たらないは構造上変わらない。

## 2. 規則（固定）

- 出発点: 本番が実際に組んだ賭け金 `type_lab_picks.legs[].stake`（mode='live'・7車）
- 選手の係数 `g_i = p̂_am_i / m3_am_i`。`p̂_am` は `kesi/run.py` の主モデル（最終市場で学習・2024-07〜2025-12）の
  出発点を朝の m3 に差し替えた予測（`kesi/morning.py` と同じ）。`m3_am` は `wt_odds_snapshot` の `morning` 三連単から作る
- 目の係数 `edge_k = g_a · g_b · g_c`（三連複も同じ3車の積）
- 傾け: `w_k = stake_k × edge_k` を元の合計へ比例配分し、各目を **元の 0.5〜2.0 倍**に収める（はみ出しは端に止めて残りを再配分）。
  100 円単位・各目 100 円以上・合計は元と同じ。目は1つも落とさない
- 係数・上下限・λ（=1）は掃引しない

## 3. 漏れ止め

- 朝のオッズはその商品の**公開時刻より前**に取ったものだけを使う（未公開の行は 07:00 より前）。
  条件を満たさないレースは除き、件数を報告する
- 払戻は公式払戻（`wt_payoffs`）× 賭け金 / 100（同着も正しく扱う）

## 4. 窓

| 区分 | 期間 | 位置づけ |
|---|---|---|
| 歴史的検査 | 2026-06-08〜2026-10-27 | 朝のオッズがある全期間。選手単位の十分位はこの期間で一度見た（商品単位は未見）ので「確認」ではない |
| 前向き | 2026-10-29 から 4 週間（公開 約1,000件） | 本番の賭け金と並べて傾けた賭け金を毎日記録する（売るのは本番のまま） |

母集団は**公開した行**（`netkeirin_submissions` の published）。全 live 行は併記。

## 5. 判定

歴史的検査（前向きへ進める条件・すべて）:
1. 回収率の差（傾け − 本番）の点推定 ≥ **+2.0pt**
2. 上位5レースの払戻を除いた回収率の差 > 0
3. 表示的中率（払戻＞賭け金）の差 ≥ **−0.5pt**（生の的中数の差は 0 であることを確認する）

差の CI は開催日単位の対応ブートストラップ（2,000回）で併記。
前向き（本番化の条件）: 同じ 1〜3 を満たし、かつ上位5除きの差の CI 下限 > 0。
いずれもユーザーの基準（現状比で改善・最低 75%）を枠として報告する。

## 6. 併記（判定外）

- 目の `edge` 五分位ごとの、最終オッズでの 1目あたり回収率（edge が配当を並べているか）
- 賭け金を増やした目の 朝m3 → 最終m3 の動き（仕組みそのもの。無ければ edge は効いていない）
- ガミ件数・プラン別の差
- 最終市場を出発点にした上限版（2026-01〜05・朝のオッズ無し・本番では使えない）は行わない（台の賭け金が無いため）

## 7. 結果（2026-10-28 実施）— **不通過**（判定1・2）。前向きの記録は始めない

スクリプト `scripts/exp_type_lab/kesi/tilt.py`。商品 24,898 → 朝のオッズの取得が商品の生成より前・払戻あり 22,261
（公開 3,015件・60日）。選手の係数が欠けた 68 商品を除外。

| 母集団 | 件数 | 回収 本番 → 傾け | 差 [95%CI] | 上位5除き 差 | 表示的中 差 | ガミ |
|---|---|---|---|---|---|---|
| **公開（判定）** | 3,015 | 73.11 → 73.21% | +0.11pt [−0.47, +0.72] | +0.03pt | −0.07pt [−0.27, +0.10] | 19 → 21 |
| 全 live（併記） | 22,193 | 87.47 → 87.52% | +0.06pt [−0.29, +0.41] | +0.06pt | −0.03pt | 148 → 155 |

生の的中数は両方同じ（構造どおり）。**傾けで動いた賭け金は 1万円あたり平均 222円**しかない。
1つの商品の目は同じ軸の選手を共有するので、目どうしの edge の差が小さく、寄せる余地がほとんど無い。

### 7.1 探索（判定外）: 商品の間では差が出るか

商品ごとの賭け金加重 edge の五分位（本番の賭け金のまま）:

| 五分位 | 公開 的中 / 回収 | 全 live 的中 / 回収 |
|---|---|---|
| 最下位（edge 0.85） | 21.1% / 83.5% | 18.3% / 84.5% |
| 第2 | 23.2% / 84.0% | 19.0% / 86.3% |
| 第3 | 20.7% / 67.7% | 19.8% / 84.9% |
| 第4 | 22.6% / 75.8% | 19.4% / 96.8% |
| 最上位（edge 1.13） | **15.4% / 54.5%** | 17.4% / 84.8% |

**edge の高い商品ほど良い、は成り立たない**（公開では最上位が最も悪い）。目の edge 五分位の 1目あたり回収も
79.8 / 79.1 / 80.2 / 96.1 / 85.2 で単調ではない。選手の g 五分位の 朝m3 → 最終m3 は 最下位 0.332→0.350・最上位 0.342→0.306 と
予測どおり動いている（仕組みはある）が、商品の回収には現れない。

### 7.2 まとめ

選手単位で見えた「朝の市場が過小評価している選手は最終市場の 1.08 倍来る」は、今の商品の
賭け金の配分にも、商品の選び方にも、回収率として現れない。この方向（市場とのずれを朝の情報で拾う）は
ここで止める。
