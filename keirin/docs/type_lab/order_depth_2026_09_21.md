## 1. 実態 — 指摘は正しい。ただし「1点目」ではなかった

**広島2R（`E_hit`・20点・帯30倍）決着 `4-3-1`**。決着集合 {1,3,4} は
**3点目 `1-3-4`** で買っていた（1点目は `5-3-4` = {3,4,5} で別集合）。6順列の扱い:

| 並び | 予測オッズ | 帯30倍 | 確率順位 |
|---|--:|---|--:|
| `3-4-1` | 12.2 | **落ち** | **9位** |
| `3-1-4` | 20.3 | **落ち** | **11位** |
| `1-3-4` | 31.8 | 通過 | 13位 ← 買った |
| `1-4-3` | 79.4 | 通過 | 34位 |
| **`4-3-1`** | 57.5 | 通過 | **36位** ← 決着 |
| `4-1-3` | 135.7 | 通過 | 45位 |

20点は確率順の1〜20位。**決着はモデルが36位と見ていた目**なので、確率順に深さを
足しても届かない。帯30倍で落ちているのは確率9位・11位だが、決着はそのどちらでもない。

**大宮2R（`A_ana`・5点・帯なし）決着 `7-2-1`**。候補120点の確率順位で
**上位7点のうち6点が同じ集合 {1,2,7}**、5点目だけ別集合に逃げていた:

    1位 1-2-7 (79.2倍) ○ / 2位 2-7-1 (44.2) ○ / 3位 1-7-2 (52.9) ○ / 4位 7-1-2 (55.6) ○
    5位 7-1-3 (136.7) ○ ← ここだけ別集合 {1,3,7}
    6位 2-1-7 (92.3) ×  / **7位 7-2-1 (37.5倍) × ← 決着**

＝ ユーザーの言う「多点に広げる前に」の構造がそのまま出ている。

🔴🔴 **2件に共通する本質は深さではなく順序の並べ方**。決着 `7-2-1` は
**{1,2,7} の6順列中で最も人気（37.5倍）なのにモデル確率は最下位**。広島2Rも同じ向き
（36位）。既知の「モデル確率の人気-穴バイアス」（実測/モデル 0〜5倍 1.52 →
300倍+ 0.78）の症状。

## 2. 🔴 「減らして入れる」は否定

点数据え置きで深さを優先する腕（集合順に各集合 d 点／先頭集合を6順列すべて）:

| 腕 | 探索 Δ表示的中 | 確認 Δ表示的中 |
|---|---|---|
| ① 深さ d=2 | **−0.65** [−1.01,−0.30] | −0.47 [−1.01,+0.08] |
| ② 深さ d=3 | **−1.42** [−1.81,−1.03] | **−1.28** [−1.89,−0.68] |
| ③ 先頭集合を6順列すべて | **−1.40** [−1.76,−1.04] | **−1.56** [−2.13,−1.00] |
| ④ 集合内をオッズ順（深さは現行） | +0.04 [−0.22,+0.29] | −0.30 [−0.72,+0.12] |
| ⑤ d=2 + オッズ順 | **−0.71** | **−0.60** |
| ⑥ 無作為対照(d=2) | **−3.01** | **−2.70** |

機序（確認窓・③）: `P(的中) = P(集合) × P(順序)`

    集合的中 49.99 → 42.68%（−7.3pt）   集合を当てた回の順序一致 57.0 → 62.5%（+5.5pt）

＝ **順序を 5.5pt 買うために集合を 7.3pt 払う**。現行の配分（平均 8.6点 / 4.8集合）は
既に効率境界の近くにある。⑥に①が 2.4pt 勝つので**並びの選び方自体に情報はある**が、
「集合を広く取る」現行に勝てない。

⚠️ この結論は 2026-09-04 の「型E: 1集合1点に制限」（集合カバレッジ +21pt なのに
表示的中 −2.85/−4.84pt）の**反対側**で、同じトレードオフの両端を測ったことになる。

## 3. 🟢 「1点足す」は効く。足す1点はオッズ最安

投資は1万円固定・ゲートを割るなら足さない（件数不変）:

| 腕 | 点数 | 探索 Δ | 確認 Δ |
|---|--:|---|---|
| ⑦ 確率最上位を1点 | 9.03 | +0.59 [+0.48,+0.71] | +0.64 [+0.47,+0.82] |
| **⑨ オッズ最安を1点** | 9.03 | **+0.66** [+0.54,+0.79] | **+0.71** [+0.53,+0.89] |
| 　対照1点 6 seed | 9.21 | +0.20〜+0.33 | +0.23〜+0.37 |
| ⑩ 上位3集合に各1点 | 9.43 | +0.83 | +0.88 |
| 　**対照3点 6 seed** | **10.12** | **+0.64〜+0.75** | **+0.60〜+0.81** |

🔴 **⑩は採らない。** 同数(3点)の無作為対照とCIが大きく重なる（対照の方が点数は多い）
＝上積みは「3点足したこと」で説明でき、並び違いを選んだ効果として立証できない。
⑨は対照の2倍以上で、**効果の約 4/5 が「並び違いを選んだこと」**（`apply_osae` の
1/3〜1/2 より良い比率）。

⚠️ 帯を無視しても効果はほぼ増えない（確認窓 +0.64 → +0.67）＝**帯を外す理由が無い**。
E_hit の帯30倍に触らずに取れる。

（同じ集合の安い並びを足す）は、`A_ana` 全体では **ΔROI −11.9pt（探索窓で有意）**。
穴狙い商品は払戻の大きさが KPI なので、安い並びを足すと商品が壊れる。

## 4. 発端の2件が各腕で救えたか（本番経路で再現）

| 腕 | 広島2R `4-3-1` | 大宮2R `7-2-1` |
|---|---|---|
| ⓪ 現行 | × | × |
| ⑦ 1点足す(確率最上位) | × | × |
| **⑨ 1点足す(オッズ最安)** | × | **○ 93,869円** |
| ⑩ 上位3集合に各1点 | ○ 22,985円 | ○ 82,605円 |
| ② 深さ d=3 | ○ 28,732円 | × |

⑨が大宮2Rを救い、⑦が救えないのが**足す1点をオッズ最安にした根拠そのもの**
（{1,2,7} の確率最上位は `2-1-7`=6位、決着 `7-2-1` は7位＝最安）。
広島2Rは決着集合が先頭の目と別なので⑨では届かない。⑩なら届くが §3 のとおり
対照と区別できないため採らない。

⚠️ **初回のプローブは足す腕が素通りしていた**（`_add_perm` は検証台の `build()`
内のフックなのに、プローブが `build_with_gate_fallback` を直に呼んでいた）。
「発動しなかった」を「効果が無い」と誤読しかけた。腕を別経路で確かめるときは
**点数が実際に増えているかを必ず見る**こと。
