## 8. では残っているのは何か

外れの構造（確認窓・全商品比）は変わらない:

| | 割合 | 状態 |
|---|--:|---|
| 軸崩壊 | 41.38% | 軸2車前提の商品では構造的に取れない |
| 順序違い | 21.02% | `line_order` の λr1.9 が天井 +16.5pt の 2.6〜3.1% を取得済み。`order_ceiling` で「情報はあるが変換できない」と確定 |
| 相手外し | 13.16% | 点数問題に畳まれる（相手3車 42.3% → 4車 66.5% → 5車 83.3%） |

🟢 **的中率を実際に上げた唯一の形は「順序を捨てる（三連複）」**で、
これは既に出荷済み（`A_trio` / 9車 `F_line`）。本稿の3量では代替できない。
残る未測定は「7車の型C/E/F でも三連複ハイブリッドを出すか」で、
型E 単体は 表示的中 +4.50 / +3.22pt・払戻中央 −26%（`type_e_2026_09_01` §5②）。
