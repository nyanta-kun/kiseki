## 1. 記述 — 3着目が「軸と同ライン」から出る率

軸2車がそろった回（`both_in3` ∧ 3着目が特定できる）だけを見る。

    確認 51.49%（n=4,040） / 探索 52.67%（n=10,040）
    同ラインの相手が1車でも居るレースに限ると 57.32% / 57.75%

🔴 **この表は「その相手が何車居るか（＝機会）」に支配される。** 軸1ラインの人数で

これは母数が増えているだけで実力構造の話ではない。実力構造を見るには §2 のように
**相手1車ずつを p3 順位で層別**する必要がある。

**同ラインをさらに「軸との位置関係」で割る**と、平坦だった量が初めて割れる。

🔴 **一律のライン優先が間違っているのは「軸1車と同ライン・さらに後ろ」**。
ここは全順位で**別ラインより低い**（1〜12% ↔ 5〜30%）。
「同ラインだから上げる」と、来ない車をわざわざ持ち上げていることになる。

🟢 **一律のライン優先が足りていないのは「軸2車と同ライン・後ろ」**。
＝ 軸2車がそのラインの前2枚で、その後ろに残っている車。
両窓で **別ラインの約2倍**（p3順位1位で 60.9 / 60.6% ↔ 30.2 / 30.5%）。

### 実力差では割れない

同ライン候補を「軸との競走得点差」で割ると、p3順位1位で 51〜55%（確認）/
52〜55%（探索）とほぼ平坦（`resid` の (b) 表）。
レース側の条件（先頭がライン最強か・先頭の得点順位・ライン内レンジ・先頭−番手差）で
「同ライン/別ラインの比」を割っても **2.0〜3.0 の幅に収まり、両窓で順序が保たれるのは
「先頭と番手が拮抗（|差| < 1.5）しているほど比が大きい」だけ**（確認 2.48/2.70 ↔
2.27/2.43、探索 2.70/2.89 ↔ 2.39/2.27）。→ §4 で商品にすると負ける。
