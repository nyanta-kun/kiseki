# レースの分割 — 日単位KPI と、型分類が「狙うべきレース」を切り分けられているか（2026-09-10）

> **問い（ユーザー）**: 1日単位での的中率・回収率・高額的中を良くしたい。日ごとの
> ばらつきを抑えつつ、日次の的中率を上げられるか。
> **問い（設計側の読み替え・2026-09-10 ユーザー訂正）**: 単独ノブの採否ではなく、
> **現行設計（`race_shape` の 2×3 格子 → 型ごとに仕事の違う商品）の前提のどれを
> 支持し、どれを支持しないか**。外れは「その商品の仕事に対して失敗したか」で見る。

## 結論

| # | 現行設計の前提 | 実測はどう読めるか |
|---|---|---|
| 1 | （暗黙）**「今日は当たらない日だ」という日単位の状態がある** | 🔴 **支持しない。** 日ごとの的中数の散らばりは**二項分布そのもの**（分散比 phi=0.953 / 1.110・並べ替え検定 p=0.72 / 0.11）。日内・会場内の相関はゼロ（ICC −0.001 / +0.004）。**「日」は分析単位にならない**——外れの原因を日で探しても情報が無い |
| 2 | **型はレース単位の判断で足りる**（節・会場の状態を見ていない） | 🟢 **支持する。** 同じ開催・同じ会場の商品が同じ方向へ外れる成分は検出できない（会場×日 ICC −0.0086 / +0.0088・窓で符号が反転＝ノイズ）。**「1日の中で会場を散らす」に価値は無い** |
| 3 | **型が「軸2車がそろうか」を決め、商品が「そこから拾う」** | 🟢 **支持する。** 二軸そろい率は型で A 72.5% → F 40.1% と単調に下がり、商品の**変換効率**（表示的中÷二軸そろい）は A 51.8% → F 74.5% と**逆順に単調**。積＝表示的中は 37.6〜24.2% に圧縮される。**型ごとに商品を変える設計は意図どおり効いている** |
| 4 | 格子の**行**（力関係 `AXIS_SUM_FIRM=1.44`）が的中の層を作る | 🟢 **支持する。** 二軸そろいは axis 帯で 39%→75%（両窓・単調） |
| 5 | 格子の**列**（荒れ `arare`）が別の層を作る | 🟡 **半分だけ支持。** 力関係を固定すると `arare` は**二軸そろいを動かさない**（axis 五分位×2窓の10セルで符号が4/5反転）。動かすのは**配当の中央値**（s>=1 ÷ s<=-1 が ×1.11〜1.36・9/10セルでプラス）。🔴 ただし **100倍+ の割合は動かさない**（両窓で符号が割れる）＝**列は「中央配当のダイヤル」であって「看板のダイヤル」ではない** |
| 6 | 境界 1.44 が正しい位置 | 🟡 **「分離の最大点」ではない**（分離は 1.58 まで単調に増える）。1.44 は**堅い側が 55.6% になる均衡点**＝6セル全部に在庫を残す位置。日次KPI の観点では**在庫が最大になる点**として妥当（下記 #7） |
| 7 | （暗黙）**選別で日次の的中率を上げられる** | 🔴 **支持しない、というより向きが逆。** 日次の的中率の散らばりは `SD = sqrt(p(1-p)/n)` に支配されるので、**件数を減らすほど日ごとのばらつきは必ず増える**（上限なし 5.97/7.32pt → 上限0.25 で 8.44/10.71pt・半減日 1.6%→7.4% / 2.5%→10.1%・10万+のある日 25.5%→21.4% / 17.2%→11.8%）。**「日ごとのばらつきを抑える」と「厳選する」は同じ設計では両立しない** |
| 8 | 型が捉えていない次元は無い | 🟡 **落車・失格(DNF)だけは型の外**。4.80/4.87% のレースで起き、**型では分かれない**（符号が窓で反転）が、**決勝系では両窓とも高い**（4.53→5.68% / 4.49→6.10%）。バンク周長・屋内・会場は事前の分離を持たない |

## 2. 🔴 「今日は当たらない日」という状態は存在しない

日ごとの表示的中数 `k_d` の散らばりを、独立ベルヌーイなら 1 になる分散比

    phi = Σ_d (k_d − n_d·r̄)² / Σ_d n_d·r̄(1−r̄)

で測り、帰無分布は**並べ替え**で作った（分布の仮定を置かない）。

| 並べ替えの仕方 | 探索 2025 (13,912件/365日) | 確認 2026 (7,097件/238日) |
|---|---|---|
| A 全体シャッフル（構成も日内も壊す） | phi=**0.953** 帰無中央 0.998・97.5%点 1.148・**p=0.72** | phi=**1.110** 帰無中央 0.994・97.5%点 1.173・**p=0.11** |
| B プラン内シャッフル（構成を保つ） | phi=0.953 中央 1.005・97.5%点 1.163・p=0.76 | phi=1.110 中央 1.030・97.5%点 1.239・p=0.20 |
| C 日内シャッフル（会場×日で測る） | phi=0.955 中央 0.992・97.5%点 1.045・p=0.92 | phi=1.036 中央 1.013・97.5%点 1.073・p=0.22 |

**対の相関 ICC**: 同じ日 **−0.00121 / +0.00364** ／ 同じ日×会場 **−0.00857 / +0.00883**
（両方とも窓で符号が反転＝ノイズ）／ 同じプラン +0.02869 / +0.03115（これだけは本物）。

日次の実測と二項の予測:

| | 探索 | 確認 |
|---|---|---|
| 日次の表示的中率 中央 | 25.00% | 25.71% |
| IQR | 20.5〜29.0 | 20.6〜30.2 |
| **実測 SD** | **6.96pt** | **8.76pt** |
| 二項なら SD ≒（1日 38.1 / 29.8件） | **6.98pt** | **8.01pt** |
| 半減日（全体の半分未満） | 4.1% | 5.0% |
| 0件の日 | 0.0% | 0.0% |

### 読み方

- **探索窓は完全に二項**（むしろ僅かに過小分散）。**確認窓も有意でない**。
  仮に phi=1.110 が本物だとしても、超過分の SD は `sqrt(0.11)×8.03 ≒ 2.7pt` が上限。
- 🔴 **したがって「直近は外れが多い」は、ほぼ確実に二項のゆらぎ**。
  現行設計に「日を跨いで効く見落とし」があるという証拠は無い。
- 🔴 **外れの分析単位はレース／型／商品であって日ではない。**
  日単位の集計から設計の欠陥を読み取ろうとしても、二項ノイズしか見えない。
  （日ごとの構成の効きは `keirin-daily-hitrate-day-index-2026-09-02` と同じ結論。
   あちらは「構成期待値で割れ」、本稿は「割った残りは二項だけ」と足している。）

### 日次の的中率 SD の分解（第3章）

| | 探索 | 確認 |
|---|---|---|
| 実測 | 6.96pt | 8.76pt |
| 二項の寄与 | 6.99pt | 8.03pt |
| **構成（プラン構成）の寄与** | **1.58pt** | **2.20pt** |
| 二乗和の予測 | 7.17pt | 8.33pt |

＝ **その日に何を売ったかで日次の期待値は 1.6〜2.2pt 動くが、二項ノイズ 7〜8pt に
埋もれて見えない。** 商品構成を日ごとに均しても、日次のばらつきは事実上変わらない。

### 日次ROI も同じ

| | 実測 SD | 同数を無作為に引いた場合 |
|---|--:|---|
| 探索 | 34.8pt | 36.2pt [32.2, 40.9] |
| 確認 | 42.4pt | 39.6pt [33.7, 46.9] |

ROI 100% を超える日の割合も 23.8% ↔ 24.1%（探索）／29.0% ↔ 27.7%（確認）で区別できない。

## 3. 🟢 型判定が「レース単位の判断」でよい根拠

第2章の C（日内シャッフル）と会場×日の ICC が示すのは、
**同じ開催・同じ会場の商品が同じ方向へ外れる成分が検出できない**ということ。

- ＝ 節や会場に「その日だけの latent な状態」があって型判定がそれを取り逃している、
  という筋は**否定できないが証拠が無い**（両窓で符号が反転する大きさしか無い）。
- ＝ **「1日の中で会場を散らす」に価値は無い**（第8章cの腕⑦でも確認）。

### 見かけの傾き「1日に同じ会場から何件目か」は構成そのもの

| 会場内の順番 | 探索 表示的中 | 確認 表示的中 |
|---|--:|--:|
| 1件目 | 26.35% | 26.77% |
| 2件目 | 26.29% | 28.95% |
| 3件目 | 25.57% | 25.24% |
| 4件目 | 25.45% | 24.51% |
| 5件目 | 23.36% | 25.64% |
| 6件目以降 | 20.93% | 19.95% |

窓をまたぐ順位相関 Spearman **+0.77** と強いが、中身を見ると**決勝系の割合**が
1件目 16.3% → 6件目 **64.5%**（確認窓）で、主なプランも `C_hit`/`F_sign` へ移る。
**種別で割ると傾きは消える**（一般: 27.3/28.0/27.6/27.6/25.0/27.0%・探索）。
プランで割っても単調な傾きは無い。

🟢 ＝ **設計どおりの姿**。開催の後半に決勝系が来て、そこには
「表示的中を狙わない商品（`F_sign`・設計上 5%）」が置かれている。
**取りこぼしではなく、看板枠がそこに在るというだけ**
（`typef_racetype_2026_09_02.md` が既に扱った層）。

## 4. 🟢 型と商品の分業は成立している（変換効率）

設計は 2段になっている:

    ① 型   … 軸2車が3着以内に**そろうか**の水準を決める
    ② 商品 … そろった前提から**実際に拾う**（券種・点数・帯・配分）

したがって商品の仕事の達成度は **変換効率 = 表示的中率 ÷ 二軸そろい率** で見る。
母集団は**実際に売る商品**（日次上限まで当てたあと・板と突き合わせ）。

## 9. 限界

- **paper 行は 2026-08-26 まで**。`C_hit` の帯下1点差込（2026-09-08・表示的中 +5.28pt）も、
  高額枠 `{型}_big`（2026-09-06）も入っていない。第4章の `C_hit` は現行より弱い姿。
- **高額枠（5本/日）を再現していない**。`{型}_sign` は paper にあるが `{型}_big` は無い。
  第7章の 10万+/日 は現行の実力を過小評価している。
- **境界 `AXIS_SUM_FIRM` を商品ごと組み直して測っていない**（§5 の理由）。
  決着ベースの検証しかできていないので、「1.44 が商品として最適か」は未回答。
- **日次の検定は 365 / 238 日**。確認窓の phi=1.110 は有意でないが、
  **「過分散が無い」ことの証明ではない**（超過 SD の上限 2.7pt という言い方が正確）。
- 落車・失格の**事前予測**は試していない。§6 は事後ラベルの層別だけ。
  `axis_disadvantage_2026_09_01.md` §1 が「軸が不利」系の事前量を AUC 0.46〜0.53 と
  否定しているので、事故の事前予測も同じ壁に当たる公算が高いが、**測っていない**。
- **1レース1万円・1レース1商品**という netkeirin の制約は前提として動かしていない。
- 探索窓（2025）は予測オッズモデルの in-sample。オッズを使う数字は確認窓が本番相当。
