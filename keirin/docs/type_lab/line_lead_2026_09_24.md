## 2. 見つけたもの — 得点1位の居ないラインの「先頭→番手」は市場に低く見られている

ラインを**レースの選別ではなく買い目の形**に使うと、初めて平均の水準（約70%）を上回った。
全7車レース（払戻の欠けを DB で埋めた 42,332R）・1ライン＝先頭→番手→3着流しの5点・1点1000円:

|---|---|---|
| 得点1位の居ないラインの 先頭→番手→流し | **85.3% [79, 92]** | **87.5% [76, 99]** |
| 同じラインの 番手→先頭→流し（逆順） | 62.8% | 67.6% |

## 3. 起きやすさそのものが偏っている（回収率ではなく発生倍率で確認）

「回収率が高いのは人気薄を買っているから」ではないことを確かめた。**発生倍率＝実際の的中 ÷ Σ(0.75/オッズ)**
（1.00 なら市場の見込みどおり）。市場全体はオッズ帯別に 0.87〜1.10 で、**人気薄ほど当たりにくい**（300倍+ は 0.87）。

| 条件 | 発生倍率 探索 | 確認 |
|---|---|---|
| 逃げ先頭・得点1位でないライン・得点1位のラインが3車以下（以下 ②） | **1.19 [1.14, 1.24]** | **1.20 [1.13, 1.26]** |
| ②＋先頭の得点5位以下（③） | 1.32 | 1.15 [1.01, 1.30] |
| （逆）強いライン（得点合計 > 214） | 1.18 | 1.24 |

🔴 **偏りの本体は②の段階で既にある。** 弱いラインに絞っても起きやすさの偏りは強まらない。
③で回収率が上がるのは、当たったときの配当の大きさと少数の大当たりによる。

## 6. 採用した形（`src/type_lab.py::line_lead_legs`）

1. 7車・得点1位の居るラインが3車以下（単騎なら1車）
2. 得点1位の居ない2車以上のラインで、**先頭が「逃」・先頭の競走得点がレース内5位以下**
3. 買い目は **先頭→番手→3着**。3着から 第三のラインの番手以降・3着内率最下位・競走得点最下位を外す
4. **1レース1万円を均等に割る**（100円単位で切り捨て・`alloc="equal"`）。条件を満たすラインが
   複数あれば全部の目を合わせて1万円
5. 競走得点 0（未格付け）は欠けとして順位から外す（特徴キャッシュと同じ扱い）

本番関数を 2026-09 の出走表に当てた実測（`sep_verify_prod.py`）: 647R・的中17・**回収率 116.8%**・
最高 2,549,500円・100%超えの日 7/23・最大3本を除くと 52.3%。検証の集計と 645/647R で点数まで一致
（食い違いは未格付けの扱い2R）。

2026-09 の日別（1レース1万円・9/1〜9/23）: 23日中 **13日が的中0**。9/9 の1日（大垣7R 7-2-3・1,019.8倍）で
約331万円。**9/9 を除くと 68%**。型ラボ実売と置き換えた場合（9/1〜9/22）は
回収率 74.8% → 93.4%・収支 −304万 → −92万だが、差の大半は 9/9 で、**22日中15日は現行の方が良い**。
表示的中は 288 → 205 に減る。

## 7. 前向きの判定（事前登録）

- 期間: 2026-09-25 〜 2026-11-24（約2か月・約1,700R の見込み）
- 主指標: **発生倍率**（的中 ÷ Σ0.75/オッズ）が **1.10 以上**（ぶれが小さく件数が少なくても判定がつく）

## 8. 限界

- 条件（先頭の脚質・得点順位・3着の除外）は探索・確認の両窓を見ながら決めた（約40の区切りを見ている）
- 払戻は確定オッズ。的中率が4%前後なので、20〜30連敗は普通に起きる
- 7車だけ。9車・6車は測っていない
- 過去2年には1レースで約745万円の的中があり、この規模の1本で窓の回収率が数十pt動く

## 9. 販売（2026-09-24 ユーザー決定）

> 「1日上限5本、穴狙いとして、現在売っていないレースに対して追加する形とします」
> 「モーニングを除外として早い未販売の5レースとしてください」

実装: `scripts/netkeirin_submit_type_lab.py` の `_run_line_lead`（`run` の末尾）。

| 項目 | 規則 |
|---|---|
| 対象 | その日にどの商品も出していない・締切前・**モーニング開催でない**レースの `L_lead` 行 |
| 順序 | **発走の早い順** |
| 本数 | **1日5本**（朝・昼・夕の波をまたいで数える・`LINE_LEAD_SLOTS_PER_DAY`） |
| 回す位置 | 型ラボの本体（上限・高額枠・自信あり）が**全部終わった後**＝既存の商品は1件も減らない |
| アイコン・出どころ | 穴狙い（`ACT_TYPE_BY_PLAN`）・`origin='line_lead'` |
| 止め方 | `LINE_LEAD_SLOTS_PER_DAY = 0`、または入稿設定（`netkeirin_settings`）で `L_lead` を無効 |
| 1レース1商品 | `L_lead` は `SELLABLE_PLAN_KEYS` の外なので、出したレースは昼・夕の型ラボから「別ランクが取った」扱い（出さない・組み直さない） |

**モーニング開催を外した根拠**（過去2年・③・1レース1万円均等）:

| | 探索 | 確認 |
|---|---|---|
| モーニング | 313R・的中3.8%・**回収率 53.8%** | 257R・的中2.7%・**44.9%** |
| デイ | 92.9% | 134.0% |
| ナイター | 134.5% | 90.3% |
| ミッドナイト | 110.1% | 145.8% |

的中率はモーニングも同程度で、当たっても配当が小さい。「発走の早い順」に選ぶとモーニングを
優先して拾ってしまい、**2026-09 の試算（売っていないレースから早い順に5本）は 108R・的中0・回収率0%**
だった（無作為に5本なら中央 9.7%）。⚠️ モーニングの件数は少なく（両窓で 570R）、
モーニング除外は2026-09 の結果を見た後に決めた条件でもある。

⚠️ **2026-09 は「型ラボが売っていないレース」の方が成績が悪かった**（182R・回収率 53%・的中3本 ↔
売っていたレース 436R・143%）。偶然の範囲（CI [0, 137] / [31, 316]）だが、型ラボが売らない
レース＝軸信頼ゲートなどで落ちたレースなので、`L_lead` に不利な性質を持つ可能性は否定できない。
型ラボの実売が 2026-08-29 からしか無いため、長い窓では確かめられない。
実売の成績は検証ページの「実際に出した分」と、監査の見張り（`audit_watch.py` の「逃げ先頭ライン」層）で追う。
