# プラン別のレース厳選と WINTICKET「AI予想 的中率74%」の検証（2026-11-03〜04）

依頼:
- 「的中率が20%くらい。外しているレースの傾向を確認し、モデルごとにレースの厳選ができないか」
- 「（条件は）モデルごとに判断しているか」
- 「WINTICKET の AI 予想は的中率74%と謳っている。事実か。事実ならウェイト調整で的中率と回収率を上げられないか」

スクリプト: `keirin/scripts/exp_type_lab/per_plan_select/`（入力 CSV の置き場所は環境変数 `PER_PLAN_DIR`）。
入力は psql の `\copy` で書き出す（§5）。

## 1. 結論

1. **売った分の表示的中は 17.2%（9/30〜11/2・1,712件）。下げている主因は商品構成**:
   的中狙い（*_hit・A_trio・F_line）は 33件/日・23.7%・回収68%、高額狙い（L_lead・*_sign・A_ana）は 18件/日・5.0%・回収78%。
2. 条件別の外れ方を**プランごとに**測ると、228セル中 |z|≥2 は 11（偶然でも約10.5）。全体としては偶然と同程度だが、
   前後半で同じ向きに残った外れ条件が 3つある → **§3 で事前登録し、前向きに判定する**（今は止めない）。
3. プラン内で「見込みの的中確率が低いレースを除く」と的中は 0〜6pt 上がるが、回収差は全プランで CI が0を跨ぎ、
   当たったときの払戻が下がる＝**目標額を下げるのと同じ**。
4. WINTICKET の 74% は**2車複・印4車のボックス（6点）の素の的中率**。自前で再現すると 72.2%（4,724R）で数字としては事実。
   ただし **52% はガミ**で、払戻＞賭け金は 20.1%・回収 69.1%。同じ買い方は自社の順位でも市場の人気順でも 73〜74% になる
   ＝AI の精度ではなく「21通り中6通りを買う」買い方で決まる数字。
5. WINTICKET の印はすでに自社モデルの入力（`FEATURE_COLS_WT`）で、自社1位＝WT◎ が 85%。
   印の重みを足しても軸の3着内率・2車複の的中は ±0.5pt で変わらない → **ウェイト調整では的中も回収も上がらない**。

## 2. プラン別の条件と外れ方

各プランの「実際の的中 ÷ Σp」でプラン自身の平均の外し方を除き、条件ごとの実際÷見込みと z を前半（〜10/16）・後半で見た。
条件: 種別・開催日目・時間帯・級班・arare・場・軸の強さ（プラン内三分位）。

前後半とも同じ向き・|z|≥2 で残った外れ条件:

## 3. 事前登録（2026-11-04 固定・この日以降の行だけで判定する）

対象: `type_lab_picks` mode='live' の**全行**（売った分だけでは件数が足りない）。7車のみ。
各プランの境界は本書の値で固定し、動かさない。

| # | プラン | 条件（固定） | 判定に必要な件数 | 目安の到達 |
|---|---|---|---|---|
| P1 | A_trio | axis_sum ≤ 1.5604 | 150行 | 約4週 |
| P2 | F_sign | axis_sum ≥ 1.364 | 150行 | 約4週 |
| P3 | F_hit | race_type が `予選` または `特予選`（測った40行の内訳 35 / 5） | 100行 | 約12週 |

指標（各条件で）:
- 見込み = その行の Σp ×（同じ窓・同じプランで**条件の外**の行の 実際÷Σp）
- z = (実際 − 見込み) / sqrt(Σ 見込み×(1−見込み))
- 回収 = 条件内 と 条件外 の Σ払戻 / Σ賭け金

判定:
- **販売を止める**: z ≤ −2.0 **かつ** 条件内の回収 < 条件外の回収（点推定）
- **続ける**: z > −1.0
- その間: 件数を倍にして一度だけ判定し直す。それでも決まらなければ続ける

3つ同時に見るので、偶然で1つ以上が止まる確率は約7%（各 z ≤ −2.0 は片側2.3%）。
検出力の目安（今回の比が続いた場合の判定時点の z）: P1 −2.7・P2 −2.9・P3 −3.2。

止めるときの実装: `keirin/src/type_lab.py` の販売プラン選択（`sell_plans_for`）で、
該当プラン×条件を売らない（生成と採点は続ける＝A_hit と同じ扱い）。

## 4. WINTICKET「AI予想 的中率74%」

公式（[お知らせ](https://www.winticket.jp/keirin/column/n4ugtMn1hWayiVERBqWQnC)）:
2024/7/30〜8/6 の新旧比較で旧 58.9% → 新 74.0%。「すべての予想について2車複でボックス買いした場合」。
ボックスの車数・回収率は書かれていない。

`wt_entries.prediction_mark` は 1レース4車（1〜4＝◎○▲△）なので、4車ボックス＝6点と読んで再現した。
払戻は `wt_odds` の最終2車複オッズ×100円（2車複の公式払戻は DB に無い・同着だけずれる）。
期間 2026-09-01〜11-03・7車 4,724R。

| 買い方 | 素の的中 | 払戻＞賭け金 | ガミ | 回収 |
|---|---|---|---|---|
| WT 印 4車BOX（6点） | **72.2%** | 20.1% | 52.1% | 69.1% |
| WT 印 3車BOX（3点） | 54.8% | 20.9% | 33.9% | 72.1% |
| WT ◎-○ 1点 | 34.8% | 33.6% | 1.2% | 75.1% |
| 市場の人気順 4車BOX | 74.0% | 20.5% | 53.5% | 68.9% |

自社の順位（`type_lab_picks.p3_order`・発走前の live 値・4,108R）の 4車BOX は 73.0%・回収 70.5% で WT と同じ。
市場の人気順は最終オッズで並べているので、わずかに有利な比較になっている。

- 公式の数字は実態と合う（10月以降も 71.9%）。ただし**素の的中**で、netkeirin の表示的中（払戻＞賭け金）に直すと約20%。
  自社の売った分の 17.2%（的中狙いだけなら 23.7%）と同じ水準。
- 的中率は買う点数でほぼ決まる。2車複は7車で21通りなので、6点買えば素の的中が7割台になる。
  三連単（210通り）を3〜8点買う自社の商品とは直接比べられない。

### 4.1 ウェイト調整

WT 印はすでに自社モデルの入力になっている（`src/preprocessing/feature_wt.py` の `FEATURE_COLS_WT` に `prediction_mark`）。
順位に印を足して（score = 自社順位 + w × 印の順位）測った:

| w | 軸1が3着内（9月 / 10月〜） | 軸2車とも3着内 | 2車複1点 | 2車複4車BOX |
|---|---|---|---|---|
| 0（現行） | 80.0 / 78.7% | 54.4 / 53.7% | 36.0 / 33.5% | 73.4 / 72.4% |
| 1 | 79.8 / 78.4% | 54.3 / 53.6% | 36.0 / 33.7% | 73.3 / 72.5% |
| 100（印だけ） | 79.6 / 77.6% | 54.2 / 53.0% | 36.4 / 34.5% | 73.1 / 72.6% |

どの w でも ±1pt 以内で、前後半の向きもそろわない。自社1位＝WT◎ が 85% で、情報はすでに取り込み済み。

### 4.2 74% 型の商品を作った場合

2車複4車BOX は回収 69〜70%。現状の売った分（71%）を下回り、合格線 75% にも届かない（回収率の判定基準: ①現状比 ②75% ③100%）。
表示的中も約20%で、上がるのは「素の的中」の見え方だけ。採らない。
