# 単騎の読み — 何が効いて何が効かないか（2026-10-12）

> きっかけ: ユーザー提起「単騎はスコア・脚質でしか判別されていないのでは。
> 出身地・展開・選手ごとの動きを読む要素は無いか」。例は 2026-10-12 大宮7R
> （A級チャレンジ予選・7車・発走 10:35）。**発走前に書いた事前の読み**。

## 0. 結論

🟢 **単騎は「平均では」較正されている**（7車・ライン情報なしのレースを除いた 38,692 行: 実3着内 25.3% ↔ 予測 24.8%／1着 6.8% ↔ 6.2%）。
問題は単騎の**中身**で、両窓（探索 2024-25 / 確認 2026-01〜10-11）とも
同じ向きに残った読みが4つある。

| # | 読み | 効き方（3着内の残差 = 実際 − p3、pt） | 市場は織り込み済みか |
|---|---|---|---|
| A | **その選手が単騎のとき、過去にモデルをどれだけ上回った／下回ったか** | 下位2/5: −1.2〜−1.9 / −0.7〜−1.9 ↔ 上位1/5: **+2.5 / +2.7** | **No**（市場の残差も Q2 −4.8/−4.7 ↔ Q5 +0.3/−0.1・2025下期/2026） |
| B | **本命の強さ**（レース内 pw 最大） | pw<40%: +1.6 / +0.6〜1.5 ↔ pw≥50%: −0.6〜−0.9 / −1.0〜−1.6 | 市場も強い本命の下で単騎を過大（2025下期 −2.1 / 2026 −4.0） |
| C | **自力型（逃/両）の単騎は1着率が過小** | 1着 +1.6〜2.0 / +1.1〜2.5（z 最大5.5）。ライン先頭の自力型は ≈0 ＝単騎固有 | 未測（単勝オッズが無い） |
| D | **単騎が3〜4人いるレース** | 3人 −1.6 / −1.0、4人 −2.6 / −4.0 | — |

🔴 **効かなかった（モデルが既に持っている／窓で割れる）**:
コメントの分類（自力・前々・決めず・先手ライン・切れ目…）は ±1pt 程度で吸収済み。
地区の関係（同地区ラインがあるのに単騎／同地区の単騎が別にいる）は単独では z≈1。
前検日談話の作戦タグ（2025-12〜の10か月）は差が出ない（調子タグの傾きは既知の
`prereg_rider_condition_2026_10_01.md` と同じ）。過去の単騎時の B率・決まり手比は
確認窓で単調にならない。

⚠️ どれも**効果量は数pt**。p3 の順位をひっくり返すほどではなく、
「単騎の3着内率を数pt上下させる補正」の大きさ。採否は A/B（ΔAUC だけでなく
1位3着内・ROI）で決めること（2026-08-31 の `lp_*` は ΔAUC ゼロで不採用になっている）。

## 1. 方法

- 母集団: `wt_entries` × `wt_races`、ガールズ除外、**7車**、単騎＝`line_size==1`。
  **単騎5人以上のレース（＝ライン情報なし）を除外**（全員 `line_size=1` になるため。
  7人全員単騎の 2,611 行は実際には欠測）
- 予測: `pred_top3_pct` / `pred_win_pct`（pw はレース内で和1に正規化）。
  出どころを確認: 2025-01 を `lgbm_wt_eval_m2501`（vintage）で再採点すると相関 0.995、
  logloss は DB 0.5576 ↔ 再採点 0.5567 で **DB の方がわずかに悪い＝in-sample ではない**
- 窓: 探索 2024-01〜2025-12 / 確認 2026-01〜10-11（年をまたぐ）。両窓で符号一致のものだけ残した
- 地区: 府県の同ライン率をデータ（2023年）から学習して決めた（同地区ペアは約9割が同ライン・
  地区違いは約2割）。🔴 `scripts/exp_pair_correlation_broad_scan.py` の `REGION` は
  **東京・山梨・長野・福井の地区が実態と違う**（実測では東京/山梨/長野＝関東、福井＝近畿）
- A の作り方: 選手ごとに**発走日より前**の単騎レースで Σ(着内−p3) を取り、
  `/(n+8)` で縮小。単騎歴5走以上だけで五分位。ライン内での同じ残差とは相関 0.10〜0.11 で、
  ライン内残差の三分位それぞれの中でも勾配が残る（＝「強い選手」ではなく「単騎が得意か」）
- 市場: 三連複の最終オッズ（2025-07〜）から各車の3着内確率を作って同じ表を出した
- スクリプトはセッションの scratchpad（未コミット）。正式に回すなら `scripts/exp_tanki_read.py` に起こす

| 3 | 関根崇人 | 北日本（福島） | **単騎**・両・「前々。」 | 26.1 | **A: 2024年以降の単騎41走で3着内 7.3%（予測平均 17.8%）・1着0 → 縮小残差 −8.8pt＝最下位1/5**。2023年以降で見ると単騎48走 10.4% ↔ 人に付いた163走 42.9% の「付けば来るが単騎だと来ない」型 |

|---|---|---|---|---|---|

## 3. 範囲外の副産物

- **番手に回った自力型（逃/両）も1着率が過小**（+0.8〜2.3pt・両窓とも正・z 1.8〜5.4）。単騎とは別件
- 市場（三連複）は単騎全体を約2pt 過大に見ている（穴側の過大＝favorite-longshot bias と整合）

## 4. 大宮7R の結果（照合のみ・事前の読みは書き換えない）

確定: **1着 阿部(1・逃) → 2着 深井(4・差) → 3着 早川(5)**。地元 1-5-4 ラインの独占。

| 照合項目 | 結果 |
|---|---|
| 1. 関根・菅原の着順 | 菅原 4着 / 関根 5着（どちらも3着外） |
| 2. 単騎2車の3着内合計 | **0車**（同形の実績 0.32〜0.33 車・予測 0.38 車） |

## 5. A/B（事前登録・2026-10-12 走らせる前に固定）

ユーザー指示「進めて」→ 読み A（選手ごとの単騎残差）をモデルへ入れて増分があるかを測る。
スクリプト: `keirin/scripts/exp_tanki_residual_ab.py`（台は `exp_h2h_line_records_ab.py`
と同じ 4窓×5seed・同じ LightGBM 設定・同じ学習開始 2024-04-01）。

### アーム

| アーム | 中身 | 役割 |
|---|---|---|
| `base` | 現行 `FEATURE_COLS_WT` | 基準 |
| `+lp_lift` | 2026-08-31 に不採用になった「ライン位置別の過去成績」5列（`lp_*`。単騎の行では単騎時の3着内率 − 通算率） | **参照**。A がこれを上回らなければ「率の差を測り直しただけ」 |
| `+tanki_resid` | `tk_resid3` = 過去の単騎レースの Σ(3着内 − p3) / (n+8)、`tk_n` = その母数。全行に付ける（単騎かどうかはモデルが `is_isolated` で見る） | 本命 |
| `posthoc` | `base` の出力に、単騎の行だけ logit(p) + a + β·`tk_resid3`。a・β は**各窓の `test_from` より前**の単騎行（DB の `pred_top3_pct` を offset にしたロジスティック回帰）で推定 | 置き場所の比較（再学習なし） |

- p3 は DB の `pred_top3_pct`（2024-01〜・月次 vintage／朝バッチ＝発走前の値）。
  実験では 2026-10-12 時点のスナップショットを凍結して使う
- 時刻順は台と同じ `(race_date, start_at, race_key)` の排他累積。
  `--selftest` で未来非依存・自己排他・過去依存を検査する
- ⚠️ この特徴はモデルの出力を入力へ戻す構造なので、採用して再学習すると残差そのものが
  縮む（自己打ち消し）。本番で使うなら後段補正の方が性質に合う可能性がある

### 指標と採用基準（あとで動かさない）

単騎は指数1位にほぼならないので、台の既定「Δ1位3着内 ≥ +0.30pt」は使わない。

- **主（どちらも確認窓 w3・w4 の両方で満たす）**
  1. **単騎の被覆**: 7車で実際に3着内に来た単騎のうち、レース内 p3 上位3に入っていた率。
     Δ が両窓で正 かつ 平均 ≥ +0.30pt
  2. **単騎行の logloss**: Δ が両窓で負
- **従**: `+tanki_resid` の Δ被覆が `+lp_lift` の Δ被覆を両確認窓で上回る
- **ガード**: ΔAUC が base の seed 標準偏差の −1倍を下回らない／Δ1位3着内（確認窓平均）≥ −0.30pt
- `posthoc` には主とガードを同じように当てる

🔴 **きれいな確認窓は無い。** w1〜w4 もその後の期間も §0〜§3 の記述分析で見ている。
ここで言えるのは「モデル（または後段補正）がこの情報を追加で取り出せるか」まで。
合格しても採用の実ゲートは**前向き記録**（2026-10-13〜12-31）に置き、別途事前登録する。
