## 2. 級班の当落線（否定）

- 級班の入れ替えは **1月と7月**に集中（変化の 81%）
- どの時点の得点で決まるかを、月ごとの平均競走得点で降級／昇級を当てる AUC で逆算すると
  **境界の 7〜8 か月前が最大**（A2→A1 昇級 0.95〜0.98 / A1 降級 0.93〜0.96）。
  ＝「1月の級班は前年1〜6月、7月の級班は前年7〜12月の成績」と整合
- 昇降級の割合は期ごとにほぼ一定（降級 S1 22% / S2 31% / A1 23% / A2 21%、
  昇級 S2 10% / A1 25% / A2 23% / A3 26%）。これを境界の分位として、
  **期の途中までの平均得点**（前月末まで＝point-in-time）が境界の ±6% にいる選手を当落線とした
- 期末（期の5〜6か月目）の3着内の残差（実際 − p3、探索 2024 / 確認 2025-26）:
  降級線 −0.37 / −0.86pt、昇級線 −1.36 / −0.39pt、A3 下位6%（代謝線）−0.79 / +0.05pt。
  ±3% に絞っても、級班別に見ても符号が揃わない
- → **「昇降級がかかると期末に頑張る」は結果に現れていない**。A/B には進めない
