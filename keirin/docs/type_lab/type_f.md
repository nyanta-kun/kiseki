# 型F「大混戦」に何を売れるか（2026-08-27）

- 定義: `axis_sum`（vintage p3 上位2車の合計）< 1.44 ∧ 荒れ度 >= 1（`docs/race_type_design_2026_08_27.md`）
- 台: `/tmp/race_type_board.npz`（7車 36,427R・**vintage walk-forward の p3/pw**）
- 再現: `scripts/exp_type_lab/type_f.py`（`base` / `trio` / `tf` / `ci` / `fine` / `tband` /
  `sel` / `h2h` / `diag` / `cap` / `stab` / `all`）
- 窓: 探索 2024-07〜2025-12（8,237R / 549日）/ **確認 2026-01〜2026-08（3,069R / 216日）**
- ⚠️ 予測オッズモデル `odds_tf_n7` の train_end は 2025-12-31。**探索窓のオッズは in-sample**。
  採否は確認窓で判断し、探索窓は符号の一致確認にだけ使う。
- 🔴 **ROI で採否を決めない**（この層は ±2.5pt に収めるのに約15.6年）。ROI は参考表示。
- 件/日 の分母はその窓の**全日数**（549日 / 216日）。

## 1. 結論

### 採用候補 — **三連複「予測オッズ10倍以上の目だけを、モデル確率の高い順に4点」**

軸2車固定をやめる。ダッチング（∝1/予測オッズ・本番と同じ）。1レース10,000円。

| 窓 | 件/日 | 点数 | 的中% | ガミ% | **表示的中%** | 払戻中央 | 平均払戻中央 | 2倍+/日 | ROI% [95%CI] |
|---|---|---|---|---|---|---|---|---|---|
| 探索 | 15.00 | 4 | 17.80 | 0.07 | **17.79** | 39,740 | 42,204 | 2.50 | 76.7 [72.4, 80.5] |
| **確認** | **14.21** | 4 | 17.89 | **0.00** | **17.89** | **37,800** | **42,488** | **2.39** | 75.8 [69.1, 83.0] |

- **入稿ゲートを 100% 通る**（4点ダッチで最小予測オッズ >= 10倍 >> 2.0倍、
  平均想定払戻の中央 42,488円 >> 2万円）。型Fの全レースに毎回商品が出せる。
- **ガミ率 0.00%**（探索窓 0.07%）。4点ダッチで全点が10倍以上なので、最悪ケース
  （4点とも 10倍・均等 2,500円）でも払戻 25,000円＝投資の2.5倍。**構造的に割れない**。
- 既存の三連複と比べて**払戻が一段上**:

| 商品 | 表示的中 | 的中中央払戻 |
|---|---|---|
| 7B | 47.4% | 25,290円 |
| 7S | 33.3% | 14,670円 |
| 7C | 29.4% | 19,530円 |
| **本案（型F・確認窓）** | **17.9%** | **37,800円** |
| 7M1 | 15.2% | 23,410円 |

  ＝ 7M1 とほぼ同じ的中頻度で**払戻が 1.6倍**。
- 平均想定払戻の中央 **42,488円** は `docs/sales_kpi.md` の
  **3.0〜5.0万帯（三連複で最も売れる・pt/R 309）のど真ん中**。
- 四半期別（2024Q3〜2026Q3・9四半期）で 表示的中 15.8〜19.6% /
  払戻中央 37,440〜41,650円 と**振れない**（ROI は 64.2〜87.4%）。

### 🔴 ROI では選んでいない

確認窓の ROI 95%CI は [69.1, 83.0]。**壁（74.85%）を跨ぐ**。本案に限らず、
CI を出した 17 腕は**全て壁を跨ぐ**（最も上振れした `TF 100倍+ 5点` でも [67.5, 104.4]）。
本稿で測った腕は延べ 245 本あるが、点推定が 60〜88% の帯に収まりきっており
**型Fに ROI のエッジは無い**と読むべき。
採用理由は「同じ件数・同じガミ0%で、払戻帯を最も売れる位置へ動かせること」。

**同じ家族の中の別案**（払戻寄りに振りたい場合）: `三連複 15倍+ 5点`
＝ 14.21件/日・表示的中 16.26%・払戻中央 44,540円・平均想定払戻中央 49,538円・
2倍+ 2.25件/日・ガミ 0.20%・ROI 81.6%（探索 74.8%）。
平均想定払戻は 3.0〜5.0万帯の上端。**下限と点数はこの家族の中で自由に動かせる**
（3-3 の掃引表）ので、店頭 KPI をどこに置くかの選択問題。

### 見送りは推奨しない

型F全体で 15件/日 を捨てると、体系の投資額の約 1/3 が消える。
一方この型の腕は ROI 70〜85% で**体系全体の 78.7%（`keirin_current_system_accuracy_vintage_2026_08_23`）
と同じ水準**にあり、型Fが構造的に悪いという証拠は無い。「大混戦だから買えない」は成り立たない。

## 2. 🔴 中心的な発見 — 型Fでは軸2車固定が天井になる

**入稿ゲートを外した素の的中率**（`type_f.py diag`）:

| 窓 | 二軸そろい | 軸2車固定+相手5点(＝総流し) | 自由5点 | 自由10点 | 自由5点が全部軸2車入り | 自由5点の平均軸数 |
|---|---|---|---|---|---|---|
| 探索 | 38.65% | **38.65%** | 43.15% | 64.66% | 6.23% | 1.65/2 |
| 確認 | 39.62% | **39.62%** | 44.61% | 65.30% | 6.48% | 1.66/2 |

🔴 **軸2車固定の的中率は、定義上「二軸そろい率」そのもの**（相手を5点＝総流しまで
広げても 39.6% を1ミリも超えない）。型Fは二軸そろいが 39.6% しかないので、
**軸2車固定の商品はどう組んでも的中率 39.6% が上限**になる。
自由選択なら同じ5点で 44.6%（+5.0pt）、10点で 65.3%。

### 同じ帯・同じ点数の直接対決（`type_f.py h2h`）

| 帯 | 形 | 窓 | 件/日 | 表示的中% | 払戻中央 |
|---|---|---|---|---|---|
| 10倍+ 2点 | 軸2車固定 | 確 | 13.65 | 8.88 | 73,970 |
| 10倍+ 2点 | **自由** | 確 | **14.21** | **10.85** | 65,000 |
| 10倍+ 3点 | 軸2車固定 | 確 | 9.59 | 12.26 | 54,920 |
| 10倍+ 3点 | **自由** | 確 | **14.21** | **14.27** | 47,020 |
| 10倍+ 4点 | 軸2車固定 | 確 | **2.35** | 18.11 | 40,315 |
| 10倍+ 4点 | **自由** | 確 | **14.21** | 17.89 | 37,800 |
| 10倍+ 5点 | 軸2車固定 | 確 | **0.14** | 20.00 | 33,010 |
| 10倍+ 5点 | **自由** | 確 | **14.21** | 21.34 | 32,060 |

探索窓も同順（自由 9.60 / 14.06 / 17.80 / 21.27 ↔ 固定 8.65 / 11.25 / 15.78 / 14.89）。

🔴 **軸2車固定は帯と両立しない**。相手は5車しかなく、そのうち予測10倍以上の目が
4本そろうレースは 16%（5本そろうのは 1%）。**点数を増やすと母集団が消える**。
自由選択なら 35点から選べるので 100% 出せる。

採用案の買い目の中身（確認窓・12,276点）: **軸2車を 2車含む 42.8% / 1車 57.1% / 0車 0.1%**。
＝ 軸を捨てているのではなく、**「軸1車＋人気薄2車」の目を半分入れている**。

### 3-1. 三連複・軸2車固定 + 相手k点（§1）

- ROI は 61.0〜85.4% に散り、**どの並べ方も両窓で一貫して他を上回らない**。

  **10点以上になるとガミ率 13〜37%** で表示的中が 15〜19% に潰れる。

  同じ点数の「予測オッズ帯 × 確率上位」に**表示的中でも払戻中央でも負ける**。
- EV順（確率×予測オッズ）で三連単を並べるのは**両窓で崩れる**
  （探索 ROI 91.5% → 確認 58.5%・表示的中 0.72%）。型Fでは EV 上位＝超高オッズで、
  予測オッズの誤差がそのまま乗る。

## 4. 効かなかったもの（再検証不要）

### 4-1. 🔴 レース選別は1つも効かない（§11）

### 4-3. その他

- **軸2車を p3上位2 以外にする**（EV順・予測オッズ順で相手を並べる等）→ §1 のとおり
  的中⇄配当のダイヤルにしかならない。両窓で優る並べ方は無い。
- **相手を「全体5番手から」採る**（§18 の知見の移植）→ 型Fでは 5番手から k=3 が
  p3昇順 k=3 と同一集合になり、独立な効果を持たない。
- **三連複 30倍+ / 50倍+** → 確認窓で 60〜69%（探索窓 59〜77%）。点数を問わず壁を割る。
- **三連単 EV順** → 確認窓で崩壊。
- **1軸固定 + 2軸目2点 + 3着流し（強弱つき）** → 10点でガミ 13.0%・表示的中 17.86% /
  払戻中央 21,795円。同じ点数の `三連単 30倍+ 10点`（14.08% / 44,000円）に
  払戻で完敗し、`三連複 10倍+ 5点`（21.34% / 32,060円）に的中で負ける。中途半端。

## 5. 採用するときに要る判断（未解決）

1. **優先順位**。1レース1商品なので、14.2件/日 は既存を押しのける。
   設計書のカバー率では型Fの **47% は無商品**なので、純増は 6〜7件/日、
   残り 7〜8件/日 は 7S(16%) / 7M1(18%) / 7B(7%) / 7H1(7%) / 7T1・7T3(4%) から奪う。
   **7S・7M1 の母集団は型F以外にもあるので全滅はしない**が、どこに挿すかは別途決める。
2. **印不一致ゲートを持たない商品になる**（型Fの74%は印一致）。
   既存3ランクの設計思想と逆行するので、`docs/race_type_design_2026_08_27.md` §6-3 と同じく
   **既存のゲートは触らず別枠として足す**こと。
3. **予測オッズの下限ゲートを二重に持つことになる**。`MIN_POINT_ODDS=2.0` は
   自動的に満たされるが、`keirin_oddspred_gap_2026_08_26` の
   「下限は c(p25)×予測 で判定する」補正（PR#313）と整合させる必要がある。
   本稿の 10倍 は**素の予測オッズ**で切っている。
4. **本稿は入稿ゲート通過後の数字だが、実入稿の再現ではない**
   （看板穴埋め・持ち越し・取消は入っていない）。採用するなら
   `netkeirin_submissions` 側での並走が要る。
