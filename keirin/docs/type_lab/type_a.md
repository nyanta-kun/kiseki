## 2. 🔴 この型で効いている制約はオッズの安さではなく「入稿ゲートの不等式」

ダッチング（∝1/予測オッズ）だと **平均想定払戻 = 10,000 ÷ Σ(1/予測オッズ)**。
したがって入稿ゲート「平均想定払戻 > 2万円」は

> **Σ(1/予測オッズ) < 0.5**　＝　**買い目の市場シェアが 0.5 × 控除後0.75 = 37.5% 未満**

という制約とまったく同じもの。型A（鉄板）は上位数点に確率が集中しているので、
**近い相手をたくさん買うほどこの不等式に当たって入稿できない**。実測（§2・確認窓）:

| 相手5点（総流し） | **0.15** |
| 相手4点（3-6） | 0.22 |
| 相手1点（順位3） | 7.19 |
| 相手2点（5,6） | 11.18 |

**型Aの54%に商品が付いていない直接の原因はこれ**（7C/7S の「軸2車＋相手4〜5点」は
この型では構造的にゲートを通らない）。したがって型A用の商品は
**「点数を絞る」か「安い目を避ける」かのどちらかしか取れない**。

## 4. 実装の可否

- 三連複の任意集合・三連単の任意集合とも **1点=1行**で入稿できる
  （`BET_KIND_TRIFECTA_FORMATION` を1点ずつ送る `formation_bet_7t1` 経路が既にある。
  7T1/7T3 が使用中）。三連複を任意集合で出す場合も `BET_KIND_TRIO_AXIS2` を
  相手1車で送れば1点1行になる（`expand_bet` で検算可能）。
- ゲートは B<0.5 を守れば `MIN_MEAN_PAYOUT` を自動的に満たす。
  `MIN_POINT_ODDS=2.0` も型Aの三連単では確認窓で1件も落ちない。
- 🔴 **賭け金はダッチング必須。均等にすると §3.2 の壊れ方をする。**
- 🔴 **点数上限は5点。** 8点以上は100円量子化でダッチングが崩れ、
  「平均想定払戻」だけが名目上跳ねる（ゲート稼ぎにしかならない）。

## 5. 注意（採用するなら必ず読む）

1. 🔴 **実払戻は想定より下振れる。** 的中目の 確定オッズ/予測オッズ の中央は
   **三連単 0.871 / 三連複 0.932**（確認窓）。板全体では 1.020 なので偏りではなく
   **当たった目ほど市場が厚く買っていた**という勝者の呪い。
   ダッチ後の「実払戻/想定」中央は 三連単 0.729 / 三連複 0.871（差は量子化ぶん）。
   → 店頭に出す「平均想定払戻」は 3.4万でも、**実際に届くのは中央 2.85万**。
   `docs/sales_kpi.md` の帯に当てるときはこの差を織り込むこと
   （[[keirin_oddspred_gap_2026_08_26]] の「2万円ゲートは実質2.2万円」と同じ現象）。
2. 🔴 **ROI は全腕・全操作点で 65〜86% に収束していて採否の材料にならない。**
   確認窓の採用候補は 74.6% CI[68.8, 80.5]＝壁(74.85%)と区別できない。
3. ⚠️ **11.18件/日はゲート後の粗の数字**で、うち約46%は既存ランク（7C/7S/7B/7M1/7T1）が
   先に取るレースと重なる（型Aの54%が無商品、という前提から）。
   実際に増えるのは **6件/日前後**。優先順位の設計が別途要る。
4. ⚠️ 探索窓の予測オッズは in-sample。**探索窓の払戻・ゲート通過率は本番相当ではない**
   （確認窓とほぼ一致してはいる）。
5. ⚠️ 型Aは印一致が 87.5〜92.5% で、**モデルと公式印がそろっている鉄板**。
   ここに商品を置くと「AIらしさ」は薄い。売り文句は的中率と払戻の安定側に寄せること。
