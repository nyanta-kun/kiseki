# 「抜けている度合い」で買い方を決める — 体系化の検討（2026-08-31）

ユーザー観察（同日）: 和歌山1R・松阪4R・松阪7R・和歌山7R・松山1R の5レースについて、
「上位が抜けているなら絞る / 下位が離れているなら切る / 抜けがないなら見送る」という
考え方を体系立てて適用できないか。

## 結論（先に）

**体系化する物差しは1つある — 買い目の累積確率（以下 カバレッジ）。5例すべてがこれ1本で表せる。**
ただし **収支（ROI）を動かす道具ではない**。動くのは店頭KPI（表示的中 ⇄ 払戻・看板）だけで、
これは `SUMMARY.md` §2.6「型は edge を作らない。決めるのは帯とカバレッジだけ」と同じ壁。

| 問い | 答え |
|---|---|
| 5例に共通する量はあるか | **ある。カバレッジ**（買った点の確率の合計＝モデルが言う的中率） |
| 現行の6つの固定点数は何だったのか | **τ≈0.29 を買う規則の近似**。1本のダイヤルへ畳める |
| ご提示の「形」（3車ボックス・1着固定×2着2車・二軸流し）は使えるか | **使えない**。同じ点数の確率上位に**両窓とも負ける**（表示的中 −4.7〜−7.2pt） |
| 「下位を切る」は効くか | **効かない**。切るほど表示的中が下がる（両窓） |
| 「抜けがないレースを見送る」は効くか | **向きは本物**（無作為対照に両窓 20/20）。ただし**現行との差は CI が 0 を跨ぐ** |
| 新しく分かったこと | **モデルの確率は集中度で較正が崩れている**（下記4章）。`axis_sum` とは別の量 |

## 0. 検証台

  ＝**軸が強くても、確率が集中しないレースはモデルの言うほど当たらない**

## 7. 提案

1. **点数を τ 1本へ畳む**（挙動は現行と同等・定数6→1）。ダイヤルが1本になり見通しが良くなる。**収支は変わらない**
2. **τ を店頭KPIのダイヤルとして扱う**。看板寄せ（τ↓）/ 的中体験寄せ（τ↑）。8/31 夕の判断（看板より的中体験）は τ↑ に対応する
3. **「ばらけすぎ」の見送りは今は入れない**。向きは両窓一致だが現行との差の CI が 0 を跨ぐ。前向きに記録して確かめる価値はある
4. **形の明示・下位切りは採らない**（両窓で負ける）
5. 和歌山7R のような **帯フィルタが本命の目を捨てる**ケースは別問題。`C_hit`(20倍+) / `E_hit`(30倍+) は
   集中したレースでカバレッジを大きく落とす（18.0%）。ここは τ と帯の相互作用として別途測る余地がある

## 限界

- 探索は2025年のみ・確認は2026-01〜08-04（7か月）。**ROI の判定には窓が短い**（この層は ±2.5pt に約15.6年）
- 確認窓を判断に使っている（一度きりを消費）
- 9車・6車は未検証（板が7車）
- 5レースの例示は n=5 であって証拠ではない

# 追補: 提案4「帯フィルタが集中レースで本命の目を捨てている」の検証（2026-08-31）

## 結論

🔴 **帯フィルタは直すべきバグではなかった。** 2万円ゲート（ダッチでは Σ(1/予測オッズ) ≤ 0.5 と同値）の
下では安い目を買うと点数が消えるので、帯 L は「払戻を確保する」の**粗いが十分な代理**として機能している。
🟢 副産物として**モデル確率の人気-穴バイアス**（両窓一致・完全単調）が出た。これは商品の改善には
直結しないが、型C/E の表示的中の天井を説明する。

## 1. 診断 — 帯が実際に捨てているもの

| | C_hit（20倍+・12点） | E_hit（30倍+・14点） |
|---|---|---|
| 帯なし上位k点のカバレッジ | 49.84 / 49.07% | 42.70 / 41.57% |
| 帯ありのカバレッジ（現行） | 29.87 / 29.91% | 27.72 / 27.96% |
| 帯で捨てた目の確率合計 | **27.74 / 26.53%**（平均4.5〜4.7点） | 25.01 / 23.13%（平均6.8〜7.1点） |
| **決着が「捨てた目」だった率** | **38.77 / 35.69%** | 31.47 / 29.00% |
| 決着が「買った目」だった率 | 22.90 / 24.63% | 18.17 / 21.93% |
| 確率1位の目が帯に掛かる割合 | **91.7 / 91.3%** | 91.8 / 89.8% |

（探索 2025 / 確認 2026。以下同じ）
**捨てた側に決着が入る率の方が高い。** ただしこれは設計どおりで、安い目は Σ 予算を食い尽くす。

## 2. 帯を「正確な制約」へ置き換えても勝たない

ダッチでは全点の払戻が同じ（＝予算/Σ(1/O)）なので **「平均想定払戻 ≥ T」⟺「Σ(1/O) ≤ 予算/T」**。
帯 L はこの粗い代理なので、正確な制約に置き換えて計画払戻を揃えた（確認窓・C_hit）:

| 腕 | 件/日 | 点数 | 表示的中 | 払戻中央 | ROI |
|---|---|---|---|---|---|
| **現行 L=20 k=12** | 6.65 | 12.00 | **24.22%** | 31,250 | 83.2 |
| Σ制約 計画35千円 L=0 | 6.65 | 5.53 | 23.52% | 33,145 | 82.8 |
| Σ制約 計画30千円 L=0 | 6.65 | 6.15 | 25.61% | 29,000 | 79.5 |
| Σ制約 計画25千円 L=0 | 6.65 | 7.12 | 30.20% | 24,200 | 79.1 |

🔴 **件/日 は全腕で同一**（Σ制約はゲート通過を構造的に保証するので母集団が変わらない）。
🔴 計画払戻を揃えると **点数が 12 → 5.5 に半減**して表示的中は上がらない。
＝ **同じ的中⇄配当ダイヤルの言い換えにすぎない**（`type_c.md` §4.2 の L×k 掃引と同じ面）。

## 3. 集中度で条件づけると窓で符号が割れる

型C を集中度（τ=0.29 到達に要る点数）で層別し、現行 ↔ 帯なしΣ制約:

| 層 | 探索 表示的中 / ROI | 確認 表示的中 / ROI |
|---|---|---|
| 集中 k≤4 | 21.19 → 21.67% / 80.8 → **77.6** | 22.43 → **25.48%** / 83.1 → **86.2** |

| ばらけ k≥9 | 23.39 → 23.39% / 76.9 → 84.1 | 36.09 → 21.80% / 126.6 → 84.0（n=133・ノイズ） |

**集中層で確認窓は +3.05pt / ROI +3.1 だが探索窓は +0.48pt / ROI −3.2** ＝ 符号が割れる。

## 4. 三連複への振り替えは不可（和歌山7R の形）

型Cの集中レース（k≤4）を `A_trio` と同じ形（軸2車＋相手n点・三連複・ダッチ）で:
