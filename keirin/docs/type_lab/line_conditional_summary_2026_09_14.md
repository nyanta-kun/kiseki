> 依頼（ユーザー・2026-09-14）:
>
> > 組み合わせ・順位についてライン優先とし買い目を決めるのは、全体を見てその方が
> > 当たりやすいということだと思う。しかし**差が少ない場合はライン以外からの組み合わせ**と

## 0. 結論

🟢 **ユーザーの構造の読みは実測で正しい。** 編成・単騎・逃げ型の数・ライン内の立ち位置は
いずれも「3着目がどこから出るか」を大きく動かす（27%〜74%）。

🔴 **だが「強さ」側（総得点・平均・先頭の能力・ライン内の実力差・強弱の逆転）は
商品にならない。** 条件つきβは 4方向・延べ 40腕以上で、両窓とも現行を上回るものが
`A_hit` の1腕しか残らなかった。

🟢🔴 **唯一残ったのは「強さ」ではなく「位置」。** 相手が軸2車のどちら側にいるかで
3着目になる率が 15.9%〜60.9% に割れ、これは λ/μ が吸収していない。
商品になるのは `A_hit`（型A・三連単3点）だけで **Δ表示的中 +1.01 / +1.40pt**、

**+4.83 / +5.31pt**（順序オラクルは +15.30 / +15.69pt）。**相手側は順序側の 1/3。**

## 9. 追補（2026-09-14）— 3車ラインの3番手「1車離れている」は個人の力か、実力差か

> ユーザー質問: ラインの得点を平均と総和で見ているが、3車ラインで1車離れていると
> その1車だけ上位に来られないのではないか。これは**個人の力**か**実力差**か分かるか。

再現: `scripts/exp_type_lab/line_third_gap.py base|twoway|resid|resid2|pos`

### 9.1 現象は実在する（ライン内の**最後尾**であることが効く）

3着以内に入る率（1行=1車・確認 / 探索）:

| ライン規模 | 先頭 | 2番手 | 3番手 | 4番手 |
|---|--:|--:|--:|--:|
| 2車（n=11,768 / 28,165） | 41.65 / 40.14% | 34.40 / 34.79% | — | — |
| 3車（n=8,218 / 20,694） | 59.02 / 58.98 | **60.66 / 61.05** | **29.16 / 29.34** | — |
| 4車（n=755 / 1,986） | 70.99 / 73.77 | 71.66 / 70.69 | **50.20 / 50.00** | **14.70 / 12.84** |

🔴 **効いているのは「何番手か」ではなく「最後尾か」。**
3番手は 3車ラインだと 29%（最後尾）だが、4車ラインだと 50%（後ろに1車いる）。
🟢 3車・4車では**番手が先頭と同等以上**（60.66 ↔ 59.02 / 71.66 ↔ 70.99）。

### 9.2 答え: **個人の力**。実力差は個人の力を止めると消える

3車ラインの3番手を「個人の力（レース内の競走得点順位）」×「ライン内の落差
（先頭・番手の平均 − 3番手）」の3×3で割ったセル（3着以内率）:

確認窓 n=8,218:

    個人の力 \ 落差    落差 小        中        落差 大     行計
    強い(上位)      37.10%(2229) 36.98%(1252) 38.54%( 506)  37.25%
    中             22.64%( 371) 24.56%( 798) 26.12%( 781)  24.82%
    弱い(下位)      18.57%( 140) 20.81%( 692) 17.74%(1449)  18.72%
    列計            34.20%       29.29%       23.98%

| | 素の効き | 相手を止めたときの効き |
|---|--:|--:|
| **個人の力** | +18.53 / +20.04pt | **+18.50 / +20.95pt（まるごと残る）** |
| **ライン内の落差** | +10.22 / +9.46pt | **−1.36 / −2.83pt（消えて符号反転）** |

相関 r(個人の力順位, 落差) = **+0.448 / +0.456**。
＝ **落差が効いて見えるのは、落差の大きいラインの3番手はそもそも個人が弱いから。**
「平均と総和の関係」で見ていた部分は、この交絡をまたいで見ている。

### 9.3 🔴 ただしどちらもモデルに足せない

粗い p3 順位で層別すると残差があるように見える（3-4位の層で 力強 49.26% ↔ 力弱 39.52%）が、
**その2群は層内の p3 が揃っていない**（平均 p3 0.4948 ↔ 0.4217）。
p3 の**値**を十分位で揃えると:

    個人の力       Δ(強い半分 − 弱い半分) = −0.14 / −1.23pt
    ライン内の落差   Δ(落差小 − 落差大)      = −1.16 / −2.52pt

＝ **残差はゼロか、わずかに逆向き。** p3 は3番手の弱さも落差も既に読んでいる。
`rate_line_branch` §4（生の率は残差ゼロ）・本稿 §2（素の力量は抜き差しで −0.14/−0.21）と同じ。

### 9.4 では §3 の「位置」となぜ違うのか

**測っている量が違う。**

| | 本追補 9.2-9.3 | §3（①の採用候補） |
|---|---|---|
| 対象 | その車**自身**が3着以内に入るか | その車が**3着目**（軸2車以外の1車）になるか |
| 条件づけ | その車自身の p3 | **軸2車との位置関係** |
| 結果 | モデルが吸収済み（残差ゼロ） | **吸収されていない**（軸1のさらに後ろ 15.9% ↔ 別ライン 30.5%） |

🟢 **「その選手が強いか」はモデルが読み終えている。読み残しているのは
「軸2車から見てどこに居るか」という関係のほう。** `A_hit` の位置の段が効いたのはそちら。
