## 2. 🔴 先に押さえるべき構造（買い方の議論の前提）

### ① ダッチング × 平均払戻ゲートは「点数の上限」として効く

配分が ∝1/予測オッズ だと**全点の想定払戻が等しくなる**ので、平均払戻ゲート
（>2万円）は実質 `Σ(1/予測オッズ) < 0.5` になる。型Eの相手はだいたい 5〜10倍なので
**3点でほぼ半分が落ちる**。実測（確認窓の件/日）:

| ダッチ点数 | 1点 | 2点 | 3点 | 4点 | 5点 |
|---|---|---|---|---|---|
| 件/日（型E 全 4.38 のうち） | 4.27 | 3.69 | 2.72 | 1.81 | 1.39 |

**三連複でダッチを選ぶと、点数を増やすほど売る回数が減る。**

### ② 均等 k 点のガミ率は「確定オッズ < k 倍」そのもの

均等なら1点 10,000/k 円なので、払戻 > 投資 ⟺ 確定オッズ > k。
入稿ゲート①は**予測**オッズ >= 2.0 しか見ないので、守ってくれるのは k=2 まで。
実測（確認窓・p3順・均等）: 2点 ガミ0.9% / 3点 12.4% / 4点 23.1% / **5点 39.6%**。

→ 3点以上を均等でやるなら**買い目側に予測オッズ下限を置いて点数と揃える**こと
（実測: 3点均等 予測>=5倍 でガミ 2.0%）。

### ③ 三連複では「1軸固定 + 2軸目2点」は「軸2固定 + 相手k点」の言い換え

三連複は順不同なので、`{a1,b1,x}` と `{a1,b2,y}` は
「軸1 + 上位数車から2車」という**同じ集合族の別の切り取り方**にしかならない。
点数を揃えた直接対決（3点・確認窓・表示的中）:

| | 探索 | 確認 |
|---|---|---|
| 軸2固定 + 相手3点（ダッチ） | 28.09% | 28.57% |
| 1軸固定 + 2軸目2点（ダッチ） | 28.18% | 27.27% |
| 同（均等） | 27.74% | 26.88% |
| 軸2固定 + 相手3点（均等） | 26.94% | 27.26% |

**差は無い。** 2軸目の選び方を p3 / 同時確率 / ライン隣接 / pw に振っても同様
（§4 の表）。二軸そろいが 42% しかないことへの手当としては機能しない
（軸1 ∧ 2位or3位 は 60.8% まで上がるが、その分1点あたりの配当が落ちて相殺される）。

- 型Eの三連複はダッチだと平均想定 24,843円 ＝ **2〜3万帯（pt/R 171）に落ちる**。
  3.0〜5.0万帯（pt/R 309）へ持っていくには点数を減らすか下限を置く必要があり、
  そこまでやるなら pt/R が4倍高い三連単のほうが素直
