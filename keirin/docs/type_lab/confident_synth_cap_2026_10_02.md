# 「自信あり」の合成オッズに上限 3.5倍を置く（2026-10-02）

> 依頼（ユーザー）:
> 本日、「自信あり」フラグを久留米3Rとしていましたが、人気決着の上、外しています。
> 「自信あり」フラグは売れるフラグになり得ますが、あまりに人気決着となるものは
> あまり購入者の購入意欲をそそりません。**レースの合成オッズが 2.5〜3.5 程度で
> 的中率を期待できるところ**にするのが良いと思います。
>
> 🟢 **採用**: 候補 = 発走18時前 ∧ **2.5 <= 合成オッズ <= 3.5**（`CONFIDENT_MAX_SYNTH_ODDS` 新設）/
> 順位 = Σp 最大（変更なし）。正本 `src/confident_pick.py::type_lab_confident_score`。

## 1. 当日の1件（裏取り）

`20261002_83_03`（久留米3R）`A_hit`・Σp 0.335。

| | |
|---|---|
| 本命 7番の1着率 / 3着内率 | 73.1% / 93.5% |
| 買い目（予測オッズ） | 7-1-3 10.4 / 7-1-5 18.0 / 7-1-2 24.7 / 7-5-4 162.3 / 5-1-3 569.4 / 1-7-3 34.4 |
| 買い目の合成オッズ（本線） | **4.37倍** |
| 確定三連単の最人気 | 7-1-4 **2.8倍**（買っていない） |

`A_hit` は「どの目が当たっても5万円」のダッチなので、安い人気の目（7-1-4 など）を買わない。
本命が抜けたレースでは Σp が大きく出る一方、人気決着だと外れる。合成が 3.5 を超えるのは
この型が多い。

## 2. 実測（1日1件・本番関数）

母集団: `type_lab_picks` の採点済み行のうち、そのレースで売る商品（`sell_plans_for`・
`A_trio` は入稿ゲート相当で判定）かつ `TYPE_LAB_CONFIDENT_PLANS`・発走18時前。
合成・Σp は `confident_pick.synthetic_odds` / `legs_hit_probability`（上帯を除く）。
軸信頼ゲート・日次上限は再現していない（実際の選定とは一部の日で別レースになる）。
探索 = paper 2025 / 確認 = paper 2026-01〜08-26 / 実地 = live 2026-08-27〜10-01。

（表示的中＝払戻 > 投資）

**選定が変わる日だけを見ると:**

| | 変わる日 | 旧選定の当たり（合成中央） | 新選定の当たり |
|---|--:|--:|--:|
| 探索 | 11 / 365 | 1 / 11（3.90倍） | 4 / 11 |
| 確認 | 12 / 238 | 1 / 12（3.71倍） | 2 / 12 |
| 実地 | 2 / 36 | 2 / 2（3.68倍） | 0 / 2 |

- Σp 最大で選ばれる合成は中央 2.8倍前後なので、上限が効くのは **3〜5% の日だけ**
- 効く日の旧選定は探索・確認で 1割前後しか当たっておらず、上限は「Σp は大きいのに当たらない」
  1本を外す方向に働く。実地は 2日で逆向き（件数が少なく判定に使えない）
- 判定基準（①現状比 ②75% ③100%）: 探索・確認とも ①を満たし（+0.4〜+0.8pt・ROI +0.8〜+3.2pt）、
  ②は既存どおり満たす。差は小さく、**主眼は当日のような「人気決着で外れる1本」を避けること**
- 下限を 3.0 に上げる案（3.0〜3.5）は的中が下がる。2.5〜3.0 は的中が最も高いが、提示の幅が狭く
  依頼の「2.5〜3.5 程度」から外れるので採らない

スクリプト: `confident_synth_cap_2026_10_02/c1.py`（候補の抽出）・`c2.py`（腕の比較）。
