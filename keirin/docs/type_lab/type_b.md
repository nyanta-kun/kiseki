### なぜこの形か

1. 🟢 **三連複は制度的に死んでいる**。型Bの確定三連複は中央6.2倍で、軸2車流しを3点以上にすると
   平均想定払戻2万円ゲートに掛かる（k=3 で 0.62件/日・k=5 で 0.09件/日）。
   「二軸そろい 64.9%」を的中率に変換したくても**入稿できない**。
2. 🟢 **三連単はゲート対象外なので型Bを100%拾える**（6.06件/日）。
3. 🟢 **ダッチングが必須**。均等だとガミが 25〜40% へ跳ね、払戻中央が1.2〜1.6万円まで落ちる。
4. 🟢 **床（合成払戻）で的中率と配当を素直に交換できる**。30,000円は
   「払戻中央が現行の最良（7B 25,290円）を上回る」かつ「表示的中が 7M1 より上」を同時に満たす点。

### 数字を出せない・主張しないこと

- 🔴 **ROI は主張しない**（80.0% CI[71.7, 88.5]・壁の下）。四半期でも 68.9〜103.9% と振れる。
- 🔴 **売上（pt/R）は主張できない**。`docs/sales_kpi.md` §11.1 の「三連単 pt/R 808」は
  **平均想定払戻 328,211円の高配当枠（7T1/7H1）の実測**であって、想定平均3万円の三連単には前例が無い。
  §11.2.1 の帯別 pt/R（3.0〜5.0万=309）も**三連複のみ**の集計で、同節が「仮説であって
  設計目標にする前に商品を揃えて測り直すこと」と明記している。**この商品の売上は測ってからしか言えない。**
- 🔴 **看板（直近の的中）は作れない**。10万円+ の的中は確認窓 **0件/216日**。
