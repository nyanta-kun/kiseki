🔴 **さらに手前の事実**: 売る9プランのうち6つ（判定レースの 85〜88%）は
`prob_top` / `signboard` で **`shape.order` を一度も読まない**。
＝ **「軸」を別の車へ再指名しても買い目は1点も動かない**（実測で変わるのは 0.5〜0.9%）。
軸崩壊は「軸の選び方」の問題ではなく **p3 の並び全体の精度**の問題。

## 4. 残っている梃子

product 層（型判定・選別・買い方・配分・帯・点数）は閉じた。残るのは:

- **p3 / pw モデルそのもの**（`lgbm_wt_eval` / `lgbm_wt_win`）の精度。
  軸2車そろいは現在 **50.2 / 50.8%**。ここが1pt上がれば天井 +16pt のうち
  比例分が素直に効く（見送りと違い日次上限の影響を受けない）
- ⚠️ ただし `axis_bust_model` §で「レース単位の構造量を非線形に混ぜる」腕は
  `p_both` 比 +0.004〜0.007 で、**レース単位の後付け特徴では届かない**ことが分かっている。
  選手単位の入力（`FEATURE_COLS_WT` 70列）の側を増やす/直すほうが筋
