### 0.2 `race_shape()` が実際に見ているもの

`src/type_lab.py::race_shape` の `arare` は**5要素だけ**:

    +1 if 軸1のライン人数==2 else (-1 if >=4 else 0)      # ライン構成（規模のみ）
    + (-1 if 先頭の遅れ率 >= 11% else +1)                  # ラインの維持
    + (+2 if 先頭の脚質 == '追' else 0)
    + (開催日目 - 2)
    + (+1 if 番手の競走得点 > 先頭の競走得点 else 0)

**ライン構成そのもの（本数×人数の組）・印の散らばり・脚質の配置・軸2車の位置関係は
どこにも入っていない。** ここが本稿の探索余地。

### 0.3 軸の取り方と、買い目確率のライン依存

- 軸2車 = `shape.order[0..1]` ＝ **p3 の上位2車**。ライン情報を一切見ない。
- 買い目確率 `rank_7t3_blend_probs` は **同ライン隣接ボーナス `λ^[1-2着隣接] × μ^[2-3着隣接]`**
  （λ=2.0 / μ=1.5）を掛ける。`_line_next` は `line_pos[b] == line_pos[a]+1` の**一方向**。

### 0.4 ゲートは3段（`partner_select` §1 と同じ）

→ 組む → 入稿ゲート（平均想定払戻 > 20,000円 かつ 全点の予測オッズ >= 2.0倍）。

## 3. 予測力 — 本番確率へ足しても伸びない

目的 `both_in3`。学習は探索窓、評価は確認窓（OOS）。

| 腕 | AUC 探索（in-sample） | **AUC 確認（OOS）** |
|---|--:|--:|
| `axis_sum` 単体 | 0.6714 | 0.6627 |
| **`p_both` 単体（本番確率）** | 0.6870 | **0.6741** |
| `rp_sd` 単体（`axis_disadvantage` の唯一の生存量） | 0.5760 | 0.5731 |
| 盤面パターンのみ（LightGBM・28変数＋3カテゴリ） | 0.6913 | **0.6417** |
| `p_both` + 盤面パターン（LightGBM） | 0.7259 | **0.6725** |

🔴 **LightGBM では OOS が下がる**（0.6741 → 0.6725）。in-sample だけ +0.039 伸びるのは
純粋な過学習。分散を落とした形（`logit(p_both)` + 少数の指標のロジスティック）でも:

| 腕 | 探索 | 確認（OOS） |
|---|--:|--:|

| + `ax_same=False` | 0.6934 | 0.6763 |
| + 主要7個 | 0.6941 | 0.6769 |

＝ **最良でも +0.0030 AUC。** 記述の −3〜7pt は、本番確率の**較正のずれ**として
存在するが**順位付けをほとんど変えない**。

### 4.3 買い方の切り替え（9車 `F_line` を7車の別ライン群へ移植）— 無作為対照に負ける

### 4.4 配当の読み（看板）— 恒等式どおり動かない

`big100` の残差で最も強い `nl_top5>=4`（p3上位5車が4本以上のラインに散る）で

## 6. 限界

- **7車のみ**。9車・6車は測っていない（9車は `F_line` が既に別ラインの手当てを持つ）。
- 窓は **2024-07〜2026-08 の 26か月**。確認窓は 2026-01〜08 の 8か月で、
  ROI の ±2.5pt を判別するには約15.6年かかる層なので、**ROI は一切採否に使っていない**。
- `both_in3` / `order_top` / `set_top8` は**商品に依存しないレース単位の代理**。
  DESIGN 4.3 の5分類（②`read_axis` / ③`read_band` / ④a`legs_budget` / ④b`legs_model`）
  とは1対1ではない。特に③`read_band`（帯下決着）は本稿の代理では見えない。
- `p_both` は `rank_7t3_blend_probs` から作った**買い目確率由来**の量で、
  軸選定に使われている `p3` そのものではない。`axis_sum` 層別の結果も併記してある。
- 確認窓を判断に使っている（一度きりを消費した）。ただし**採用した腕はゼロ**なので、
  次に同じ台で別の腕を試すときは「確認窓は既に 2,600 本ぶん見られている」ことを
  前提に読むこと。
- 交差は**2変数まで**。3変数以上は n>=300 を満たすセルがほとんど残らないので測っていない。
- **`line_order_2026_09_10.md` の λr（順序の向き）を本番へ入れた後の世界では
  2.4 の残差は縮むはず**だが、λr は未実装なので測っていない。
