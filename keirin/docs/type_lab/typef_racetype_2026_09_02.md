> 発端（ユーザー）: 「決勝・特選が難易度が上がり F に寄る、結果当たりづらいは現状の
> モデルとして正しそうだが、F についても決勝・特選の F と下位レースの F では傾向や
> 狙い方が異なる可能性がある。この切り口で買い目を分け、F の的中率を上げ、
> **最終日の的中率向上**の戦略とできないか」
>
> 検証: `scripts/exp_type_lab/typef_racetype.py`（`desc` / `plans` / `lineup` / `marginal`）
> 台: `/tmp/race_type_board.npz`（7車 36,427R・vintage walk-forward の p3/pw）
> 窓: 探索 2024-07〜2025-12 / 確認 2026-01〜08。買い目は**本番の `build_legs` / `allocate`**

## 0. 結論

| 問い | 答え |

| では最終日が当たらない原因は | 🔴🔴 **看板枠 `F_sign` の置き場所**。2026-09-01 に入れた `SIGNBOARD_RACE_TYPES` が 決勝系・準決勝系・**特選** に掛かり、最終日はこの3種別が集中する |

## 1. 型F の中では、種別で「決着の傾向」はほとんど分かれない

| 決勝系 | 37.11 / **41.25**% | 10.14 / 10.09% | 63.7 / **52.4** | 32.9 / 31.2% | 1.287 / 1.292 | 0.190 / 0.183 |
| 特選・選抜系 | 37.20 / 38.80% | 11.38 / 11.42% | 60.7 / 61.5 | **35.8 / 36.0%** | 1.306 / 1.312 | 0.199 / 0.194 |

🟢 **入力側は両窓で一貫して分かれる**——決勝系のFは「Fの中でもさらに軸が弱く相手も割れている」

確認で最上位と符号が反転する**。軸崩壊率で両窓一貫するのは「準決勝系が低い」だけ。

## 3. 🔴🔴 最終日が当たらないのは「型F」ではなく「看板枠が最終日に集中する」から

ラインナップ全体を再現し、`SIGNBOARD_RACE_TYPES` だけを変えて開催日目別に見る
（**確認窓 2026-01〜08 / 216日 / 10,404R**。探索窓の値は括弧）:

| 案 | 件/日 | 全体 表示的中 | **最終日 表示的中** | 10万+/日 | ROI |
|---|---|---|---|---|---|
| 現行（決勝系+準決勝系+特選） | 35.35 (34.37) | 23.10% (22.79) | **19.14%** (18.67) | 0.306 (0.281) | 82.2 (76.8) |
| **特選を外す**（決勝系+準決勝系） | 34.70 (33.79) | **25.04%** (24.62) | **24.89%** (23.81) | 0.194 (0.179) | 82.7 (77.3) |
| 決勝系+特選（準決勝系を外す） | 34.91 (33.89) | 24.40% (24.10) | 19.14% (18.69) | 0.236 (0.206) | 82.1 (76.8) |
| 決勝系のみ | 34.27 (33.30) | 26.38% (25.98) | 24.89% (23.83) | 0.125 (0.104) | 82.5 (77.3) |
| 看板枠なし | 34.27 (34.27) | 26.61% (26.06) | 25.64% (24.08) | 0.106 (0.080) | 83.4 (76.4) |
| 型F 全部 | 36.88 (36.01) | 19.76% (18.85) | 14.74% (13.45) | 0.523 (0.530) | 82.1 (76.5) |

🟢 **向きも大きさも両窓で完全に一致する**（そもそも `F_sign` の表示的中が設計上5%なので、
これは発見ではなく**算数**——「5%の商品を何件並べるか」の会計恒等式）。

- **最終日を動かすのは `特選` だけ**（最終日に決勝は1R・準決勝は無い）。
  特選を外すと最終日 19.14 → 24.89%（**+5.8pt**・探索 +5.1pt）。
- **準決勝系を外すと動くのは2日目**（22.95 → 26.85% / 23.34 → 27.29%）。
- 代償は 10万+ が 0.306 → 0.194件/日（**−37%**・探索 −36%）。ROI は +0.5pt で実質不変。

### 🔴 「看板枠を別の種別へ移す」は効かない（無作為対照の役割）

同じ件数を 一般系/予選系 へ移す案は **窓で符号が反転する**:

| | 全体 表示的中 | 最終日 表示的中 | 10万+/日 |
|---|---|---|---|
| 現行 | 22.79 / 23.10% | 18.67 / 19.14% | 0.281 / 0.306 |
| 一般系へ移す | 22.68 / **23.71%** | **18.24** / **20.53%** | 0.259 / 0.292 |
| 一般系+予選系へ移す | **21.85** / 22.99% | **18.24** / **20.53%** | 0.330 / 0.324 |

確認窓だけ見ると「移すと良くなる」に見えるが、探索窓では悪くなる。
＝ **置き場所には情報が無い**（§2 の「F_sign はどの群でも同じ」と整合）。

## 4. 🟡 型F のゲート落ちを拾う（件数の話・的中率の話ではない）

`F_hit` は12点なので入稿ゲート（平均想定払戻 > 2万円 ＝ 平均予測オッズ > 24倍）に
**24% 落ちる**。落ちるのは買い目が人気側に寄ったレース＝本来いちばん当たる側。
そこを `帯15倍+ 12点`（＝ `C_hit` と同じ形）で拾うと:

| 型F 単体 | 件/日 | 表示的中 | ROI | 2倍+/日 |
|---|---|---|---|---|
| `F_hit` のみ（現行） | 9.61 / 9.14 | 27.55 / 28.27% | 71.6 / 73.2 | 1.47 / 1.48 |
| **`F_hit` → 落ちたら帯15倍12点** | **12.53 / 12.01** | 27.13 / 27.32% | 72.3 / 72.9 | **2.03 / 1.92** |

追加された分だけを見ると 表示的中 **25.75% [23.61, 27.89] / 24.32% [20.94, 27.69]**、
ROI 74.8 / 72.1%、払戻中央 25,110 / 22,540円。**体系の平均（22.8 / 23.1%）と同等以上**。

ラインナップ全体では **件/日 +1.6 (+4.5%) / +1.5 (+4.3%)** で
表示的中（22.79→22.90 / 23.10→23.16%）・ROI（76.8→76.6 / 82.2→82.0）・10万+（不変）は動かない。

🔴 **これは「Fの的中率が上がる」話ではない。** 在庫（売れるレース数）が 4%増えるだけで、
`docs/sales_kpi.md` の pt/日 に効く一方、表示的中は 0.1pt しか動かない。
ROI は追加分だけ見ると体系平均より低い（確認窓 72.1% ↔ 82.2%）ので、
量を取りに行く判断のときだけ入れること。

## 5. 実データでの裏づけ（2026-09-01 ↔ 09-02）

| 2026-09-01 | 51件 | 8件 | 準決勝5・決勝2・特選1（1的中） |

## 6. 🔴 採否の前に

1. **両窓とも既に使われている。** 確認窓 2026 は種別の分析で何度も開封済み
   （[[keirin_type_lab_race_filter_rejected_2026_08_27]] /
   `time_and_race_type_2026_08_29.md`）。上の数字は**探索であって独立な確認ではない**。
   ただし §3 は「5%の商品を何件並べるか」の算数なので、**向きは窓に依存しない**。
   不確かなのは 10万+ の件数の方。
2. **これは 2026-09-01 にユーザー判断で入れたばかりの取引の巻き戻し**
   （「型F はたまにでも大きく当たることが宣伝効果につながる」）。
   `SIGNBOARD_RACE_TYPES` から `特選 / 初特選 / 特秀` を外すだけの1行変更で戻せる。
3. **看板は「見られるレース」に置くほど宣伝効果が高いが、同時に「見られるレースで
   当たらない」ことになる。** 売上の84%は看板レースに集まる（CLAUDE.md）。
   これは測定では決まらない店頭KPIの判断。
