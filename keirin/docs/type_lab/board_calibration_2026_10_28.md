## 2. 仮説

組番確率を「PL 板の確率」と「予測オッズの含意確率」の合成で作り直し、準決勝で重みを分ければ、
(1) 組番確率の対数損失が下がり、(2) 同じ商品構造のまま商品が当たりやすい目を選ぶようになり
**表示的中率が上がる**。(3) 1日の上限枠を較正後の当たりやすさの順に使えば、さらに上がる。

## 3. モデル（固定）

各レース（7車・210目）で

    q_k  = (1/PO_k) / Σ_j (1/PO_j)                    # 予測オッズの含意確率（レース内で和1）
    p_k  = rank_7t3_blend_probs(...)                  # 本番の PL 板（ライン加点込み）
    p*_k ∝ exp( a_g · log p_k + b_g · log q_k )       # レース内で和1に正規化

- `g` = 準決勝系（`RTYPE` に「準決勝」を含む＝準決勝・チャレンジ準決勝）/ それ以外
- 推定: 勝ち目の条件付きロジット（210 目のソフトマックス）の最尤。下限 `log` は 1e-9 で切る
- M0 = 本番の p（基準）/ M1 = `g` で分けない (a, b) / **M2 = `g` 別の (a, b)（本命）**
- 三連複の確率は p* を本番と同じ `_fold_to_trio` で畳む。並べ替え用の `order_probs` は**変えない**

## 6. 指標と判定（確認窓 2026 で）

指標: 表示的中率（払戻＞賭け金）/ 回収率 / 上位5レースの払戻を除いた回収率 /
4万+/日・10万+/日 / 件/日。差は `current` との**開催日単位の対応ブートストラップ**（2,000回・95%）。

前向き（paper）へ進める条件（すべて満たす）:

1. **較正**: 勝ち目の対数損失が M2 < M0 で、差の CI（レース単位ブートストラップ）が 0 を跨がない
2. **的中**: `C2P` の表示的中率 − `current` ≥ **+2.0pt** かつ CI 下限 > 0
3. **回収**: `C2P` の回収率（上位5除き）の点推定 ≥ `current` の同じ値、かつ回収率 ≥ 75%

どれかを満たさなければ不採用として記録する。C2P が落ちて C2 が満たす場合は C2 を候補にする
（優先順の寄与と較正の寄与を分けて書く）。係数・群分け・閾値の掃引はしない。
10万+/日 の減少は判定に入れないが必ず並べて書く（的中と高額は同じダイヤルの両端）。
