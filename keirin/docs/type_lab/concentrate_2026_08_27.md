# 競合の高額的中を型ラボの買い方に取り込めるか（2026-08-27）

`docs/rival_hot_highpay_2026_08_27.md`（好調予想家10人・8月15,194商品・高額的中30件の分解）
の「取り込めるもの」を、型ラボの実データで測った。
再現: `keirin/scripts/exp_type_lab/{rival_gap,concentrate}.py`

## 出発点（競合側の実測）

| | 競合10人 | 自社（8/07〜08/26 実売795商品） |
|---|---|---|
| 的中倍率 中央 / 最大 | **228倍 / 1,141倍** | **5.6倍 / 62.4倍** |
| 10万円以上 | 0.33〜1.5件/日 | **0.10件/日** |
| 1商品の総投資 | 10,000円（ほぼ固定） | 同じ |
| 点数 中央 | 8点 | 三連複枠は 4〜5点 |

高額的中30件の **9件は 1〜2点に 3,000〜10,000円**を置いた集中型
（96万円＝5,000円×192倍の2点・39万円＝10,000円×39倍の1点）。
**「高額的中＝万車券」ではなく、1点の厚みで作っている。**

## 🔴 最初に間違えた計算

「点数を半分にすれば払戻は倍」は正しいが、**点数を減らせば的中率も落ちる**。
的中率を据え置いたまま倍率だけ上げる計算をすると、C_hit の10万+率が
0.57% → 23.41% という**あり得ない数字**が出る。

正しくは、保存してある `legs`（`prob` / `pred_odds` つき）と `win_combo` から
**上位k点だけ買っていたら当たったか**を1件ずつ判定して再現する。

## 結果: 既定6プラン合計（確認窓 2026-05-01〜08-26 / 118日 / 6,025R）

投資は**どの案も 51万円/日で同じ**（1レース1万円は変えない）。

| 買い方 | 件/日 | 表示的中 | 倍率中央 | **10万+/日** | ROI |
|---|---|---|---|---|---|
| **実際（3〜14点）** | 51.1 | **24.48%** | 15.2 | **0.102** | 80.1% |
| 上位1点（確率順） | 51.1 | 8.05% | 4.9 | 1.017 | 70.2% |
| 上位2点（確率順） | 51.1 | 11.57% | 6.4 | 0.992 | 72.0% |
| 上位1点（EV順） | 51.1 | 2.22% | 17.5 | 0.805 | 77.3% |
| **上位2点（EV順）** | 51.1 | **5.06%** | 13.9 | **0.932** | 82.0% |
| 上位3点（EV順） | 51.1 | 8.45% | 7.6 | 1.008 | 80.2% |

🟢 **10万円超が 0.102 → 0.93件/日（9.1倍）。競合上位（0.33〜1.5件/日）と同水準に届く。**
🔴 **代償は表示的中 24.48% → 5.06%。** ROI は 80.1 ↔ 82.0% で**動いていない**
（控除率の壁の周辺・CI は重なる）。

＝ 競合分析の主張「**差は予測精度ではなく買い方（点数）**」を自社データが再現した。

## EV順と確率順の使い分け（既存の結論と矛盾しない）

- 集中（1〜3点）では **EV順が確率順に勝つ**（10万+ を保ったまま ROI +6〜10pt）
- これは `trifecta_playbook.md` §2.3「100〜300倍帯は EV順・30〜50倍帯は確率順」と同じ向き
- ⚠️ `ev_axis_rank_2026_08_27.md` の「EV は三連単で逆行」と混同しないこと。
  あちらは**どのレースを買うか**（レース間の EV 比較）で逆行。
  こちらは**1レースの中でどの目を残すか**（レース内の目の並べ替え）。**別の使い方**

## 判定

| 競合から来た案 | 判定 |
|---|---|
| **点数を絞って1点を厚くする（集中型）** | 🟢 **採用候補。自社に無い形で、10万+ を作る唯一の手段**。三連複枠は 668商品で最大 79,500円＝構造的に作れない |
| 三連単枠の件数を増やす | 🟢 別途（`trifecta_playbook.md` §8）。台は `予選/準決勝/特一般 × 50倍+ × 10点` |
| 1行=1点で金額を点ごとに変える | 🟢 実装済み（`BetLeg` 分割・7H1 が実施中） |
| レース選別 | ❌ **競合はしていない**（45〜74件/日＝ほぼ全レース）。自社の「絞る」方向とは逆 |
| ROI（収益性） | ❌ 10人合計 72.4% ＝壁の下。取り込むものが無い |
| 二車複 | 🟡 モデル・採点・入稿の3箇所に新設が要る。作る前に walk-forward で壁を確認 |

## 採用する場合に決めること

1. **表示的中 5% の商品を店頭にどう置くか。** netkeirin の主要ソートは表示的中率で、
   単独で出すと売れない。**当てる商品との並走**が前提（`docs/sales_kpi.md`）
2. **10万+ が2日に1回出ると「直近の的中」枠を占有する**（当たるたび上書き）。
   ベース商品の小的中が見えなくなる（`trifecta_playbook.md` §8 の未解決論点）
3. 🔴 **窓が足りない。** 確認窓は今日だけで複数回使っており、48腕の多重比較も入っている。
   採用の前に **2024〜2025 の paper を生成して窓を増やす**か、前向きの実地で確かめる
