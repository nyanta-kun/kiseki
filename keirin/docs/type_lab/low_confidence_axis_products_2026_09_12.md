## 0. 先に訂正 — ブリーフの前提1点が実装と違う

### 0.1 🔴 型ラボの「軸1」は **p3（3着内率）最上位**で、pw（勝率）最上位ではない

`race_shape` は `order = sorted(top3_probs, key=-p3)`。したがって

- **「軸1を p3最上位へ差し替える」は定義上 no-op**（すでにそう）。
- 旧ランク 7S の `rank_7s_select_axis`（軸1=pw最上位）と**別物**。混同しないこと。

差し替え先として意味があるのは **pw最上位 / ◎ / 予測オッズ最安（人気）/ 軸2** の4つ。
実測の一致率（両窓ほぼ同じ）:

| | a1==pw1 | a1==予測オッズ最安 | a1==◎ | pw1==予測オッズ最安 |
|---|--:|--:|--:|--:|
| 探索 | 89.5% | 89.6% | 89.7% | 96.6% |
| 確認 | 90.0% | 90.1% | 90.3% | 97.7% |

＝ **差し替えが発火しうるのは 10% のレースだけ**で、そこでは pw1 / 人気 / ◎ の3つが
ほぼ同じ車を指す（互いに 96〜98% 一致）。**別々の腕として測る意味はほぼ無い。**

### 0.2 🔴🔴 売っている商品の 85〜88% は軸を読まない

`build_legs` の分岐と `order` の使用:

| `structure` | プラン | `shape.order` を使うか |
|---|---|---|
| `prob_top` | `A_hit` `B_hit` `C_hit` `E_hit` `F_hit` | **使わない**（確率降順に積むだけ） |
| `signboard`（bust なし） | `F_sign` `{B,C,D}_sign` | **使わない** |
| `signboard`（bust=True） | `{B,C,D}_big` | `order[0]` を**除外**するのに使う |
| `bust_top` | `A_ana` | `order[0]` を**除外**するのに使う |
| `axis2_flow` / `axis2_drop_fav` | `A_trio` `D_hit` | 軸2車の**集合**として使う（順序は無意味） |
| `axis1_second2` | `A_pay`（売らない）/ 9車 `F_pay` | 1着固定に使う |
| `line_axis2_flow` | 9車 `F_line` | `line_pair` を使う（`order` ではない） |

**実測（軸の再指名で買い目が変わったレースの割合・`04_noop_gate.py`）:**

| plan | `sw_a2` | `sw_pw` | `sw_mkt` | `sw_hon` |
|---|--:|--:|--:|--:|
| `A_ana` | **100.00 / 100.00%** | 11.0 / 16.0% | 11.7 / 15.3% | 11.7 / 16.0% |
| `A_trio` | 0.00 | 0.5 / 0.9% | 0.4 / 0.6% | 0.4 / 0.9% |
| `D_hit` | 0.00 | 2.9 / 2.3% | 3.2 / 1.8% | 3.0 / 2.2% |
| `A_hit` `B_hit` `C_hit` `E_hit` `F_hit` `F_sign` | **0.00** | **0.00** | **0.00** | **0.00** |
| **全体** | 3.30 / 4.39% | **0.53 / 0.89%** | 0.56 / 0.82% | 0.55 / 0.88% |

（`sw_a2` が `A_ana` で 100% なのは「除外する車」が入れ替わるため。三連複では
`a1↔a2` の入れ替えは frozenset なので恒等。）

→ **ブリーフの腕②を素直に「軸の再指名」として実装すると、測るものが存在しない。**
そこで②は **「1着に置く車をプールで制限する」**形に読み替えて測った（下記 §2）。
これは `bust`（③）と同じ機構（`pred_odds` 辞書を絞る）で表現でき、**①→②→③ が
1本の連続したはしご**になる。

## 6. なぜ ② が効かないのか（機序）

1. **🔴🔴 軸1は買い目を作っていない。** 売る商品の 85〜88%（`prob_top`/`signboard`）は
   `shape.order` を読まず、`rank_7t3_blend_probs` の確率降順に積む。その確率は
   **pw（1着率）を1着側に、p3 を3着内側に使って作られている**ので、
   「1着に据える車を pw / 人気で選び直す」操作は**既に確率順の中に入っている**。
   実際 `hd_pw` と `hd_mkt` は表示的中・10万+率とも**互いに 0.01pt 差**
   （25.25 ↔ 25.25 探索 / 23.91 ↔ 23.93 確認）＝ 同じ操作。

2. **🔴 「軸2の方が来る層」は存在しない。** どの層でも 1着=軸1 > 1着=軸2
   （唯一の逆転は `pw_gap12_lo25` の確認窓で、探索窓では逆＝符号反転）。
   差し替えは**必ず期待勝率を下げる**。

3. **🔴 市場は「軸1が薄い」を正しく値付けしている。** §1.3 の 10pt 分離は本物だが、
   その情報は**予測オッズ（＝`odds_tf_n7` が写している市場）に既に入っている**。
   `dis` 層で人気側へ寄せる `hd_mkt` が確認窓で全層マイナスになるのがその証拠——
   人気側の目は安く、同じ計画払戻に詰めるとカバレッジが落ちる。

4. **🔴 1着を1車に固定すると的中上限が 21〜30% に落ちる**（§2.2）。
   `hd_a2` の的中はこの上限の中でしか動かない。一方 `bust` は
   **残り120通りから確率上位を選び直す**操作なので点数が増える（T=15万で 2.8→10.9点）。
   **同じ「軸1を尊重しない」でも、`hd_a2` は集合を狭め `bust` は広げる。**

5. **🔴 計画払戻を揃えると 10万+率は形で決まらない**（3.41〜4.00%）。
   `highpay_slots_2026_09_06.md` の恒等式 `P(払戻≥X) = 帯ROI × 予算/X` のとおり。
   プールが動かすのは ROI だけで、そこは次項のとおり裾依存。

6. **🔴🔴 低信頼層で `bust` が見せる ROI +10〜+15pt は「裾」でしかない。**
   払戻に上限を掛けて測り直すと消える（`09_roi_trim.py`）:

   | 層 / 窓 | 上限なし | ≤30万 | **≤10万** | ≤5万 |

   ＝ **ROI 優位は「10万円超をたまに当てる」という一撃商品の性質そのもの**で、

## 9. 限界

1. **確認窓を消費した。** §3.2 の `bust` × `axis_sum_lo25` は
   `mark_second_third_bets_2026_09_12.md` §5.4 と**同じ測定の独立再現**（+1.44/+1.44 が一致）で
   新規消費ではないが、`pw_gap12_lo25` / `p3_gap12_lo25` / `pw_max_lo25` / `dis` の
   4層 × 6プール × 4 T は本稿で初めて確認窓に当てた。
2. **多重比較が大きい**（層6 × プール6 × T4 × 2窓 ≒ 288セル）。
   CI 下限が +0.04〜+0.31pt の腕（§3.5）は採用に足りない。
3. **日次上限の再現が粗い**（本台は7車のみ・`cup_grade` の免除条件が本番と一致しない）。
   高額枠の母集団が 1.2〜1.4件/日しか出ず、本番の 4.4本/日と合わない。
   **高額枠の中だけを差し替える案は、この台では判定不能。**
4. **`apply_line_swap` は掛かっていない**（台が `RaceShape` を直接組んで `lines` を
   持つが、`build_race_type_board` 由来の `A_line_pos` を int で渡しており型は一致する。
   ただし `line_legs` の効果は `DESIGN.md` 2.2 の注記どおり +1.9〜2.3pt ぶん過小）。
5. **`hd_*` は三連複プラン（`A_trio` / `D_hit`）では定義できない**ので、
   その 8〜10% のレースは対比較から落ちている（`bust` は三連複でも定義でき、含まれる）。
6. **「人気」は実オッズではなく予測オッズ（`odds_tf_n7`）由来。**
   実オッズを読みとして使う案は `market_drift_2026_09_11.md` が既に否定している
   （入稿時点の充足がナイター35% / ミッドナイト18%）。
7. **2026年は8か月ぶん**。10万+ / 30万+ の Δ は Poisson ノイズが支配的で、
   0.1pt 前後の差は判別できない。
