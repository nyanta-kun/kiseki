# 安い決着が見込まれるレースだけ目標を下げる — A_hit / B_hit（2026-09-29）

## 発端（ユーザー、2026-09-29）

> A_hit のアプローチについて、無理狙いをした結果、外して０になるくらいであれば
> 「安い配当だからレース自体を回避」「安いが的中期待度が高い場合は払戻額を下げることを許容」
> とするのも良さそうです。

背景の分解（修正後の比較台・確認窓）: A_hit の外れの内訳は **二軸はそろったが5倍未満で決着 25.6%**・
買い目で外した 31.4%（順序違い 12.4 / 3着違い 19.0）・軸で外した 21.8%。
`HIT_BAND_TARGET`（どの目でも5万円のダッチ）は Σ(1/予測オッズ) <= 予算/5万 = 0.2 なので
**5倍未満の目を1点も買えない**。本命の目が6〜7倍だと枠をその1点で使い切り、**実質3点**
（本命1点＋少額2点）になる（2026-09-29 の実入稿 C_hit 8件がこの形で 0 的中）。

## 採った形

`type_lab.apply_cheap_target` — 7車の `A_hit` / `B_hit` で、
`cheap_share`（**予測5倍未満の目に載っているモデル確率の割合**）がプラン内の閾値以上なら、
目標を 5万 → **2.5万** に下げる（`CHEAP_TARGET`）。それ以外は1点も変えない。

| 定数 | 値 | 根拠 |
|---|---|---|
| `CHEAP_TARGET` | 25,000 | 2万は入稿ゲート（平均想定払戻 > 2万）をダッチの端数で割り A_hit の 32% で組めない。2.5万は組成 100% |
| `CHEAP_ODDS` | 5.0 | 5万ダッチの枠に1点も入らない境目 |
| `CHEAP_SHARE_MIN` | A 0.2807 / B 0.1158 | 探索窓・入稿ゲート＋軸信頼ゲート通過後のプラン内 70% 点（＝上位30%） |

- 🔴 **較正は要らない。** 生のモデル確率の `cheap_share` は「決着5倍未満」への AUC 探索 0.815 / 確認 0.793 で、
  予測オッズ帯で較正した版（0.811 / 0.788）と同等。本番に較正表を持ち込まない
- 行の `plan_key` は変えない。**切り替えた行は `legs[].target = 25000`** で見分ける
  （`pred_mean_payout` では見分けられない — add_perm の再ダッチで5万の行も3万台へ下がる）
- `rule_version` の7車 payload に `_cheap` を載せた（新旧の行は版で分かれる）

### 一律に目標を下げるより効率が良い（採用理由の核心）

同じ的中で 4万+ が多い（行単位・確認窓）:

| | 表示的中 | 4万+/日 |
|---|--:|--:|
| A_hit 一律4万 | 25.71 | 0.292 |
| A_hit 本案（2万） | 28.33 | 0.306 |
| B_hit 一律4万 | 28.01 | 0.194 |
| B_hit 本案（2万） | 29.87 | 0.199 |

一律に下げるのは目標額のダイヤルを回すだけで、9/22 の判断（大口優先）を戻すことになる。
条件つきは「5万では構造的に取れないレース」だけを動かすので曲線の外側に出る。

## 否定したもの（同じ日に測った）

| 案 | 結果 |
|---|---|
| 安いレースを**見送る** | 表示的中は上がるが当たる 64件（確認）も捨て件数 −32%。ROI の CI は確認窓で 0 を跨ぐ |
| **混合**（見込みが高ければ下げる・低ければ見送る） | 目標を下げるだけの形に届かない |
| **C_hit** へ同じ操作 | 一律引き下げと同じ曲線（確認 本案 21.8% / 0.551 ↔ 一律4万 22.0% / 0.565）＝上乗せなし |
| **E_hit**: 「明確な実力不足の選手」「ラインから展開が明確」で帯下決着を見分ける | AUC 0.45〜0.55（情報なし）。効くのは市場の偏り（0.63〜0.66）と二軸同ライン（0.61）だけ。偏りの大きい1/3を F_hit 型へ替えると的中 +2.6〜4.2pt だが救済:破壊 ≈ 2:1・3万+ 減・無作為対照との差は約 1pt |
| A/C へ並べ替え（`ORDER_SWAP_PLANS` 拡張） | 目標額を 4万前後へ下げるのと同じ曲線上 |

## ⚠️ 限界

- **確認窓は見ている。** A は探索窓で閾値を決めて確認窓で一度読んだ。B は A の結果を見てから足した。
  前向きの確かめを下の事前登録で行う
- 探索窓の予測オッズは in-sample（`odds_tf_n7` の train_end 2025-12-31）
- 7車のみ。9車は予測オッズの分布が違うので掛けない

## 事前登録（前向きの答え合わせ・2026-09-29 に固定）

- **対象**: デプロイ後の `type_lab_picks` で `mode='live'`・7車・`plan_key in (A_hit, B_hit)`・
  `legs[0].target = 25000`（切替行）・精算済み・実際に入稿したもの（`netkeirin_submissions` と突き合わせ）
- **主指標**: 切替行の表示的中（払戻 > 賭け金）
- **期待値**（台・確認窓）: 切替行 A 37.6% / B 31.9%（件数加重で約 35%）。同じレースを5万のまま買った場合は A 14.8% / B 21.4%
- **判定点**: 切替行が **n = 150** に達した時点（台の件数なら約 2.8件/日 → 約8週。日次上限後はそれより少ない）
- **合格**: 表示的中の 95% 下限（Wilson）が **20%** を超える（＝5万のままの期待 約17% を上回る）
- **中止**: n >= 75 の時点で点推定が **20% 未満** なら `CHEAP_SHARE_MIN = {}` で戻す
- **副指標**（採否には使わない）: 全商品の 4万+/日（期待 −0.1件/日）・ROI
- 切替行でない A_hit / B_hit の成績は**変わらないはず**（買い目が同一）。変わっていたら実装を疑う

## 戻し方

`CHEAP_SHARE_MIN = {}`（`rule_version` が変わり新旧の行は自動で分かれる）。
