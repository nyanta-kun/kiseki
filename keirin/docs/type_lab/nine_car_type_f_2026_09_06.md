# 9車の型F を三連複へ（2026-09-06）

発端はユーザー観察「**9車のFが50%以上という状況がまさに課題。ここを売らないと商品も
大幅に減るため売る必要があるが、Fの二軸34%の精度が不足している**」。

母集団: `type_lab_picks` の paper（9車・型F・`F_hit` を売る種別）**1,958R**。
窓は 探索 2025 / 確認 2026。オッズは `wt_odds` の**確定**オッズ。

⚠️ **本番は予測オッズ**なので点数と「組めないレース」の割合は変わる。向きは両窓で
一致しているが、量は前向き実測で確かめること。

## 1. なぜ 9車の型F が問題なのか

9車型F は **9車レースの 57.7%**。型判定そのものは車数をまたいで妥当で
（同じ型なら 7車と 9車でそろい率がほぼ一致）、9車全体のそろい率が低いのは
**構成（型F が過半）** が主因で、型内の劣化は −2.7pt にすぎない。

## 2. 外れの中身

| | 探索2025 | 確認2026 |
|---|---|---|
| 軸2車そろい | 36.48% | 37.55% |
| 　軸1（ラインの先頭）が3着内 | 64.57 | 64.53 |
| 　軸2（番手）が3着内 | **48.83** | **49.24** |
| そろった時の3着カバー（4点） | 76.11 | 80.00 |

不的中の内訳: **軸2だけ飛ぶ 38.9 / 38.6%（最大）** / 両方飛ぶ 32.0 / 34.0 /
軸1だけ飛ぶ 17.1 / 16.7 / そろったが3着外し 12.1 / 10.7。

## 3. 軸の取り方はもう天井

軸1候補の3着内率はどれも 64.5〜66.5% で差が無い。**そろい率で最良なのは
「最強ライン（3着内率の合計が最大のライン）の先頭 × 同ラインの3着内率最上位」**:

| 組み合わせ | 探索 | 確認 |
|---|---|---|
| **最強ライン先頭 × 同ラインのp3最上位** | **36.48** | **37.55** |
| 全体pw 1位 × 同ラインのp3最上位 | 36.20 | 35.21 |
| 全体p3 1位 × 全体p3上位 | 35.59 | 31.29 |
| 最強ライン先頭 × 全体p3上位 | 35.35 | 31.02 |
| 最強ライン先頭 × 次点ライン先頭 | 23.73 | 22.14 |

🔴 **軸2はライン内から取ること。** 全体の3着内率上位から取ると確認窓で 31.0% まで落ちる。
🔴 軸なしの4車ボックス（4点）は 26.31 / 25.17% で、下の三連複の的中を下回る。

## 4. 🔴🔴 「そろわない70%」の選別は全滅

`psum`（最強ラインの2車の3着内率合計）は「そろわない」を **AUC 0.601 / 0.616**
（両窓・向き一致）で予測できる。`pgap` 0.592 / 0.610、`pw_ent` 0.552 / 0.546 も同方向。
**検出そのものは本物**。しかし下位20%を別の組み方へ差し替えると:

| 差し替え先 | 探索（現行 24.79） | 確認（現行 27.20） |
|---|---|---|
| 軸1だけ固定・確率上位 | 25.55 | 25.44 |
| 軸なし・確率上位 | 25.93 | 25.44 |
| 2番目に強いラインの2車 | 25.74 | 25.76 |
| 現行の軸2車（3着内率上位2） | 26.12 | 25.12 |
| 20倍以上から確率上位 | 23.55 | 24.48 |

**確認窓では全腕が現行を下回る**（探索では全腕が上回る＝符号反転）。
無作為対照には勝つ腕がある（＝選別は機能している）が、**替える先が無い**。
「そろいにくい側だけ +2点」も対照勝ち 6/30・9/30 で**無作為以下**。

🔴 **同ライン隣接ボーナス（`rank_7t3_blend_probs` の `adj_w`）の強化も効かない。**
λ 2.0→6.0 で12点の集合カバーは 40.8→50.8% と単調に上がるが、順序一致（＝的中）は
24.6% で頭打ちし λ6.0 では下がる。最良 λ が窓で入れ替わる（2025 λ3.0 / 2026 λ4.0）。

## 5. 🟢 採用: 三連複 ×「最強ラインの2車」×「計画払戻2万円まで積む」

| 案 | 商品数（ゲート） | 平均点数 | 表示的中 | ROI | 払戻中央 |
|---|---|---|---|---|---|
| ① 現行 三連単12点 | 1117(90%) / 659(92%) | 12 | 22.38 / 19.88 | 78.5 / 67.1 | 31,680 / 29,671 |
| 三連複 固定4点 | 1053(85%) / 625(87%) | 4 | 24.88 / 27.20 | 75.0 / 86.3 | 27,239 / 27,760 |
| **⑫ 三連複 τ適応（採用）** | **1139(92%) / 681(95%)** | 6.19 / 6.25 | **31.61 / 33.48** | 79.2 / 86.4 | 22,803 / 22,985 |

対応比較 Δ表示的中（⑫−①）: **+9.00 [+6.27, +11.81] / +13.64 [+9.98, +17.36]**
（**両窓とも0を跨がない**）。ROI 78.8→79.1 / 67.2→87.1 で**両窓とも下がらない**。

🟢 **商品数は現行より増える。** 固定k点はゲートに落ちたレースを丸ごと失うが、
τ適応は通る最大kへ落とすので落ちない（固定6点 27.67/30.32・固定7点 28.92/30.58 で件数も少ない）。

🟢🟢 **「レース情報で分ける」は τ適応が自動でやっている。**
`psum` 五分位別の平均点数は そろいにくい 6.89/6.92 → そろいやすい 5.11/4.93。
荒れるレースはオッズが高く、同じ2万円の枠でより多く買えるので、
**明示的な条件分岐なしに点数が増える**。手で書いた選別ルールが全部無作為対照に
負けたのは、オッズが既にその情報を持っていたから。

⚠️ ただし**70%を埋め切ってはいない**。そろいにくい側の表示的中は 19.91/27.01% で
最下位のままで、点数増が部分的に埋めているだけ。そろい率 37% は天井のまま。

## 6. 🔴 配分はダッチ（conf傾斜ではない）

| 配分 | Δ表示的中 vs ダッチ | ΔROI | Δ払戻中央 |
|---|---|---|---|
| conf傾斜（床2倍＝他プランと同じ） | −0.88 [−1.50,−0.35] / −0.74 [−1.47,−0.15] | −1.6 / −1.0 | +120 / ±0円 |
| conf傾斜（床1倍） | +0.61 [+0.17,+1.05] / +1.02 [+0.29,+1.76] | **−4.0 [−6.1,−1.8] / −4.0 [−7.2,−0.5]** | −1,400 / −1,680円 |
| 確率比例 | −3.34 / −5.42 | −5.4 / −7.8 | −1,330 / −1,045円 |
| 均等 | −5.93 / −8.05 | −4.0 / −8.2 | −3,560 / −2,940円 |

**現行と同じ conf床2倍は表示的中もROIも両窓でダッチに負ける。**

🔴 **三連複では床の仕事が無い。** ダッチが全点の払戻を揃え、Σ の上限が計画払戻
2万円（＝投資の2.2倍）を保証する。三連複の予測オッズ誤差は小さく
（live 実測・的中時の 実払戻/計画: **最小 0.456・0.45未満は 0/65件**）、最悪でも投資を割らない。
**三連単は 10.8% が 0.45未満**なので、あちらでは床が効いている。

🔴 **目標払戻 T を上げてはいけない。** T=20,000（＝`MIN_MEAN_PAYOUT`）が最良で、
22,000 / 25,000 / 30,000 / 35,000 と上げると表示的中もROIも単調に下がる。

## 7. 組めないレースは売らない

3点も積めない（＝計画払戻2万円を保てない）レースは商品にしない
（`TRIO_LINE_MIN_LEGS`）。**「1万円以下は当たりと扱わない」**（2026-09-06 ユーザー方針）
に沿う。実測で落ちるのは 5〜8%。8〜9月の実地で落ちた3件（08-30 特選7R /
09-03 一予選4R / 09-04 選抜2R）は**すべて現行の三連単12点でも当たっていない**。

## 10. 実装

- `keirin/src/type_lab.py`
  - `PLANS["F_line"]` … `trio` / `line_axis2_flow` / `sigma_max=TRIO_LINE_SIGMA_MAX` / `alloc="dutch"`
  - `RaceShape.line_pair` … 最強ラインの上位2車（3着内率の降順）。`race_shape` が作る
  - `_lines_of` の既定を **2車以上**へ（`line_legs` は 3車未満を自分で弾く）
  - `sell_plans_for` … 9車 かつ 決勝系でない型F → `F_line`
- `rule_version(9)` に `_sell9` として混ぜてあるので、9車の版は自動で分かれる
- ⚠️ **7車の版も割れる**（`PLANS` に1プラン増えたため）。7車の**買い方は変えていない**が
  生成される行は増えるので、版が分かれるのは正しい
