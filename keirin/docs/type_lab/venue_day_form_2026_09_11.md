# 02 「その会場・その開催のいまの決着傾向」は荒れ度の入力になるか — **否定**（2026-09-11）

**結論: 否定。** 前日・同一開催の「実際の決着」（三連単配当中央・逃げ/差し率・◎/指数1位の3着内率・
同ライン決着率、いずれも会場の普段からの乖離＝残差）は、**記述としては配当を僅かに分ける**
（ρ≈+0.04〜+0.07）が、**`axis_sum`・`arare`・`pw_ent` へ足した増分はゼロ**
（ΔAUC 両窓とも ±0.001 以内・CI が 0 を跨ぐか負）。`arare` の加点項にすると型が 8.9% 動くが、
型内の分離は **窓で符号が反転**（型A: 探索 −4.3pt ↔ 確認 +10.2pt・どちらも CI 0 跨ぎ）。
機序も実測で確定した: **前日の決着傾向は「その開催の出走構成」の反映で、今日の ex-ante 量が
既に持っている**（選手は 98% が前日と同じ・残差は今日の `arare` と ρ=+0.18）。
**「日固有」の成分は分散分解で 0**（会場×日の平均サプライズの分散 ≒ 二項ノイズの期待値・
前日→当日の自己相関 r=+0.002〜+0.03・CI 0 跨ぎ）。
風（G06）が落ちたのと同じ形——**結果の代理でも同じ壁に当たる。**

触る層: **第1層 ①型判定（`arare` の加点）**。第2層以降には到達しない。

## 5. 機序（実測）

1. **前日の決着傾向 = 今日の出走構成の反映。** 同一開催では **前日と同じ選手が 98.0%**
   （2025-01〜・3,169 会場日・中央 98.8%・p10 96.1%）。入れ替わらないから持ち越すのではなく、
   **入れ替わらないから ex-ante 量が同じものを既に見ている**:
   `r_prev_ltf_med` は今日の `arare` と ρ=+0.178・`pw_ent` と +0.137・`axis_sum` と −0.090。
   §2 の記述的な分離はこの相関の写しで、§3 で消える。
2. **開催日目の交絡。** `r_prev_ltf_med` の平均は day2 で −0.35（前日＝初日は予選で堅い）・
   day3 で −0.05・day4 で +0.67。`day_index` は既に `arare` の加点にある（ρ=+0.216）。
3. **「日固有」の成分が無い。** 会場×日の平均サプライズ（実績 − ex-ante 期待）の分散を
   二項・残差ノイズの期待値と比べると

   | 窓 | そろい | logPAY |
   |---|---|---|
   | 探索（2,651 会場日） | −4.2%（0.02838 vs 0.02957） | +4.7% |
   | 確認（1,089 会場日） | −0.1% | −3.0% |

   ＝ **1日 12R 前後の決着のばらつきは、ほぼ全部がレース単位のノイズ**。前日→当日の
   サプライズ自己相関は r = +0.018 / +0.002（そろい）・+0.034 / −0.011（logPAY）で全て CI 0 跨ぎ。
   「バンクが今日は先行が残る」という日固有の状態は、**あったとしても 12R では測れない大きさ**
   （1日のそろい率の SE ≒ 14pt）。
4. G06 の風と同じ構図。風は「原因の代理」で決まり手を ±2pp しか動かさなかった。決着は
   「結果の代理」だが、結果は **選手構成（既知）＋ノイズ** に分解でき、既知の部分は特徴に入っている。
   **原因側でも結果側でも、日単位の環境変数は型判定に足すものを持っていない。**

## 6. 限界

- 前日が存在するのは板の 63.9%（初日は欠測→0 埋め＋欠測フラグ）。
- 「会場の普段」は直近365日平均。期間の頭（2024-07 の前後）は手前ぶんが薄い。
- 決まり手の残差は 7車以外（9車・6車）も含めた会場日集計。ただし板の目的変数は 7車のみ。
- 加点項の閾値（q20/q80）は探索窓で決めた1通り。§3 の増分ゼロは閾値に依らない（連続量で測っている）。
- 確認窓を消費した（増分 7セット × 2目的 × 2モデル＋加点1通り）。採用ゼロ。
- 商品 KPI（表示的中・10万+）は測っていない——第1層で落ちたため。
