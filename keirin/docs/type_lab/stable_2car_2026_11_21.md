ユーザー依頼: 「日々の的中率・回収率が落ちている。『確率的には正しい』という報告ではなく、
安定して的中率・回収率を確保するにはどうすればいいかを調査・検討する」。

スクリプト: `keirin/scripts/exp_type_lab/stable_2car/a1〜a5.py`（入力 CSV は psql で書き出し・本文の SQL 参照）。

### 3.3 🔴 これは新しい優位性ではない

軸ペアは **69% が2車複の最終1番人気**。その場合の回収 77.3%、そうでない場合 73.9%。
回収が75%前後に保てるのは、**低いオッズほど控除の損が小さい（本命‐大穴の偏り）**ためで、
2026-09-29 の「効くのは高確率1点」と同じ曲線上の点。モデルが市場に勝っているわけではない。
**採る理由は「平均が上がる」ではなく「週の揺れが小さくなる」こと。**

## 5. 案

### 案1（推奨）: 型A/B/C の的中系を「二軸の2車複1点」にする

- B_hit・C_hit を2車複1点に置き換える。型A は2車複1点で再開する（A_hit は 10/24 停止）
- D_hit は件数が少ない（145件）。置き換えてよいが判定は別枠
- E_hit・F_hit・F_line・A_trio はそのまま
- 見込み（P2）: 週の表示的中 22%→約32%、「先週的中 20%未満」の週 21%→ほぼ0、「先週回収 65%未満」の週 8%→2%

### 案2: 高額系の量をどうするか（ユーザー判断）

高額系は揺れの 79% を作る一方、回収の平均を押し上げている。

- 減らす（P3）: 週回収の上振れも消える（90%点 108→92）。週の表示的中は最も高い
- 今のまま（P1/P2）: 推奨
- 増やす（11/19 の高額枠案3）: 10万+ は増えるが、**この文書の目的（週の安定）とは逆向き**

### 案3: やらないこと

- 型E/F を2車複にする（対比較で的中も回収も下がる）
- ワイド（`wt_odds.quinellaPlace` は公式払戻と照合できない。払戻の下限の可能性があり測れていない）
- 日ごとの数字で判断すること（1日 ±5pt は件数から必ず出る揺れ）

## 7. 三連複・三連単で同じ安定を作る（2026-11-21 追記・ユーザー依頼「三連複、三連単での購入方法を検討して」）

スクリプト: `a6.py`（買い方ごとの倍率）/ `a7.py`（型別）/ `a8.py`（対比較・週の分布）/ `a9.py`（可変点数）。
入力は二軸を含む三連複・三連単の全目（`legs3.csv`・確定オッズと朝オッズ `wt_odds_snapshot.morning`）。

- 1レース1万円。**配分は朝オッズだけで決める**（ダッチ＝朝オッズの逆数に比例・100円単位）。払戻は確定オッズ
- 三連複の確定オッズは公式払戻と 99.5% 一致（3,930件・払戻100円の返還行を除く）

**結論を先に: 同じレースで測った「当たりやすさのダイヤル」**（型A/B/C・表示的中 / 回収）

### 7.5 効かなかったこと

- **ガミを避ける可変点数**（朝の見込み倍率が足りなければ相手を減らす）: 表示的中 34.9% → 最大 35.9%。
  ガミの多くは朝から締切までのオッズの下落で起き、朝の時点では避けられない
- **中間の目標額**（朝の見込みで 2万・2.5万円取れる点数だけ／取れなければ見送り）: 的中 29〜34%・回収 72〜76% と両方下がる

### 7.6 三連複案の利点（2車複案と比べて）

- 入稿・採点の仕組みがそのまま使える。`A_trio`（三連複2点・`axis2_flow`・ダッチ）が既にある
- 🔴 **型A で効くのは点数ではなく「2万円取れるか」のゲート（`trio_ok`）を外すこと。** 相手2点と3点は
  35.3% / 76.3 と 35.0% / 77.2 で区別できない。今の A_trio（ゲートを通ったレースだけ）は対比較で
  38.2% / 86.8（n=89）と既に案以上で、伸びるのは A_trio が今は売っていないレースの分だけ
- 🔴 **ゲートを外すのは過去のユーザー判断の逆向き。** 9/22 の「どの目でも5万円」（`HIT_BAND_TARGET`）と
