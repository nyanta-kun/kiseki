# 旧ランクのうち「高額的中を作れるもの」を高額枠へ復活させる価値はあるか（2026-09-11）

発端（ユーザー 2026-09-11）:

> 旧ランクにおいて新ランク（型ラボ）では当たらず、旧ランクでのみ的中しているものはあるか？
> → **一部の高額的中のあるものに限定し、優先するプランが考えられると思います**

---

## 1. 結論（先に）

1. 🔴🔴 **旧ランクを高額枠（`HIGHPAY_SLOTS_PER_DAY = 5`）へ差し込む価値は無い。**
   同一レース・同一窓のペア比較で、**10万+ は旧ランク7種すべてが型ラボの看板枠
   `{型}_sign` に負ける**（7M1 −1.72pt / 7H1 −1.81pt / 7T2 −2.10pt、いずれも
   95%CI が 0 を跨がない）。しかも**旧ランク側は入稿ゲート未通過**という
   旧に有利な条件での比較。
2. 🟢 **例外は 30万+ の1点だけ。** `7T2` は `{型}_sign` より 30万+ を作る
   （0.98% ↔ 0.26%・差 +0.72pt CI[+0.20,+1.25]・15件↔4件）。`7H1` も同方向
   （0.65% ↔ 0.39%・CI は 0 を跨ぐ）。**ただしその席は 2026-09-06 に新設した
   `{型}_big`（軸1外し・計画払戻40万）が既に埋めており**、
   `docs/highpay_5slots_2026_09_06.md` 9.3 の同一母集団実測では
   `_big` の 30万+ は **1.21〜1.57%/商品** で 7T2 の 0.98% を上回る。
3. 🔴 **発端の「旧だけ的中」は高額ではない。** 型ラボ実売期（2026-08-29〜09-11・
   744商品）で「旧だけ当たり」は 121件あるが、**10万+ は 1件（0.8%）・30万+ は 0件・
   払戻中央 16,530円**。62%（75/121）は 2万円未満。旧の複数ランクから
   **事後に最大の1つを選ぶ**という旧に最大限有利な数え方でこの値。
4. 🔴 **旧ランクの「実売」記録では 10万+ はほぼ出ていない。**
   入稿ゲートと1レース1商品を通った 865商品（2026-08-07〜08-28）で
   **10万+ は 2件（0.23%/商品）・30万+ は 0件**。2件はどちらも `7T1`。
   高額の実績（`7H1` 255,480円 等）は **すべて `picks_history` ＝ゲート未通過の候補**であって、
   売った記録ではない。
5. 🟢 **枠が余る問題は実在するが、余りは小さく、埋め方も旧ランクではない。**
   本番再現（`docs/type_lab/daily_portfolio_2026_09_10.md` §5）で高額枠は
   **4.40〜4.44本/日・5本埋まった日 68%**＝不足は **0.56本/日**。
   実運用（09-06〜09-11）も 4.67本/日。埋める候補としては型ラボ自身の
   `F_sign`（隙間に 13.6〜19.2R/日・10万+ 3.62〜3.90%）が旧ランクの最良
   （7T2 2.36% / 7M1 2.03〜2.90%）を上回る。
   **どちらで埋めても 10万+ は 月+0.4〜0.6回**で、ここは主戦場ではない。

## 2. 台の選択と限界（🔴 ここが本件の肝）

`picks_history`（旧ランク）には**予測オッズが無い**ので入稿ゲートを直接あてられない。
使える台と、その台で何が言えるかを先に固定した。

| **台2** `netkeirin_submissions`（型ラボ実売） | 2026-08-29〜09-11 | 744 | 型ラボの現物。高額枠の実売は 09-06 以降 **28件のみ** | 高額枠の収支は判定不能（n=24・的中0） |
| **台3** `type_lab_picks` mode=paper の `{型}_sign` | 2025-01-01〜2026-08-04 | 33,587R | 型ラボ看板枠の**ゲート適用済み**成績。捨てる側を axis_sum 下位50%で近似 | `_big` は paper に無い（2026-09-06 新設） |

### 🔴 期間の交絡（消せない）

- 旧ランクの最終入稿は **2026-08-28**、型ラボの実売開始は **2026-08-27**。
  **両者が同時に売られたのは実質2日**しかない。
  ＝ **「実売 vs 実売」の同一期間比較は原理的に作れない。**
- そこで本稿の主測定は **台3 × 台4 の同一レース・同一窓ペア比較**にした。
  型ラボ側はゲート適用・旧側はゲート未通過なので、**旧に有利側へ倒した比較**である。
  それでも旧が 10万+ で負けるなら結論は堅い、という設計。

### そのほかの限界

- 「捨てる側」の再現は **日ごとに `axis_sum` 昇順で下位50%**。本番の
  `cap_priority` は `(2×軸信頼 + 実力伯仲)/3` を波ごとに使うので近似
  （`docs/highpay_5slots_2026_09_06.md` 9.6 と同じ近似）。
- 予測オッズモデル `odds_tf_n7` の train_end は 2025-12-31。**2025窓は in-sample**。
  そのため 2025 / 2026 を分けて出し、**両窓で向きが一致するものだけを主張**した。
- 🔴 `7T1` / `7T2` / `7T3` は **2026-01 から**しか存在しない（2025窓に行が無い）。
  高額を作る旧ランクほど**確認窓が1つしか取れない**。
- 🔴 `7T2` は **2026-08-21 で生成が止まっている**（2026-09 は 0行）。
  `netkeirin_settings` に行すら無く、**一度も入稿されたことがない**
  （memory: 候補420件・入稿0%）。復活には生成と配線の両方が要る。
- `picks_history.bet_amount` は名目値（`docs/RECOMMENDATION.md`）。ここでは
  「1商品 10,000円で買ったときの払戻」を出すための分母としてのみ使い、
  「購入した」の意味では使っていない。
- ROI は本稿の判断指標に使わない（±2.5pt に約15.6年）。見るのは
  **10万+/商品・30万+/商品・払戻中央・件/日**。

### 恒等式（判断の土台）

`P(払戻 >= X) = 帯ROI × 予算 / E[払戻 | 払戻 >= X]`。
＝ **看板の本数は「帯ROI」と「その帯の平均払戻」の2つだけで決まる**。
券種・点数・並べ方は、この2つを動かさない限り看板の本数を動かさない。
本稿はこの左辺（10万+/商品・30万+/商品）を直接数える。

## 8. 限界

- 🔴 **旧の実売と型ラボの実売は同一期間で比べられない**（重なりは2日）。
  主測定は候補（旧・ゲート未通過）× paper（型ラボ・ゲート通過）のペアで、
  **旧に有利側へ倒した比較**。それでも旧が負けたので結論は堅いと判断したが、
  「旧をゲートに通したら上がるかもしれない」は否定していない
  （ゲートは平均想定払戻 2万円未満を落とすので、高額狙いの旧ランクにはあまり効かないはず、
  という**推論**であって実測ではない）。
- 🔴 **`{型}_big` は本稿で再測定していない。** paper に行が無く、live は 09-06〜09-11 の
  17商品（的中0）しかない。4.3 の `_big` の数字は `docs/highpay_5slots_2026_09_06.md` 9.3 の引用。
  ただし同 doc の `{型}_sign` の数字は本稿の台で再現できた。
- 🔴 `7T1` / `7T2` / `7T3` は 2026年のみ。**確認窓が無い。**
- 「捨てる側」は `axis_sum` 下位50% の近似（本番は `rp_sd` を混ぜ、波ごとに判定）。
- 2025窓は予測オッズモデルが in-sample。両窓で向きが一致するものだけを主張した。
- 30万+ / 50万+ の件数は各腕で 0〜15件。**順序は算数（計画払戻を上げれば増える）なので
  信頼できるが、絶対値はブレる。**
- 件数を減らす／入れ替える腕に**無作為対照20seed は置いていない**。本稿の主張は
  「同一レース・同一件数のペアで旧が負ける」であって「件数を絞ると良くなる」ではないため。
- `picks_history` の `rule_version` は世代混在する。本稿はランクごとの世代分割をしていない。

  （**`#` の後ろがランク接尾辞**。これを外さないと台3と結合できない）
