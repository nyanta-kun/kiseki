# 事前登録: 選手コメントの「調子が良い」は市場より当たるか（2026-10-01）

## 1. 経緯

winticket の選手コメント（前検日・レース後。本文は 2025-12 以降）を 142,624 件取得し、
claude-haiku-4-5 で分類した（調子・落車・怪我・自信など）。取得・分類・保存は
`src/rider_interviews.py`・`scripts/{collect,tag,load}_rider_interviews.py`、表は `keirin.rider_interviews`。

2026-10-01 の本判定（探索 2025-12〜2026-05 / 確認 2026-06〜09-29・事前登録つき）:

| 判定 | 結果 |
|---|---|
| タグ単位（35本）・現行モデル基準 | **8本が両窓で有効**（レース後の調子悪い・直近3件平均の調子悪い・落車・怪我、前検日の調子悪い・調子良い・怪我・自信あり。3着内率で ±1〜4pt） |
| 内容の増分・現行モデル基準 | **あり**（上位3着の順位尤度 1レースあたり −0.0062 [−0.0091, −0.0033]） |
| 内容の増分・確定市場基準 | **なし**（−0.0016 [−0.0035, +0.0003]）＝市場がほぼ織り込み済み |

感度確認（レース後コメントを翌々日以降だけに使う／基準を DB の予測値に揃える）でも結論は同じ。

**副表（判定には使っていない 35本×市場基準）で、両窓とも有効だったのが1本だけあった:**

> **前検日コメントで「調子が良い」（condition >= 1）と言った選手の3着内率は、確定市場の予測より
> +1.2pt（探索）/ +1.4pt（確認）高い。** 同タグ以外の選手との差も +0.9 / +1.0pt。

35本を見た中からの拾い出しなので、偶然を否定できない。**判定窓を未来に固定して一度だけ測る。**

## 2. 仮説と定義（ここから変えない）

- 対象: 7車・9車のレースの出走。着順 0（欠車・失格）と中止は除く
- フラグ: その開催（`cup_id`）の前検日コメントがあり、分類の `condition >= 1`、かつ
  その前検日ページの公開時刻（`src_updated_at`）が**出走日の 07:00 JST 以前**
- 市場の3着内確率: 確定三連単オッズの 1/オッズ をレース内で正規化し、その車を含む目の和
- 指標: `R = mean(着順<=3 − 市場の3着内確率 | フラグあり)` と
  `D = R − mean(同 | 前検日コメントあり・フラグなし)`
- 統計: 日クラスタ・ブートストラップ 2,000本の 95%CI

## 3. 判定（2026-10-01〜2026-12-31・一度だけ評価する）

| 判定 | 条件 |
|---|---|
| **採用候補** | フラグあり n >= 2,000 出走 ∧ R の CI 下限 > 0 ∧ D の CI 下限 > 0 |
| 不採用 | それ以外 |

- 採用候補でも**すぐに買い方へは入れない**。回収率に効くか（その選手を含む目の実際の回収率）を
  台で測ってから、ユーザーが判断する
- 判定窓の途中で定義・閾値を変えない。分類のモデル・プロンプトを変えた場合は、その日以降を
  別の世代として数え、判定は変更前の世代だけで行う（`tag_model` 列で分かれる）

## 4. 画面での使い方（判定とは独立・2026-10-01 ユーザー指示）

`/keirin` の出走表で選手名をタップすると、コメント（前検日・前走後・このレース後）を出す。
**発走前に公開されていた直近のコメントが「調子が良い」なら選手名を青字**にする
（判定の正本は `backend/src/services/keirin_rider_comments.py`。このレースのレース後コメントは
発走後に出るので青の判定に使わない）。
