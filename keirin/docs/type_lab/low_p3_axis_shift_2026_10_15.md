# 本命の3着内率が低いとき、次点を軸に組むべきか（2026-10-15）

**結論: 否定。** 本命（軸1 = p3 1位）の3着内率が低い層では本命が飛びやすいのは事実だが、
**次点（軸2）はそれ以上に飛ぶ**。p3[軸1] のどの十分位でも、両窓とも
「軸1の実3着内率 ≧ 軸2の実3着内率」だった。当てにいく商品で軸1を外して組み直すと
表示的中が −11〜−13pt（両窓 CI<0）落ち、回収率の差は全条件で CI が 0 を跨ぐ。

- ユーザー提案: 「3着内率が一定以下の場合、飛ぶ確率も上がるので、その次の選手を軸に組み立てる方が
  有効なオッズの的中を取れるのでは」
- 触る層: ②商品（軸の取り方）
- 台: `/tmp/race_type_board.npz` 7車 36,237R・探索 2024-07〜2025-12 / 確認 2026-01〜
- 前例: `axis_swap_by_confidence_2026_09_12.md`（軸1を人気側へ差し替え → 効果ゼロ）、
  `mark_second_third_bets_2026_09_12.md` §5.4（軸1を買わない `bust` は高額枠でのみ有効）。
  本件で新しいのは **層を p3[軸1] 単体で切ったこと**と、**当てにいく商品へ適用したこと**

## 2. 商品での測定（`low_p3_axis_arms.py`）

現行ラインナップ（`lineup_arms.run`・日次上限/軸信頼ゲート込み）の売り行のうち、
p3[軸1] < 探索窓の分位（10/20/30% = 0.718 / 0.750 / 0.778）の行を本番関数で組み直した。
対象は主に F_hit / F_sign / E_hit / D_hit（A/B/C は型の定義上ほぼ入らない）。

- **drop**: 軸1を含む目を全部外す（三連複は `order` を1つ繰り下げ）
- **shift**: 三連複のみ。軸を #2・#3 にし、軸1は相手の先頭に残す
- **無作為対照**: 同数の売り行を無作為に drop（20seed・下位20%のみ）

| 層 | 窓 | 件/日 | 現行 表示的中/ROI | drop 表示的中/ROI | Δ表示的中 [CI] | ΔROI [CI] |
|---|---|--:|---|---|---|---|
| 下位10% | 探索 | 2.77 | 21.41 / 76.0 | 10.31 / 80.5 | −11.10 [−13.72, −8.67] | +4.5 [−15.7, +23.9] |
| | 確認 | 3.00 | 23.57 / 88.9 | 11.25 / 94.4 | −12.33 [−16.33, −8.32] | +5.4 [−26.3, +38.7] |
| 下位20% | 探索 | 5.55 | 22.52 / 77.3 | 10.37 / 84.1 | −12.15 [−14.08, −10.27] | +6.8 [−7.5, +21.5] |
| | 確認 | 6.15 | 22.65 / 81.5 | 10.16 / 83.8 | −12.49 [−15.27, −9.70] | +2.3 [−18.2, +24.1] |
| 下位30% | 探索 | 8.32 | 22.63 / 79.5 | 9.70 / 79.2 | −12.93 [−14.45, −11.34] | −0.3 [−11.4, +11.6] |
| | 確認 | 9.17 | 22.73 / 77.4 | 9.65 / 84.6 | −13.08 [−15.35, −10.76] | +7.2 [−10.8, +25.5] |

- 4万+ は増える（確認・下位20%: 62 → 94本）。**的中を払戻へ置き換えただけ**。
- shift（D_hit・n=66〜327）: 表示的中 −9〜−13pt、ROI 差 +2〜+30 だが CI ±40〜70pt。
- 無作為対照の drop は ΔROI 中央 −12.3 / −12.5。低 p3 層の方が落ちにくいのは
  「その層では軸1がよく飛ぶ」（§1）の言い換えで、新しい情報ではない。

回収率の基準（現状比 → 75% → 100%）: 現行も案も 75% は超えるが、現状比の改善は CI が 0 を跨ぎ、
表示的中は有意に半減する → 採用する腕なし。

## 3. 既にある形との関係

軸が最も薄い層（軸信頼ゲート落ち）では、「軸1を1点も買わない」形を既に `A_ana` / `*_big`
（`bust_top` / `plan.bust`）として売っている。本件はそれをゲートを通る当てにいく商品へ広げる形で、
そこでは効かなかった。

## 4. 限界

- 落車・失格レースは除いていない（差 +7pt に対して結論は動かない見込み）
- 払戻は台の PAY（確定オッズ×100）で、同着ぶん約0.2%過大
- 層は較正前 p3 で切った（較正は単調なので軸1/軸2 の順位は変わらない）
