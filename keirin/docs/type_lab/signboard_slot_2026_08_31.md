## 1. 🔴🔴 高額払戻は「当てる」問題ではなく「予算をどこに置くか」の問題

市場効率下では

```
P(払戻 >= X) = 帯ROI × 予算 / X
```

**券種・点数・配分・並べ方に依存しない**（[[keirin_highpay_payout_ceiling_2026_08_06]]）。
1レース1万円なら 10万+ の上限は 7.5%/レース、30万+ は 2.5%/レース。

現行ラインナップ（確認2026・7車・48.2件/日）の実測は **10万+ 0.39件/日 = 0.8%/レース**
＝**上限の約1割しか使っていない**。理由はモデルの精度ではなく買い目の作りで、
プランごとの「最大計画払戻の中央値」を見るとはっきりする:

```
F_pay 147,290円  ← 10万に届く唯一の設計    A_pay  76,362（未販売）
F_hit  49,800    E_hit 44,322   C_hit 37,660   A_hit 36,454   B_hit 32,406   D_hit 32,278
```

**過半のプランは、当たっても10万円に届かない。** 現行の 10万+ の 88% を `F_pay` 1本が
出しているのはこの帰結（`lineup_signboard.py`）。

## 2. 🔴 看板の本数は「点の選び方」では動かない

全型を看板枠にしたうえで、選び方だけを7通り変えた（確定払戻で採点）:

| 選び方 | 10万+/日 探索/確認 | ROI 探索/確認 | ΔROI 95%CI（確認） |
|---|---|---|---|
| EV順・制限なし | 1.66 / 1.67 | 71.5 / 70.7% | [−13.8, +2.1] |
| **確率順・制限なし** | 1.93 / 1.74 | 79.1 / 70.7% | [−13.1, +1.2] |
| 予測オッズ昇順（人気順） | 1.79 / 1.78 | 73.1 / 72.0% | [−11.6, +2.8] |
| 確率順・<=300倍 | 1.93 / 1.74 | 79.2 / 71.6% | [−12.4, +2.2] |
| EV順・<=300倍 | 1.72 / 1.84 | 73.8 / 77.3% | [−6.2, +7.6] |
| 確率順・<=600倍 | 1.93 / 1.74 | 79.3 / 71.1% | [−12.7, +1.6] |
| 確率上位30点→EV順 | 1.73 / 1.86 | 75.5 / 79.1% | [−5.2, +10.2] |

- 🔴 **10万+/日 は 1.66〜1.93（探索）/ 1.67〜1.86（確認）でほぼ一定**＝恒等式どおり。
- 🔴 **ROI 差は全案とも CI が 0 を跨ぐ**。探索窓で「確率順」が有意に見える（+1.5〜+13.6）が
  **確認窓で符号が反転する**（−13.1〜+1.2）。
  [[keirin_type_lab_race_filter_rejected_2026_08_27]] の「無作為対照に負ける」と同型。
- → **確率順・オッズ上限600倍**を採用。理由は ROI ではなく
  ①点数が中央3点で説明しやすい ②表示的中が最良側 ③帯ROI が崩れる 600倍超を踏まない
  （三連単の帯ROI は 600倍まで 71〜76% だが 600-1200倍 64.5% / 1200倍- 51.6%）。

## 3. 計画払戻 T の掃引 — **10万ちょうどで組んではいけない**

予測オッズは確定より高めに出るので、計画10万だと的中の 55% しか10万に届かない:

| 計画T | 的中率 | 的中→10万 到達 | 10万+/日（確認） | 30万+/日 |
|---|---|---|---|---|
| 8万 | 8.51% | 34.8% | 1.37 | 0.02 |
| 10万 | 6.79% | 55.4% | 1.74 | 0.03 |
| 12万 | 5.64% | 71.1% | 1.86 | 0.06 |
| **15万** | 4.57% | **83.9%** | **1.78** | 0.19 |
| 20万 | 3.08% | 94.1% | 1.34 | 0.39 |

**T=15万を採用**（`SIGNBOARD_TARGET`）。12万と15万で 10万+/日 はほぼ同じだが、
15万は約束の達成率が 84% と高く 30万+ が3倍出る。20万を超えると点数が減りすぎて本数が落ちる。

## 4. ダイヤル — どの型を看板枠にするか

**本番の `build_legs` + `allocate` を import して**採点し直した数字（`verify_sign.py` と同じ）:

| 看板枠を置く型 | 枠/日 | 表示的中 探索/確認 | ROI 探索/確認 | 10万+/日 | 30万+/日 | ΔROI CI（確認） |
|---|---|---|---|---|---|---|
| なし（現行） | 0 | 19.97 / 20.74% | 71.4 / 76.7% | 0.35 / 0.39 | 0.01 / 0.02 | — |
| **F**（採用） | 14.2 | 18.54 / 19.47% | 73.9 / 75.4% | 0.58 / 0.54 | 0.02 / 0.02 | [−6.6, +3.6] |
| F+C | 23.1 | 15.42 / 16.17% | 75.0 / 76.2% | 0.97 / 0.91 | 0.04 / 0.03 | [−6.7, +5.7] |
| F+C+E | 27.5 | 14.50 / 14.82% | 76.2 / 74.4% | 1.11 / 1.01 | 0.06 / 0.04 | [−8.7, +3.8] |
| F+C+E+B | 33.5 | 12.03 / 11.95% | 78.1 / 73.1% | 1.41 / 1.26 | 0.08 / 0.05 | [−9.7, +2.9] |
| 全型 | 48.2 | 4.82 / 4.52% | 79.3 / 71.2% | 1.93 / 1.74 | 0.11 / 0.07 | [−12.6, +1.7] |

🔴 **ROI はどこでも判別不能**（CI が 0 を跨ぐ・探索と確認で符号が違う）。
＝ **これは収支の選択ではなく店頭KPIの選択**（[[keirin_rank_priority_ev_rejected_2026_08_25]] と同型）。
交換レートは **看板1件 ≒ 表示的中 1pt** 前後。

**採用は `SIGNBOARD_TYPES = ("F",)`**。`F_pay` は現行で最弱（ROI 70.7%）かつ既に一撃枠なので、
置き換えの代償（表示的中 −1.3pt）が最も小さいところ。

## 5. 🔴🔴 看板 5件/日 は 1レース1万円では作れない

恒等式より本数は予算に比例する。全レース（7車 64件/日＋9車11件/日）を看板枠にしても
1万円では **約2.5〜2.9件/日** が上限。実測（全型・計画15万・確認窓）:

| 1レースの予算 | 10万+/日 | 投資/日 |
|---|---|---|
| 1万円 | 1.94 | 51.6万円 |
| 1.5万円 | 2.95 | 77.5万円 |
| 2万円 | 3.82 | 103.3万円 |
| **3万円** | **5.68** | **155.0万円** |

**5件/日 には 1レース約2.6〜3万円（投資 約135〜155万円/日）が要る。**
表示的中は全型看板枠で 4.5% まで落ちる（現行 20.7%）。

代案として「看板 = 5万+」と定義を下げるなら、1万円のままで **3.8〜3.9件/日**（全型看板枠）。

## 7. 限界

- 台は7車のみ・2024-07〜2026-08-04。
- 賭け金は100円単位に丸めるので、計画払戻は最大 `100円 × 予測オッズ` だけ T を割る
  （実測の中央は 149,300円で、実務上は T に張り付く）。
- そもそも「計画払戻」は予測オッズに基づく**狙い**であって保証ではない（達成率 84%）。
