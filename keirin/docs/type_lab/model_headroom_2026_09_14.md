## 5. A/B の3腕（`exp_model_headroom_ab.py`）

| 腕 | 根拠 |
|---|---|
| **+車数（`n_entries`）** | 特徴に車数が無い。学習データの **15% が7車以外**（9車 8.1% / 6車 5.2% / 5車 1.2% / 8車 0.5%）。`score_rank` / `wr_rank` / `top3r_rank` / `frame_no` / `line_*` は車数で意味が変わるが、モデルは1行ずつ見るので車数を知りようがない |
| **+H2H** | 撤回の根拠が**いま使っていない旧ランクの ROI**。現在の作法は「ROI で採否を決めない」 |
| **7車のみ学習** | 商品は7車主力。データ −15% と引き換えにランク系特徴の意味が揃う |

指標は AUC / 1位勝率 / 1位3着内 / **上位2車そろい率**（＝軸崩壊の裏返し）。
窓は w1 2026-04-13〜07-15 / w2 2026-01-01〜04-12・5seed。

⚠️ **両窓とも `keirin_protocol.BURNED_WINDOWS` の焼けた窓＝VAL。** 出るのは探索の結果で
採否ではない。`MIN_TEST_WINDOWS = 4`（＝1年）が要る。
🔴 プロトコルの警告: このレイヤの効果量は +0.3pt 級で**窓ごとのばらつきが同じ大きさ**
（実測 SD 0.15pt）。「窓を増やせない代わりに**効果量の大きい変更**を狙うこと」。

## 6. A/B の結果 — 🔴 3腕とも不採用

w1 2026-04-13〜07-15（train 396,063 / test 50,358）/ w2 2026-01-01〜04-12（341,555 / 54,508）・
5seed。baseline AUC 0.77867 / 0.78088（seed 標準偏差 0.00006 / 0.00013）。

| 腕 | 窓 | ΔAUC | Δ1位勝率 | Δ1位3着内 | **Δ上位2車そろい** |
|---|---|--:|--:|--:|--:|
| **+車数** | w1 | +0.00006 | +0.12pt | −0.00pt | +0.01pt |
| **+車数** | w2 | +0.00018 | +0.05pt | −0.03pt | +0.07pt |
| +H2H | w1 | +0.00027 | **−0.12pt** | **−0.31pt** | −0.02pt |
| +H2H | w2 | +0.00013 | −0.05pt | +0.00pt | +0.03pt |
| 7車のみ学習 | w1 | **−0.00251** | +0.08pt | +0.03pt | −0.12pt |

| +車数+H2H | w2 | +0.00026 | −0.08pt | −0.08pt | +0.08pt |

### 読み方

🟡 **`+車数` だけが AUC・1位勝率・そろい率の3つとも両窓でプラス**だが、**小さすぎる**。
比較の物差しは同じハーネスで採用された `MEETING_FORM`（節内成績）で、あちらは
**ΔAUC +0.00058 / +0.00068・Δ1位勝率 +0.33 / +0.14pt**。車数はその **1/5〜1/3**。
`keirin_protocol` の実測 SD は 0.15pt なので、+0.05〜0.12pt は**窓ノイズの中**。

🔴 **`+H2H` は AUC が僅かに上がるのにレース単位の指標が動かない/下がる**
（w1 で 1位3着内 −0.31pt）。2026-07-28 の撤回（旧ランクの ROI 悪化）は
**物差しを変えても結論が変わらない**と確認できた。再提案しないこと。

🔴 **`7車のみ学習` は明確に悪い**（ΔAUC −0.0025 / −0.0028＝seed SD の 20〜40倍）。
ランク系特徴の意味が揃う利得より、データ 15% 減の損失が大きい。
2026-07-19 の「全期間で学習する」判断（データ量 1.6倍で ΔAUC +0.0127）と同じ向き。

🔴 **`+車数+H2H` は窓で符号が割れる**（Δ1位勝率 +0.14 / −0.08）。

## 7. 結論 — 特徴側の余地は尽きている

| 方向 | 状態 |
|---|---|
| DB 内の未使用列 | 🔴 尽きた（`unused_morning_inputs_2026_09_10` + 本稿 §4） |
| 使い方の修正（車数・7車限定） | 🔴 本稿 §6 で否定 |
| H2H | 🔴 2度の検証で否定（ROI基準・AUC/レース指標基準の両方） |
| 較正 | 🔴 直す対象が無い（§3・`calibration_to_shape_2026_09_11`） |
| レース単位の構造量を非線形に混ぜる | 🔴 `p_both` 比 +0.004〜0.007（`axis_bust_model_2026_09_11`） |

**残るのは「いま DB に無いデータを入れる」か「目的関数・アーキテクチャを変える」の2つだけ。**
どちらも `MIN_TEST_WINDOWS = 4`（1年）が要る規模の話で、
プロトコルの「効果量の大きい変更を狙うこと」に照らすと、
**+0.3pt 未満を追う限り投資対効果が成立しない。**
