# 短期の脚質・直近の調子は相手選定／軸崩壊に使えるか（2026-09-14）

> ユーザーの仮説: 「**短期の脚質**や他のラインとの相互関係で有力になることもある」

既存検証（`rate_line_branch_2026_09_13.md`）で否定されたのは `rows.pkl` の `style` /
`rate` ＝ **期間成績（長期）**。ここでは **直近N走ベースの短期量**を新規に作って測った。

## 結論（先に）

| 問い | 答え |
|---|---|
| 短期量は長期量より情報があるか | 🟢 **ある**。記述でも残差でも長期を上回る |
| 相手選定（3着目）に使えるか | 🔴 **使えない**。p3 へ足すと全腕・両窓で現行以下 |
| 軸崩壊の事前検知に使えるか | 🟢 AUC 0.56〜0.57（長期は 0.475〜0.524）。だが 🔴 **`axis_sum`(0.65) に負ける** |
| レース選別（商品）に使えるか | 🔴 **使えない**。`axis_sum` 単独に全 dose で負け、足しても CI が 0 を跨ぐ |
| 型E/F の選抜確率に載せられるか | 🔴 **全5腕・両窓で現行より表示的中が下がる**（対照には 14〜20/20 で勝つ） |

**採用候補なし。** 機序は「p3 モデルが既に短期を見ている」＋「軸崩壊の検出は
`axis_sum` が上位互換」。

## 1. 何を作ったか（`scripts/exp_type_lab/shortform_build.py`）

🔴 **先に本番を読んだ。`FEATURE_COLS_WT` には短期量が既に大量に入っている**:

    win_3m / top3_3m / quin_3m / win_6m / top3_6m / quin_6m / venue_wr / days_since / wr_trend
    rp_prev_delta / rp_delta_90 / rp_delta_180 / rp_trend
    b_rate_90 / s_rate_90 / fh_rel_90 / fh_best_rate_90
    cup_n_so_far / cup_top3_rate / cup_win_rate / cup_mean_order_n

＝ **p3 モデルは「直近の調子」を既に見ている**。そこで**モデルに無い形**に絞った:

1. **走数ベース**の直近N走（N=3,5,10）。既存は全て**日数窓**で、出走間隔が空いた選手では中身が別物
2. **決まり手（`factor`）由来の短期脚質**（逃/捲/差/マ）。モデルは一度も使っていない
   （`ex_*` は汚染列として 2026-07-31 に除外済み）
3. **長期 `style` ラベルと直近実行のズレ**（脚質が変わっている選手）
4. **直近の欠車・失格**（`finish_order = 0`）。モデルは `finish_order >= 1` しか見ない

計 47本 / 27,799レース中 27,504 で全車全特徴が有限。

## 2. リーク検査（`shortform.py leak`）

| 検査 | 結果 |
|---|---|
| ① 独立再計算（`race_date <` で絞って直接 tail(N)）との一致 | `top3_5` / `b5` / `top3_10` とも **n=2,800 で不一致 0 件・最大差 0.000000** |
| ② 当日を窓に含めた場合（＝リークしていたらこう見える） | 自分の3着内を当てる AUC **0.596 → 0.801**（`top3` 直近5走）。当日を外せている |
| ③ ソース列の年次充足率 | `finish_order` 99.5〜100% / `res_back`・`final_half` 96.8〜100% / `factor` 28.0〜28.2%（1・2着のみ記録＝仕様）。**年で不連続なし＝後からの一括埋めではない** |

- 構造的な保証は `shift(1)` ＋ (race_date, race_no) 昇順。当日の自レースは必ず窓の外
- `finish_order` が NULL/0 の行は値を NaN 化（`add_rp_trend_features_wt` と同じ方針）
- 使ったのは**過去レースの結果列**だけ（`finish_order`/`res_back`/`res_standing`/
  `final_half`/`factor`/`race_point`）。`ex_*` は一切触っていない

**捨てた量**: なし（47本すべて上記①②を通過）。ただし `dnf3`/`dnf5` は
ほぼ全員 0 で中央値が 0 になり五分位・上下半分が作れない＝**実質使えない**。

## 3. 記述: 3着目になる率（`shortform.py desc`・軸2車そろい回の相手5車）

母数 20.00%。単調なのは次の3系統だけ（**両窓で単調**）:

| 量 | Q1 → Q5（確認） | Q1 → Q5（探索） |
|---|---|---|
| 直近10走 3着内率 | 12.47 → **25.00%** | 12.59 → **25.17%** |
| 直近10走 正規化着順（小=良） | 25.89 → **13.13%** | 25.60 → **12.93%** |
| 直近10走 上がり相対（負=速い） | 22.96 → **15.94%** | 22.43 → **15.56%** |

n = 20,200（確認）/ 50,200（探索）。
**長期の率は m=1 で 25〜27% しか取れなかったが、短期は記述レベルでは本物**。

## 4. 残差テスト（`shortform.py resid`）

p3 の相手順位（1..5）で層別し、層の中で短期量の上位半分／下位半分に割る。
母数は確認 42.30/24.21/16.83/10.97/5.69%。

**10セル中 10セルで同符号だったのは 1 つだけ**:

| 量 | 確認（順位1..5 の差） | 探索 |
|---|---|---|
| 直近10走 上がり相対（遅い側） | −3.1 / −2.6 / −2.1 / −1.0 / −1.1 | −3.1 / −3.0 / −1.6 / −1.9 / −1.7 |

次点は `mark10`（マーク率・順位1で +3.2/+3.3）と `sashi10`。
`ord10`・`top310` は順位1〜2で符号が割れる。

🟢 **長期の率は残差ゼロだった（全10セルで母数と区別できない）のに対し、短期は残差を持つ。**
ここまでは仮説どおり。

## 5. 相手選定に変換できるか（`shortform.py partner` ＋ 追加掃引）

軸2車そろい回の「3着目」を相手上位 m 車で覆える率（確認 n=4,040 / 探索 n=10,040）:

| 選び方 | m=1 確認 | m=1 探索 |
|---|---|---|
| モデル p3（現行） | 42.30% | 42.45% |
| 同ライン優先（既知の最良） | 44.68% | 44.90% |
| 短期単独: 直近10走 3着内率 | 26.93% | 27.34% |
| p3 + 0.1×直近10走 上がり相対 | 42.38% | 42.46% |
| p3 + 0.2×同 | 42.15% | 42.00% |
| p3 + 0.1×マーク率 / 差し率 / 着順 / 3着内率 | 41.7〜42.2% | 41.7〜42.4% |

**重み 0.1/0.2/0.4 × 6量 の 18腕すべて、両窓とも現行と同じか下**。
唯一 +0.08/+0.01pt の `上がり相対 w=0.1` も m=2/m=3 では負ける。

🔴 **残差はあるのに相手選定へ変換できない。** 機序は「残差の大きさが層内の順位を
入れ替えるほど無い」——上がり相対の残差は最大 3.1pt で、p3 の層間差
（42.30 → 24.21%、18pt）の 1/6 しかない。

## 6. 軸崩壊の事前検知（`shortform.py auc`・全商品 n=8,053 / 19,746・軸崩壊 49.8/49.2%）

| 量 | 確認 | 探索 |
|---|---|---|
| （参考）`axis_sum` | 0.353 | 0.341 |
| （参考）`rp_sd` | 0.428 | 0.433 |
| **直近10走 正規化着順: 軸2車 − 相手上位3** | **0.563** | **0.573** |
| 直近10走 逃げ率 / B取得率 / 自力率: 軸 − 相手 | 0.437〜0.441 | 0.434〜0.444 |

## 8. 商品にできるか

### 8-1. レース選別（`shortform_filter.py`・比較相手は**現行＝全件**）

確認 現行 24.08% / 探索 現行 24.17%。Δ は現行差。

| 腕 | 20% 落とす（確認） | （探索） | 33%（確認） | （探索） |
|---|---|---|---|---|
| 短期: 直近10走 着順 gap | +0.65pt | +1.07pt | +1.05pt | +1.37pt |
| 短期: 着順gap + 3着内率gap | +0.54 | +1.10 | +0.87 | +1.28 |
| **既存: `axis_sum` だけで同数落とす** | **+1.50** | **+1.57** | **+2.50** | **+2.92** |
| 既存+短期（z の和） | +1.64 | +1.65 | +2.07 | +2.52 |
| 無作為対照 20seed（平均） | 24.15% | 24.10% | 24.14% | 24.11% |

- 🟢 短期単独は無作為対照に勝つ（+0.5〜+1.1pt）。**だが対照に勝つのは採用理由にならない**
- 🔴 **全 dose で `axis_sum` 単独に負ける**
- 🔴 足しても効かない。Δ（足す − `axis_sum` のみ）のレース単位 bootstrap 95%CI:

      落とす 10%   確認 +0.06 [−0.25, +0.32]   探索 +0.08 [−0.06, +0.27]
      落とす 20%   確認 +0.14 [−0.33, +0.50]   探索 +0.08 [−0.19, +0.33]
      落とす 33%   確認 −0.44 [−1.06, +0.20]   探索 −0.41 [−0.78, −0.03]

  **dose を上げると符号が反転し、33% では探索窓で有意にマイナス**＝上積みは無い。
- ⚠️ どの絞りも **10万+/日 が 0.231 → 0.13〜0.18（−25〜−45%）** と看板を削る。

### 8-2. 型E/F の選抜確率へ載せる（`shortform.py product`・`exp(w·z)`）

点数・帯・配分・ゲートは現行のまま。対照は同じ z を車番シャッフル 20seed。

| 腕 | 確認 Δ表示的中 | 対照勝ち | 探索 Δ | 対照勝ち |
|---|---|---|---|---|
| 直近10走 上がり相対 w=0.3 | **−0.52pt** | 20/20 | **−0.05pt** | 20/20 |
| 同 w=0.6 | −2.55 | 20/20 | −1.92 | 20/20 |
| 直近10走 マーク率 w=0.3 | −0.99 | 17/20 | −0.96 | 20/20 |
| 直近10走 3着内率 w=0.3 | −1.18 | 14/20 | −0.50 | 20/20 |
| 直近10走 正規化着順 w=0.3 | −0.97 | 18/20 | −0.30 | 20/20 |

現行 = 確認 23.20% / 探索 22.71%（n=2,431 / 5,985）。

🔴 **全腕・両窓で現行より下。対照には勝つ**——`rate_line_branch` のライン β と同じ形
（＝二重計上）。ROI は上がる（76.2→79.0 / 70.8→75.6）が、この層の ROI は採否に使わない。

## 9. なぜ効かないか（機序）

1. **p3 モデルが既に短期を見ている**。`win_3m`/`top3_3m`/`b_rate_90`/`cup_*` など
   17列が `FEATURE_COLS_WT` に入っており、上から素の短期量を足すと**二重計上**になる
   （ライン β・長期の率と同じ）
2. **残差の大きさが足りない**。上がり相対の残差は最大 3.1pt で、p3 の層間差 18pt の 1/6。
   順位を入れ替えるほどの量ではない
3. **軸崩壊の検出では `axis_sum` が上位互換**。短期 gap が持つ情報は 8/10 セルで
   残差として見えるが、商品にすると `axis_sum` を動かすほうが常に強い
