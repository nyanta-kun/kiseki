# 事前登録: 二軸の「役割」を変えた2つの買い方（2026-09-30）

2026-09-30 の総合監査（波乱検知）で、二軸の選び方を 12 通り × 買い目の形で比べた（約 280 腕）。
現行を**両窓で** ROI で上回るものは無かったが、確認窓（2026-01〜08-04）だけ高く出た形が2つあり、
市場の歪み（下記）と機序が合うので、**判定窓を 2026-10〜12 に固定して前向きに測る**。
ここに書いた定義・判定を、判定窓のデータを見た後に変えてはいけない。

売らない。本番の生成（`src/type_lab.py`）にも入れない。判定は下記の台で行う。

## 1. 動機（2026-09-30 監査で見えた市場の歪み・両窓で同じ向き）

- 最強ラインの「先頭→番手」の1-2着を、確定市場は 6〜11% 安く見ている（実際/確定 1.065 / 1.112）
- 逃げ比率の高い選手の1着を、確定市場は 8〜11% 安く見ている（X3）
- 本番の三連単確率は逆に先頭の1着を高く見ている（モデル 42.6% ↔ 実際 37.6%）

⚠️ 同日の BT2 で、逃げ比率を 1着モデル（LightGBM）に入れても市場に対する増分は消えた。
   歪みは本物でも**それを取り込む形が見つかっていない**。ここで測るのは買い方の側。

## 2. 定義（7車のみ・朝の情報だけ）

共通:
- 3着内率 p3・1着率 pw は本番と同じモデル（判定では月次 vintage `*_mYYMM`）
- 三連単の確率 = 本番の入稿確率 `rank_7t3_blend_probs`、予測オッズ = `odds_tf_n7`（train_end 2025-12-31）
- 予算 10,000円・100円単位・各点 100円以上を置いて残りを重みで配る（端数は重み最大の点へ）
- 配分はダッチ（重み = 1/予測オッズ）
- 相手の選び方「同ライン優先→p3順」: 軸2車のどちらかと同じライン（2車以上のライン）の車を先に、
  残りを p3 の降順で。軸は除く

### BT3「自力軸＋番手軸」
- 軸: 2車以上のラインのうち **p3(先頭)＋p3(番手)** が最大のラインの **先頭 A・番手 B**
  （隊列の位置 1・2。そういうラインが無ければ p3 上位2車）
- 相手: 同ライン優先→p3順で **2車**
- 買い目: 三連単 **A→B→相手** の2点

### BT4「能力軸＋期待値軸」
- 軸 A: p3 1位
- 軸 B: A を除いて **モデル3着内確率 ÷ 市場3着内確率** が最大の車
  - モデル3着内確率 = 三連単確率を車ごとに足したもの
  - 市場3着内確率 = 予測オッズの逆数をレース内で正規化し、車ごとに足したもの
- 相手: 同ライン優先→p3順で **2車**
- 買い目: 三連複 **{A,B,相手}** の2点

参照実装（確認窓の数字を出したもの）: 2026-09-30 監査 X4 の `x4lib.py`
（`axes_defs` の「自力+番手(最強ライン)」「能力軸+期待値軸(比最大)」・`partners(rule="line_p3")`・
`legs("S1"/"T")`・`ticket(alloc="dutch")`）。

## 4. 判定（2026-10-01〜2026-12-31・一度だけ評価する）

台: 7車の比較台を 2026-10〜12 まで延長する（p3/pw は月次 vintage、予測オッズは `odds_tf_n7`）。
母集団: **その日に現行ラインナップ（本番の lineup の再現）が売ったレース**。現行の買い目と同一レースで比べる。
統計: 日クラスタ・ブートストラップ 2,000本。

| | 採用候補の条件（すべて満たす） |
|---|---|
| BT3 | n >= 300 レース ∧ 現行との ROI 差の 95%CI 下限 > 0 ∧ 4万+/日 が現行の 80% 以上 |
| BT4 | n >= 300 レース ∧ 現行との ROI 差の 95%CI 下限 > 0 ∧ 万車券レースの捕捉率が現行の 2倍以上 |

- 満たさなければ不採用として記録する。判定窓で形・閾値・母集団を選び直さない
- 満たしても**すぐには売らない**。売るかどうかは、置き換える枠（A/C_hit の一部・高額枠の一部）を
  決めてからユーザーが判断する
- 見る指標（判定以外は参考）: 件/日・表示的中・ROI・払戻中央・3万+/4万+/10万+ 件/日・万車券捕捉・
  ガミ率・最大連敗・最大ドローダウン
