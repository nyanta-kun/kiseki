## 1. レースの型（A〜F）

判定の正本は `src/type_lab.py::race_shape`。入力は**発走前に確定するものだけ**
（3着内率・1着率・ライン構成・脚質・競走得点・遅れ率・開催日目）。

### 1.1 第1軸 — 軸の堅さ `axis_sum`

    axis_sum = 3着内率の上位2車の合計
    axis_sum >= AXIS_SUM_FIRM (= 1.44)  →  堅い側（A / B / C）
                            未満        →  崩れ側（D / E / F）

この 1.44 は旧 7C の受理閾値と同じ値で、**二軸そろい率を 66% ↔ 39% に分ける**
（`docs/type_lab/`・レースの型3層の第1層）。

### 1.2 第2軸 — 荒れ度 `s`（ライン構造）

指数1位が属するラインの形から作る整数スコア。

| 条件 | s への加算 |
|---|---|
| ライン人数 2人 | **+1** |
| ライン人数 4人以上 | −1 |
| 先頭の遅れ率 >= 11.0% | −1 / 未満なら +1 |
| 先頭の脚質が「追」 | +2 |
| 開催日目 − 2 | −1 〜 +1 |
| 番手の競走得点 > 先頭の競走得点 | +1 |

    堅い側:  s <= -1 → A（鉄板）  /  s == 0 → B（堅い・中） /  s >= 1 → C（堅いが崩れ筋）
    崩れ側:  s <= -1 → D（混戦・軸あり）/ s == 0 → E（混戦・中）/ s >= 1 → F（大混戦）

🔴 **「指数1位が2人ラインにいる」が単独で最も危険**（二軸そろい 43.9% ↔ 4人ライン 65.9%
↔ 単騎 62.6% で**非単調**）。だから人数は単調な重みになっていない。

### 1.3 補助 — `pw_ent`（1着率の読みにくさ）と `gap`（相手の開き）

- `pw_ent` = 1着率のエントロピー。**型A の振り分けにだけ使う**（§2.2）
- `gap` = 全体3・4番手の平均 − 5〜7番手の平均。**計算しているが商品には使っていない**。
  分離は本物（順当 28.0→44.5%）だが**両向きとも窓で符号が反転**し、`axis_sum` との
  相関も +0.363 で独立でない → 不採用（`docs/type_lab/gap_gate_2026_08_28.md`）

## 3. 入稿までの関門

売ると決めた1商品が、netkeirin へ出るまでに4つ通る。実装は
`scripts/netkeirin_submit_type_lab.py`。

### 3.1 平均想定払戻 > 20,000円（`MIN_MEAN_PAYOUT`）

🔴 **これが「何点買えるか」を決めている唯一の式。** ダッチング（賭け金 ∝ 1/予測オッズ）では
どの点が当たっても払戻が同額になるので

    平均想定払戻 = 予算 ÷ Σ(1/予測オッズ)

つまり `> 20,000` は **`Σ(1/予測オッズ) < 0.5`＝買い目の市場シェア 37.5% 未満**と同値。
型A/B で三連複が成立しないのはこれ（相手3点で 0.62〜0.66件/日しか通らない）。

### 3.2 1点の最低予測オッズ >= 2.0（`MIN_POINT_ODDS`）

**比なので予算を上げても通らない。** ダッチだと点数を増やすほど最低オッズが上がるので、
これが実質的な点数の上限になる。

### 3.3 軸信頼ゲート（`AXIS_GATE_MIN`）

プランごとに `axis_sum` の下限を持つ。値は**探索窓2025でそのプランが選ばれた行の p20**。

| プラン | 下限 | プラン | 下限 |
|---|---|---|---|
| `A_hit` / `A_pay` | 1.537 | `C_hit` | 1.480 |
| `A_trio` | 1.499 | `D_hit` | 1.263 |
| `A_ana` | 1.470 | `E_hit` | 1.245 |
| `B_hit` | 1.504 | `F_hit` / `F_pay` / `F_sign` | 1.230 |

🔴 **知らないプランは通す。** 閾値が無いことを理由に商品を止めない
（新設プランが静かに全滅するのを防ぐ）。代わりに
「売りうるプランは必ず閾値を持つ」ことをテストで固定している。

効果は 29.5件/日・ROI 85.0% [78.2, 92.9]・表示的中 24.5→27.8%。
**一連の検証で初めて無作為対照20本に 20/20 で勝った腕。**
代償は 10万+ が 0.102→0.034件/日（看板が1/3）。

### 3.4 入力健全性

並び予想・AI印が未公開のレースは**出さない**（`entry_health.missing_market_inputs`）。
🔴 欠測は欠測として扱われない——印なし＝最弱・ライン無し＝全員同ラインと読まれ、
**エラーなしで指数もオッズも静かにずれる**（2026-08-26 熊本の全7Rで実際に起きた）。
看板穴埋めより優先する。

### 3.5 日次上限

    上限 = max(1, int(その回に判定するレース数 × 0.5))

- **枠外**（`daily_cap_exempt`）: 9車 / 決勝 / 準決勝 / グレード3以上。
  分母からも上限の消費からも外す
- **残す順** = `(2 × 軸信頼のプラン内順位 + 実力伯仲のプラン内順位) / 3`
  - 実力伯仲 = `rp_sd`（レース内の競走得点の標準偏差）。`axis_sum` と相関 0.220 で
    ほぼ独立なのに、**軸信頼の五分位すべてで両窓とも軸崩壊率を約2倍に分ける**
  - 同件数で表示的中 +0.28〜+1.00pt（両窓とも CI が 0 超）。10万+ も多く残る
- 🔴 **読めなければ上限を掛けない**（fail-open）。0 として扱うと**1件も入稿されない**
- 🔴 **判定を見送ったレースは分母に入れない**。昼・夜の枠が 0 になるため

### 3.6 高額枠（2026-09-06〜）

**上限で捨てるレースに `{型}_sign` を置く**。既存商品は1件も減らない。

    型B / 型C / 型D ∧ 7車 ∧ 上限に当たった行  → 1日 5本まで
      1・3・5本目 → {型}_sign（計画払戻15万・軸1も買う）
      2・4本目   → {型}_big （計画払戻40万・**軸1を1点も買わない**）
    （`type_lab.HIGHPAY_TYPES` / `HIGHPAY_SLOTS_PER_DAY` / `HIGHPAY_BIG_SLOTS` /
      `HIGHPAY_BIG_TARGET` / `highpay_plan_for`）

- **本数はその日で数える**（波をまたいで5本）。出自は `origin='highpay_fill'` で
  記録するので、通常の商品と分けて成績を追える
- **上限の枠は消費しない**（枠外と同じ扱い）。消費すると高額枠を出した日ほど
  通常の商品が減る
- 入稿ゲート（想定払戻・1点オッズ）は掛ける。軸信頼ゲートは**掛けない**
  （母集団が定義上「軸信頼の低い側」なので絞る意味が無い。`F_sign` と同じ理由）
- 期待値（`type_lab_picks` paper・落とす側の型B+C+D・探索2025 / 確認2026）:

- 🔴 **型A・型E は入れない**（両窓とも ROI が壁の下・48.7〜70.6%）。

- ⚠️ 代償は**表示的中 約 −1.9pt**（5本 × 的中5% を 47件/日 に足す算数）。

- **30万超は `{型}_big` でしか出ない**（2026-09-06・ユーザー判断②）。計画15万は

## 4. 確率と予測オッズ

### 4.1 買い目の確率

`strategy_wt.rank_7t3_blend_probs` — **位置別合成 Plackett–Luce ＋ 同ライン隣接ボーナス**。

    a = normalize(1着率), b = normalize(3着内率)
    s_i = normalize(a**w_i × b**(1-w_i)),  w = (1, 0.5, 0)
    P(x,y,z) = s0[x] × s1[y]/(1-s1[x]) × s2[z]/(1-s2[x]-s2[y])
    P(x,y,z) ← P(x,y,z) × λ^[y は x の直後] × μ^[z は y の直後]      λ=2.0, μ=1.5

🔴 **周辺確率の積ではライン依存を表現できない。** PL と実測が食い違う 68.9% のうち
**29.8% は「2着に別ラインの車」**（二軸そろい 22.31% ↔ 11.65%）。
ボーナスを入れると top1的中 +0.96/+1.01pt・ROI +6.9/+13.7pt（両窓とも有意・9/9四半期プラス）。

🔴 **ボーナスは「配分」ではなく「絞り込み」に使って初めて効く。**
配分だけに入れると逆に悪化する（32.84→32.32%）。確率順で点を選ぶ側に効かせること。

### 4.2 予測オッズ

**完全に自前モデル**（`odds_tf_n7/n9`＝三連単・`odds_trio_n7/n9`＝三連複）。
🔴 **板（`wt_odds`）は入稿経路では一切読まない**（2026-08-26 に最後の三連単経路を撤去）。
朝は板が薄く、薄い板ほど大きく出る歪みがあるため。

### 4.3 表示の保守倍率

計画の払戻をそのまま画面に出すと**確定がそれを割る**。判定量は k点の最小なので、
`backend/src/services/keirin_payout_floor.py` が**券種 × 点数**の下側25%分位を掛ける。

    trio     1点 0.917 → 5点 0.638 → 14点 0.519
    trifecta 1点 0.821 → 5点 0.579 → 14点 0.487

導入で「表示を確定が割る割合 56.7 → 29.9%」・ガミ警告の再現率 15 → 52.5%。
**入稿の中身は変えていない**（表示と看板の不揃いを直しただけ）。

## 6. 数字の読み方（この領域の作法）

🔴 **ROI で採否を決めない。** この層で ROI を ±2.5pt に収めるには**約15.6年**かかる。
月次で見てよいのは **件数・表示的中・払戻中央値**の3つ。

🔴 **件数を減らす検証には必ず無作為対照を置く。** 件数が減ると CI が広がり、
上振れを効果と誤読する。実際「型・種別・場で絞る」全案（79.5〜81.3%）は
**無作為半分の対照（83.0〜84.8%）に負けていた**。

🔴 **対照は 20 seed。3 seed では足りない**（2026-08-27 の否定はその3本が
自分のベースラインを +2.9〜4.7pt 上回る上振れだった。20seed 中央値だと結論が逆転した）。

🔴 **窓は2つ**（探索 2025 / 確認 2026-01〜08-04）。**両窓で符号が一致しないものは採らない。**

🔴 **表示的中＝ガミを除いた的中**（払戻 > 賭け金）。netkeirin の表示もこちら。
生の的中率と混ぜない。

🔴 **控除率25%の壁が成り立つのは25倍未満まで。** 型A三連複の帯別回収率は
0〜25倍 73〜84% ↔ 25〜50倍 54〜69% ↔ 100倍+ 36〜45%。
**高配当商品は精度ではなく値付けで負ける。**

## 7. 決着済み（再検証しない）

| 案 | 結果 |
|---|---|
| 期待値で優先順位を並べる | **EV最大と EV最小が同じ結果**（全商品の EV がほぼ同じ＝市場が全部を壁へ値付け） |
| `gap`（相手の開き）で絞る | 分離は本物だが**両向きとも窓で符号反転**・`axis_sum` と相関 0.363 |
| 落車失格レースの学習除外・重み付け | 3通りとも分離が改善せず。AUC も不動 |
| 型A の波乱検出（買いへの変換） | 構造は本物だが**丸ごと人気薄帯**で ROI 55〜74%。100倍+の40.5%が軸崩壊 |
| 型E の精度向上 | 的中率は上げられるが **ROI がついてこない**（Σ五分位でも平ら） |
| 「軸が不利」な指数 | 脚質・単騎・ライン内位置・人数・遅れ率・先行争い・WT印・市場不一致＋合成6種が**すべて AUC 0.46〜0.53** |
| レースを型・種別・場で厳選 | **無作為対照に負ける**（絞りは ROI を動かしていない） |
| 明示的な形の制約（3車BOX・1着固定×2着2車・二軸流し） | 4形とも両窓で確率上位に負ける |
| ユーザー案「1軸固定+2軸目2点」 | 三連複では順不同で同じ族＝差ゼロ。三連単でも確率上位に負ける |
| 均等配分 | 全型で壊れる（均等k点のガミ率 ≈ P(確定 < k倍)）。**ダッチ一択** |
| 帯フィルタ（C 15倍+ / E 30倍+）は本命を捨てているのでは | **バグではない**。ダッチでは帯は `Σ(1/O) <= 予算/T` の粗い代理 |
| 型C に合成オッズの下限を足す | 帯15倍の上で測ると**表示的中 −1.6pt（C_hit は −7.4pt）**・ROI は窓で符号反転。帯を下げた直後に点数も減らすことになる（`docs/type_lab/synthetic_floor_recheck_2026_09_02.md`） |

**一般則**: 市場と同じ向きの分類器は、精度がどれだけ高くても ROI にならない。
新しい案は ①市場に無い予測はあるか → ②それは市場と**逆**を向いているか →
③そこで初めて買い方を探す、の順で立てる。

## 8. いま決まっていないこと（追加検証の候補）

1. **券種の変更**（型E ほか）— 可能。ただし総払戻・的中率との兼ね合いで判断する。
   実測では三連複4点へ振ると表示的中 +1.1〜1.5pt だが **ΔROI は窓で符号反転**
2. **モデル確率の較正崩れ** — 集中度で系統的にずれる（τ到達点数 1-2点 +5.4/+3.6pt →
   15点+ −7.6/−3.5pt・両窓単調）。人気-穴バイアスも8帯単調
   （実測/モデル 0〜5倍 1.52 → 300倍+ 0.78）。
   🔴 **並べ直しても +0.2pt で誤差**だったが、`p3` モデルの特徴量側で直す案は未検証
3. **`rp_sd` を p3 モデルの特徴量に入れる** — いまは上限の順位付けにしか使っていない
4. **旧ランクのペーパー継続** — 商品として使えるものが残っていないかの材料。
   `lgbm_wt_favbust_m2609` まで vintage を揃えて honest に測れる状態にしてある
5. **カバレッジ τ の一本化** — 現行の6つの固定点数は τ≈0.29 の近似で、
   統一しても収支は動かない（定数6→1の整理としては有効）
