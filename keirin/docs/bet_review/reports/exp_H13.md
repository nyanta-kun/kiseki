## 1. 目的変数の定義（実データで確認してから）

| 列 | 実測した意味 |
|---|---|
| `res_back`（B） | **有無（0/1）**。1レースに**ちょうど1人**（2023-10〜2025-12 の 61,859 レース中 61,720 が合計1、139 が合計0）。欠損は 195 行（レース単位）。B を取るのは `line_pos=1` の選手が 28%、脚質「逃」が 40%、「追」は 0.6% |
| `res_standing`（S） | **有無（0/1）**。1レースに**0人か1人**（合計0が 7,074R＝約11%・合計2以上は無し）。2025 の7車では S 無しが上期 7.6%・下期 5.0% |
| 同一人が S と B | 2.9% |

- 目視した1レース（`20250311_35_05`・7車）: 車番5（両・line_group1 の先頭・`res_back`=1・finish 1着）が B、車番1（追・同ライン番手）が S、というように **B は先頭が取り S は別の選手が取る**ことが多い。
- **主**: B を取った選手（レース内でちょうど1人のレースのみ）。**副**: S を取った選手（ちょうど1人のレースのみ）。
- 🔴 `s_count`/`h_count`/`b_count` と決まり手累計は**特徴量に使っていない**。直近窓の累計で、取得時点が確認できず、`Δb_count` が当該レースの `res_back` とも前走の `res_back` とも相関する（リークを否定できない）。代わりに選手単位の point-in-time 率（本番 `add_sb_dyn_features_wt` の `b_rate_90`・`s_rate_90`・`fh_*`、自前の `b_rate_365`・確定走数。いずれも `closed="left"`）を使った。事前登録の「S/B 傾向（`s_count`・`b_count`・`b_rate_90` 等）」のうち `s_count`・`b_count` を外した点が文面との差分。
- 結果列（`finish_order`・`res_*`・`final_half`）は履歴の集計にだけ使い、特徴行には残さない。出走取消・失格（`finish_order<1`）の選手は発走前には分からないので**候補に残した**（履歴集計からだけ外れる＝本番と同じ）。`cancel=1` のレース（869行）は除外。

## 2. モデルと母集団

- 入力 39 列（`h13_features.py` の `FEATURES`）: 選手の B/S 傾向（`b_rate_90`/`s_rate_90`/`b_rate_365`/`fh_*`）・脚質・`prediction_mark`（**記者予想＝市場寄りの発走前情報**。入れている）・ライン内位置・得点、**同じレースの相手との相対量**（B 率のレース内順位／シェア／他選手最大との差・逃の人数・他ラインの先頭の B 率の最大・自ラインの人数と得点合計・自ラインで自分より前の僚機の B 率 等）。予測はレース内で合計1に正規化。
- 学習 = 2024-01-01〜12-31（5〜9車・B（S）がちょうど1人のレース。B 27,619R／S 23,989R）。早期停止は 2024-11〜12 を検証にして反復数を決め（B 354・S 336）、同じ反復数×1.1 で 2024 全体を refit。**2025 は学習・停止・ハイパラのいずれにも使っていない**（LightGBM のパラメータは固定・掃引せず。2023-10〜12 は 90 日窓の warm-up 専用）。
- 評価 = `race_type_board.npz` の 2025・7車 17,756R のうち B ちょうど1人の **17,753R**（S は **16,650R**）。上期 8,643R／下期 9,110R（B）。
- **ライン情報の欠測**: この抽出の `line_group`/`line_pos` 欠損は 0＝**DB の最終状態**で、朝の欠測（`reports/feature_audit.md`）を再現していない。朝に並びが取れないレースでは新特徴の一部が使えなくなるので、ここでの精度は**朝版の上限寄り**。

## 6. 付記（読む人への注意・採否には触れない）

- Step0a の差は、評価に使ったレースの「その日の組み合わせ」特徴（相対量）と `b_rate_365`・ライン内位置の寄与を含む。素朴との差のうち相対量だけの寄与は分けて測っていない（事前登録の範囲外）。
- (iii) 隊列推定の top1 は1点指名なので logloss が出ない。確率化する手段は事前登録に無く作っていない。
- 同率の top1 は車番最小で解いている（素朴の同率＝全員 B 率 0 のレースがあるため、素朴の的中率はこの規則に依存する）。
- B 取りの予測は 0a では素朴・隊列推定より有意に良いが、0b（最終オッズに対する1-2着の倍率）では隊列推定を下回り、不一致レースでは新の選ぶラインのほうが当たるのに最終オッズがそれ以上に織り込んでいる。
