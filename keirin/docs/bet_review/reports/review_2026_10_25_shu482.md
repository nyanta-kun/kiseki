## 1. 結論（先に）

1. **482 は「人気決着しそうなレースを避ける」選び方をしていない。** 選んだレースと選ばなかったレースで、
   市場の集中度・最低三連単・当たり目の倍率と人気は同じ（§2.2）。
   高額の正体は**買い目の側**で、3点前後の中に 21〜100番人気の目を入れ、1点 2,000〜5,000円を置いている。
2. **482 の回収率は控除率の壁の上にあるとは言えない。** 85日で 78.6% [62.5, 96.4]・**最大3本を除くと 68.5%**。
   高額は分散の作り方であって収支の証拠ではない（playbook §1.4 の再確認）。
3. **予算が1レース1万円で固定なら、的中率と高額の頻度は交換関係にある**（`P(払戻≥T) ≈ 回収率×予算/T`）。
   自社モデルでも同じ交換関係が出た。**3指標すべてで 482 を上回る単一の商品は作れない。**
   - 482 の形（確率上位2〜3点・均等）を自社で組むと: 表示的中 15〜17%（482 の約2倍）・50万+ はほぼ0
   - ご提案の形（予測100倍超×2点・5,000円）: **50万+ が 482 の 2.3倍**（0.66% ↔ 0.285%。482 の
     95%CI は [0.15, 0.50]% なので区別できる）。代わりに表示的中は 1.3%（482 は 7.9%）。
     ⚠️ 自社は 2026-01〜08、482 は 08-01〜10-24 で窓が違う
   - 2つを**混ぜる**と、的中 8.8%・50万+ 0.35%・回収率 73% [64, 83] で、**482 と同じ位置に並ぶ**
     （的中・50万+・回収率とも区別できない）。10万+ は 1.34%（482 は 1.76%）で下回る（§4.2）
4. **50〜100万狙いの推奨は作れる。** 確認窓で最も良かったのは次の2つ（§4）:
   - **50万狙い: 予測200倍超を確率順に3点・3,300円**（予測どおりなら当たって66万円以上。確定オッズが予測より下がると届かない）— 50万+ 0.77%・
     100万+ 0.23%・表示的中 1.1%・回収率 81.5% [66, 98]（探索窓 80.4%）
   - **100万狙い: 予測200倍超を2点・5,000円**（予測どおりなら100万円以上）— 50万+ 0.63%・100万+ 0.36%・
     表示的中 0.7%
   - 1日48本売れば 50万+ は月約11回。代わりに**払戻0円の日が 58〜69%** ある
   - 300倍超・500倍超へ上げて点数を増やす形は、50万+ も回収率も 200倍超より悪い

### 4.1 人気決着しそうなレースを避けると良くなるか — ならない

発走前に分かる「予測オッズ上位5目の市場シェア」で5分位に分けた（Q5＝人気決着しそう）。
「予測100倍+ 上位2点」の 50万+ は 探索 0.80 / 0.75 / 0.87 / 0.58 / **0.80%**、確認 0.67 / 0.88 / 0.72 / 0.63 / **0.43%**。
**窓で順序がそろわない。** 確認窓では Q5 が最も悪いが、探索窓では Q1 と同じ。
既存の否定結果（`docs/trifecta_playbook.md` §3.2：荒れ指標・混戦度での選別は全滅）と同じ結論。
🔴 **選別すると件数だけが減り、1日あたりの 50万+ が減る。** 50万+ の本数は件数に比例する。

## 5. 提案

| 案 | 中身 | 見込み（7車・確認窓・1本あたり） | 判断が要るところ |

| **A. 50万狙いの一撃枠（推奨）** | 予測200倍超の目を確率順に3点・3,300円ずつ。レースは選ばない | 50万+ 0.77% / 100万+ 0.23% / 表示的中 1.1% / 回収率 81.5% [66, 98] | 1日10本なら 50万+ 月約2.3回。**0円の日が大半** |

| C. ご提案そのまま | 予測100倍超を2点・5,000円ずつ | 50万+ 0.66% / 100万+ 0.14% / 表示的中 1.3% | A より 50万+ が少ない（回収率は点推定で劣るが CI は重なる） |

- 🔴 どの案も**回収率を上げる提案ではない**。動くのは「当たる頻度」と「当たったときの大きさ」の配分だけ。
  A の回収率 81.5% も CI [66, 98] で壁（75%）と区別できない
- 50万+ の本数は**売る本数に比例する**。482 は1日約50本売っているから週1回の50万+ が出ている。
  自社で同じ頻度を出すには、A を1日20本前後売る必要がある（20本で 50万+ 約0.15/日）
- 既存の `*_big`（軸1外し・計画40万）は `HIGHPAY_BIG_SLOTS` を戻せば再開できるが、
  本検証では「軸1外し」より「確率順のまま高倍率に限る」方が 50万+ も回収率も良かった

## 6. 限界

- 482 の数字は 85日。**回収率の CI は ±17pt** あり、自社のどの腕とも区別できない
- 検証台は 7車だけ。9車（482 の 9%）は測っていない
- 検証台の払戻は確定オッズ。予測で100倍超でも確定で下がることがあるが、払戻は確定値で数えているので中立
- 50万+ の件数は確認窓で1腕あたり 40〜70件。**順序は信頼できるが、絶対値は ±30% 程度ぶれる**
- 482 の買い目の形は 8月の詳細ページ調査に依存している。9月以降は一覧だけで見たが、
  的中1点の賭け金の分布（中央 2,500円・p90 10,000円）は8月と同じだった
