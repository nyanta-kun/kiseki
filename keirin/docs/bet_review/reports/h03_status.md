# H03 現状確認 — 決勝は軸信頼ゲートで落ちているか（2026-10-05 実測・読み取りのみ）

採否は書かない。対象は `race_type` が「決勝」「チャレンジ決勝」に**完全一致**するレース（ガールズ決勝・準決勝・チャレンジ準決勝は除く）。
`wt_races.status=3`（終了）のみ数えた。2026-10-05 当日の決勝3件（status=1）は判定前なので除外。

## 1. 本番コードで決勝が落ちうる段（`netkeirin_submit_type_lab.py::_reject` の順）

| 段 | 決勝への効き | 落ちた記録 |
|---|---|---|
| 無効化・既出・別ランクが取得済み | 静かに除外（記録なし） | なし |
| 発走15分前を過ぎた（closed） | 波（朝/昼/夕）が遅れたときだけ | `submission_skips.reason_code='closed'` |
| 並び・AI印の欠測（missing_lineup） | 欠測のレース | `missing_lineup`（後の波で再判定） |
| **軸信頼ゲート** `_passes_axis_gate` → `keirin_type_lab_gate.passes_axis_gate` | **7車のみ**。9車・axis_sum欠測・表に無いプラン(A_ana, T_*)は通す。決勝の免除は無い | `axis_gate`（reason_text に軸信頼値）。`type_lab_picks.axis_sum` と `AXIS_GATE_MIN` で再現可 |
| 入稿ゲート `_gate_reason`（平均払戻・1点オッズ・想定払戻下限） | 決勝も掛かる | `gate_mean_payout` / `gate_point_odds` / `gate_expected_floor` |
| 日次上限 | `daily_cap_exempt` が「決勝」を部分一致で枠外にし、`_priority`=1.0 ＝**決勝は落ちない** | `daily_cap`（決勝には出ていない） |
| 後段の救済 | 軸ゲート落ちは高額枠（B/C/D のみ）へ差し替え可。出せたときは `axis_gate` を**記録しない**。さらに `L_lead`（逃げ先頭ライン）が無商品レースに足される（2026-09-24〜） | `netkeirin_submissions.origin` = `highpay_fill` / `line_lead` |

現行 p20 の下限: A_hit 1.595 / A_trio 1.504 / B_hit 1.483 / C_hit 1.469 / D_hit 1.265 / E_hit 1.263 / F_hit 1.246 / F_sign 1.238。
