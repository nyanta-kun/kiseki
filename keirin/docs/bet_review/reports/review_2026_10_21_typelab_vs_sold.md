## 2. 紙上が良く見える理由 — 1レースに 7 本の行がある

| 後知恵で各レースの最良の行を選ぶ | **378.8%**（10万+ の行があったレース 189R） |
| 各レースで行を無作為に1本選ぶ（500回） | 中央 77.5% [61.4, 93.4] |

### 4.3 読み方の注意

- 売らなかったレースの行は昼・夕の組み直し後（並び・オッズが後の時点）、売ったレースの行は入稿時点で止まる。
  段だけが売るレースは後の情報で組まれている。**両方が売ったレース（1,304R）の比較が清潔な側**。
- 実売の側は窓の中で規則が4回変わっている（#606/#607 は 09-22〜23、並び違いの押さえ・穴狙いアイコン・
  決勝の軸信頼ゲート免除 A/B は 10-12）。段の規則は窓の中で固定。

## 5. 「スランプなく一定の回収率」について（実売・09-01〜10-20・50日）

日次回収率: p10 39.8 / p25 50.3 / 中央 64.4 / p75 85.0 / p90 115.4%。50%割れは 50日中 12日。
週次: 49.7〜95.1%。月次: 9月 75.4% / 10月 71.8%。

- 監査（`AUDIT_2026_09_20.md`）どおり、買い方の工夫で届く回収率の上限は 78〜82%。**組合せを変えて
  日次・週次で 100% を安定して超える形は、この台でも H01〜H22 の仮説でも見つかっていない**
- 「スランプを減らす」と「高額払戻」は同じダイヤルの両端（H09・plan_switch 10/17）。穴系（的中 3〜6%）の本数を
  減らせば日次の底は上がるが 10万+ が算術どおり減る。段の規則は今回の窓で日次中央 +8.9pt・週の最低 +13.8pt と
  見えたが、§4.2 のとおり大半は `L_lead` を売っていたレースの差で、型ラボの商品どうしでは差がほぼ無い

## 6. 結論

1. 型ラボ画面の高額払戻の多さは、**1レース7本の行のどれかが当たる**ことによる見え方。事前に同じ商品を選ぶ方法は無い（§2）。
2. 同じレースで商品を一律に差し替える案（`_sign`/`_big`/`_hit`/段の各プラン）に、多重比較を越えて確かな改善は無い（§3）。
3. 販売停止中の段の規則（停止は1日の結果による判断）を本番の関数で組み直すと全体で +3.7pt [−5.5, +12.3]。
   ただし**型ラボの通常の商品どうしでは +1.2pt [−11.0, +13.7]**で、上乗せのほとんどは実売の `L_lead`（この窓 31.4%）を
   置き換えた分（§4.2）。段そのものの優位は示せていない。
4. 日・週・月の安定した 100% 超は、組合せの見直しでは届かない（§5）。
