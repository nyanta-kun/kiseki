### 0.3 事前登録が決めていなかった点の解釈（結果を見る前に `h19_build.py` の docstring に固定したもの）
1. **k≥4**（p3≥0.60 が4人以上）は k=3 として扱い、堅い3車は p3 上位3車。
2. **k=3**: 堅い3車の6並びを `rank_7t3_blend_probs` の確率降順に足し、合成 2.2 倍を割る直前（`break`）で止める。**先頭1点でも 1/予測オッズ > 1/2.2（＝1点の予測オッズ < 2.2 倍）なら「捨てる」**。丸め後に本番ゲートを割る場合も捨てる。3a=見送り、3b=穴目（型A→`A_ana`、他→`T_upset`・`S.build`＋`S.gate_ok`・落ちたら見送り）。
3. **k=2**: 相手1車ごとに (a,b,c),(b,a,c) の**2点組**で p3 降順に足す。最小1相手（2点）に上丸め。2.0 倍未満の点を含む・平均2万円未満なら組めない。
4. **k=1**: `tier_axis` のコード形（候補＝その1車が1着の目→確率順→cap で k_fit→`max(3, min(8, k_fit))`→2.0倍未満を除いて先頭 k 点）。1着は「堅い1車」で、`win_top`・gap 条件は使わない。
5. **k=1/2 で組めない**（本番ゲートを割る）場合は ① に戻す（k=1: 38R・k=2: 815R。捨て規則を持つのは k=3 だけ）。k=0 も ①。
6. **④**: ②（③）と同じ点数を、210目から確率降順・2.0 倍未満を除いて先頭 n 点・dutch（形の制約なし）。買うレースは ②（③）と同一。**④ は合成 2.2 倍・平均2万円のゲートを掛けていない（事前登録の定義どおり・点数だけを揃える対照）。実測（②が組めた 11,046R）で ④₂ の 24.0% が合成 2.2 倍未満・14.2% が本番の入稿ゲート落ち（②は 3.7% / 0%）。k=2 では 29.4% / 17.5%。したがって ②−④₂ の差は「形」だけでなく「④ が安い（当たりやすい）目も買っている」効果を含む（表は §4.2 の前）。**③ の穴目に対する ④₃ は「確率上位 n 点」で穴とは別物**なので、k=3 の捨てレースの ③−④₃ は弱い比較。
7. **判定の版**: 事前登録の「②または③ − ①」は、② が k=3 で見送る（投資が減る）ので 2 通りの読みがある。**V1 = ② の全体 vs ① の全体**（見送りで投資が減る分も含む）、**V2 = ① を ② が買ったレースに絞った対比**。両方出し、判定も両方に出す（結論は同じ）。表示的中 = 払戻 > 投資、的中率 = 払戻 > 0、10万+ = 払戻 ≥ 10万円（/日は 365 日で割る）。
8. **「上期・下期で同符号」**は ΔROI と Δ表示的中のそれぞれについて、上期と下期の点推定の符号が一致することとして機械的に判定した。
