### 0.3 事前登録が決めていなかった点の解釈（結果を見る前に `h22_build.py` の docstring に固定したもの）
1. **頭 H** = 二軸のうち pw の高い方。pw が同値なら `order[0]`（実測 H = `order[0]`（p3 1位）は 90.3%）。
2. **単騎** = 台の LG は '' / '0' を持たず、単騎は「1人だけのグループ」。単騎 = そのグループの人数が 1。二軸の片方が単騎なら、その軸からは同ライン候補は出ない。
3. **Pline**: 同ライン候補 = 二軸のどちらかと同じ（2人以上の）ライン内の非軸の車。距離 = 同ラインにいる軸との |ライン内位置の差| の最小（二軸が同ライン・別ラインのどちらも同じ式）。距離の昇順 → p3 降順 → 車番で並べて先に採り、足りなければ残りを p3 降順で補う（単騎も他のライン外の車と同列）。
4. **Pline_t**: 同ライン候補は Pline と同じ。補う段で、単騎は脚質 逃/両 のものだけを p3 順に残し、追の単騎は「同ライン候補＋残した車」が 2 車に満たないときだけ末尾から補う。全員単騎のレース（7グループ）は Pline_t = Pline とする規則も置いたが、**該当は 0R**（発動しなかった）。
5. **候補集合 U** は `po_tf` に無い目を除く（vintage は全 210 目そろうので影響なし）。
6. **F6**: U を確率降順（同値は目の辞書順）に並べ、Σ(1/予測オッズ) が 1/(T/1万円) を超える手前（break）まで積む。**先頭1点だけで超える場合も 1 点は持つ**（最低1点）。このとき合成 < T なので見送りになる。
7. **見送り** = 実際に買う stakes（`allocate` が 0円の点を落とした後）の合成 = 1/Σ(1/予測オッズ) × 1万円 < T。入稿ゲート落ちは見送りとは別に数える（どちらも買わない）。T の境界は合成 ≥ T（等号は買う）。
8. **F6 × T なし**: F6 の積み上げに T が要るので、「T=3万で積んだ買い目を、見送りだけ外して（入稿ゲートのみで）買う」と固定した。③ の母集団もこれ。**この定義だと ②−③ は「同じ形・同じ点数ルールのまま、見送りの有無だけ」を比べる**（F6 の ② と ③ の買い目はレースごとに同一）。参考に `F6@2`（T=2万で積み・見送りなし）を記述だけ作った（§9）。
9. **T=5万の F6** は積み上げの基準も見送りも 5万（買い目が T=3万と別）。
10. **判定1 の ①** は (a) 1日全体の ①（主）に対して判定し、(b) 同一レース対を §2.4 に併記した。
11. 上期・下期の「点推定で ① 以上」は ② と ① のそれぞれの期の回収率（期ごとの全体）を比べた。
12. ガミ率 = 的中のうち払戻 ≦ 投資。的中率 = 払戻 > 0。10万+ = 払戻 ≧ 10万円。/日 は母集団の開催日数（通年 365・上期 181・下期 184）で割る。
