## 動かせない制約

- 1レースの予算は 10,000円が上限 / 1レース1商品 / hit 系は三連単に固定（2026-09-03 方針）

  2026-07-16 以降は「現状測定のみ」（9/20 決定）。**確認は前向き記録（2026-10〜）で一度だけ**。
  → **このセッションで本番に出るものは無い。判定は 2026-12〜2027Q1**
- 掃引は事前登録に追記してから行う

### H13 その日の組み合わせで「誰が S/B を取るか」を予測する（2026-10-05 追加・ユーザー指示）
根拠: `reports/line_order_coverage.md`。過去の否定は「選手の過去率を足す／条件で分ける」形で、
**その日の相手・並びとの組み合わせで S/B を取る人を予測してから使う形**は未検証。

- 目的変数: レース後の実績 `res_back`（B を取ったか）と `res_standing`（S を取ったか）。列の意味（回数か有無か・車番か）は実データで確かめてから定義する。
- 予測モデル: 選手単位 LightGBM。入力は**発走前に得られる量だけ**（選手の S/B 傾向・脚質・ライン内の位置に加え、**同じレースの相手との相対量**＝レース内の B 率順位・先行の人数・他ラインの先頭の B 率の最大 等）。学習 ≤ 2024-12-31、評価 2025（walk-forward・in-sample にしない）。予測はレース内で合計1に正規化。
- 比較対象: 現行の隊列推定（ラインの前後を `b_rate_90` の最大で並べる）と、各選手の `b_rate_90` をそのまま使う素朴な予測。
- **Step0a（予測として意味があるか）**: 2025 の7車で「B を取る選手」を当てる精度（レース内1位の的中率・logloss）が素朴な予測を上回る（開催日ブートストラップの差の CI 下限 > 0）。満たさなければ停止。
- **Step0b（市場に対して意味があるか）**: 予測で B を取るとしたラインの「先頭→番手の1-2着」の、**最終オッズに対する発生倍率**が、現行の隊列推定で前に置いたラインのそれを上回る（差の CI 下限 > 0）∧ それ自体の CI 下限 > 1.00。満たさなければ停止（市場が既に織り込んでいる）。
- Step1（隊列推定の置き換え・三連単の位置別確率への入力・買い目での検証）は Step0 を通過してから改めて事前登録する。

### H15 高額枠の設計は妥当だったか
- 対象: 高額枠で売る/売ったレース。(a) 看板枠 `F_sign`（決勝・準決勝の型F）(b) 高額枠 `{B,C,D}_sign`（日次上限で落ちたレースに置く5本）。
- 比較（同一レース対）: (a) `F_sign` ↔ 同じレースの `F_hit`。(b) `{型}_sign` ↔ 同じレースの `{型}_hit`（本来は日次上限で売らないレース。「売らない」も併記）。
- 指標: 回収率・表示的中・10万+/日・的中時払戻の中央値・上位1/3/5件除外後の回収率（2025 の台）。
  売上（2026-08-27〜の実売・記述）: 1本あたり販売有償pt を高額枠 ↔ 同日・同種別の hit 商品で比べる（`AUDIT_2026_09_20.md` §5 の同日ペアの手法）。
- 判定（機械）: **妥当** = 1本あたり販売有償pt の差の CI 下限 > 0 ∧ ΔROI（高額枠 − hit）の CI 下限 > −5pt。
  **見直し候補** = ΔROI の CI 上限 < 0 ∧ 売上差の CI が 0 を跨ぐ。それ以外は判定保留。
- 添付3レース（2026-10-05 防府 1R/5R/6R）を本番の規則で再現し、なぜその目を買ったかを目視で示す。

### H16 3車目が絞れていれば三連複にする
- 前提（既知）: 三連複のオッズは同じ3車の三連単6通りの合成より平均 7〜11% 不利（`AUDIT_2026_09_20.md` §3.2）。
  券種を下げると払戻が入稿ゲート下限に張り付き 10万+ が消える（`docs/type_lab/bet_type_2026_09_10.md`）。
- 三連複の予測オッズは三連単の予測板から導出する（`bet_type_2026_09_10.md` の方法・探索用 vintage を使う）。
- **Step0（記述・停止判定なし）**: 2025 で、現行 hit 商品が買う3車の組ごとに「三連複オッズ ÷ その組で買った三連単の合成オッズ」の分布。
  2026-06〜 の朝スナップショットで、朝の比が最終の比をどれだけ予測するか（持続性）。
- **腕**（同一レース・1万円・入稿ゲート・軸信頼ゲートは本番どおり）:
  ① 現行（三連単）
  ② 組が絞れている（hit 商品の買い目が覆う3車の組が **3組以下**）なら、その組を三連複で買う（予測三連複オッズでダッチ）。4組以上は現行のまま
  ③ ②のうち、組ごとに **予測三連複オッズ ≥ その組で買う三連単の予測合成オッズ** のときだけ三連複にする（オッズを見て有利な方を選ぶ）
- 合格: ΔROI（②または③ − ①）の CI 下限 > 0 ∧ 上期・下期とも点推定 > 0 ∧ 表示的中の低下 ≤ 1.0pt。
