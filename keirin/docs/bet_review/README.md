## 動かせない制約

- 1レースの予算は 10,000円が上限 / 1レース1商品 / hit 系は三連単に固定（2026-09-03 方針）
- 本番の入稿ロジックは採否が決まるまで変更しない
- 払戻は wt 系に実払戻が無く **最終オッズ × 100 円**で代用する（上限値。1,000円を足せば組のオッズは下がる）。
  そのため指示書の「確定オッズでの回収率は参考値」は文字どおりには守れず、**入稿時点の側が近似**になる
- 窓: 探索 = 2025。2026-01〜09 は監査の確認窓・波乱指数 S0/H2 で**消費済み**。
  2026-07-16 以降は「現状測定のみ」（9/20 決定）。**確認は前向き記録（2026-10〜）で一度だけ**。
  → **このセッションで本番に出るものは無い。判定は 2026-12〜2027Q1**
- 掃引は事前登録に追記してから行う

## 事前登録 — Phase 4（2026-10-05・データに触る前に固定）

本体は `hypotheses/H01_line_bias_overlay.json`・`H06_flat_race_cheap100_morning.json` の
`feature_definition` / `test_design`。ここでは**変えてはいけないもの**だけを固定する。

### 共通
- 台: `type_lab_picks` の paper 行は使わない（全行 rule_version `cf39e62d1442`＝9/22・9/23 の変更前）。
  `race_type_board.npz`（7車・vintage p3/pw。`keirin/data/exp_bet_review/` に複製済み）＋本番関数で組み直す。
- 予測オッズ: `odds_tf` は train_end 2025-12-31 で 2025 は in-sample。**探索用 vintage（train_end 2024-12-31）を作り直して使う**。
  作れなかった場合は最終オッズ代理で測り、結果に明記する（その場合の合格は「暫定」）。
- 探索窓 = 2025-01-01〜12-31。上期（1〜6月）/ 下期（7〜12月）で符号の一致を見る。
- CI = 開催日単位ブートストラップ 2,000回・95%。払戻 = 最終オッズ×100（上限値）。
- サンプル量: 的中30件以上 かつ 開催日60日以上（未満は保留）。
- 2025 で基準を満たしたものだけを、前向き記録（紙上・売らない）へ回す。確認は 2026-10〜12 で**一度だけ**。

### H01 ライン決着の上乗せ
- Step0 停止判定: 2025 の7車で k1〜k3 の「予測オッズ（探索用 vintage）に対する発生倍率」の CI 下限 > 1.00 の区分が無ければ停止。
- β_k は探索窓の CI 下限側に丸めて固定（掃引しない）。3着には掛けない。
- 合格: ΔROI（LB 適用 − 現行・同一レース対）の CI 下限 > 0 ∧ 上期・下期とも点推定 > 0 ∧ 表示的中の低下 ≤ 1.0pt ∧ 10万+/日 が減らない。
- 前向きの主指標: 予測オッズに対する発生倍率（1つに固定）。

### H06 H2 の朝版
- 対象: 7車 ∧ `mdl_ent` ≥ 2025 の p80（固定値）。三連単の予測オッズ ≥ 100 の目を予測オッズの昇順に10点・ダッチ・1万円。閾値・点数は掃引しない。
- 腕: ①同一レースの現行商品 ②H06 ③同件数の無作為レースで H06 を買う対照 20 seed。
- 合格: ②−① の ΔROI の CI 下限 > 0 ∧ ②が③に 18/20 以上で勝つ ∧ 上位3本を除いた回収率 ≥ 75% ∧ 上期・下期で同符号。
- 前向きの主指標: 発生倍率（買った目の実的中 ÷ Σ0.75/最終オッズ）≥ 1.05。
- `axis_sum` < 1.327 で `L_flat` と重なるレースは別掲する。
