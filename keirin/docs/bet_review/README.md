## ユーザー決定（2026-10-05）

| 項目 | 決定 |
|---|---|
| 対象 | **netkeirin へ入稿している推奨買い目の全体**（型ラボが中心。高額枠・自信あり・`L_lead` を含む） |
| Phase 0 / 1 | 9/20 監査（`AUDIT_2026_09_20.md`）を**参照し、差分だけを測る**。未測定の差分は「入稿時点のオッズ」での比較 |
| 採否の基準 | **売上が最優先**。ユーザーの見立ては「売上を動かすのは 回収率 ＞ 的中率」。→ 回収率を第一基準にし、10万円以上の的中頻度と払戻の中央値を併記する |

| モデル呼び分け | **指示書どおり全部分ける**（実装・測定 = Sonnet、レッドチーム・仮説 = 履歴を渡さない新規 Opus、抽出 = Haiku） |

| H2型・`L_lead`・型ラボの関係 | 型ラボ優先などの序列は置かない。**「1レース1商品」の制約の下で、レースごとにどの商品を割り当てると1日の的中率・回収率が上がり安定するか**という配分問題として扱う |
| ブランチ | `feat/keirin-bet-review`（main から）。波乱指数 S0/H2 は `feat/keirin-upset-index`（未 push）に残す |

⚠️ 「回収率が売上を動かす」は**作業仮説**。監査（§5）で測られているのは
「10万円以上の的中の翌日は売上 ×1.49」「的中率は売上に効かない」「ラベル・自信あり・決勝が効く」まで。
回収率→売上を直接測ったものは無い。

## 動かせない制約

- 1レースの予算は 10,000円が上限 / 1レース1商品 / hit 系は三連単に固定（2026-09-03 方針）
- 本番の入稿ロジックは採否が決まるまで変更しない
- 払戻は wt 系に実払戻が無く **最終オッズ × 100 円**で代用する（上限値。1,000円を足せば組のオッズは下がる）。
  そのため指示書の「確定オッズでの回収率は参考値」は文字どおりには守れず、**入稿時点の側が近似**になる
- 窓: 探索 = 2025。2026-01〜09 は監査の確認窓・波乱指数 S0/H2 で**消費済み**。
  2026-07-16 以降は「現状測定のみ」（9/20 決定）。**確認は前向き記録（2026-10〜）で一度だけ**。
  → **このセッションで本番に出るものは無い。判定は 2026-12〜2027Q1**
- 掃引は事前登録に追記してから行う
