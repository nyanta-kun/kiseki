# 事前登録: 7S のレース選別に波乱スコアを使う（2026-08-21）

**この文書は 2024 年のデータを一度も見ない状態で書いた。** 実行後に本文を書き換えない
（結果は「結果」節に追記するだけ）。

## 背景

2026-08-21 に [[keirin_7s_gate_resweep_2026_08_21]] で、7S のレース選別軸として
波乱スコア（`lgbm_upset_screen`）が `axis_sum` / `entropy` より優れることを観測した
（25%残しで「2倍以上で的中」が Δ+3.00pt / +2.81pt・同件数ランダム帰無の 98.4 / 93.8 %点）。

🔴 **ただし発見と検証に同じ 2025〜2026 のデータを使っており、確認窓が残っていない。**
前向き確認は 7S が 5.45件/日しかないため約12ヶ月かかる。そこで
**この仮説について一度も見ていない 2024 年**（7S 4,211R）を確認窓として使う。

## 凍結した判定規則（結果を見る前に確定）

| 項目 | 値 |
|---|---|
| モデル | `lgbm_upset_screen_n15v2312`（`--train-end 2023-12-31`・26,722R・31特徴） |
| 閾値 | **0.311346** ＝ 7車・2023-12-31 以前 24,441R のスコア **p75** |
| 規則 | 7S が選んだレースのうち **スコア >= 閾値** のものだけ残す（上位25%相当） |
| 対象 | `picks_history` rank=RANK_7S / bet_amount>0 / 2024-01-01〜2024-12-31 |
| 主KPI | **「2倍以上で的中」**（payout / bet >= 2.0） |
| 副次 | 「5倍以上で的中」・ROI（**採否には使わない**） |

🔴 閾値は **2023-12-31 以前のデータだけ**から決めた。2024 の分布で分位を取り直すことは
しない（それをすると 2024 を見たことになる）。

## 採用ライン

以下を**両方**満たしたときだけ「2024 で再現した」とする。

1. 残した側の「2倍以上で的中」が、7S 全件比 **+1.5pt 以上**
2. 同じ件数をランダムに残した帰無分布の **90%点以上**

満たさなければ、この選別軸は 2025〜2026 に固有だったと判断し**採用しない**。

## 予想される弱点（先に書いておく）

- 2024 の 7S は件数が 4,211R と 2025(1,996) より多い＝**ゲートが当時ゆるかった**。
  母集団がゆるいほど選別の余地は大きく出やすい（有利に働く方向のバイアス）
- 買い目構造は 2024〜2026 を通じて 5点・10,000円で一定なので、そこの交絡は無い
- `wt_entries.pred_top3_pct` は 2024-01 以降しか無いが、**波乱スコアはこの列を使わない**
  ので影響しない

## 🔴 判定の訂正（2026-08-21・独立監査により）: **棄却ではなく「判定不能」**

初出でここに「❌ 再現しない → 採用しない」と書いたが**誤りだった**。
独立監査で **確認窓 4,211R の 79%（2024-01〜07 の 3,341R）が別母集団**と判明した。

    7車レース総数に対する 7S 選出率
      2024-01〜07 : 21.7〜27.0%
      2024-08〜   :  8.3〜 9.9%        ← 2024-08 で構造的に断裂

原因は `axis_sum` の較正ドリフトではなく **`wt_overlap_n`**。軸2車が公式◎◯と
一致しない割合が 2024-01〜07 は 65〜71%、2024-08 以降は 22〜27% と3倍違う。
月次凍結 vintage は 2024-01 時点で学習13ヶ月しかなく公式印に収束していないため、
**2024H1 の 7S は「市場と乖離したレース」ではなく「モデルが未熟で印と揃わなかった
レース」**＝7S のエッジの定義そのものが成立していない。

窓を割ると符号が変わる（すべて honest・凍結閾値 0.311346・v2312）:

| 窓 | n | 残す | 全2倍+ | 残2倍+ | Δ | 帰無%点 |
|---|---|---|---|---|---|---|
| 2024 全体（当初の判定） | 4211 | 1314 | 11.85 | 11.80 | −0.05 | 45.0% |
| **2024H1 (01–07)** | 3341 | 1039 | 11.28 | 10.68 | −0.60 | 22.1% |
| **2024H2 (08–12)** | 870 | 275 | 14.02 | **16.00** | **+1.98** | 85.0% |

ベースライン（2倍+ 11.28% vs 14.02%）もガミ率（13.7% vs 7.6%）も違う。
**2024H2 だけが 2025/2026 と同じ商品**で、そこは n=870・帰無 SD 2.08pt ＝ 検出力不足。

🔴 **「2024 はゲートがゆるく選別の余地が大きく出やすい」という事前の予想は逆だった。**
ゆるいのではなく**波乱スコアが何も分離しない別種の母集団**だった
（2024H1 の四分位は 11.14 / 11.02 / 11.86 / 11.12 と完全に平坦）。

→ 正しい記録は **「棄却」ではなく「判定不能。確認窓を1つ無駄にした」**。

⚠️ **この結果を「波乱スコアによるレース選別は否定済み」の根拠に使ってはいけない。**

## 次から必ずやること（今回の失敗の本体）

失敗の原因は閾値でも検出力でもなく **窓の選び方**だった。確認窓を選ぶときは
**結果を見る前に**、その窓のゲート通過率・`wt_overlap_n` 分布・ベースライン KPI を
本番窓と突き合わせること。今回なら 65〜71% vs 22〜27% で一発で弾けた。

（当初の記述）2025/2026 で見えた +3.00 / +2.81pt は 2024 では **−0.05pt**。
ただし上記のとおり、この −0.05pt は**母集団の違う 2024H1 に支配されている**。

🔴 **モデルの質の問題ではない。** 同じ `lgbm_upset_screen_n15v2312` は 2024 の7車
23,138R で波乱を明確に分離している（四分位で決着中央 15.4→60.2倍・
≥300倍率 5.2%→11.8%・AUC 0.5895）。**入力は生きていて、仮説が否定された。**

🔴 事前に「2024 はゲートがゆるく件数が多い（4,211 vs 1,996）ので選別の余地は
**大きく出やすい**」と書いた。有利なバイアスがかかる側で何も出なかったので、
否定の側に強い証拠になる。
