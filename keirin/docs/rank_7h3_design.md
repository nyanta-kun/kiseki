# RANK_7H3 — 穴推奨「本命連対どまり型」設計書（2026-08-12）

三連単で1レース10万円超の払戻を狙う新ランク。**既存ランクの定義は一切変えない**。
検証の全文: [三連単の使いどころ](https://claude.ai/code/artifact/eea883fb-7468-4717-a505-8685d1e7ffad) /
memory `keirin_trifecta_highpay_slot_2026_08_12`。

## 1. なぜ新ランクにするのか

三連複ベース（看板+準決勝・軸2車流し）は **表示的中 29.0%** を作る的中率商品で、
これを三連単へ替えると 5〜14% まで崩れる。一方で 10万円超の払戻は三連複だと
**14.4日に1回**しか出ない。両立は同じ商品の中では不可能なので、**母集団を分けて
別ランクとして併走させる**（7H1/7H2/9H1 と同じ「穴推奨系」の位置づけ）。

| | 既存の的中率商品 | 本ランク 7H3 |
|---|---|---|
| 母集団 | 看板+準決勝 | **看板でも準決勝でもないレース** |
| 券種 | 三連複 | **三連単フォーメーション6点** |
| 表示的中 | 29.0% | 約5% |
| 10万円超 | 14.4日に1回 | **3.5日に1回** |

母集団が排他なので **既存ランクの成績・入稿を1件も奪わない**（7C は全7車が母集団
なので重複するが、`overlap_expected` と入稿優先順位で解決する。下記 §6）。

## 2. 何を買うのか

「指数上位2車は3着以内に来るが、勝ち切るのは別の車」という決着を狙う。
市場はこの形を過小評価しており、看板外×高軸積で **edge 1.59**（＝市場含意より
59%多く的中）が出る。

```
軸 a1, a2 = pred_top3 上位2車
相手 legs = 指数3〜7位のうち pred_top3 >= 20%。3車以上残れば「最も強い1車＋最も弱い2車」

買い目（三連単フォーメーション）
    1着列 = legs（相手）
    2着列 = [a1, a2]
    3着列 = [a1, a2]
  → 展開すると (t,a1,a2) と (t,a2,a1) が相手ごとに1組 ＝ 相手数 × 2 点（最大6点）
```

`legs` の規則は三連複ベースと同一（`rank_7h3_legs()` に実装し、
テストで規則そのものを固定する）。

## 3. ゲート

```
(1) n_entries == 7
(2) race_type に 決勝 / 特選 / 選抜 のいずれも含まない   ← 「看板でも準決勝でもない」
(3) 軸積 = p3[a1] × p3[a2] >= 0.70
(4) 相手が2車以上取れる（= 買い目が2点以上組める）
```

⚠️ (2) は `marquee.is_marquee_race()` を**使わない**。あれは準決勝を明示的に除外する
仕様で、本ランクは準決勝も対象外にしたい。「決勝」の部分一致で準決勝が入るのを
利用した専用述語 `rank_7h3_is_target_race_type()` を置く。

⚠️ (3) の 0.70 は**モデルの較正に依存する絶対閾値**。7H1 の
`RANK_7H1_BUST_PROB_MIN` と同じ性質なので、再学習したら分布を確認すること。

## 4. 賭け金

Plackett-Luce（`pred_win_pct` 由来）で各目の確率を出し、本番 `allocate_budget`
へ重みとして渡す。予算は 1レース `RACE_BUDGET`(10,000円)。

| 配分 | ROI | 10倍間隔 | ガミ率 |
|---|---|---|---|
| 均等 | 1.239 | 5.3日 | 1.7% |
| **Plackett-Luce** | **1.526** | **4.7日** | **0.0%** |
| p3積 | 1.134 | 5.1日 | 0.0% |

差の大半は裾（n=1,192・的中58本）なので**この表でPLを選んだのではない**。
PLを採る理由は「重みを確率に比例させると払戻が揃う」という配分の原理そのもので、
`stake_allocation` が予測オッズを使うのと同じ考え方。三連単の予測オッズモデルは
無いので PL が現時点で実装できる最良の近似になる。

## 6. 既存への影響と、その封じ方

| 影響先 | 内容 | 対処 |
|---|---|---|
| 7C（全7車が母集団） | 看板外レースで重複する | 入稿順で **7C より後ろ**に置き、7C に譲る。`overlap_expected=True` で失敗集計から外す |
| 7H1 / 7H2 / 9H1 | 7H1・7H2 は7車だが**看板を含む**母集団なので一部重複 | 7H1 > 7H2 の既存優先順位は動かさない。7H3 はその後ろ |
| 既存6ランクの成績 | 母集団が排他（看板+準決勝 vs 看板外） | 影響なし |
| Discord ヘッダー合計 | 穴推奨系は元から除外 | `in_header_total=False` |

**入稿優先順位（RANK_CONFIGS の定義順）**: 7H1 > 7H2 > 9H1 > 7SS > 7S > 7A > 7C > **7H3** > 7B。
7C の後ろ・7B の前。7B は準決勝限定なので 7H3 とは母集団が排他。
