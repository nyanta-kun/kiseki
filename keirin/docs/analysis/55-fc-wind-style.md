# 予報風速 × 脚質 — 増分情報はあるが決定を動かさない（2026-08-18・不採用）

> `keirin.wt_race_conditions`（2026-08-18 新設）で気象が揃い、記述統計では
> **風が強いほど 逃 が 追 に対して相対的に良い**ことが確認されていた
> （memory `keirin_wind_direction_2026_08_18`）。本番モデルは気象特徴を1つも
> 持たないので、これは原理的に未利用の情報である。
>
> 検証の結果、**「モデルが織り込めていない」ことは有意に確認できた**（残差の傾き
> z=+4.9 / +4.3 / +3.2 と3窓で再現）。だが **その情報を入れても軸も相手も的中率が
> 動かない**。効果の大きさ（強風時で p3 ±1.8pt）が、軸の入れ替えを起こすほどの
> 差ではないため。**本番モデル・後段とも変更しない。**

ハーネス: `scripts/exp_fc_wind_wt.py`（特徴量 A/B）/ `scripts/exp_fc_wind_adjust_wt.py`（後段補正）

---

## 使うのは予報だけ

| 系統 | 列 | 本番で使えるか |
|---|---|---|
| 発走時点の実測 | `wind_speed`（winticket） | ❌ 発走後にしか出ない。推奨は朝に作る |
| 朝の予報 | `fc_wind_speed`（Open-Meteo） | ✅ これだけ |

実測と予報の相関は **0.474**（n=101,537）。予報は 10m 高度の屋外風速、実測は
競輪場発表なのでスケールも違う（平均 2.3 vs 1.1 m/s）。**検証は最初から予報で行う。**

⚠️ さらに、今回使った予報はアーカイブ（`historical-forecast-api`）＝直近のモデルランで、
**朝 07:00 に取れる予報より当日値に近い**。前日発表の予報との相関は 0.72（実測）。
つまり本検証は**本番より楽観側**の条件で回している。それでも下記のとおり動かなかった。

## 効果はある（記述統計・レース内正規化着順）

会場×年月で中心化（季節性・会場差を除去）した正規化着順（0=1着・低いほど良い）:

| 予報風速 | 7車 逃−追 | 9車 逃−追 |
|---|---|---|
| <1.5 m/s | −0.0879 | +0.0187 |
| 1.5–2.5 | −0.0800 | +0.0056 |
| 2.5–3.5 | −0.0858 | +0.0109 |
| 3.5–5 | −0.0941 | −0.0112 |
| **5+** | **−0.1153** | **−0.0249** |

7車は 逃 有利がさらに 0.027 拡大、9車は **有利不利が反転**（+0.019 → −0.025）。
実測風速でも同型（7車 −0.0863 → −0.1306）。**帯に対して単調。**

## モデルは織り込んでいない（残差検定）

`残差 = 実績3着内 − 予測p3` を `β · s · max(w−2.5, 0)`（s = 逃 +1 / 両 0 / 追 −1）で回帰。
標準誤差はレースでクラスタ。

| 窓 | β /(m/s) | z |
|---|---|---|
| CAL 2025-01〜06（λ推定用・out-of-sample） | +0.00607 | **+4.92** |
| VAL 2025-07〜2026-02 | +0.00603 | **+4.29** |
| TEST 2026-03〜07-15 | +0.00497 | **+3.15** |

3窓で同符号・有意。**未利用の情報が実在することは確定。**
ただし大きさは 5.5 m/s で逃 +1.8pt / 追 −1.8pt に過ぎない。

## それでも決定は動かない

### ① 特徴量として足す（`fc_wind` と 符号つき `fc_wind × 脚質`）

TRAIN 2023-07〜2025-06 のみで学習したリーク無し LGBM。seed 3本の平均差と、
base の seed 振れ幅を並べる。

| 窓 | AUC 差 | 7車 二軸 | 9車 二軸 | 軸2車の組が変わったR |
|---|---|---|---|---|
| VAL | +0.0000（振れ 0.0002） | +0.20pt（振れ 0.02） | −0.39pt（振れ 0.77） | 5.9% / 9.5% |
| TEST | −0.0002（振れ 0.0004） | +0.06pt（振れ 0.20） | −0.18pt（振れ 0.54） | 6.2% / 7.9% |

順位は 6〜9% のレースで動くのに、的中は**動いた分がそのまま相殺**されている。
2026-06-13 の G06（実測風速・doc24）が AUC で不通過にしたのと同じ結論に、
**順位系の指標で測っても**なる。

### ② 後段で1パラメータ補正（`logit(p') = logit(p) + λ·s·max(w−W0,0)`）

λ は CAL 窓の残差から推定（W0=2.5 で λ=0.033）。LightGBM に掘らせるのではなく
**効果を直接書き下す**方式。

| 窓 / 母集団 | 軸2車の組が変わったR | 二軸的中 差 |
|---|---|---|
| VAL 7車 全体 | 0.68% | +0.04pt |
| TEST 7車 全体 | 0.71% | ±0.00pt |
| VAL 7車 風≥5 (594R) | 6.1% | **+1.35pt** |
| TEST 7車 風≥5 (431R) | 6.7% | **−0.46pt** |

λ を 2倍・4倍にすると悪化する（TEST 7車 風≥5 で −2.09 / −2.78pt）。
**強風帯だけ見ても窓で符号が反転**し、推定した λ が最良点。

### ③ 相手（3番手以降）の並べ替えだけに使う

軸2車は据え置き、二軸的中したレースで「残り1枠を k 点で拾えたか」:

| 窓 | k=1 | k=2 | k=3 |
|---|---|---|---|
| VAL 7車 | +0.16pt | −0.02 | −0.02 |
| TEST 7車 | −0.07pt | −0.17 | −0.20 |

風≥3.5 に絞ると TEST は k=2 で **−1.05pt**。改善しない。

### ④ 狙い所（層）が窓で入れ替わる

残差の傾きを p3 順位で層別すると、**VAL は人気薄・TEST は軸帯**に出る。

| 層（7車） | VAL β / z | TEST β / z |
|---|---|---|
| p3 上位2（軸帯） | +0.0027 / +0.87 | +0.0095 / **+3.00** |
| 3–4位 | +0.0066 / +1.85 | +0.0049 / +1.33 |
| 5–7位（人気薄） | +0.0076 / **+3.35** | +0.0002 / +0.07 |

**「強風の人気薄の逃を買う」のような固定ルールは立たない。**

## なぜ動かないのか（天井の計算）

- 効果の大きさは **強風(5.5 m/s)でも p3 ±1.8pt**。軸2車を決める p3 の差は
  通常これより大きいので、入れ替わるのは**ほぼ同値の2車**だけ。
  同値の2車を入れ替えても期待値はほとんど変わらない。
- 予報 5 m/s 以上は 7車レースの **4.0%**（VAL 594/14,927）、3.5 以上でも 14.6%。
  仮に強風帯を完全に取り切っても全体では **+0.05pt 規模**。

**不採用。** `FEATURE_COLS_WT` に気象特徴を追加しない。後段補正も入れない。

残すもの（次に別テーマで使う）:

- `keirin.wt_race_conditions` と 2本の backfill スクリプト
- 本ハーネス2本（風向・雨・別の交互作用を測るときに使い回す）

# 追記（2026-08-18）: 風向版「強風 × 向かい風で逃を下げる」も不成立

ユーザー提案「一定以上の強風で補正ウェイトを上げ、**B を取る逃げを下げ・追込を上げる**」を検定した。
ハーネス: `scripts/exp_fc_wind_dir_wt.py`

## まず、風速だけで逆張りすると確実に損をする

上の λ を**負**（逃↓ 追↑）にして当てた 7車・二軸的中の差:

| 母集団 | λ=−0.132 | −0.066 | −0.033 | 0 | +0.033 | +0.066 |
|---|---|---|---|---|---|---|
| VAL 全体 14,927R | −0.11 | −0.01 | +0.01 | 0 | +0.02 | +0.03 |
| VAL 風≥5 594R | **−1.35** | +0.51 | +0.67 | 0 | +1.18 | +1.18 |
| TEST 風≥3.5 1,236R | **−0.57** | −0.08 | +0.08 | 0 | −0.16 | −0.32 |
| TEST 風≥5 431R | **−1.86** | −0.70 | −0.23 | 0 | −0.23 | −1.16 |

**ウェイトを上げるほど単調に悪化する。** 生の数字でも 逃（ライン先頭）の勝率は
24.25%（<1.5 m/s）→ **25.47%（5+）**、追の3着内率は 37.83% → **36.46%** で、
強風で有利になるのは逃の側（5+ vs 3.5未満で 逃 +1.3pt z≈+2.6 / 追 −0.7pt z≈−2.9）。

## 風向版の検定

風速ではなく**向き**なら仮説が立つ（B を取る側だけが風を受ける）。2段構えで測った。

### (c) 「向かい風の軸」は実在して再現する

会場ごとに **上がり200m（`wt_entries.final_half`）が最も遅くなる風向 φ_v** を
TRAIN+CAL（〜2025-06）だけで推定し、後の窓で当てはめる（会場×年月で中心化＝季節性除去）。

| 窓 | 上がりの遅れ β | z | 会場別の符号再現 |
|---|---|---|---|
| VAL | +0.0160 秒/(m/s) | **+7.06** | 27/36 |
| TEST | +0.0246 秒/(m/s) | **+7.60** | 26/34 |
| 確認窓 2026-07-16〜 | +0.0201 秒/(m/s) | +2.78 | 17/27 |

5 m/s なら上がりが **0.08〜0.12秒** 遅くなる。**軸の推定は効いている**（測定は生きている）。

### (d) その軸で着順は動かない

同じ φ で「逃有利度 g」を回帰（速度項と同時に入れて分離）:

| 窓 | 速度 β / z | **向かい風 β / z** | 強風(≥3.5)のみ 向かい風 β / z |
|---|---|---|---|
| VAL | +0.00472 / **+7.05** | +0.00014 / +0.43 | +0.00007 / +0.15 |
| TEST | +0.00328 / **+4.76** | +0.00032 / +0.66 | +0.00100 / +1.47 |
| 確認窓 | +0.00659 / +1.98 | +0.00086 / +0.72 | — |

**仮説は負を予測するが、係数は3窓とも正で有意でない。** 速度項だけが生き残る。
着順から φ を自由推定した版（会場ごと2パラメータ）でも同じで、プラセボ
（会場ラベルをシャッフルした φ・200回）に対して実測は上位 **62.5% / 52.0%**
＝**帰無分布のど真ん中**。

### (e) 指標を変えると符号が変わる（＝ノイズ水準）

前回メモの 🟡「強風時のみ向かい風で逃げ切り率が下がる」を同じ指標で追試すると、
符号は確かに仮説どおりだが有意ではない:

| 窓（風≥3.5） | 逃 1着 向かい−追い | 逃 3着内 | 追 1着 |
|---|---|---|---|
| TRAIN+CAL | −0.80pt (z−1.11) | −1.40pt (z−1.69) | +0.42pt |
| VAL | −0.48pt (z−0.34) | −0.87pt (z−0.54) | +0.25pt |
| TEST | −2.26pt (z−1.27) | −0.47pt (z−0.23) | +1.93pt (z+2.29) |

**正規化着順の回帰では正、逃げ切り率では負**。指標依存で符号が入れ替わる＝
どちらもノイズの中と読むのが妥当。

### (f) 提案どおりに当てた A/B

`logit(p') = logit(p) − μ·s·h·1[w ≥ しきい値]`（h = 向かい風成分）。7車・二軸的中の差:

| μ | VAL 全体 | VAL 強風≥3.5 | TEST 全体 | TEST 強風≥3.5 |
|---|---|---|---|---|
| 0.033 | +0.01 | +0.05 | +0.01 | +0.08 |
| 0.066 | −0.04 | −0.28 | −0.06 | −0.40 |
| 0.132 | −0.26 | −1.65 | −0.24 | −1.54 |
| 0.264 | −0.84 | **−5.33** | −0.62 | **−3.88** |

しきい値を 5 m/s にしても同じ形（μ=0.264 で 強風帯 −4.88 / −5.80pt）。
**「ウェイトを大きくする」という提案の核心部分が、そのまま損失に直結する。**

## 判定と、なぜそうなるか

**風向版も不採用。** 風速版とあわせて、風で逃/追の評価を入れ替える案は閉じる。

物理的には筋が通る解釈がある: **向かい風は全員を等しく遅くする**（上がり +0.1秒/5m/s は
実測できた）。全員に等しくかかる量は**レース内の相対順位に乗らない**。
一方で「強風ほど逃が有利」は別経路——差しは抜くために風の中へ外に持ち出す必要があり、
そのコストが風とともに上がる——で説明でき、こちらは 3窓とも z+5〜+7 で残る。

⚠️ **上がりタイムに効くこと（z+7）と、着順に効くことは別**。
   本件は「測定は成功しているのに、その量が意思決定に伝わらない」典型例として残す。
