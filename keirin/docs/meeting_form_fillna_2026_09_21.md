# 節内成績の欠測の埋め方は改善にならない — **否定**（2026-09-21）

> 発端（ユーザー・2026-09-21）:
> > 現在、レース単位で出場選手の指数比較で推奨が出ていると思います。
> > 斡旋期間内の成績によるモチベーション、調子など考慮されていますか？

再現: `scripts/exp_cup_nan_ab.py`（`exp_meeting_form_ab.py` と同じ方法論・2窓×5seed）

## 0. 結論

| 問い | 答え |
|---|---|
| 斡旋期間内の成績・調子は入っているか | 🟢 **入っている**（`cup_*` 4本 + `rp_*`/`win_3m` 等） |
| どれだけ効いているか | 🔴 **gain 0.83%**（3着内率モデル）。AI印+競走得点3本で 62.8% |
| 残差は残っているか | 🟢 **残っている**（「2走+3着内なし」が両窓で有意に過大評価） |
| 欠測の扱いを直せば取れるか | 🔴 **取れない**。ΔAUC は seed ノイズ内・指標は窓で符号反転 |
| モチベーションの特徴量はあるか | 🔴 **無い**（勝ち上がり圏内・級班境界・賞金ランキングはいずれも未実装） |

## 2. 残差は本物（自社 p3・vintage walk-forward・予測1位の選手）

| 層 | n(探索/確認) | 探索 残差 [CI95] | 確認 残差 [CI95] |
|---|---|---|---|
| 初日（履歴なし） | 9,600 / 3,888 | −1.26 [−2.01,−0.53]★ | −1.99 [−3.14,−0.79]★ |
| 1走済 3着内あり | 3,748 / 1,512 | −0.60 | −0.55 |
| 1走済 3着内なし | 4,780 / 1,877 | −2.61 [−3.84,−1.37]★ | −1.50 |
| 2走+ 全て3着内 | 1,682 / 675 | −0.80 | +0.85 |
| 2走+ 一部3着内 | 3,954 / 1,639 | +0.04 | −1.41 |
| **2走+ 3着内なし** | 2,199 / 873 | **−2.82 [−4.66,−0.92]★** | **−3.26 [−6.15,−0.28]★** |
| 差（全て3着内 − 3着内なし） | | +2.02 [**−0.71**,+4.75] | +4.10 [**−0.08**,+8.34] |

🔴 **「差」は両窓とも CI が 0 を跨ぐ**。両窓で有意なのは「2走+ 3着内なし」の過大評価だけ。
全層がマイナス（モデル全体が 1.3〜1.5pt 過大）なので、全体平均を引いた**相対**は −1.5 / −1.7pt。

🟢 **順位によって過大評価の大きさが違う**（上位 −2.8〜−3.7 ↔ 下位 −1.0〜−1.8）＝
補正すれば順位が動く、という形にはなっていた。

🔴 **1着率（pw）側は両窓一貫の信号なし**（有意セルが窓で入れ替わり符号も反転）。
＝ 発端の広島2R（1着が指数4位・pw 6.1%）は**この方向でも取れない**。

## 3. 🔴 だが特徴量にすると増分ゼロ

`add_meeting_form_features_wt` は最後に `fillna(0.0)` しており、**初日と「開催内3着内なし」が
同じ 0.0 で渡される**（該当 33.9%）。JRA v28 の「欠損は NaN のまま渡す」と同型に見えたので
A/B を取った。

| 腕 | 窓 | ΔAUC | Δ1位勝率 | Δ1位3着内 | Δ上位2車そろい |
|---|---|---|---|---|---|
| nan（初日をNaN） | w1 | −0.00006 | +0.01 | −0.13 | −0.02 |
| 〃 | w2 | +0.00004 | −0.05 | −0.07 | +0.07 |
| flag（`cup_no_top3`/`cup_all_top3`） | w1 | +0.00001 | −0.06 | −0.15 | +0.24 |
| 〃 | w2 | −0.00007 | +0.03 | +0.06 | +0.10 |
| nan+flag | w1 | −0.00008 | −0.23 | −0.26 | +0.02 |
| 〃 | w2 | +0.00007 | −0.11 | +0.05 | +0.05 |

baseline の seed 標準偏差は AUC **0.00018 / 0.00007** で、**ΔAUC は全腕ノイズ内**。
採用水準（`line_leader` 6列 +0.00044/+0.00072・節内成績 +0.00058/+0.00068＝両窓全指標プラス）
に届かず、指標の符号も窓で入れ替わる。→ **不採用。**

＝ `cup_n_so_far` との交互作用でモデルは既に取り切っていた（docstring の
「`cup_n_so_far` を必ず一緒に入れること」が効いている）。

## 4. 未検証で残るもの（モチベーションの代理）

いずれも**番組編成から決まる外生情報**で、既存の否定腕（前日の決着傾向・風）とは性質が違う:

- **勝ち上がり圏内か**（明日の準決勝・決勝に乗るために今日必要な着順）
- 級班入替の境界（期の後半・`period_norm` はあるが「その選手が境界にいるか」は無い）
- 賞金ランキング（GP 出場ラインなど）

⚠️ ただし本稿の §3 で「残差があっても増分ゼロ」が再現したので、**記述の残差だけを根拠に
実装へ進まないこと**。

## 5. 踏んだ罠

🔴 **採用された検証の台は、採用後は同じには動かない。** `exp_meeting_form_ab.py` は
節内成績が `FEATURE_COLS_WT` に**無い**前提（66特徴）で書かれており、自分で
`add_meeting_form_features_wt` を呼ぶ。その検証の結果として採用され
`build_features_wt` が呼ぶようになった（70特徴）ため、流用すると**二重付与で
`cup_n_so_far` が消える**（`KeyError`）。同日の `base` 汚染と同根で、
**自分の変更が後続の測定の前提を動かす**型。
