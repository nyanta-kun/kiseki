`/yoso/hot/?rf=topk` に載っていた10人と、その 2026-08-01〜08-27 の全公開商品 15,194件。

## 1. 高額的中30件は「1万円をどう割るか」の問題でしかない

`/yoso/hot/` が挙げる「直近の高額的中」30件を詳細ページから1点ずつ展開した:

| | 中央値 | 範囲 |
|---|---|---|
| 1商品の総投資 | **10,000円** | 9,500〜10,000（**全件ほぼ固定**） |
| 点数 | 8点 | 1〜16 |
| **的中した1点の賭け金** | **1,300円** | 400〜10,000 |
| **的中倍率** | **228倍** | 12〜1,141 |

券種は **三連単27件 / 二車複3件**。形式はフォーメーション23・通常12・1-2着流し3。

払戻は例外なく `的中した1点の賭け金 × 的中倍率` で、作られ方は2つしかない:

| 型 | 件数 | 例 |
|---|---|---|
| **倍率型**（200倍以上を薄く広く） | 18/30 | 943,110円 = 900円 × **1,047.9倍**（8点・LONEFOX） |
| **集中型**（1点に3,000〜10,000円） | 9/30 | 960,500円 = **5,000円** × 192.1倍（**2点**・厳選AIマスター）<br>390,000円 = **10,000円** × 39.0倍（**1点**・iAI -居合-）<br>217,000円 = **10,000円** × 21.7倍（**1点・二車複**・シュウの二車福） |

🔴 **「高額的中＝万車券」ではない。** 96万円の松阪3Rは192倍、39万円の防府9Rは**39倍**、
21.7万円の和歌山8Rは**二車複21.7倍**。**倍率ではなく1点の厚みで作っている**。

## 3. 自社との差（8/07〜8/26・売った795商品）

| | 自社 | 好調10人 |
|---|---|---|
| 1点あたり賭け金（中央） | **1,700円** | 1,300円（的中点） |
| **的中倍率（中央 / 最大）** | **5.6倍 / 62.4倍** | **228倍 / 1,141倍** |
| 払戻中央（的中時） | 15,765円 | 11,630〜57,040円 |
| **最大払戻（20日間）** | **212,160円** | 217,000〜1,503,500円 |
| 10万円以上 | **2件（0.10件/日）** | 9〜41件（0.33〜1.5件/日） |

**100倍以上の的中は20日間で0件。** 差は予測精度ではなく**買い方**にある。

内訳を券種で割ると位置づけがはっきりする:

| 自社の枠 | 件数 | 件/日 | 的中率 | ROI | 10万+率 | 最大払戻 |
|---|---|---|---|---|---|---|
| 三連複（7S/7C/7A/7B/7M1/9C…） | 668 | 33.4 | 39.5% | 72.9% | **0.00%** | 79,500円 |
| 三連単（7T1/7H1/7T3/9H1） | 126 | 6.3 | 4.8% | 37.7%（CI 1.1〜88.0） | **1.59%** | 212,160円 |

🔴 **三連複枠は構造的に10万円を作れない**（20日・668商品で最大79,500円）。
🟢 **三連単枠の10万+率 1.59%（2/126）は LONEFOX の 2.05%（41/1,999）と同オーダー**
（ただし2件なので幅は非常に大きい）。**違いは件数**——彼らは74件/日、こちらは6.3件/日。

## 4. 取り込めるもの / 取り込めないもの

| | 判定 | 理由 |
|---|---|---|
| ROI（収益性） | ❌ 取り込むものが無い | 10人合計72.4%＝壁の下。既存の内部結論と一致 |
| **三連単枠の件数を増やす** | 🟢 最有力 | 10万+率は既に同等。件数が1桁少ないだけ。7T1 は 2026-08-24 に決勝限定へ絞った直後 |
| **1点を厚くする（1〜3点）** | 🟢 実装済みの形 | 7T1 は既に中央2点・1点3,300円＝厳選AIマスター（2点×5,000円）と同型。上限を上げる余地 |
| 1行=1点で金額を点ごとに変える | 🟢 可能 | 大河原修司は3点に 7,000/2,000/1,000。自社も `BetLeg` 分割で表現可（7H1 が実施中） |
| **二車複** | 🟡 未実装・要判断 | シュウの二車福は**的中37.4%・ROI79.8%・最大21.7万**を1点10,000円で作る。<br>自社は `_BET_TYPE_JP` が3連複/3連単のみ、`keirin_settlement._ORDERED` も2券種のみ。<br>予測オッズモデル・採点・入稿の3箇所に新設が要る |
| レース選別 | ❌ | 彼らは45〜74件/日＝ほぼ全レース。選別していない（厳選AIマスター16件/日が例外） |

🔴 **既存の内部結論と矛盾しない。** 「大きいところは帯でなく点数で作る（払戻=オッズ×10,000/点数）」
（[[keirin_tf_line_pair_bonus_2026_08_26]]）、「4.38点→2.25点で表示的中26.1→33.6%・払戻中央
9,250→15,500円・ROI不変」（[[keirin_trio_exclusion_model_2026_08_25]]）を**外部データが独立に裏付けた**。
新しいのは「競合の高額的中の9/30は200倍未満＝集中型」という**倍率の実測分布**だけ。
