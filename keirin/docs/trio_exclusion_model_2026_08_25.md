# 「◎が来るなら3着に来ない確率」で相手を削る案の検証（2026-08-25）

## ユーザー提案

> 入着する選手を抽出するモデル・順位を見るモデルは作った。だが払戻額を増やすには
> 1点あたりの金額を増やしたい。そこで「来ない側」、しかも **◎が来るなら3着には
> 来ない確率** を出すモデルを作り、相手を減らせないか。

主張を2つに分けて測った。

| # | 問い | 答え |

| Q2 | 点数を減らすと払戻・表示的中・ROI はどう動くか | 🟢 **表示的中も払戻も上がる。実行する価値がある（ただしモデルは要らない）** |

## 🔴 Q1: 提案の形（ME）は周辺 p3 の言い換えでしかない

### 識別性能（AUC・両窓ほぼ同値）

| 目的変数 | p3 | MJ | **ME** | ME2 |
|---|---|---|---|---|
| 買い目的中（三者同時） | 0.707 | **0.755** | 0.719 | 0.742 |
| 相手が3着内 \| ◎が3着内 | 0.721 | 0.694 | **0.729** | 0.717 |
| 相手が3着内 \| 二軸3着内 | 0.750 | 0.759 | 0.761 | **0.774** |

🔴 **ME は自分の土俵（◎条件つき）ですら p3 に +0.007 しか勝てない。**
スピアマン相関 **p3–ME = 0.92〜0.93**、1番手の相手が p3 と一致する率 **77〜83%**。
＝「◎が来る条件」を付けても、周辺 p3 とほぼ同じ順序しか出てこない。

### 同点数での対応差（vs 現行 p3 並べ替え・7車全レース）

| 腕 | 点数 | 探索窓 的中Δ | 確認窓 的中Δ |
|---|---|---|---|
| **ME** | 1 | +0.64pt [+0.27,+1.01] | +0.39pt [+0.11,+0.67] |
| MJ | 1 | **+1.60pt** [+1.12,+2.07] | **+1.30pt** [+0.97,+1.62] |
| ME2 | 1 | **+1.63pt** [+1.13,+2.16] | **+1.23pt** [+0.90,+1.57] |

🔴 **効くのは「来ない側を当てること」ではなく「○も同時に条件に入れること」。**
ME2 と MJ は**一致率 87〜91%**で、実質同じもの。これは数式どおり:

    P(3車すべて3着内) = P(二軸が3着内) × P(相手も3着内 | 二軸が3着内)

レース内で軸2車は固定なので第1項は定数 → **不来確率の昇順 = 条件つき3着内確率の
降順 = 三者同時確率の降順**で argmax が一致する。
**◎だけを条件にすると○の情報を捨てるので、かえって弱くなる**（ME < MJ ≒ ME2）。

🔴 **したがって「不来モデル」は新しい層ではなく §24（相手＝三者同時確率）の別表現**。
§24 は既に vintage で両窓検証済み（[[keirin_s24_vintage_reverify_2026_08_23]]）で、
**7C には移植できないことも測って否定済み**（§29・5候補中4〜5点を買うので集合が
91〜94% 同じ）。本検証はその結論を独立に再現した（下表 k=5 で全腕が完全一致）。

## 🟢 Q2: 点数を減らすこと自体は効く — ただし機序は算数で、モデルは要らない

1レース `RACE_BUDGET`=10,000円を点数で割る（**点数を減らすと1点あたりが増える**）。
7C ゲート近似・**現行の並べ替え(p3)のまま閾値だけ動かした**結果:

| 平均点数 | 1点あたり | 生の的中 | **表示的中**(払戻>賭け金) | ROI | 払戻中央 | 2万+件/日 |
|---|---|---|---|---|---|---|
| **4.38（現行）** | 2,200円 | 58.6 / 58.8% | **26.1 / 25.3%** | 78.4 / 77.3% | 9,250 / 9,000円 | 2.40 / 2.20 |
| 3.58 | 2,500円 | 54.4 / 54.3% | 29.2 / 28.0% | 79.1 / 76.7% | 10,775 / 10,230円 | 2.48 / 2.24 |
| 2.87 | 3,300円 | 48.7 / 49.0% | 32.2 / 31.7% | 77.4 / 76.3% | 12,870 / 12,500円 | 2.72 / 2.47 |
| **2.25** | **4,400円** | 42.7 / 43.2% | **33.6 / 33.6%** 🟢 | 76.5 / 76.1% | **15,500 / 15,000円** | **3.12 / 3.00** |
| 1.76 | 5,000円 | 37.3 / 37.6% | 32.8 / 32.8% | 76.8 / 75.9% | 18,000 / 18,000円 | 3.72 / 3.57 |
| 1.00 | 10,000円 | 25.8 / 26.4% | 25.8 / 26.4% | 74.6 / 77.8% | 25,000 / 26,000円 | 4.38 / 4.42 |

（左＝探索窓 / 右＝確認窓。**表示的中の山が両窓とも 2.2〜2.3点ちょうどに立つ**）

🟢 **現行 4.38点 → 2.25点で、表示的中 +7.5pt / 払戻中央 1.67倍 / 2万+件 1.3倍。**
🔴 **ROI は −1.5pt 前後で動かない**（探索 78.4→76.5・確認 77.3→76.1・CI は重なる）。

### 機序は算数（モデルの手柄ではない）

    4.38点 → 1点2,200円 → 表示的中には **オッズ 4.5倍超** が必要
    2.25点 → 1点4,400円 → 表示的中には **オッズ 2.3倍超** で足りる

**同じ買い目・同じオッズでも、点数が半分なら表示的中になる敷居が半分になる。**
生の的中率は 58.6→42.7% と 16pt 落ちるが、落ちた分はほぼ全部**ガミ**なので
店頭に出る数字（ガミ除きの表示的中）は逆に上がる。
下限があるのは、2点を割ると生の的中の減りが敷居の下がりに追いつかなくなるため。

⚠️ **山の位置は「削り方」ではなく「点数」で決まる。** 同じ平均点数で腕を替えても
表示的中はほぼ同じ（2.25点付近: P3 33.6 / MJ 33.0〜33.3 / ME 34.2〜34.5%）。
モデルで並べ替えると**生の**的中は +2.3pt 増えるが、増える分はオッズの低い目なので
**表示的中には乗らない**（市場が織り込んでいる）。

## 結論

1. 🔴 **提案どおりの「◎が来るなら来ない確率」モデルは作らなくてよい。**
   ◎だけの条件つけは周辺 p3 の言い換え（相関 0.92）。○も条件に入れれば意味を持つが、
   それは §24 の三者同時確率と同じもので、**7C のように4〜5点買う商品には伝わらない**
2. 🟢 **「相手を減らして1点あたりを増やす」という狙い自体は正しく、実測でも取れる。**
   ただし取り方は**閾値を上げるだけ**（`RANK_7C_LEG_P3_MIN` 0.15 → 0.30 相当）で、
   新しいモデルは不要
3. 🔴 **ROI は動かない。** 変わるのは的中の種類（ガミ→表示的中）と配当の大きさだけ。
   これは既知の一般則（回収率は 74〜80% に収束し、動くのはガミ率と配当の大きさ）と整合

## 判断が要る点

現行 7C は `RANK_7C_LEGS_MIN = 4`（相手が4点未満なら**買わない**）なので、
2.25点への変更は 7C の同一性を変える。かつ `rank_7c_select_legs` の docstring は
**「的中体験を優先するユーザー判断で絶対15%を採用」**と記録している。

🔴 **ただしその判断は「生の的中率が 43〜62% に落ちる」という表現で行われていた。**
本検証では**店頭に出る表示的中は逆に上がる**（26.1→33.6%）。
＝当時の判断材料と実際の店頭 KPI が食い違っている可能性がある。再判断の価値あり。

選択肢は2つ:
- (A) 7C の足切りを上げる（既存商品の性格が変わる。生の的中率は落ちる）
- (B) 7C は据え置き、2点前後の別枠を新設する（[[keirin_s24_vintage_reverify_2026_08_23]]
  の「1〜2点しか買わない三連複の商品が無い」という積み残しと同じ場所）
