# 7C 軸2差し替え（◎◯一致時の印外し）の再検証（2026-08-26）

## 問い（ユーザー）

> 二軸を取る際に WT◎◯ と一致した場合、印置き換えをするとしていた。しかし結果 ◎△
> となってもそこまでオッズが変わらない様に感じる。該当商品のレース条件において、
> **指数1位2位とした場合、的中率・ROI が変わるか**、
> **WT◎◯ と一致するのはどれくらいの率か** 確認して。

対象: `strategy_wt.rank_7c_reselect_axis2_off_marks`（2026-08-19 採用・2026-08-21 に
落差 0.30 の停止条件を追加）。

（vintage walk-forward 予測・確定オッズ採点・本番関数をそのまま通す）。

## 結論（先に3行）

1. **一致率は 75.6%（探索窓）/ 83.6%（確認窓）**。そのうち 86〜88% で実際に差し替わる。
   7C が買ったレースの **59〜64% が差し替え後の買い目**。
2. 🔴 **ユーザーの体感は正しい。差し替えても ◎◯ の目は買っている。**
   差し替え後は **◎◯▲ の目を 84〜100% のレースで買い、そこに予算の 36〜46% を置く**
   （◯が軸から相手へ回るだけ）。的中したときの倍率は **5.2倍 → 3.0倍**、
   払戻中央は **19,320円 → 12,880円**。**差し替えは配当を上げていない。下げている。**
3. 指数1位2位へ戻すと **的中率は下がる（−4.6/−6.4pt・有意）が、表示的中と ROI は動かない**。
   代わりに **払戻中央が +2,400/+3,800円・2万円超が 0.97→1.20 件/日（+24%）** 増える。
   ＝ ROI 一定のまま「当たる回数 ↔ 当たりの大きさ」を交換するダイヤル。

## 🔴 採用時（2026-08-19）の実測はベースラインが本番と違っていた

`scripts/exp_7c_axis2_reselect_off_marks.py`（当時のハーネス）は

    着順            1着 1(◎) → 2着 3(◯) → 3着 2(▲)
    確定 三連複 1-2-3 = 3.2倍

    現行  : 軸 1-2（◯を相手へ）→ 1=2=3 に 7,000円 → **22,400円**（本番の実入稿と同一）

### 🔴 ただし1日では符号が決まらない
