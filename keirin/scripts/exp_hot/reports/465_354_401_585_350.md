### 1-1. 465「シュウの二車福」= 二車複を**1点10,000円**で売る商品

- **実効点数は中央 1点**（1点 63 / 2点 22 / 3点 17・平均 1.55点）。
- **配分は完全に3種類の定型**しかない: `10,000円 × 1点` / `5,000円 × 2点` / `3,300円 × 3点`。**100% 均等**（傾斜ゼロ）。
- 買い目の2車は**必ず自社の予測勝率の上位4車から**選ばれる。予測勝率1位を含む商品が **93/102**。
  - 2車の順位ペア: (1位,2位) 67 / (1位,3位) 36 / (1位,4位) 30 / (2位,3位) 14 / (2位,4位) 7 / (3位,4位) 4 → **(1位,2位)は42%しかない**。1位を軸に3位・4位へ流すのが半分以上。
  - 「推奨選手」として名指しするのは 予測勝率1位 84 / 2位 17 / 3位 1。
- 商品名の下のコメントが `的中自信度：S、穴予想度：B` のような**格付けメタ**になっている（12種類）。
  自信度と点数の対応（サンプル）: `SS`→1点、`S`→1〜2点、`A`→1〜2点、`B`→1点。**自信度が高いほど点数を絞る**わけではなく、点数はほぼ独立。

### 1-2. 401「二ノ輪大嵐」= **3連単と2車単を日によって使い分ける**

- 2車単の定型は**4点固定**、配分 `1,000 / 1,000 / 1,000 / 500円` = 3,500円。
  中身は `◎-○` `◎-☆` `◎-無印` `○-▲` の4点（◎頭が3点・○頭が1点）。**32/32件が完全に同一構造**。
- 母集団で購入額 3,500円（＝2車単）の的中率は **142/843 = 16.8%**。同じ人の 3連単14点（10,000円）は **128/1,000 = 12.8%**、3連単8点（9,500円）は **84/576 = 14.6%**。
  → **2車単4点は3連単より的中率が高い**が、それでも母集団 ROI は 64.9% で5人中最下位。

### 1-3. 券種を増やす価値の判断材料（当社は三連単・三連複のみ）

| | 465 二車複1点 | 401 2車単4点 | 354 3連単4点 | 585 3連単8点 | 350 3連単20点 |
|---|--:|--:|--:|--:|--:|

## 5. 的中率型なのに 10万+ が出る理由 — **倍率型ではなく「集中型」**

`払戻 = 的中した1点の賭け金 × 的中倍率` に分解。

### 5-1. 465 シュウの二車福（13件・全件）

| 賭け金/的中点 | 件数 | 倍率レンジ |
|---|--:|---|
| 10,000円（1点集中） | **9件** | 10.0〜21.7倍 |
| 5,000円（2点） | 2件 | 20.6・25.5倍 |
| 3,300円（3点） | 2件 | 32.9・35.8倍 |

- 的中点の賭け金 **中央 10,000円**、倍率 **中央 17.4倍**（min 10.0 / max 35.8）。
- 最大は 217,000円 = `10,000円 × 21.7倍`。
- 🔴 **完全な集中型**。二車複の 10〜35倍という「二車複としては大穴だが競輪全体では中穴」の目を、
  **1点に全額（10,000円）置いているから 10万円に届く**。点数を3点に割った回は
  32.9〜35.8倍という**倍率のほうを引き上げないと 10万に届かない**。
- 逆に言うと **465 は「10倍以上の二車複」を年13/2,051 = 0.63% の頻度で当てているだけ**で、
  倍率を稼ぐ設計は一切していない。

### 5-2. 354 大河原修司（31件・全件）

| | 値 |
|---|---|
| 的中点の賭け金 中央 | **4,000円**（レンジ 1,000〜7,000円） |
| 倍率 中央 | **40.0倍**（min 15.7 / max 474.1） |
| 最大 | 474,100円 = `1,000円 × 474.1倍` |
| 2位 | 449,200円 = `4,000円 × 112.3倍` |

- **集中型と倍率型のハイブリッド**。的中点の賭け金の内訳:
  `4,000円 10件 / 7,000円 6件 / 2,000円 6件 / 3,000円 3件 / 6,000円 3件 / 1,000円 2件 / 5,000円 1件`。
- 3点型 `(7,000/2,000/1,000)` の 7,000円が当たると 15.7〜32.4倍でも 10万を超える（6件）。
- 🟢 **「本命を厚く」が高額的中の主要因**。31件中 **23件（74%）が的中点3,000円以上**、
  1,000〜2,000円の押さえで当たったのは8件（そちらは 51.9〜474.1倍が必要）。

### 5-3. 参考: 高額型2人との対比（同じ分解）

| | 401 二ノ輪大嵐 31件 | 585 Equine Genius 29件 |
|---|---|---|
| 的中点の賭け金 中央 | 1,000円 | 1,200円 |
| 倍率 中央 | **204.2倍**（98〜854倍） | **115.1倍**（83〜1,104倍） |
| 最大 | 477,200 = 1,000×477.2 | 1,324,200 = **1,200×1,103.5** |

🔴 **これが分水嶺**。465/354 は `賭け金 4,000〜10,000円 × 10〜40倍`、401/585 は
`賭け金 1,000〜1,200円 × 100〜200倍`。**同じ10万円でも作り方が真逆**で、
465/354 は「読みが当たれば必ず10万」、401/585 は「薄く広げて大穴を待つ」。

### 5-4. 350 鈴木誠（1件）

161,700円 = `500円 × 161.7倍 × 2`。**同じ組み合わせが2つのフォーメーションで重複していた**
ため実効 1,000円が乗っていた（`an465/350.jsonl` の 20260807 和歌山10R）。
つまり**意図した集中ではなく、シナリオの重なりの副産物**。

## 6. 【最重要】鈴木誠（350）の中身 — 1日5本をどう選び、どう組んでいるか

### 6-1. 選び方は「厳選」ではない — **1開催の後半5レースを機械的に全部**

36日中 **25日**しか出しておらず、出した日は**必ず 5本ちょうど**（min=max=5）。

| 開催 | 日程 | 対象R |
|---|---|---|
| 小田原 | 8/1〜8/4（4日） | 8-12R（最終日のみ 7-11R） |
| 和歌山 | 8/6〜8/9（4日） | 8-12R |
| 松山 | 8/11〜8/16（**6日**） | 7-11R |
| 松戸 | 8/22〜8/25（4日） | 8-12R |
| 前橋 | 8/27〜8/30（4日） | 8-12R |
| 青森 | 9/3〜9/5（3日・継続中） | 8-12R |

- **1日に触る場は必ず1つだけ**。その開催の**最終5レース（後半戦）を全部**出す。
- **Ｓ級 124/125（99.2%）**。Ａ級・ガールズは一切扱わない（例外は和歌山8/9のＬ級1本）。
- レース種別は開催の進行そのまま: 一次予選26 → 二次予選32 → 特選19 → 準決勝18 → 特秀11 →
  初日特別選抜5 → 決勝5。**「決勝だけ」「準決勝だけ」といった選別は一切していない**。
- **選択の意思決定は「どの開催に張り付くか」の1回だけ**（6日間の松山＝GII級の記念開催を含む）。
  レース単位の取捨選択はゼロ。

🟢 **当社が作ろうとしている「1日5本の別商品」との比較**:
鈴木誠は**レースを厳選していない**。「1開催に張り付き、後半5Rを毎日出す」という
**連載型（開催をフォローする物語）**であって、当社の「日次で全国から良いレースを5本選ぶ」
という**選抜型**とは商品設計が根本的に違う。
選抜型にすると、①同じ選手・同じラインを追う連続性が出せない ②「最終日に決勝で回収」という
物語が作れない、という差が生じる。

### 6-2. 組み方 — 「見解のシナリオ数 = フォーメーションのブロック数」

- **3連単のみ**。1商品あたりのブロック（フォーメーション行）数: 1→10件 / **2→65件** / **3→41件** / 4→7件 / 5→1件 / 8→1件。
- ブロックの種別（全304ブロック）:

| 種別 | 件数 |
|---|--:|
| **1着1車固定（二段流し）** | 180 |
| **1・2着同一2車（表裏入替）** | 102 |
| 1着2車 | 9 |
| 点買い | 6 |
| 1着3車 | 4 |
| 1・2着同一3車 | 3 |

- ブロックの形（1着-2着-3着の候補車数）上位: `2-2-4`(46) / `1-3-5`(42) / `1-3-4`(34) / `2-2-3`(32) / `2-2-5`(22) / `1-1-3`(16) / `1-2-5`(13)
- 合計点数は **中央20点・平均19.6点**（10点 11件 / 20点 28件が最頻）。購入額は 9,000〜10,000円。
- 1点賭け金は **500円が主軸**（1,192点）。次いで 400円(537) / 300円(243) / 1,000円(196) / 200円(169)。
  **ブロックごとに単価を変える**（例: 本命シナリオ 500円 → 対抗シナリオ 400円 → 保険 200円）。
  完全均等は 51/125 = 41%、傾斜比 max/min は 中央 1.25・最大 5.00。

### 6-3. 印

- **必ず ◎○▲△ の4車**（124/125。1件だけ3車）。
- **◎は 124/125 = 99.2% で「1着候補」に入る**。買い目のどこかに入るのは 125/125。
- 1着候補に入る印の回数: ◎124 / ▲79 / ○64 / △32。
  → **▲が○より1着に置かれやすい**。○は番手（2着）として扱われることが多い。
- 3着候補には**無印の車も入れる**。

### 6-4. 見解の書き方 — **展開の実況を1〜3シナリオ並べる**

- 文字数 **中央41字**（min 21 / max 79）。**1〜3文、読点区切りで2〜3節が7割超**（節数2:49件・3:52件）。

### 8-1. 350 鈴木誠（人力・元選手）

## 9. 当社への含意（数字ベース）

1. **二車複は ROI を動かさないが表示的中率を +19pt 動かす**。465 は二車複1点で 的中37.1%・ROI 79.1%、
   3連単4点の354は 的中18.4%・ROI 78.9%。**ROI は同じ**。券種の追加は収支ではなく店頭KPIの手段。
2. **二車複でも 10万+ は出せる**（0.63%・0.36件/日）。ただし条件は **1点に10,000円を集中させること**
   （13件中9件が 10,000円×10〜21.7倍）。点数を3点に割ると 33倍以上が必要になる。
3. **点数を積んで的中率を作る道（350型・20点）はガミ48%を招く**。表示的中率は上がるが
   「当たったのに減った」体験が半分。**当社が的中率を上げるなら券種を落とすほう（465型）が筋が良い**。
4. **穴を追うと ROI が沈む**（401 64.9% / 585 63.0% ↔ 465 79.1% / 354 78.9%）。
   高額型2人は 1,000〜1,200円 × 100〜200倍 で10万+を作っているが、その代償が ROI −15pt。
5. **配分はオッズ連動ではなく固定階段**が業界標準（5人全員）。当社の予測オッズ逆数ダッチングは
   競合には無い設計。端数が出ることの見え方は要検討。
6. **「1日5本」商品は選抜型ではなく連載型（1開催×後半5R）が実在の型**。
   選抜型を採るなら、鈴木誠には無い「全国から選ぶ」という価値を明示する必要がある。
