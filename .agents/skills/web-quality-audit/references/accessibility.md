## チェック項目

### 1. WCAG 2.2 準拠（レベルA/AA）

#### 知覚可能
- **代替テキスト**: 全ての画像に適切なalt属性が設定されているか
- **動画/音声**: キャプション、音声解説、トランスクリプトの提供
- **コンテンツの構造**: 見出しレベルの適切な使用（h1→h2→h3の順序）
- **色に依存しない情報伝達**: 色のみで情報を区別していないか
- **コントラスト比**: テキスト4.5:1以上、大きなテキスト3:1以上
- **テキストのリサイズ**: 200%拡大時のレイアウト崩れがないか
- **リフロー**: 320px幅での水平スクロール不要な表示

#### 操作可能
- **キーボード操作**: 全機能がキーボードのみで操作可能か
- **フォーカス管理**: フォーカスの視覚的表示、適切な順序
- **スキップリンク**: メインコンテンツへのスキップナビゲーション
- **タイムアウト**: 操作時間の延長・停止が可能か
- **フラッシュ**: 1秒に3回以上のフラッシュがないか
- **ターゲットサイズ**: タッチターゲット24x24px以上（推奨44x44px）

#### 理解可能
- **言語設定**: html要素のlang属性
- **フォームラベル**: 全フォーム要素に適切なlabelが関連付けられているか
- **エラー識別**: エラー箇所の明示、修正方法の提案
- **一貫したナビゲーション**: 各ページで一貫したUI配置
- **入力補助**: 必須項目の明示、入力形式のヒント

#### 堅牢性
- **HTMLバリデーション**: 正しいHTML構造
- **ARIA属性**: 適切なrole、aria-label、aria-describedby等の使用
- **名前/役割/値**: カスタムUIコンポーネントの適切なアクセシブルネーム

### 2. スクリーンリーダー対応
- **ランドマーク**: main、nav、header、footer等のランドマークロール
- **ライブリージョン**: 動的コンテンツ更新のaria-live通知
- **非表示コンテンツ**: aria-hidden、sr-onlyクラスの適切な使用
- **ダイアログ**: モーダルのフォーカストラップとaria-modal

### 3. フレームワーク固有

#### React
- Fragment vs div の適切な使用
- React Helmet/Head でのページタイトル管理
- カスタムフックでのフォーカス管理

#### Vue
- vue-announcer等でのルート変更通知
- teleportコンポーネントのアクセシビリティ
