# 法務 チェック項目

## 検索クエリ例
- `web application legal compliance checklist {year}`
- `GDPR web application requirements`
- `個人情報保護法 WEBサイト 対応 {year}`
- `open source license compliance`
- `特定商取引法 ECサイト 要件`
- `cookie consent requirements {country} {year}`

## チェック項目

### 1. ライセンスコンプライアンス
- **OSSライセンス**: 使用している全OSSパッケージのライセンス確認
- **ライセンスの互換性**: GPL、MIT、Apache等のライセンス互換性
- **コピーレフト汚染**: GPLライセンスのライブラリがプロプライエタリコードに影響していないか
- **ライセンス表示**: 必要なライセンス表記、著作権表示の実施
- **フォント/画像のライセンス**: 使用しているアセットのライセンス確認

### 2. プライバシー・個人情報保護
- **プライバシーポリシー**: 適切な内容のプライバシーポリシーの掲載
- **個人情報保護法対応**: 利用目的の明示、適切な取得・管理・廃棄
- **GDPR対応**（EUユーザーが対象の場合）:
  - データ処理の法的根拠
  - データ主体の権利（アクセス、修正、削除、ポータビリティ）
  - データ保護影響評価（DPIA）
  - DPO（データ保護責任者）の設置
- **Cookie同意**: Cookie Consent Bannerの実装、オプトイン/オプトアウト

### 3. 電子商取引法令（ECサイトの場合）
- **特定商取引法**: 事業者情報、返品・キャンセルポリシーの表示
- **景品表示法**: 不当表示、有利誤認表示の確認
- **資金決済法**: 前払式支払手段、暗号資産関連の対応
- **PCI DSS**: クレジットカード情報の取り扱い

### 4. アクセシビリティ法令
- **障害者差別解消法**: 合理的配慮の提供
- **ADA対応**（米国ユーザーが対象の場合）
- **EAA（European Accessibility Act）**（EUの場合）

### 5. コンテンツ関連
- **著作権**: ユーザー生成コンテンツの取り扱い、DMCA対応
- **利用規約**: サービス利用規約の適切な掲載と同意取得
- **免責事項**: 必要な免責事項の記載
- **年齢制限**: COPPA対応（13歳未満のユーザーデータ）

### 6. セキュリティ関連法令
- **不正アクセス禁止法**: アクセス制御の適切な実装
- **個人情報漏洩時の報告義務**: インシデント対応手順の整備
- **電気通信事業法**: 通信の秘密の保護（該当する場合）

### 7. 国際対応
- **データの越境移転**: サーバー所在地と法的要件の整合性
- **各国の規制**: 対象国ごとの法的要件への対応
- **言語要件**: 法的文書の多言語対応
