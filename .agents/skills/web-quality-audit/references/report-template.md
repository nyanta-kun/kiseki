## 課題IDの命名規則

各エージェントの課題IDは以下のプレフィックスを使用する：

| エージェント | プレフィックス | 例 |
|---|---|---|
| シニアエンジニア | `ENG-` | ENG-001, ENG-002 |
| QA | `QA-` | QA-001, QA-002 |
| 性能 | `PERF-` | PERF-001, PERF-002 |
| セキュリティ | `SEC-` | SEC-001, SEC-002 |
| 法務 | `LEG-` | LEG-001, LEG-002 |
| アクセシビリティ | `A11Y-` | A11Y-001, A11Y-002 |
| UX/UI | `UX-` | UX-001, UX-002 |
| インフラ/DevOps | `INF-` | INF-001, INF-002 |
| SEO/Web標準 | `SEO-` | SEO-001, SEO-002 |
