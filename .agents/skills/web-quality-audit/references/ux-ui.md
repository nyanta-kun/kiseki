## チェック項目

### 1. レスポンシブデザイン
- **ブレークポイント**: モバイル/タブレット/デスクトップの適切な対応
- **タッチ操作**: タップターゲットのサイズ、スワイプジェスチャー
- **コンテンツの優先順位**: モバイルでの情報表示の優先度
- **画像/メディア**: デバイスに応じた適切なサイズ配信
- **ナビゲーション**: モバイルメニュー（ハンバーガー等）の使いやすさ

### 2. ナビゲーションと情報設計
- **情報アーキテクチャ**: 論理的なページ構造、適切な階層
- **ナビゲーションの一貫性**: 全ページでの統一的なナビゲーション
- **パンくずリスト**: 現在位置の明示
- **検索機能**: 適切な検索機能の提供（必要な場合）
- **404ページ**: カスタム404ページとナビゲーション導線

### 3. フォーム設計
- **ラベルとプレースホルダー**: 適切な使い分け（プレースホルダーのみは不可）
- **バリデーション**: リアルタイムバリデーション、適切なタイミング
- **エラー表示**: エラー箇所の明示、修正方法の案内
- **入力の簡素化**: オートコンプリート、デフォルト値、入力マスク
- **進捗表示**: 複数ステップフォームでの進行状況表示
- **確認画面**: 重要な操作前の確認ステップ

### 4. フィードバックとローディング
- **ローディング状態**: スケルトンスクリーン、スピナー、プログレスバー
- **操作フィードバック**: ボタンクリック、フォーム送信後の視覚的反応
- **トースト/通知**: 操作結果の適切な通知
- **空状態**: データがない場合の適切な表示とCTA
- **エラー状態**: エラー発生時の分かりやすいメッセージと復帰導線

### 5. ビジュアルデザインの一貫性
- **デザインシステム**: 色、フォント、スペーシングの一貫性
- **コンポーネントの統一**: ボタン、カード、リスト等のスタイル統一
- **アイコンの一貫性**: アイコンセットの統一、意味の一貫性
- **タイポグラフィ**: フォントサイズ、行間、文字間の適切な設定
- **余白とスペーシング**: 一貫したスペーシングシステム

### 6. インタラクションデザイン
- **アニメーション**: 目的のあるアニメーション、motion-reduced対応
- **マイクロインタラクション**: ホバー、フォーカス、アクティブ状態
- **スクロール体験**: スムーズスクロール、無限スクロールの適切さ
- **モーダル/ダイアログ**: 適切な使用場面、閉じる手段の明確さ

### 7. コンテンツ
- **文言の明瞭さ**: ユーザーが理解しやすい言葉遣い
- **CTA（行動喚起）**: 明確で具体的なアクションラベル
- **ヘルプ/ガイダンス**: ツールチップ、ヘルプテキストの提供
