# 平八（note 予想家）の馬印データセット

note の予想家 [平八](https://note.com/heihachi888) が公開している「平八的馬印」の
表画像を OCR で復元し、DB の出走表と照合して構造化したもの。
`indices/dm_signals.py` の **平八バッジ**（`SIGNAL_HEIHACHI`）はこの分析から出ている。

## 中身

| ファイル | 内容 |
|---|---|
| `data/heihachi/marks_2024_2026.tsv` | **19,429印 / 4,964レース / 198開催日**（2024-01-06〜2026-08-01） |
| `data/heihachi/note_posts.tsv` | 記事一覧 462件（無料387 / 有料75）。どこが未取得かの台帳 |

`marks_2024_2026.tsv` の列:

- `mark` … `◎`（狙いたい穴馬）/ `○`（馬券内率）/ `▲`（的中率と回収率のバランス）/ `☆`（一発ありそうな穴馬）
- `horse_number` … **DB の出走表から取った確定値**（OCR の数字ではない）
- `name_similarity` … OCR で読んだ馬名と DB の馬名の一致度（1.0 = 完全一致）
- `race_match_score` … その行をどのレースに割り当てたかの確信度（4頭ぶんの平均一致度）

## 再取得の手順

```bash
# 1. 画像を集める（無料記事のみ。有料記事には触れない）
python3 scripts/heihachi/fetch_notes.py --out data/heihachi/raw

# 2. macOS Vision の OCR バイナリをビルド（tesseract より日本語の表に強い）
swiftc -O -o scripts/heihachi/ocr scripts/heihachi/ocr.swift

# 3. OCR して DB の出走表と照合し、馬番を確定させる
python3 scripts/heihachi/match_marks.py \
    --imgs data/heihachi/raw/imgs --out data/heihachi/marks.tsv
```

## なぜ馬名で照合するのか

表は画像で、**OCR の数字は当てにならない**。実際 2026-09-05 の表では
◎の馬番を 4件読み違えていた（1→7、5→1、7→9 など）。一方で馬名はほぼ正確に
読めるので、馬名を DB の出走表と突き合わせて馬番は DB 側から取る。
これで桁誤りが自動的に補正される。

`ocr.swift` は各テキストの**バウンディングボックス**も返す。表の列は x 座標で
分かれているので、`extract_marks.py` は x 帯で ◎/○/▲/☆ を振り分け、
y でクラスタリングして行にしている。左端のレース名（`札1` など）は
Vision が読み落とすことが多いが、**4頭の馬名からレースを一意に特定できる**ので
使っていない。

精度: 2026-09-05 の表を手作業の正解と突き合わせ、**119/119印・30/30レースが一致**。

## わかったこと（分析の要点）

| 印 | n | 人気(中央値) | 1〜4番人気の割合 |
|---|---|---|---|
| ◎ | 4,876 | 8番人気 | **9.4%** |
| ○ | 4,898 | 1番人気 | 94.0% |
| ▲ | 4,799 | 3番人気 | 79.7% |
| ☆ | 4,856 | 6番人気 | 28.5% |

- ◎は「**人気5位以下**」を先に課したうえで **JV-Next DM対戦型**の上位を拾う形
  （人気5位以下プール内で +0.113、t=25.7）。血統は +0.001（t=0.2）で見ていない
- **印そのものに独立情報はほぼ無い。** 対照実験で
  「印 × 指数3位以内 × 10-50倍」単114.5%/複111.8% に対し
  「**印を無視して**指数3位以内 × 10-50倍」単116.5%/複103.1% とほぼ同等
- `jvan_battle_dm` / `jvan_time_dm` は既に v28 の38列特徴に入っている
  （`composite.py`）。平八が使っている情報は composite がもう食べているので、
  **平八の印から新しく取れる情報はもう無い**というのが結論

そこで印は使わず、平八が示していた「穴サイドで3着内率が構造的に高いゾーン」を
自前の指数だけで再現したのが平八バッジ。条件と実測値は
`backend/src/indices/dm_signals.py` の `SIGNAL_HEIHACHI` 節を参照。
