## 測定1: プールは控除率どおり沈んでいる（888開催・15年）

`EV = 0.7 + キャリーオーバー初期 / 売上`（払戻率70%・売上 = 発売票数 × 100円）

| | WIN5 | 地方トリプル馬単（参考） |
|---|---|---|
| プール平均EV | **0.7057** | 0.773 |
| 中央値 | 0.7000 | 0.700 |
| **EV > 1.0 の頻度** | **5/888 = 0.6%** | 8.1%（年29回） |
| 売上中央値 | **6.9億円** | 1,700万円 |
| 的中無（繰越発生） | 15年で10回 | 12年で1,166回 |

🔑 **売上規模が40倍あるため、キャリーオーバーがEVを押し上げにくい。**
5.4億円の繰越（2026-02-08）でようやく EV=2.52 になったのが唯一の大きな例で、
残り4回は 1.00〜1.06 に留まる。**地方よりキャリーオーバー狙いの余地が小さい。**

## 🔴 測定3: 指数は in-sample ですら人気順に負ける（220開催・2023-05以降）

`calculated_indices` v27 は2023-05以降しかなく、かつバックフィルで上書きされた
in-sample 値（全期間学習モデルの遡及適用）。**最も甘い条件での比較。**

| 各R上位K | 点数 | 人気順 | 指数順（in-sample） |
|---|---|---|---|
| 上位3 | 243 | **8.6%** | 5.5% |
| 上位4 | 1,024 | **14.1%** | 10.9% |
| 上位5 | 3,125 | **26.8%** | 19.1% |
| 上位6 | 7,776 | **38.6%** | 31.4% |
| 上位8 | 32,768 | **62.7%** | 55.9% |

最小的中点数の中央値: 人気順 **144点**（14,400円） vs 指数順 **210点**（21,000円）。
**指数の方が1.5倍多く買う必要がある。**

勝ち馬の指数順位の分布（in-sample）: 1位25.5% / 累積 2位44.6% / 3位57.3% /
5位72.9% / 8位88.9%。人気順（1番人気29.0% / 累積5番人気78.3%）に劣る。

→ **in-sample で全選択率で負けている以上、honest では確実に負ける。**
本セッションで JRA の複勝ROI が in-sample 0.906 → honest 0.831、市場への増分が
+0.053 → **−0.022 と符号反転**した実績がある（`HANDOFF_2026-08-23.md`）。

## 踏んだバグ（同じ轍を踏まないために）

最初の測定で**指数順が 100% 的中**という結果が出た。SQL で

```sql
rank() OVER (PARTITION BY race_id ORDER BY composite_index DESC)
...
WHERE rr.finish_position = 1
```

と書いたところ、**WHERE がウィンドウ関数より先に適用され、勝ち馬1頭だけの中で
順位を計算していた**（常に1位）。順位付けは全頭で行い、そのあとで勝ち馬に絞る
CTE に直した。

🔑 **「良すぎる数字が出たら疑う」で気づけた。** 100% は物理的にありえない。

## 意味すること — 律速は「1レースあたりの単勝的中率」

WIN5 は5レースの積なので、**1レースあたりの勝ち馬予測が市場を上回らない限り、
組み合わせをどう工夫しても市場に勝てない**。配分アルゴリズム
（`betting/multi_race_formation.py`）も、入力の勝率が市場より良くなければ
点数配分を最適化するだけで、市場を抜くことはできない。

これは本セッションで独立に確認された事実と一致する:
- JRA 指数と人気順のレース内 Spearman = **0.815**（ほぼ市場のエコー）
- 市場への上乗せ **ΔAUC +0.0025**
- 複勝ROIの市場への増分 **−0.022 [−0.040, −0.003]（有意にマイナス）**

→ **WIN5 に固有の問題ではなく、単勝の予測精度そのものが律速。**
そちらを改めて検討することになる。

## 決着したこと / 残ること

**やらないこと（再検証しない）**
- 指数の並べ替えで WIN5 の収支を取る路線
- そのための walk-forward 再構成（in-sample で負けている以上、答えは出ている）
- キャリーオーバー狙い（EV>1.0 が 15年で5回では検証窓が作れない）

**残ること**

  ただし**買い目の並べ替えは指数ではなく人気順（市場）を使うこと**
- 897開催・15年分の払戻・キャリーオーバー・発売票数は DB に残る
