# JRA 人気薄帯の識別力の天井 — walk-forward 実測（2026-09-06）

「指数の市場残差を使って大穴を拾えないか」（継続課題4）に着手する前の feasibility 測定。

**結論: 人気薄帯には、市場のエコーを差し引いた正味の識別力がもう残っていない。
残差モデルを作っても壁を越えない。**

## 測り方

`backend/scripts/jra_darkhorse_walkforward.py`（既存）をそのまま使用。

```bash
cd backend
.venv/bin/python scripts/jra_darkhorse_walkforward.py \
    --eval-start 20250101 --eval-end 20260930
```

- **四半期ごとに vintage モデルを学習し直して**その四半期を採点する（look-ahead なし）
  - 例: 2025Q3 は 2023-05-06〜2025-06-29 の 787日で学習 → 2025Q3 を予測
- 母集団 160,185行 / 11,664レース（2023-05-06〜2026-09-06）、評価は 2025Q1〜2026Q3 の7四半期
- 主指標は **人気を完全に揃えた層化リフト**（strata = `win_popularity` そのもの）。
  composite 順位と人気順位のレース内 Spearman は 0.815 なので、揃えないと
  「市場のエコー」を自分の手柄として数えてしまう

「帯内 指数1位」−「帯内 それ以外」の3着内率の差。

| 帯 | **WF honest** | in-sample (DB v27) | 判定 |
|---|---|---|---|
| 1-4番人気 | **+5.77pt** [+4.07, +7.58] | +11.67pt [+9.87, +13.49] | 有意 |
| 5-8番人気 | **+2.24pt** [+0.82, +3.67] | +7.05pt [+5.63, +8.49] | かろうじて有意 |
| 9-12番人気 | +0.87pt **[-0.12, +1.82]** | +2.67pt [+1.68, +3.68] | **有意でない** |

## 4. 連続値の残差でも同じ。しかも in-sample だと逆の結論が出る

`モデル勝率 − 市場内包確率`（レース内で控除率を正規化）で層別した単勝回収率:

| 残差帯 | in-sample 2025-07〜2026-06 | **真の OOS 2026-06-29〜09-06** |
|---|---|---|
| < -0.05 | 61% | 90% |
| ±0.01 | 48% | 62% |
| +0.01〜+0.05 | 97% | 73% |
| +0.05〜+0.10 | 130% | 60% |
| **+0.10 以上** | **149%** | **59%** |

in-sample では美しく単調に伸びるが、**OOS では消えて逆転する**。
つまり in-sample の残差は「モデルが答えを覚えている量」を測っているだけ。

⚠️ v28 本番モデルの `refit_period` は 2023-05-06〜**2026-06-28**
（`models/v28_iswin_calib_metrics.json`）。`inference_v28.py` はこの refit モデルで
バックフィルするので、**2026-06-28 以前の `calculated_indices` v28 は全部 in-sample**。

## 6. 判断

**継続課題4（残差モデル）は着手しない。** 根拠:

1. 人気薄帯の正味リフトが統計的にゼロ（§2）
2. 残差ルールの天井が 0.79（§3）で、連続値にしても OOS では消える（§4）
3. 地方競馬側が同じ結論に到達済み — `backend/docs/chihou_darkhorse_feasibility_2026_08_05.md`:
   「帯の中でモデル勝率の上位を取ると ROI は**下がる**（全帯で −0.06〜−0.16）。
   **市場特徴を外して学習し直しても EV 十分位は無効のまま**」

これは作り方の問題ではなく、**現在の特徴量セットが市場と同じ情報しか持っていない**
という構造の話。同じ壁は他でも確認済み:

- note の予想家「平八」の馬印 19,429件を逆解析しても独立情報は無かった
  （`scripts/heihachi/README.md`）
- 平八が使っていた `jvan_battle_dm` は既に v28 の38列特徴に入っている

## 7. 代わりに残っている道

- **A. 情報源を増やす** — モデルの作り方ではなく入力を変えないと動かない。
  市場が織り込みにくい情報（パドック、直前の馬体、当日の外部情報）の探索
- **B. 「当てる」用途に集中する** — honest でも 1-4番人気帯には +5.77pt の正味リフトが
  残っている。回収は無理でも**的中率の分離としては本物**。hit_tier や平八バッジは
  この用途なので、そちらを磨くほうが確実
- **C. 何もしない** — 「現状の指数は能力推定としては妥当で、市場を出し抜く余地は
  測定した範囲では無い」は悪い結論ではない
