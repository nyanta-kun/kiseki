# Claude Code 引き継ぎ ― 「メイン会場の決勝・特選・チャレンジ決勝に的中を集中させる」作戦の検討

## 1. 今回の件（背景と発見）

二軸探偵（netkeirin 予想家）の 8/8 実績をレース単位で分析したところ、以下が判明した。

- 8/8 は 31戦11的中（的中率 35.5%）、回収率 74.9%、売上（＝販売有償pt）5,060。フラットな数字は良好。
- しかし **売上の 84%（4,250pt）が「外れたレース」に集中**。的中したレースに乗った売上は 16%（810pt）だけ。
- 売上上位はすべて**決勝・特選クラスの看板レース**で、全て外れ：
  - いわき平 A級 チャレンジ決勝 1,650pt / 買い手7人 / 外れ
  - いわき平 A級 特選 1,150pt / 6人 / 外れ
  - 伊東 A級 チャレンジ決勝 600pt / 3人 / 外れ
- 一方、**高配当（≒4〜5万の払い戻し）を返したレースは軒並み売上ゼロ**：
  - 岐阜 A級 準決勝 回収447%（≒44,700円）→ 買い手0・売上0
  - 佐世保 SA混合 男子新人戦予選 回収204% → 買い手0・売上0
- 決勝/特選クラス 10レース中の的中は 2 のみ。にもかかわらず、その 10レースに当日売上の 84% が乗った。

**構造化した結論**：「売れた時に当たらず、当たり出した時に売れていない」。買い手は注目度の高い**メイン会場の決勝・特選・チャレンジ決勝**に集中するが、モデルはまさにそこを取りこぼしている。売上加重で見ると“当てた体験”を提供できておらず、集客が伸びない根因になっている。

**検討したい作戦**：メイン会場の決勝・特選・チャレンジ決勝での的中精度を最優先化し、そこに最も自信のある二軸（上位ランク）を集中させる。売れないが当たった準決・予選は無料公開／的中報告で誘導に回す。

## 3. 「メイン会場における決勝・特選・チャレンジ決勝」の確認方法

Claude Code に渡す判定の“中身”。ドメイン定義とデータ上の当たり所を分けて示す。

### 3-1. レース種別（決勝・特選・チャレンジ決勝）の特定

競輪の1開催（多くは3〜6日制）で、注目と売上が集まる看板レースは概ね次のとおり。

- **決勝**：開催最終日の最終レース。最も注目・売上が集まる。
- **特選（特別選抜）**：実力上位を集めた特別レース。初日〜中日の看板。
- **チャレンジ決勝**：A級チャレンジ（新人・下位級）の決勝。

データ上の当たり所（実スキーマ名はリポジトリで確認させること）：

- **レース名／種別カラム**に「決勝」「特別選抜（＝特選）」「チャレンジ決勝」の文字列が入る。分析支援ツールのレース別明細でも同表記（例：「A 決勝」「A 特選」「A チャレンジ決勝」）。文字列マッチ or 種別コードで判定。
- **レース番号**：決勝は当日の最終R（会場の最大レース番号）。
- **級班（S級/A級/ガールズ L級）**：S級決勝＞A級決勝の順で注目が高い。級班カラムで層別。
- **開催日程**：最終日フラグ or 「〇日目／全〇日」で決勝日を識別。

### 3-2. 「メイン会場」の特定 ― 2通り

**(a) 事前判定（レース前に“今日どこを本命に張るか”を決める用）**
開催の格・条件で決まる。優先度の高い順に会場を採点する。

- **開催グレード**：GP > G1 > G2 > G3（記念）> F1 > F2（ミッドナイト）。上位グレードの開催がメイン会場。
- **ナイター／ミッドナイト区分**：ナイター場は仕事後の購買が乗りやすく、後半レースに売上が集中（8/8のいわき平が該当）。
- **S級開催の有無**：S級が組まれている開催は注目が高い。
- **決勝日（最終日）**：決勝が置かれる日は当該会場がその日のメインになりやすい。

→ これらはスケジュール／出走表（projected entries 系）から取得。開催グレード・ナイター区分・級班・開催日数が鍵。

**(b) 事後判定（分析・検証用の“実際に売れた場”）**
netkeirin の**レース別売上（販売有償pt・購入者数）を会場×日付で集計**し、当日トップの会場を「メイン会場」とみなす。

- データ源：分析支援ツール「予想家成績状況（レース別）」（`https://umaiaggre.yosoka.netkeiba.com/tool_keirin/result/yosoka_result.html`、明細＝レース別）。会場は集計名に含まれる（例「08/08 いわき平 A級 チャレンジ決勝」）。
- 実運用では kiseki に取り込んだ netkeirin レース別売上テーブルがあればそれを会場集計。なければ日次(netkeirin_sales_daily)は会場内訳を持たない点に注意（レース別の取り込みが要る）。

**(a)と(b)の突き合わせ**が重要：事前に“メインだと見込んだ会場”に本当に売上が集中したか（＝予想精度を上げる価値がある場か）を、事後の販売有償ptで検証する。8/8は事前(ナイター・A級決勝のいわき平)と事後(売上トップ=いわき平)が一致していた。

### 3-3. 実装時の最小フィルタ（擬似ロジック）

```
看板レース = レース種別 in {決勝, 特別選抜(特選), チャレンジ決勝}
メイン会場(事前) = 開催グレード・ナイター・S級有無・決勝日 でスコア上位の会場
メイン会場(事後) = Σ販売有償pt を 会場×日 で集計し当日トップ
対象レース = 看板レース かつ (メイン会場(事前) または メイン会場(事後))
```

このフィルタで切り出したレースについて、モデルの二軸的中率・回収率を全体と比較し、弱ければ最優先の改善対象、という流れ。
