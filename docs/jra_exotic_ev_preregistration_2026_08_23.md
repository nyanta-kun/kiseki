## 母集団

- JRA 10場、`abnormality_code` が取消・除外でない完走馬
- 単勝オッズ ≥ 12 倍（穴馬帯。複勝的中時に3倍以上つく確率が69%を超える最初の帯）
- 三連複・ワイド・馬連・馬単・複勝の確定オッズが**すべて**揃うレース
- 複勝が2頭以上発売されているレース（4頭立て以下を除く）

## 特徴量（10列・すべて対数）

各券種の確定オッズから逆算した marginal:

| 列 | 意味 | 規格化 |
|---|---|---|
| `m_trio` | 三連複全組 → 3着以内 | Σ=3 |
| `m_wide` | ワイド全組 → 3着以内 | Σ=3（Σ(1/odds) を3に正規化後、2で割る）|
| `m_quin` | 馬連全組 → 2着以内 | Σ=2 |
| `m_exa1` / `m_exa2` | 馬単 → 勝ち / 2着 | Σ=1 |
| `m_win` / `m_win2` | 単勝オッズ + Henery(λ=0.82) → 3着以内 / 2着以内 | Σ=3 / Σ=2 |
| `mkt_p` | 単勝オッズ → 勝ち | Σ=1 |
| `m_place` | 複勝オッズ → 3着以内 | Σ=3 |
| `hc` | 頭数 | — |

⚠️ ワイドと複勝の `latest_odds` は**最低オッズ**が入る。複勝は補正係数 K で戻す。

## モデル

- ロジスティック回帰（`C=0.3`, `max_iter=5000`）、目的変数は「3着以内（`place_slots` 準拠）」
- **全馬で学習し、評価だけ穴馬帯に絞る**（部分集合で学習しない）
- 出力はそのまま確率として使う。**レース内で Σ=3 への再規格化はしない**（較正が壊れる）

## 期待値

    EV = p_hat × 複勝オッズ(格納値) × K

`K` = 学習期間だけで推定した「実払戻 ÷ 格納値」の中央値（探索時は 1.100）。
**評価期間のデータで K を推定し直さない。**

## 期間の割り方

- 学習: 母集団の最初の 60%（開催日ベース）
- 評価: 残りの 40%。前半・後半に2分割して両方報告する

## 事前登録する閾値

**EV ≥ 0.95 のみ。** 他の閾値は報告してよいが、採否判断には使わない。

## 判定基準

| | 基準 |
|---|---|
| 主 | 複勝 ROI の 95%CI 下限 > 1.00（評価期間まとめ） |
| 従 | 日次 ROI 中央値 > 1.00 |
| 頑健性 | 評価前半・後半の両方で点推定 > 1.00 |

**主基準を満たさなければ不採用**とし、閾値を動かして探し直さない。
