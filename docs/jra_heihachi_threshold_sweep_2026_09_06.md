# 平八バッジのしきい値 頑健性評価（2026-09-06）

`[[jra_heihachi_badge]]` のしきい値を、`jra_protocol` の窓に沿って評価し直した記録。

**結論から: 回収率の主張は支持されなかった。3着内率の分離だけが残る。**

## 経緯

平八バッジは 2026-09-06 に、全期間（2023-01〜2026-09）の平均だけを見て既定値を
決めていた。既存の「特穴」(`[[jra_anagusa_elite_signal]]`) が 2窓のスイープで
決めているのに対し、この手続きを踏んでいなかったため、やり直した。

## 窓

| 窓 | 期間 | 用途 |
|---|---|---|
| W1 | 2025-07-01〜2025-12-31 | 探索（VAL 前半・TRAIN_END 後なのでモデルには OOS） |
| W2 | 2026-01-01〜2026-06-30 | 探索（VAL 後半） |
| TEST | 2026-07-01〜2026-09-06 | 一度きり評価（2026Q3・台帳に記録済み） |

## 1. 2窓スイープには選別力が無かった

`指数順位 {2,3,4,5} × オッズ下限 {5,8,10,12,15,20} × 上限 {25,30,40,50,60,100}
× 複勝確率 {.20〜.45} × {OP特別以上, 全レース}` の 1,392〜1,728 通りを回した。

| 各窓の最低 n | 「2窓とも複勝ROI>1」を満たす割合 |
|---|---|
| n≥30 | **47%**（651/1392） |
| n≥100 | 39%（400/1018） |
| n≥200 | 30%（222/746） |

候補の3〜5割が通ってしまう。**VAL 期間（2025H2・2026H1）がこの手のシグナルに
とって単に good period だった**ということで、ここでの生存は情報を持たない。
「2窓とも1超」を採用基準にしたら、ほぼ何でも通る。

## 3. 残るもの: 3着内率の分離

回収率と違い、**3着内率の分離は TEST でも残っている**。

| | ベースライン | 全レース/rk3/10-50/30% |
|---|---|---|
| W1 | 22.1% | 32.2% |
| W2 | 20.9% | 35.3% |
| TEST | 22.8% | **29.8%** |

既存の「穴」バッジと同じ性格（`dm_signals.py` の
「複勝ROIは母集団全体で<1(控除率の壁)であり、『回収率』でなく
『的中率の頑健な分離』が目的」）に落ち着く。

## 4. 示唆

1. **平八バッジは「回収率を狙うタグ」ではなく「3着内率を分離するタグ」として
   位置づけ直すべき。** 画面の回収率の注記も同様に直す必要がある
2. 既定値を絞るほど n が落ち、点推定のブレだけが大きくなる。現行の
   15-40倍/40% は TEST で n=9 まで落ちるので、しきい値としては細すぎる
3. しきい値を TEST の結果を見て選び直すと 2026Q3 を焼くことになる。
   選び直すなら **2026Q4 を独立窓として使う**か、of の判断で「的中率基準」に
   切り替えて回収率の主張を落とす

## 5. 注意

- v28 は 2023-2025 にバックフィルされており、W1（2025H2）は TRAIN_END(2025-06-30)
  より後なのでモデルには OOS。W2・TEST も同様
- ただし 2026Q3 は 2026-09-04 の v28 デプロイ判断で既に一度開封されている
  （台帳参照）。完全に無垢な窓ではない
- TEST の n が小さい（現行既定で9頭）。この期間だけで「効かない」と断定する
  のではなく、「W1/W2 の強い数字は再現しなかった」と読むのが正しい
