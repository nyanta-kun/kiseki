# 二軸探偵｜入稿時 再検討方針 ＆ タイトル生成インプット

最終更新：2026-08-09
用途：**この文書を ClaudeCode に読ませ、入稿商品のタイトル・見解（`netkeirin_settings.title_template` / `comment_template`）を生成・改訂するためのインプット。**
根拠：大サンプル検証（STEP1/1B/1C）で確定した購入方針（`docs/二軸探偵_入稿購入ルール改定_仕様書.md`）と、利用者目線のタイトル課題（`二軸探偵_タイトル見解_改善提案.md`）を統合したもの。

---

## 0. この文書の位置づけ（ClaudeCodeへ）

- タイトル／見解は「**実際に買っている中身**」と一致していなければならない。方針が変わったら文言も変える。この文書は "いま何をどう買っているか＝各ランクの性格" を確定情報として与える。
- タイトルは一覧画面で購入可否をほぼ決める最重要要素（見解本文は購入後）。**狙い（堅い／妙味／大穴）＋二軸ブランド＋レース固有の数字**を必ず織り込む。
- 誇大・断定（「絶対」「鉄板」）は禁止。二軸探偵の "静かに照らす・回収率で語る" トーンを守る。

## 1. 大前提：確定した購入方針（2026-08 検証済み）

大サンプル＋アウトオブサンプル検証で、以下が確定した。**タイトルはこの実態に合わせる。**

- **配分・集中・相手の並べ替えでは、的中率ランク(7C/7A)のROIは上がらない**（控除率25%＝市場効率の壁）。→ 7C集中・7Aライン優先は棄却。
- **低配当レース見送りが効くのは 7A だけ**（ROI 84→90〜98%、2026年OOSでも再現）。7C/7Sは無効。
- **ダッチ配分（1.3倍保証）が有効なのは高配当 7H1/9H1 のみ**（人気の目に依存しないため）。
- **的中率ランクのガミは "バグ" ではなく "的中率を買うためのコスト"**。人気の目は切らない（切ると収支悪化）。→ ガミ抑制を売り文句にできるのは **ダッチを効かせる 7H1/9H1 のみ**。7C/7A では「ガミが減る」と書かない。

## 2. ランク別｜入稿時サマリ（タイトルに込める "性格"）

| ランク | いま実際に買っているもの | 狙いの性格 | 頻度（入稿数） | タイトルに込める核 |
|---|---|---|---|---|
| **7S / 9S** | 軸2車が明確に抜けた本命堅め・総流し | 王道・自信 | 中 | 自信／本命堅め |
| **7A / 9A** | **top2_sum q20ゲートON＝本命が割れた高配当レースだけ厳選**・総流し | 妙味を厳選（少数精鋭） | **低（従来比 約▲80%）** | 厳選・妙味・中〜高配当 |
| **7B** | 相手まで絞った少点数構成 | 絞り・1点の厚み | 中 | 少点数・絞り（**「準決勝」は書かない**） |
| **7C** | 現行の総流しを完全維持（市場効率でレバー無し） | 的中体験・手堅く | 高（主力） | 手堅く的中・本線 |
| **7SS** | entropy不合格 × **軸2車が同一ライン**（勝負アイコン「自信あり」） | ライン本線・自信 | 低 | ライン本線・自信 |
| **7H1 / 9H1** | **ダッチ配分（朝オッズで1.3倍保証・低オッズ目を選別）**・本命バスト型 | 大穴・高配当（配分最適化） | 低 | 本命バスト・高配当・配分最適 |

**重要な変化点（前回タイトル案からの更新）：**
- **7A は "厳選" を前面に**。ゲートONで出走が約8割減った＝「今日出したら、それは選び抜いた妙味の一戦」。少数精鋭・希少性をタイトルの武器にできる（例：「本日の厳選妙味」）。日によって7Aが0件のこともある点も、逆に "毎日は出さない" 信頼の演出に使える。
- **7C は "的中体験枠" と明確化**。大穴を狙わず的中を積む主力。毎日コツコツ派に向けた安定タイトル。
- **7H1/9H1 は "配分の工夫" を1要素として足せる**（ダッチでガミを抑えている＝当たったときの取りこぼしが少ない）。ただし買い目の点数・保証倍率そのものは伏せる。
- **タイトルは `狙い｜レース見解` の2ブロックへ（2026-08-09 実装済み）**。会場・R番号・日付は
  netkeirin の一覧に別途出るので**外した**。後半はレース構造から自動で選ばれる（§3B）。
  **7車/9車の区別も書かない**（購入者には不要）。
- **7SS は "波乱" ではない**。2026-08-02 に全廃した旧7SS（波乱軸選出）と名前が同じだけの別物で、
  現行は「entropy不合格 × 軸2車が同一ライン」＝勝負アイコンも「自信あり」。ライン本線で書く。

## 3. 入稿時に使える変数（朝確定・発走まで不変）

🔴 **テンプレートに書ける変数はここに挙げたものが全て。** 実装は
`keirin/scripts/netkeirin_submit_wt.py::_apply_template()` の固定辞書で、
**未定義の `{...}` は例外にせずそのまま素通しする**。つまり存在しない変数名を書くと
商品タイトルに `{bust_prob}` という文字列がそのまま出る（エラーにならず静かに壊れる）。

| 変数 | 意味 | 使いどころ |
|---|---|---|
| `{shape}` | **レース構造の見解**（自動選択・下記 §3B） | **タイトル後半の主役**。全ランク |
| `{shape_note}` | 同じ構造判定を1〜2文にしたもの | **見解本文の冒頭**。全ランク |
| `{stake_note}` | 賭け金配分の説明（均等／傾斜を**実際の買い目から**判定） | 見解本文。全ランク |
| `{venue}` | 会場名（`venue_info.name`・全角2〜4字） | 原則不使用（netkeirin 一覧に別途表示され重複するため） |
| `{race_no}` | レース番号 | 同上・原則不使用 |
| `{date}` | 対象日 `YYYY-MM-DD` | 原則不使用 |
| `{rank}` | ランクキー | 内部確認用 |
| `{axis1}` `{axis2}` | 軸2車の車番 | **タイトル・本文冒頭では使用禁止**（買い目の露出）。本文の【二軸】節でのみ使う |

**未実装のため使えない**（2026-08-09 時点）：`{race_type}` `top2_sum` `{gap12}` `{bust_prob}`
`morning_fav_odds` `EV` `dutch_min_return` `{excluded}`。これらを差し込みたい場合は
先に `_apply_template()` の拡張が要る。

注意：**買い目（点数・具体的な車番・保証倍率の数値）はタイトル／プレビューに出さない**。出すのは「狙い・根拠・期待」まで。

### 3B. `{shape}`｜レース構造ラベル

入稿時点で確定している値（`wt_entries` の予測確率・登録脚質・ライン）だけで決まる6ラベル。
判定と文言の**単一正本は `keirin/src/race_shape.py`**（`SHAPE_TITLES`）。
文言はランク×ラベルで固定されており、設定画面からは変更できない。

| ラベル | 判定 | 実測比率 |
|---|---|---|
| `solo` 1車抜け | 1着率 1位−2位 ≥ 26pt | 30.4% |
| `duo` 二枚看板 | solo以外 ∧ 3着内率 2位−3位 ≥ 18pt | 19.4% |
| `line` 同ライン | 上記以外 ∧ 軸2車が同一ライン | 18.4% |
| `split` 別線対決 | 上記以外 ∧ 軸2車が別ライン | 13.4% |
| `mixed` 混戦 | 1着率差 ≤ 10pt ∧ 3着内率差 ≤ 7pt | 9.9% |
| `clash` 先行争い | 別ライン ∧ 逃げ（登録脚質）≥ 3人 | 8.6% |

比率は 2026-07-01 以降・7車以上の 2,913 レース実測。閾値は「はっきり言い切れるレースにだけ
ラベルを付ける」意図で上位・下位30%点に置いている。**表示専用で、どのレースを買うかには
一切影響しない。**

⚠️ **同ライン判定はそのランク自身の軸2車で行う**。7C だけ軸が `axis1_7c`/`axis2_7c` で
他ランク（`axis1`/`axis2`）と別物なので、取り違えると全レースで line/split が入れ替わる。

### 3C. `{stake_note}`｜配分の説明は買い目から導く

ダッチ配分（7H1/9H1）も傾斜配分（他ランク）も、**朝オッズが揃わなければ均等へ
フォールバックする**（欠損は約半数）。そのため「オッズに応じて配分しています」を
テンプレートに固定で書くと**半分のレースで嘘になる**。

`_stake_note_for()` が**実際に入稿する買い目**の単価を券種ごとに見て、
ばらついていれば傾斜、揃っていれば均等の文面を返す。
7H1 は三連単と三連複で単価が違うのが正常なので、**券種をまたいで比べてはいけない**。

ガミ抑制の一文が付くのは 7H1/9H1 が傾斜になったときだけ（§4-6）。

## 4. タイトル／見解の要件（生成ルール）

1. **タイトル必須・空文字禁止・タグ禁止**。全角14〜18字目安（上限20字。`tests/test_race_shape.py` が機械的に検査する）。
2. **構成**：`狙い（堅い/妙味/大穴）｜{shape}`。前半（狙い）は DB の `title_template`、後半は
   `race_shape.SHAPE_TITLES` が持つ。二軸ブランド語（二軸／照らす／探偵）を前半に1つ入れる。
   **会場・R番号・日付は入れない**（netkeirin の一覧に別途表示され重複するため・2026-08-09）。
   **7車/9車の区別も書かない**（購入者には不要。9S/9A/9H1 は 7S/7A/7H1 と同一文言）。
3. **見解プレビュー**：買いたくなる1〜2文。根拠と期待だけ見せ、買い目は伏せる。機械タグ「指数中心」は廃止。
4. **世界観の一貫**：探偵・闇/光・厳選・回収率。誇大な断定は禁止。
5. **末尾の集客導線**（購入後見解の末尾に全ランク共通）：的中実績はプロフィール公開中→「ウマい！」お気に入り登録の一言。発走直前の最終オッズ確認を促す一文も全ランクに残す（信頼づくり）。
6. **実態一致の原則**：7Cで「大穴」と書かない。7C/7Aで「ガミを抑えた」と書かない（ダッチは効かせていない）。7H1/9H1でのみ「配分を工夫」表現を許可。7Aは「厳選／今日の妙味」を積極的に使う。

## 5. ランク別｜タイトル・見解 方針

タイトルは **2026-08-09 に実装済み**。前半（狙い）は
`keirin/scripts/update_netkeirin_title_templates.py::TITLE_TEMPLATES` が DB へ流し込み、
後半（レース見解）は `keirin/src/race_shape.py::SHAPE_TITLES` が持つ。
**前半はランク内で一定にすること**（構造ごとに前半を変えたくなったら、それは前半ではなく
`SHAPE_TITLES` 側に持たせるべき違い）。

| ランク | 前半（`title_template`） |
|---|---|
| 7S / 9S | `自信の二軸｜{shape}` |
| 7A / 9A | `厳選の二軸｜{shape}` |
| 7B | `相手を絞った二軸｜{shape}` |
| 7C | `本線の二軸｜{shape}` |
| 7SS | `ライン本線の二軸｜{shape}` |
| 7H1 / 9H1 | `穴狙いの二軸｜{shape}` |

後半（`{shape}` の実文言）:

| | solo | duo | line | split | clash | mixed |
|---|---|---|---|---|---|---|
| **7S** | 本命一枚が抜けた | 二枚看板が堅い | ライン決着を素直に | 別線対決を制す | 先行争いでも軸は不動 | 混戦でも軸は譲らない |
| **7A** | ―（下記） | 上位2車堅く3着が妙味 | ライン決着に妙味 | 別線対決に妙味 | 先行争いが妙味を生む | 混戦の妙味を照らす |
| **7B** | 1番手が明確 | 二枚看板を軸に | ライン決着に絞る | 別線対決を絞る | 先行争いを見切る | 混戦を絞り込む |
| **7C** | 軸1車が抜けた | 二枚看板で手堅く | ライン通りに手堅く | 別線対決も本線で | 先行争いでも本線で | 混戦でも本線を通す |
| **7SS** | 1番手が抜けた | 二枚看板が堅い | ライン決着濃厚 | ―（下記） | ―（下記） | 混戦こそ本線 |
| **7H1** | 抜けた本命を疑う | 二枚看板の一角が崩れる | ライン決着の盲点 | 別線対決が荒れを呼ぶ | 先行争いで波乱を待つ | 混戦から高配当を |

**定義上あり得ない組み合わせ**（欠かしてあるのは意図的）:
- **7A × solo** — q20ゲートで「本命が割れた」レースだけを通すので1車抜けと両立しない。
  `classify_shape()` が 7A のときだけ solo を捨ててライン系へ倒す。
- **7SS × split / clash** — 「軸2車が同一ライン」が選出条件そのもの。
  出たら選出ロジックかライン判定が壊れた合図なので、`shape_title_text()` が
  **警告を返して入稿ログに出す**（無言でフォールバックしない）。

### 5B. 見解本文（`comment_template`）

**2026-08-09 に実装済み**（`update_netkeirin_templates.py::COMMENT_TEMPLATES`）。
全ランク共通の骨格:

```
{shape_note}                    ← レース構造の見解1〜2文。車番を含まない

【二軸】
本レースで照らし出した二軸は、◎{axis1}番・○{axis2}番です。

【この買い目について】
<ランク固有の狙い＋買い方>
{stake_note}

【ご購入にあたって】  … 発走直前の最終オッズ確認をうながす
【予想者より】        … 的中実績はプロフィール公開中→「ウマい！」お気に入り登録
【参考データ】        … この直後に出走選手の1着率・3着内率テーブルが自動追記される
```

🔴 **冒頭に軸2車を置かない。** netkeirin は本文の先頭をプレビュー表示しうるので、
従来の「本レースで照らし出した二軸は、◎1番・○2番です。」が1行目だと
**無料で買い目を配る**ことになる（§4-3）。◎○ は【二軸】節まで下げてある。

🔴 **集客導線は【参考データ】より前**。出走表は本文の**末尾へ自動追記**されるので、
後ろに置くと表が導線の下に来て締まらない。

ランクごとの狙い（【この買い目について】の1文目）:
- **7S / 9S**：当方の指数で軸2車がはっきり抜けたレースだけ。三連複・軸2車流し。
- **7A / 9A**：本命が割れ、相手次第で配当が伸びるレースだけを絞ってお届け。**毎日は出ない**。
- **7B**：軸2車が明確に絞り込めたレースだけ。相手も絞った構成。
  **「準決勝」は書かない**（購入者に伝わりにくいとの判断・2026-08-09）。
- **7C**：大穴は狙わず、まず当てることを優先。3着以内に届きそうにない車は相手から外す。
- **7SS**：軸2車が同じラインで揃ったレースだけ。
- **7H1 / 9H1**：抜けた本命が4着以下に沈むと読んだレース。本命と同ラインの選手も外す。

⚠️ **2026-08-09 以前は 7S/7A/7C/7SS/9S/9A が「軸2車に自信が持てるレースだけを厳選して
お届けしています」という同一文**で、7C（主力・的中体験枠）や 7SS（ライン本線）の実態と
合っていなかった。`tests/test_race_shape.py::test_comment_body_differentiates_ranks` が
同一文へ戻るのを検出する。

## 6. 入稿時チェックリスト（再検討ポイント）

各営業日の入稿前に、ランク／レース単位で以下を確認し、タイトル生成に反映する。

1. **このレースはそのランクで実際に購入対象か**（7A は top2_sum q20ゲートを通ったか。落ちたレースは 7A タイトルを作らない）。
2. **狙いの性格が正しいか**（7C を妙味/大穴と書いていないか。7A は厳選・妙味になっているか）。
3. **入稿ログに `WARN ... 構造ラベル ... は定義上発生しないはず` が出ていないか**
   （7SS × split/clash・未定義ランク）。出ていたら選出ロジックかライン判定を疑う。
4. **ガミ抑制の文言は 7H1/9H1 のみに限定されているか**（7C/7A には書かない）。
   → `stake_note_text()` が機械的に保証。設定画面で本文を手編集したときだけ要確認。
5. **7A が0件の日**：無理に量産せず、その日は 7C/7S 中心の並びで良い（希少性はブランド上むしろプラス）。
6. **誇大・断定・買い目の露出がないか**（点数・車番・保証倍率の数値は出さない）。
   → タイトルと本文冒頭は `tests/test_race_shape.py` が検査。
7. **末尾の集客導線と最終オッズ確認の一文が入っているか**。→ 同上（テストで検査）。

上記 3・4・6・7 は `tests/test_race_shape.py` が機械的に検査する。**手で毎日確認するのは
1・2・5 だけでよい**（設定画面から本文を手編集した場合は全項目を目視すること）。

## 7. 検証との接続（前向き）

- タイトルだけ先行改訂し、「本日の二軸」量産日 vs 改訂タイトル日で **販売数・売れ筋順位** を比較（日次ダッシュボードの検証セクションで観察）。
- 特に **7A の厳選タイトル**が「少数でも売れるか（1件あたり販売数）」を追う。ゲートで件数が減るため、1件あたりの訴求が効かないと総販売が落ちるリスクがある。件数×1件販売数で総売上を見て、7Aゲートのq20をq30〜q40へ緩める判断材料にする。
- タイトル改訂の効果は「当てて→告知して→集客」の相関が最も効く既知結果と合わせ、的中日のタイトル・見解が固定客化に効いているかを確認する。
