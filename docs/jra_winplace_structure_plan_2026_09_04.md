ユーザーの観測: **現行の単勝率は市場を超えていない。** 市場オッズに依存しない改善を探す。

> レースには1着を取りに行った結果3着内に残った馬と、勝つのは難しいため1着は諦めて

> ケースもあるのではないか。

この2つは同じ根に繋がる。**現行は「1頭につき強さが1つ」というモデルを置いており、

## 2. 中心となる主張（これを検証する）

**Harville / Plackett-Luce は Luce モデルであり、各馬に「強さ」を1つだけ割り当てる。**
ランダム効用で書くと全馬のノイズ項が同一スケールの Gumbel に従うという仮定であり、
この仮定の下では**単勝確率の順位と複勝確率の順位は数学的に必ず一致する（交差しない）**。

Henery の λ は全馬共通のスカラーなので、本命/穴の**集計的な**歪みは直せるが、
**馬ごとの交差は1件も作れない**。

したがってユーザーの仮説が実在するなら、それは
**馬ごとに着順分布の散らばり σ_i が違う**（heteroscedastic random utility）という形でしか
表現できず、現行の3ヘッド構成では原理的に出力できない。

### 2.1 🔴 既存の測定は、この仮説の反証になっていない

`jra_rank_quality_review_2026.json` の `p_top3`（独立二値ヘッド）の上乗せは
`HEAD_top1_place` で +0.4pt にとどまる。**しかしこの指標は指数1位の馬しか見ないため、
「単勝順では下位だが複勝順では上位」という交差を原理的に検出できない。**
交差が何件起きていても、1位馬が入れ替わらない限り数字は動かない。

**よって仮説は未棄却である。** 交差を見るための指標を先に作る（§3）。

## 4. Phase A — 残差診断（学習なし・これが最初の判定点）

**目的**: ユーザーの仮説（馬ごとの交差）が実在するかを、モデルを作らずに確かめる。

### 4.1 手順

1. walk-forward で `p_win` を再構成する（DB の値は訓練内混入があるため使わない）
2. `p_place_harville = _harville_place_probs(p_win)` を**本番と同じ関数で**算出する
   （🔴 独立実装をしない。`src/indices/composite.py` の関数をそのまま import する）
3. 各馬の残差 `r_i = 実測(3着内) − p_place_harville_i` を取る
4. **`p_win` の10分位で層別する**
5. 各層内で、次の切り口ごとに残差の平均と 95%CI（レースクラスタ bootstrap）を出す
   - `runner_type ∈ {escape, leader, mid, closer}`（`pace_handicap.py:117` の関数を import）
   - 過去5走の**着順の分散**の3分位
   - 過去5走の**勝率と複勝率の比**の3分位

🔴 **`p_win` で層別しないと、λ が既に扱っている本命-穴バイアスを再発見するだけになる。**
これは層別の目的そのものなので省略不可。

### 4.2 判定基準（事前に固定する）

| 判定 | 条件 |
|---|---|
| **仮説あり** | 探索窓で、いずれかの切り口で層内の残差差が **95%CI が 0 を跨がず**、かつ**確認窓で同符号で再現**する |
| **仮説なし** | 上記を満たす切り口が 0 件 |

**効果量の報告**: 残差差の pt 値と、それが複勝確率の何%に相当するかを併記する。
有意でも効果量が 1pt 未満なら「実在するが小さい」と書く。

### 4.3 stop rule

**Phase A が「仮説なし」なら、σ_i を持つモデル（§6c）には進まない。**
複勝は単勝の従属変数のままとし、§5 と §7 だけを実施する。

## 5. Phase B — 測定基盤（Phase A と並行・独立）

現状 `jra_rank_quality_review.py` が持つ指標は top1勝率 / NDCG@3 / Spearman / ECE / Brier。
**単勝率の精度を測る proper scoring rule と、市場ベースラインの並置が無い。**

追加するもの:

| 指標 | 理由 |
|---|---|
| **レース単位の多項対数損失** `-Σ_race log p(勝ち馬)` | 1レース1事象の proper scoring rule。単勝率の精度そのもの |
| 一様分布 `1/n` に対する情報利得 | 頭数の違いを吸収して窓をまたいで比較できる |
| **同窓の市場ベースライン**（1番人気の勝率・市場含意確率の多項対数損失） | 「市場を超えていない」を数字で固定する。**リポジトリに現存しない** |
| **複勝側の順位品質**（3着内馬の被覆率・複勝の対数損失・`is_top3` に対する Spearman） | §2.1 の通り `top1_place` では交差を検出できない |

🔴 市場ベースラインは**評価にのみ**使う。特徴量には入れない（本件は「市場に依存しない改善」の検討）。
🔴 市場含意確率は**発走前オッズ**から作る。確定人気（`race_results.win_popularity`）は使わない
（発走10分前の1番人気が確定と一致するのは 80.7%・`CLAUDE.md:1327`）。

**top1勝率は n=2,046 で SE ≈ 1.0pt** であり 0.5pt の改善を判定できない。以降の施策は
すべて多項対数損失で採否を決める。
