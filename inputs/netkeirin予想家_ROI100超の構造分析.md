# netkeirin予想家 ROI100%超の構造分析

作成日：2026-07-30
前提：自モデルは車単位の信号積み上げで**ROI 79%が天井**（比1.056）。必要な比1.333の約1/6しか埋まっていない。
本文書の問い：**netkeirin上に年間ROI 100%超の予想家が実在するなら、その差分はどこから来ているのか。**

---

## 0. 結論（先に）

**ギャップの正体は「新しい特徴量」ではなく「賭ける対象の選び方」である。**

自モデルの測定フレームは「**全レース・全車**を五分位に切って比を測る」構造になっている。この枠組みで出た「天井1.056」は、正確には**全レースに賭け続ける前提での天井**。一方、ROI 100%超を出している予想家は全員が例外なく**賭けるレースを絞っている**。

比1.333は「全買い目」で必要なのではなく「**実際に賭けた買い目の集合**」で必要なだけ。母集団を1/10に絞れば、平均1.05の信号でも選択後の部分集合で1.33に達し得る。**79%と101%の間を埋める唯一の構造的な筋がここにある。**

加えて、車単位の比とN連単単位の比は**数学的に別の量**であり、後者は未測定である。この2点が本文書の核心。

**この表から読み取るべきこと（順番が重要）**

1. **週間の数字は完全にノイズ。** Jは週間133%だが年間83%。週間で133%を出している予想家を見て「勝てるロジックがある」と判断してはいけない。**評価は年間のみで行う。**
2. **年間83%は自モデルの79%とほぼ同じ水準。** つまり「穴狙い3連単の専業予想家」は自モデルとほぼ同じ壁にいる。これは自モデルが劣っているのではなく、**穴志向という戦略が構造的にその水準に収束する**ことを示している。自モデルのFLB測定（市場確率<5%帯で比0.765・ROI 57%）と完全に整合する。
3. **年間101%を出しているMr.Tの的中率は25%。** これは穴狙いではない。的中率25%で回収率101%なら、的中1回あたりの回収は投資額の約4倍。**中確率帯で二軸を組み、中位配当を拾う構造**である（次章で実例を分解）。

**したがって最初の結論はこうなる：ROI 100%超の実例は「穴を当てる」ことでは達成されていない。** 二軸探偵のブランドが穴志向である限り、Jの83%が到達点になる可能性が高い。ここはブランド設計と数字の間の構造的な矛盾として、明示的に扱う必要がある。

## 2. 最重要発見：Mr.Tの買い目は「二軸構造」そのものだった

2026年7月28日 豊橋10R（G3・S級特秀・7車立て）の実際の買い目を全点取得できた。**これが本文書で最も価値のある材料。**

### 2-1. 買い目の全体像

投資 10,000円 / 3連単30点 / **1点あたり100円〜1,200円の非均等配分**
結果：`6＞1＞3` 的中（700円 × 52.4倍 = 36,680円） 収支 **+26,680円**

```
軸2車 = 1（平野想真・得点101.70・逃）と 6（山内卓也・得点98.00・追）
※同一ライン（1平野 - 6山内 - 3新田 の3車ライン）の先頭と番手

■ 1着1・2着6（本線）        1＞6＞2/3/4/5/9      5点  3,100円
■ 1着1・2着その他            1＞2＞X, 1＞5＞X,
                              1＞9＞X, 1＞3＞6     14点 3,100円
■ 1着6・2着1（裏）           6＞1＞2/3/5/9        4点  1,700円
■ 1着その他・2着1            2＞1＞X, 5＞1＞X,
                              9＞1＞X, 3＞1＞6     8点  2,100円
```

### 2-2. ここから読み取れる設計原理（4点）

**(1) 構造は完全に「二軸」である。**
30点すべてが「**1と6のうち少なくとも1車が1着、もう1車が2着以内**」という条件を満たす。二軸探偵が目指している構造と同一。しかも軸2車は**同一ラインの先頭と番手**であり、「軸1に連動してくる可能性が高い選手」という発想がそのまま実装されている。**二軸というコンセプト自体は、年間ROI 101%の予想家が実際に採用している構造として裏付けが取れた。**

**(2) 1着・2着の順序を両方買っている（表裏）。**
`1＞6＞X` と `6＞1＞X` の両方を持っている。二軸モデルの出力を「1着はどちらか確定させる」方向に持っていく必要はなく、**「2車が1-2着を占める」という同時事象を狙い、順序は両建てする**のが実装として正解であることを示している。実際に的中したのは裏の `6＞1＞3` だった。**表だけ買っていたら外れている。**

**(3) 賭け金が均等ではない。ここが最大の学習点。**
最大1,200円（`1＞6＞3`）から最小100円まで12倍の差がある。同じ点集合でも配分でROIは変わる。**自モデルの測定は「点の選択」の精度しか見ていないが、ROIは「点の選択 × 配分」の積で決まる。** 配分の次元がまったく評価されていない。

**(4) 1番人気を軸から外し、相手には残している。**
見解では「北津留翼（5番車・得点110.65）に人気が集まりそうだが、今節の動きは本調子には一息とみる」。得点最上位クラスの選手を軸から外しつつ、`1＞5＞X` `5＞1＞X` で保険を掛けている。**「人気を外す」と「人気を切る」を区別している**。二軸モデルでも、軸から外した人気馬を相手に残すかどうかは配分の問題として扱える。

## 3. ROI 79% → 101% を埋める3つの次元

自モデルの測定フレームに存在しない次元を3つ特定した。**優先度はこの順。**

### 次元① レース選択（race selection）★最重要

3名全員が独立に、しかも明示的に述べている。

- **Mr.T**：「特定のレースにこだわらず、**オッズ妙味があると判断したレースを厳選**」
- **J**：「不確定要素の大きい『**競り**』のあるレースは避けるなど、レース選定にも独自のこだわり」「**穴の可能性を感じたレースだけを厳選**」
- **中川**：「**主導権争いが明確で、流れが一本に決まるレースは一点で勝負**します。展開の分岐が多いときは、あえて言葉でヒントを残す『穴狙い』に回す」

**3名が共通して言っているのは「予測の不確実性が低いレースだけを選ぶ」ということ。** 中川の表現が最も明確で、「流れが一本に決まる」か「展開の分岐が多い」かでレースを二分し、前者にのみ一点で資金を投じている。

**これは自モデルで即実装できる。** モデルの予測分布そのものが不確実性の指標になる。

```
# レース単位の「予測可能性」指標（すべてモデル出力から計算可能・追加データ不要）
pred_entropy            # 車ごとの1着確率分布のシャノンエントロピー（低い＝読みやすい）
top1_prob               # 最上位車の予測確率（高い＝一本に決まる）
top1_minus_top2         # 1位と2位の予測確率差（大きい＝主導権が明確）
top2_prob_sum           # 上位2車の確率合計 ★二軸モデルならこれが本命指標
ensemble_disagreement   # 複数モデル／複数シードの予測の分散（大きい＝読めない）
model_vs_market_kl      # 自モデル分布と市場含意分布のKLダイバージェンス
                        # 大きい＝市場と見解が食い違う＝妙味がある可能性

# 展開の分岐リスク（第II部の既存設計と接続）
B_top2_gap              # バック回数上位2名の差（小さい＝主導権争い＝中川の言う「分岐が多い」）
n_senko_in_race         # 先行型の人数
has_seri                # 競りの有無（Jが明示的に除外している条件）
line_size_entropy       # ライン構成の予測しやすさ
```

**測定手順（既存スクリプトの改造で足りる）**

1. 全レースを `top2_prob_sum`（または `pred_entropy`）で十分位に分割
2. 各十分位で**その分位に賭けた場合のROI**を算出。全レース平均ではなく分位別に見る
3. **上位分位でROIが1.333を超える分位が存在するかを確認する。** 存在すれば、そこが賭けるべきレース群
4. 分位を絞るとサンプルが減るのでTRAIN/TEST両窓での安定性は特に厳しく見る

**この測定が本文書で最優先の提案。** 「全レースの平均ROIが79%」と「上位10%のレースのROIが79%」はまったく別の主張であり、後者はまだ検証されていない。

### 次元② 券種と組み合わせ構造 ★測定単位の盲点

**車単位の比とN連単単位の比は数学的に別の量である。** 自モデルの測定（車の3着内確率の比＝最大1.056、ペアの比＝最大1.039）は、3連単の順序付き同時確率の比を測っていない。

3連単の的中には「どの3車か」に加えて「**その順序**」の推定が必要で、順序部分に独立したedgeが存在し得る。実例（2-2の(2)）が示す通り、Mr.Tは表裏を両建てしており、順序の推定に自信がないことを配分で表現している。逆に言えば、**順序の確率推定に自分のモデルの優位性があるなら、そこは車単位の比には一切現れない。**

さらに構造的な理由がある。3連単は組み合わせ数が7車立てで210通り、9車立てで504通り。**組み合わせ数が多い券種ほど市場の価格形成は粗くなる**（1点あたりの投票額が薄く、大衆の注目が上位人気に偏る）。二車複・二車単の少数の組み合わせは市場が精緻に価格付けするが、3連単の中位配当帯は相対的に放置されやすい。**Mr.Tが3連単中心で、しかも中確率帯（的中25%）を狙っているのはこの構造と整合する。**

```
# 測定すべきこと（未実施と推定）
1. 券種ごとの比の測定
   二車複 / 二車単 / 三連複 / 三連単 それぞれで
   「自モデル予測確率 ÷ 市場含意確率」を確率帯別に算出
   → 券種によって比が違うなら、そこが券種選択のロジックになる

2. 3連単の「順序」部分の比
   ・同一3車集合の中で、順序を当てる確率の推定精度を市場と比較
   ・「上位2車が1-2着を占める（順序不問）」の比 と
     「順序を特定した」の比 を分けて測る
   → 前者だけにedgeがあるなら、表裏両建てが正解と数値で確認できる

3. 二軸構造そのものの比
   「軸2車が1-2着（順序不問）× 3着流し」という買い目集合単位で
   実測的中率 ÷ 市場含意確率 を算出
   → これは車単位・ペア単位のどちらとも異なる第3の測定単位
```

**Mr.Tの実例が示す測定単位は「二軸＋3着流しという買い目集合」であり、自モデルはこの単位で一度も測っていない。**

### 次元③ 賭け金配分（staking）

実例では1点あたり100〜1,200円の12倍の幅がある。均等配分ではない。

同じ点集合・同じ確率推定でも、配分を変えればROIは変わる。理屈は単純で、**期待値の高い点に厚く、低い点に薄く置けば全体の期待値が上がる**。逆に均等配分は「全点の期待値が等しい」という強い仮定を暗黙に置いている。

```
# 実装（モデル出力とオッズがあれば計算のみ）
ev_per_point = model_prob × odds        # 点ごとの期待値
# 配分方式の比較
uniform_stake                            # 均等（現行の暗黙の前提）
ev_proportional_stake                    # 期待値比例
kelly_fractional_stake                   # Kelly基準の一定割合（分散を抑える）
ev_threshold_filter                      # ev < 1.0 の点は買わない（点数を削る）
```

**特に効くのは最後の `ev_threshold_filter`。** 買い目を広げると的中率は上がるがROIは下がる。中川が「点数を広げれば的中率は上がる。だが、それでは回収率が上がらず、ファンの利益にも繋がらない」と述べているのは、まさにこの現象を経験的に言語化したもの。**期待値1.0未満の点を機械的に削るだけでROIは改善する。追加の情報は一切要らない。**

**注意**：これは新しいedgeを生むものではなく、既存のedgeを効率的に取り出す操作。比1.056の信号を1.333にはできない。しかし**79%→85%程度の改善は配分だけで起こり得る**ため、次元①と組み合わせて評価すべき。

## 4. 3名共通の定性ロジックと、自モデルでの位置づけ

3名の発言から、市場で実際に使われているロジックを抽出し、ABC分類に落とす。

### 「初手（スタート直後の位置取り）」— 中川が最重視

> 「予想の起点として最初に見るのは、出走表の数字ではない。スタート直後の位置取り、すなわち『初手』だ」「**誰が前を取るかで、レースの形はほぼ決まる。ここが全てのスタートです**」
> 「選手の並び、車番、**スタート回数**、そして各選手の『**好みの位置**』をデータから読み解き、最初の形を決定する」

**元選手（通算バック1,350本・生涯バック奪取率50%超）が「出走表の数字より先に見る」と言っている変数**である点が重い。そして彼が挙げた材料は**並び・車番・スタート回数**という、すべて出走表にある公開データ。

これは前回メモの **II-4（S回数とS/B比率）** と完全に一致する。S回数は出走表に記載されているのに予想での使用頻度が低い変数として挙げていたが、**プロが最重要視していることが裏付けられた。優先度を上げるべき。**

「好みの位置」の定量化が未実装。これは実装可能：

```
# 「好みの位置」＝過去レースでその選手が実際に取った位置の分布
pos_dist_entropy        # 位置取りの分散（一貫している選手 vs 状況次第の選手）
preferred_pos_mode      # 最頻の位置（前/中/後）
pos_consistency         # 直近N走で同じ位置を取った率
S_rate × car_no         # 内枠×S意志＝実際に前を取れる（既提案）
S_rate × preferred_pos  # 「前を取りたい」と「実際に前を取る」の一致度
```

### 「着順ではなく内容」— Mr.Tと中川が同じことを言っている

> Mr.T：「数字より"内容"です。長い距離を先行して風を受けながら粘った選手は順位が悪くても調子がいい。逆に、たまたま番手で勝っただけなら数字ほどの価値はない」
> 中川：「展開に恵まれただけの1着よりも、自分の型を貫いて、死力を尽くした末に負けた2着、3着の方がはるかに価値がある場合がある。逆に、**自分の得意な展開に持ち込みながら負けているなら、それは深刻な『危険信号』**」

**中川の後半が特に重要。** これは単なる「着順は展開次第」ではなく、**「展開と結果の整合性」という二次的な指標**を述べている。

- 得意な展開に持ち込めた × 負けた → **危険信号（衰えている）**
- 不利な展開 × 負けた → 情報価値なし（割引くべきでない）
- 不利な展開 × 粘った → 好調シグナル

これは**「決まり手（自分の型を通せたか）× 着順」の交互作用**として実装できる。前回メモのC-7（上がりタイム順位−着順）を一段深めたもの。

```
# 展開と結果の整合性
got_preferred_style     # そのレースで自分の脚質通りの走りができたか
                        # （逃げ型が逃げた／追込型が番手を確保した）
style_match × finish_rank   # ★中川の言う「危険信号」の実装
                        # got_preferred=1 かつ 着順が悪い → 負のシグナル
                        # got_preferred=0 かつ 着順が悪い → 中立（割引かない）
agari_rank_minus_finish_rank  # 既提案（展開に恵まれなかった度）
```

**この「展開×結果の整合性」は、市場が着順という単一の数字で粗く処理している部分を精密化するもので、C分類の定義に合致する。** しかも外部データ不要。

### 「ラインの意図」— Mr.T

> 「『ラインの意図』です。並びの裏には必ず理由がある。なぜこのラインなのか、どういう駆け引きがあるのか」

これは前回メモ I-3 の「車番−得点順位の残差＝編成委員の主観情報」と同じ構造の発想を、ライン側に適用したもの。並びは公開されているが、**「なぜその並びになったか」（同県・同地区・師弟・過去の連携実績）は定量化されていない。**

```
line_same_pref_count        # ライン内の同県選手数
line_same_region_count      # 同地区
line_pair_history_count     # そのライン内の2車が過去に同じ並びで走った回数
                            # ★「連携実績のあるライン」は結束が固いはず
line_pair_sujime_rate       # その組み合わせの過去スジ目決着率
line_is_unusual             # 同県・同地区でないライン（＝寄り合い所帯＝崩れやすい）
```

**`line_pair_history_count` は二軸探偵の核と直結する。** 「軸1に連動してくる選手」の最も直接的な証拠は「過去に実際に連動した実績」である。

### オッズの扱い — 中川の手順が示唆的

> 「netkeirinの予想を出す段階では、**オッズは見ません。先に見ると自分の分析が引っ張られてしまう**。まず展開を組み立て、その後にズレを確認するために見るんです」

これは前回メモ II-5 で述べた「オッズを学習に入れるとモデルが市場を模倣し、期待値の源泉が消える」という警告と**まったく同じ構造の主張**。人間が経験的に到達した手順が、機械学習の設計原則と一致している。**学習にはオッズを入れず、選別段階でのみ使う**という設計は正しい。

## 5. 生存者バイアスの正しい扱い（結論を歪めないために）

以上を踏まえた上で、**netkeirinの数字をそのまま「達成可能な水準」と見なすことには留保が必要**。

**留保すべき点**

1. **母集団が見えない。** netkeirinには多数の予想家が在籍し、ランキング上位が優先的に露出する。N人から上位を抽出すれば、偶然でも100%超は出る。「100%超の予想家が3人いる」は「100%超が達成可能」の証明にはならない
2. **数字はサイト側の集計であり、独立監査ではない。** 集計の窓・除外規則（欠場レースの扱い等）は不明
3. **年間101%・104%は100%をわずかに超える水準にすぎない。** 「必要な比1.333」を全レースで達成しているわけではなく、**選択後の部分集合で1.0強を達成している**と解釈するのが自然。この解釈は次元①（レース選択）の重要性を裏付ける

**それでも構造的な示唆として重い理由**

3名は文体もスタイルも異なるが、**レース選択・点数の絞り込み・オッズを後から見る手順という3点で完全に一致している**。これは偶然の生存者に共通して現れる特徴ではない（偶然の生存者なら戦略は多様に散らばるはず）。**「何を予測するか」ではなく「どこで賭けるか」に共通の構造がある**という読み方は、生存者バイアスを考慮してもなお成立する。

**検証可能な形にする**：netkeirinの予想家ランキングを一定期間スクレイピングし、**予想家数の分布に対して上位のROIが二項分布から期待される範囲を超えているか**を検定すれば、生存者バイアスかどうかは判定できる（サイトの利用規約の確認は必要）。ただしこれは学術的な確認であり、自モデルの改善には直結しないため優先度は低い。

## 6. Claude Code での検証タスク（優先度順）

すべて**追加データ収集ゼロ**で実行可能。既存のモデル出力とオッズだけで足りる。

### タスク1【最優先】レース選択による分位別ROI

```
目的：「全レース平均79%」が「選ばれたレースでも79%」なのかを確認する
手順：
  1. 全レースについて top2_prob_sum, pred_entropy, top1_minus_top2,
     model_vs_market_kl を算出
  2. 各指標で十分位に分割し、分位別に ROI と比を算出
  3. TRAIN/TEST 両窓で上位分位の比を比較
判定：
  上位分位で比 > 1.333 が両窓で再現 → レース選択が答え。ここに集中
  全分位で比がフラット（1.05前後） → レース選択では埋まらない。次元②へ
注意：
  分位を絞るとサンプルが減る。各分位のレース数と信頼区間を必ず併記
  「上位1%だけ勝てる」は実運用に耐えない（年間の賭けレース数が足りない）
  ので、上位10%〜20%で成立するかを重視すること
```

### タスク2【最優先】測定単位を「二軸＋3着流し」に変更した比

```
目的：車単位・ペア単位で天井1.056でも、二軸買い目集合単位では違う値になるか
手順：
  1. 自モデル上位2車を軸とし、「その2車が1-2着を占める（順序不問）」事象を定義
  2. この事象の実測発生率 ÷ 市場含意確率（該当する3連単/二車複の合成）を算出
  3. さらに順序を特定した場合の比を別に算出し、両者を比較
判定：
  順序不問の比 > 順序特定の比 → 表裏両建てが正解（Mr.Tの実装と一致）
  どちらも1.05前後 → 券種を変えても埋まらない。次元③と①に絞る
```

### タスク3 券種別の比

```
目的：券種によって市場の価格形成の粗さが違うか（組み合わせ数が多い券種は粗いという仮説）
手順：二車複・二車単・三連複・三連単それぞれで、確率帯別に比を算出
判定：三連単の中確率帯（市場確率5〜20%）で比が他券種より高ければ、
      そこが Mr.T の的中率25%・平均4倍回収と整合する狙い場
```

### タスク4 配分最適化のバックテスト

```
目的：同じ点集合でも配分でROIがどれだけ動くか
手順：uniform / ev比例 / Kelly / ev<1.0除外 の4方式でROIを比較
判定：ev<1.0除外だけで何%改善するかを確認。新情報ゼロで得られる改善分
注意：新しいedgeは生まれない。次元①と組み合わせた場合の合計効果で評価
```

### タスク5 「展開×結果の整合性」特徴量（中川ロジックの実装）

```
目的：着順という単一指標を「展開と結果の整合性」に分解する
実装：got_preferred_style（脚質通りに走れたか）× 着順 の交互作用
判定：「得意展開かつ着順不良」が負のシグナルとして両窓で有意か
     （これが中川の言う「深刻な危険信号」）
```

### タスク6 ライン連携履歴（`line_pair_history_count`）

```
目的：「軸1に連動してくる選手」の最も直接的な証拠＝過去の連携実績を定量化
実装：ライン内2車の組み合わせの過去同一並び回数・スジ目決着率
判定：二軸探偵の軸2選定に直接使える。連携実績のあるペアで比が上がるか
```

### タスク7 S回数・初手関連の優先度引き上げ

```
理由：元選手（中川）が「出走表の数字より先に見る」と明言した変数
実装：S_rate × car_no, S_rate × B_rate（S/B比率）, 位置取り分布のエントロピー
```

## 7. ブランド設計への含意（数字と訴求の衝突）

数字が示していることを率直に書く。

- 自モデルのFLB測定：市場確率<5%帯の比0.765（**ROI 57%**）
- J（徹底した穴狙い・3連単）：年間83%
- Mr.T（中確率帯・多券種・レース厳選）：年間101%

**穴を狙うほどROIは下がる、という関係が自前の測定と市場の実例の両方で一致している。** 「二軸探偵」の**軸を絞るという構造は年間101%の予想家が実際に採用しているもので、正しい**。しかし**穴志向という味付けは、ROIを構造的に下げる方向に働く。**

ここは二者択一ではなく、**商品を分けるのが自然な解**だと考える。

- **ROI商品**：中確率帯の二軸＋レース厳選。「勝ち続ける」訴求。Mr.T型
- **的中/夢商品**：穴狙い。「二軸探偵が高配当を射抜く」訴求。J型
- 前回メモに書いた「A分類は的中率商品としての価値はある」という整理がここで効いてくる

なお中川の以下の発言は、予想家という商品設計そのものについての示唆として有用。

> 「そんな穴20点も言われても誰も買わへん。**一点で当ててくれたら安くても買うわ**」
> 「アンチの人であっても的中を楽しめるように、**軸は絶対にブレさせません**。5番が軸ならそこは明確にする。そうすることで、僕の予想の裏を想像するスペースが生まれる」

**「軸を明示する」ことが商品価値である**という指摘は、二軸探偵のブランド設計と完全に一致している。ユーザーが自分でひねれる余地を残すことが、むしろ信頼と購買につながるという構造。

## 8. まとめ

| 論点 | 結論 |
|---|---|
| ROI 100%超の実例は存在するか | **存在する**（Mr.T年間101%・中川104%）。ただし生存者バイアスの留保あり |
| その差分は新しい特徴量か | **違う。「賭ける対象の選び方」である**（レース選択・券種・配分） |
| 二軸という構造は正しいか | **正しい**。年間101%の予想家の買い目が実際に二軸＋3着流し構造 |
| 表裏（順序）はどうすべきか | **両建てが正解**。実例の的中は裏側。順序を特定しない設計に |
| 穴狙いは有効か | **構造的に不利**。自前FLB測定と市場の実例（Jの83%）が一致 |
| 自モデルの天井79%は本当の天井か | **「全レースに賭ける前提」の天井にすぎない。**レース選択後の部分集合での比は未測定 |
| 次に何を測るか | **タスク1（レース選択の分位別ROI）とタスク2（二軸買い目集合単位の比）** |

**一言で言えば、探索の方向を「もっと良い特徴量を探す」から「同じ信号でどこに賭けるかを選ぶ」に切り替えるべき、というのが本調査の結論。**
