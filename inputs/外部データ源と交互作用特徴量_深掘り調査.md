# 第I部：WINTICKET外のデータ源

## I-1. 先頭誘導員（誘導員）★最優先の新規候補

### 何が分かったか

JKA『競輪の番組編成の要領』第4章第1節第7項および出走表の記載事項から、以下が確定している。

- **先頭固定競走では先頭誘導員（先頭員）が付き、その氏名は出走表に記載される。**
- 誘導員は**開催初日の概ね2週間前に打診、概ね10日前に本財団へ通報**され、当該誘導員に参加通知が出る。つまり**発走のはるか前に誰が誘導するか確定している。**
- 誘導員は原則として**担任都道府県内の選手**から選任される（＝会場ごとに登場する誘導員の顔ぶれが固定的で、履歴が蓄積しやすい）。
- 誘導員は審判室の指示を受けながら周回し、**選手は誘導員を追い抜けない。** つまり誘導員のラップが**レース前半のペースの上限を物理的に規定している。**

### なぜCか

誘導員が刻むペースが速ければ先行選手の脚が削られ差し・捲りが決まりやすくなり、遅ければ隊列が詰まって先行が残りやすくなる。**これはレース展開の最上流の変数**でありながら、市場では「誘導員が誰か」は予想の話題にほぼ上がらない。人間は誘導員の名前を見ても何の情報も引き出していない。一方、我々は**誘導員IDごとに過去レースの結果を集計するだけで、その誘導員の「ペース傾向」を推定できる。** 「市場が見てはいる（出走表に書いてある）が、まったく処理していない」という点でCの定義に最も忠実。

### 実装

```
# 誘導員マスタの構築（出走表から誘導員名を抽出し、過去レースに紐付け）
pacer_id
pacer_race_count                # その誘導員の総担当レース数（信頼度の重み）
pacer_mean_agari_time_z         # 担当レースの上がりタイムを会場・級班で正規化した平均
                                # 低い＝ラストが速い＝前半が緩い（脚が残る）ペース
pacer_nige_rate                 # 担当レースの1着決まり手が「逃」だった比率
pacer_sashi_rate                # 同「差」比率
pacer_line_sujime_rate          # スジ目決着率（ライン内で1-2着が決まった比率）
pacer_favorite_win_rate         # 1番人気の1着率（＝堅く収まりやすい誘導員か）

# ★本命特徴量：会場・級班・時期で条件付けたベースラインからの偏差
pacer_nige_rate_residual        # pacer_nige_rate − 同会場同級班の平均逃げ率
pacer_agari_residual            # 同様に上がりタイムの残差

# 交互作用
pacer_nige_rate_residual × 当該選手の脚質（先行かどうか）
pacer_agari_residual × bank_length
```

### 実装上の注意

- **誘導員の担当は会場に強く紐づく**ため、誘導員効果と会場効果が交絡する。必ず**同一会場内での誘導員間の差**として測ること。会場を跨いだ生の比較は会場効果を拾って偽陽性になる。
- 誘導員の担当レース数が少ないとノイズになる。**担当50レース未満は「その他」に丸める**などの縮約（shrinkage）を入れる。ベイズ的な事前分布への縮約（同会場平均への収縮）が安全。
- **先頭固定競走でないレースには誘導員が付かない。** フラグで分離すること。
- 出走表に誘導員名が記載されるのは公式仕様だが、**WINTICKETの画面・APIレスポンスに含まれているかは要確認。** 含まれていなければKEIRIN.JPの出走表側から取得する必要がある（＝ここだけが外部収集）。

## I-2. 概定番組表による「勝ち上がりインセンティブ」★強い新規候補

### 何が分かったか

『競輪の番組編成の要領』第2章第2節より、**GIII・FI・FII・250は「本財団があらかじめ定めた対戦選手の組合せの基準（概定番組表）」に基づいて編成される。** つまり勝ち上がりの構造は開催前から決定論的に決まっている。具体的には以下が確認できた。

- 3日制：初日予選 → 2着（レースにより3着）以内で2日目準決勝へ → 準決勝3レース各3着以内の計9名が決勝へ
- 4日制：初日・2日目が予選、3日目準決勝、4日目決勝
- **初日特選（シード戦）に出走する選手は着順に関わらず準決勝に進める**
- 順位決定戦・特選など、勝ち上がりに繋がらない敗者側レースが存在する
- 失格者は次に出走すべき競走から除外される
- 同着・棄権・競走不成立時は、直近前走の格・着位による優先順位、または**抽選による「みなし着位」**で勝ち上がりが決まる

### なぜCか

**「このレースで何着に入れば何が得られるか」が選手ごとに違う。** 着順不問でシードされている選手は無理をする理由がなく、逆にボーダー着位の1つ外にいる選手は勝負に出る。市場では「決勝だから気合が入る」程度の粗い処理しかされていないが、**概定番組表を実装すれば「このレースの当該選手にとっての勝ち上がりの限界着位」を全レースについて機械的に計算できる。** これは選手の強さとは直交する「動機」の変数であり、既存特徴量への純増寄与が期待できる。

### 実装

```
advancement_threshold           # このレースで勝ち上がるのに必要な着位（2 or 3 or None）
is_seeded                       # 着順不問で次に進める（初日特選など）→ 走る動機が弱い
is_dead_end_race                # 勝ち上がりに繋がらないレース（順位決定戦・特選の一部）
                                # → レース全体の本気度が下がる＝波乱要因にもなる
day_in_series / total_days
is_final                        # 決勝
is_semifinal

# 交互作用（本命）
is_seeded × 脚質（先行）         # シードされた先行選手は主導権を取りに行かない可能性
is_dead_end_race × 得点順位     # 消化レースで上位選手が流す＝下位選手の激走余地
advancement_threshold × ライン内位置
```

### 副産物：学習データのクリーニング

**競走不成立時の「みなし着位」は抽選で決まる**（第5節）。これは純粋なノイズなので、学習データから除外するか別扱いにすべき。同様に**落車による棄権・繰上げ充当のレース**も、実力とは無関係な着位が混入する。これらを識別できれば学習データの質が上がる。**特徴量を増やすより先に、この除外を入れるほうが効果が大きい可能性がある。**

## I-3. 車番の情報量：規程から読み解く交絡 ★重要な修正

### 何が分かったか

前回メモで「4/6/8番車が高配当に絡みやすいのは番組編成上の交絡の疑い」と書いたが、規程と実務情報で裏付けが取れた。

- 『番組編成の要領』第4章第2節第6項(3)：**「番組編成委員は、競走ごとの出場選手の選手番号を、選手の脚力、脚質、競走成績等を勘案して決定する」**
- 実務上の運用として、9車立てでは**得点が低い選手を4・6・8番車に配置し、次に同じラインにならないと想定される選手同士で同枠を組むように5・7・9番車を配置、残りを1〜3番車**に置く、と説明されている
- グレードレース等の9車立てでは枠番が用いられる
- **ミッドナイト競輪は2020年10月以降、競走得点の高い順に1番車から機械的に配置される**（＝裁量ゼロ）

### 結論（2つ）

**(a) 車番系特徴量は開催時間帯で層別が必須。**
ミッドナイトでは車番＝得点順位なので、車番は得点順位と完全共線であり追加情報量ゼロ。一方それ以外の開催では車番に編成委員の裁量が乗る。**両者を混ぜて車番を1つの特徴量として学習させると、意味が異なる2つの変数を1列に押し込むことになり効果が相殺される。** これは既存モデルで車番が効かなかった原因である可能性がある。**まずこの層別だけ入れて測り直すことを推奨。**

**(b) 「車番 − 得点順位」の残差は編成委員の主観情報のプロキシになる（C候補）。**
非ミッドナイト開催では、車番は「得点順位」＋「編成委員が想定したライン構成・脚質バランス」の関数。したがって**得点順位から予測される車番と実際の車番のズレは、編成委員がその選手をどう見たかという情報**を含む。編成委員は前検日に選手から事情聴取までして能力を把握する立場（第4章第2節第3項）であり、**一般のベッターより情報優位にある内部者の判断が、車番という形で公開されている**と解釈できる。

```
expected_car_no_from_score      # 得点順位から規程の運用に沿って推定した車番
car_no_residual                 # 実際の車番 − 上記　★本命特徴量
is_midnight                     # 層別フラグ（ここでは residual は常に0になるはず）
car_no_residual × is_midnight   # 交互作用でミッドナイトを自動的に無効化
```

## I-4. 補充選手・流用選手・あっせん辞退 ★中程度の新規候補

『番組編成の要領』から、通常の出走表からは見えない選手の背景が規程として定義されている。

- **予備選手**：トーナメントごとに原則1名以上が選出されており、欠場が出ると補充される
- **流用選手**：予備選手でも足りない場合、**「当該競輪の最終日と次に参加する競輪の開催初日との間が原則として3日以上空いている選手」を他開催から流用**して参加させることができる
- **中途欠場選手の補充**：開催途中でも補充が行われる
- **あっせん辞退**：成績不振等により選手側があっせんを辞退する制度があり、辞退選手名簿がJKAに提出される

### なぜCか

**流用選手は「本来その開催に出る予定がなかった選手」**であり、準備・調整の前提が他の出走者と異なる。しかも規程上「次の開催まで3日以上空いている選手」という条件があるため、**流用選手はC-1（連戦負荷）の観点でも特異点になる。** 市場は出走表を見ても流用かどうか分からないため、完全に織り込まれていない。

**あっせん辞退明けの選手**も同様。辞退は成績不振や体調に起因するため、復帰直後の期待値は通常と異なるはずだが、市場は「久しぶりに見る名前」程度の処理しかしていない。

### 実装

```
is_substitute_rider             # 前検日以降の出走表更新で追加された選手（差分検知で特定可能）
                                # ※WINTICKETの出走表を時系列で保存していれば検出できる
days_since_last_appearance      # 既存days_sinceと重複するが、極端に長い場合はあっせん辞退明けの
                                # 可能性が高い（90日以上など）
long_absence_return             # 前回出走から90日以上（怪我・辞退明けフラグの代理）
```

**注意**：`days_since` が長い理由は「怪我」「あっせん辞退」「単純な斡旋の谷」で意味が正反対。前回メモでも指摘した通り、**これらを分離できないと符号が相殺してノイズになる。** 分離の手がかりとして、直前の開催で落車・失格があったか（結果データから取得可能）を併用すること。

## I-5. 日本競輪選手養成所（JIK）の記録データ ★新人選手のコールドスタート対策

### 何が分かったか

日本競輪選手養成所（JIK）の公式サイトに**「記録等資料室」**が設けられており、**期別平均最高タイム一覧、入所試験合格者成績**などが公開されている。養成所では卒業までに記録会が3回（入所直後の5月頃・中間期の9月頃・卒業間近の翌年2月頃）実施され、種目は**200mフライングダッシュ、400mフライングダッシュ、1000mタイムトライアル（男子）／500mTT（女子）、3000mTT（男子）／2000mTT（女子）**。また体力測定として身長・体重・胸囲・大腿囲などの計測値がPDFで公開されている実績がある（例：115回生の体力測定データ）。

### なぜCか

**新人選手（デビュー1〜2年）は競走得点のサンプルが不足しており、モデルの予測が最も不安定な層。** ここに養成所時代のフィジカル指標（1000mTT・200mFDのタイム、卒業記録）を注入できれば、**市場が「新人だから分からない」として粗く扱っている領域を、我々だけが定量的に埋められる。** 典型的なコールドスタート問題の解決であり、しかもデータは公開されている。

さらに、**200mFD（瞬発力）と3000mTT（持久力）の比**は選手の脚質適性の先行指標になる可能性がある。デビュー後の脚質分類（逃・両・追）は結果から事後的に付くものだが、養成所タイムは事前に脚質適性を示唆する。

### 実装

```
jik_graduation_period           # 卒業期（既存データにある可能性が高い）
jik_1000mTT_sec                 # 卒業時記録
jik_200mFD_sec
jik_3000mTT_sec
jik_sprint_endurance_ratio      # 200mFD / 3000mTT を正規化した比 → 脚質適性の先行指標
jik_rank_in_period              # 同期内順位（期ごとの平均タイムが公開されているので偏差も出せる）
jik_time_z_by_period            # 期別平均からのz-score（期ごとの水準差を吸収）

# 適用範囲を絞る（重要）
career_years                    # デビューからの年数
jik_1000mTT_z × (career_years < 3)  # 新人にのみ効かせる交互作用
```

**注意**：養成所記録はキャリアが進むと情報価値が急速に減衰するはず（実戦成績が蓄積するため）。**キャリア年数との交互作用で減衰させないと、ベテランに対して古い情報を効かせてしまい逆にノイズになる。** 適用範囲を新人層に絞って測定すること。

**取得方法**：JIKサイトの記録資料室（PDF/HTML）。期別なので年2回の更新で済み、収集コストは小さい。ただしPDFのパースが必要な場合がある。

## I-6. JCF強化指定選手（ナショナルチーム）★中程度

日本自転車競技連盟（JCF）が**強化指定選手一覧を公開**している。日本のトラック短距離ナショナルチームのメンバーはほぼ競輪選手が兼任しており、強化指定Aは男女合わせて8名程度、強化指定全体で20名前後。

### なぜ使えるか

2つの効果が**逆方向**に働くため、分離して測る価値がある。

- **正の効果**：ナショナル指定選手は純粋な短距離能力（瞬発力）が国内トップ水準。競走得点には現れにくい「地力」の指標になる
- **負の効果**：国際大会・合宿による長期の国内欠場が入り、競輪の実戦感が落ちる。また帰国直後は時差・移動負荷が大きい（C-1の連戦負荷と結合）

```
is_jcf_designated               # 強化指定選手フラグ（年度ごとのリストから作成）
days_since_intl_absence         # 長期欠場（国際大会遠征と推定される期間）明けからの日数
is_jcf_designated × days_since_last_race
```

**取得方法**：JCF公式の強化指定選手一覧。年度単位の小さなマスタ。

## I-7. バンク諸元マスタ ★実質必須のインフラ

全43場について**周長・みなし直線・カント角度・幅員**が公開されている（遠山競輪研究所の競輪場データ集、各種まとめサイト）。カントは最も緩いもので約24°30′、最もきついもので36°0′（前橋：335m・カント36°・みなし直線46.7m）。

**周長（333/400/500）だけを使っているなら情報を捨てている。** カント角度・みなし直線長は連続値であり、同じ400mバンクの中でも走路特性が大きく異なる。第II部の交互作用で使うため、これは特徴量というよりインフラとして整備すべき。

```
bank_length                     # 周長（既存の可能性大）
bank_straight_m                 # みなし直線長（連続値）
bank_cant_deg                   # カント角度（連続値、度分を10進に変換）
bank_width_m                    # 幅員
bank_homestretch_azimuth        # ホームストレッチ方位角（風の成分分解用・地図から作成）
```

さらに、出走表の記載事項として規程上**「当該競輪場における各級距離別の制限タイム、最高記録者とそのタイム」**を載せられることになっているため、**バンクレコード**も参照可能。これを使えば「そのバンクの絶対的な速さ」を正規化の基準にできる。

## I-8. 上がりタイム（KEIRIN.JP のレース結果）

**KEIRIN.JPのレース結果に「上り」欄として上がりタイム（ラスト半周＝200mのタイム）が公開されている。** 前回メモのC-7として挙げたが、取得先が確定した。WINTICKETに含まれていなければKEIRIN.JP側から取得する。

数値が小さい＝ラストで加速できた、大きい＝失速した、という直接的な脚力・余力の指標。**着順は展開に左右されるが上がりタイムは脚力に近い**ため、「着順は悪いが上がりは優秀」＝展開に恵まれなかった選手の検出に使える（詳細は前回メモC-7）。

## I-10. 参照専用（新規収集の価値は低い）

# 第II部：WINTICKET内データの組み合わせ・交互作用特徴量

**設計方針**：単体で効かなかった変数は、掛け合わせると効くことがある。特に競輪は「選手の強さ」と「走路の特性」と「隊列の力学」が乗算的に作用するため、**加法的なモデルでは表現できない構造**が多い。以下、既知の定量的知見が裏付けにあるものを優先して記載する。

## II-1. バンク特性 × 級班 × 脚質 ★裏付けのある交互作用

**根拠となる既知の集計**：バンク長別・クラス別の1着/2着決まり手比率の集計によれば、**バンク長が長いほど「逃げ」の決まり手が減り「差し」が増える。** 333mバンクは1着決まり手の割合がほぼ均等、500mバンクは1着の約半分が差し。さらに**S級戦では逃げの決まり手がチャレンジ戦の半分以下**になる。

つまり「逃げが決まる確率」は**周長と級班の両方に依存する二重の交互作用**であることが集計レベルで確認されている。単体の脚質フラグでは絶対に表現できない。

```
# 基本形
kyakushitsu × bank_length
kyakushitsu × class_grade                    # S級/A級1・2班/A級3班(チャレンジ)/L級
kyakushitsu × bank_length × class_grade      # ★三重交互作用（上記集計の直接の実装）

# 連続値版（周長のカテゴリ化より情報量が多い）
kyakushitsu × bank_straight_m                # みなし直線が長い＝差し有利
kyakushitsu × bank_cant_deg                  # カントがきつい＝後方から踏み込める＝捲り有利
nige_count × bank_straight_m                 # 逃げ実績のある選手×直線長
sashi_count × bank_straight_m
```

**測定時の注意**：級班とバンク周長でセグメントを切ると急速にサンプルが薄くなる。三重交互作用は**まず二重で有意性を確認してから**進むこと。

## II-2. 隊列の力学：レース内の脚質構成 ★純増寄与が期待できる

選手単体の脚質ではなく、**そのレースに先行型が何人いるか**が展開を決める。前回調査で参照したパ部競輪の特徴量設計でも「バック回数10回以上の選手が複数いると逃げ同士の叩き合いが起きる」という発想が採用されており、閾値を変えると別のモデルになると述べられている。これを一般化する。

```
# レース単位の構成変数（全選手に同じ値が入る）
n_senko_in_race                 # 先行型（逃）の人数
n_oikomi_in_race                # 追込型（追）の人数
n_jizai_in_race                 # 自在型（両）
n_tanki_in_race                 # 単騎の人数
n_lines                         # ライン本数
line_size_entropy               # ライン構成のエントロピー（3-3-3は高く、7-1-1は低い）
                                # ＝隊列の予測しやすさの指標

# バック回数の分布（叩き合いリスク）
B_max_in_race
B_top2_gap                      # 上位2名のバック回数差（小さい＝主導権争い）
B_over_threshold_count          # 閾値超えの人数（閾値は8/10/12でグリッドサーチ）
B_gini                          # バック回数のジニ係数（1人に集中しているか分散しているか）

# ★交互作用：叩き合いリスク × 当該選手の立ち位置
B_top2_gap × (当該選手が先行型か)      # 主導権争いがある中の先行は共倒れリスク
B_top2_gap × (当該選手が追込型か)      # 同じ状況で追込は恩恵
n_senko_in_race × bank_straight_m      # 先行多数×長い直線＝差し決着の確率がさらに上がる
```

**仮説の要点**：`B_top2_gap` が小さい（主導権争いが起きる）レースでは、**先行型の期待値が下がり追込型・単騎の期待値が上がる。** 市場は「叩き合いになりそう」程度には読むが、バック回数の分布形状として定量化はしていない。第II部の中でこれが最も期待値が高いと考える。

## II-3. ライン内の非対称性 ★二軸探偵の核と接続

前回メモ（二軸探偵）の内容と接続する。ライン全体の強さではなく**ライン内の力関係の非対称性**を数値化する。

```
# 当該選手の視点から
line_position                   # 1=先頭, 2=番手, 3=三番手, 0=単騎
line_size                       # 所属ラインの車数
score_gap_to_line_head          # ライン先頭選手との得点差（番手選手にとっての「格差」）
score_gap_to_line_next          # ライン内の次位選手との得点差
line_head_B_count               # 自ラインの先頭選手のバック回数（＝主導権を取れるか）
line_head_nige_rate             # 自ライン先頭の逃げ率

# ★三番手ジャンプの検出（二軸探偵の差別化ロジック）
bante_minus_sanbante_score      # 番手選手の得点 − 三番手選手の得点
                                # 負の値が大きい＝番手が弱く三番手が差してくる余地
is_bante_weaker_than_sanbante   # 上記のフラグ版

# ★交互作用
line_position × bank_straight_m          # 直線が長いほど番手・三番手が有利
line_position × line_head_B_count        # 先頭が強い×番手＝スジ目の信頼度が上がる
score_gap_to_line_head × bank_cant_deg
line_size × car_no                       # 「長いライン×内枠」の複合有利（定説の定量化）
```

## II-4. S回数（スタート取り）の活用 ★見落とされがち

出走表に**S（スタートを取った回数）** が記載されている。「Sを取る」とは発走時に先頭誘導員のすぐ後ろに付くこと。これは**その選手が前々の位置を取りに行く意志と技術**を示す指標だが、B（バック）回数に比べて予想での使用頻度が低い。

```
S_count                         # スタート取り回数（既存データにあるはず）
S_rate                          # S回数 / 出走回数
S_count_sa                      # レース内最大値との差（パ部方式の相対化）
S_top2_gap                      # 上位2名のS回数差（＝スタート争いの激しさ）

# ★交互作用（ここが本題）
S_rate × car_no                 # 内枠×Sを取る意志＝実際に前を取れる確率が高い
                                # 外枠でS率が高い選手は「取りに行くが取れない」可能性
S_rate × n_senko_in_race        # 先行が多いレースでS争いが起きる
S_rate × B_rate                 # Sは取るがバックは取らない＝番手狙いの脚質シグナル
                                # SとBの比率は「前々に行くが主導権は譲る」という
                                # 脚質分類（逃/両/追）より細かい行動パターンを表す
```

**S/B比率の解釈**：S率が高くB率が低い選手は「好位を取るが先行はしない」＝自在型の中でも番手狙いの行動を取る。この区別は脚質の3分類（逃・両・追）では失われている情報であり、**同じ「両」の中でも行動が正反対の選手を分離できる。**

## II-5. 市場データとの掛け合わせ ★期待値ベースの選別に直結

オッズは特徴量として直接使うのではなく、**「自モデルの予測」と「市場の含意確率」の乖離**として使う（前回メモの測定プロトコルと同じ発想を特徴量に持ち込む）。

```
implied_prob                    # 確定オッズから算出、控除率を戻して1.0に正規化
popularity_rank                 # 人気順位
model_prob_minus_implied        # ★自モデル予測確率 − 市場含意確率
                                # 正＝市場が過小評価している

# 交絡確認用（重要）
score_rank_minus_popularity_rank  # 得点順位 − 人気順位
                                  # 正＝得点は高いのに人気がない（何か理由があるはず）
                                  # この「理由」を他の特徴量で説明できるかを見る
```

**注意（重要）**：`implied_prob` を学習時の特徴量に入れると、モデルが市場の予測を模倣するだけになり、**期待値の源泉である「市場との乖離」が消える。** 市場データは**学習には入れず、評価・選別の段階でのみ使う**構成を推奨する。学習に入れるとしても、`implied_prob` を目的変数から差し引いた残差を学習させる（residual learning）など、明示的に「市場が説明できない部分」だけを学習する設計にすること。

## II-6. 会場適性 × バンク類似度 ★サンプル不足を補う工夫

「その選手はその会場が得意か」は使われる観点だが、**個別会場での出走回数は少なくサンプル不足**になりやすい。バンク諸元（周長・カント・直線長）で会場をクラスタリングし、**「類似バンクでの成績」に拡張することでサンプルを稼ぐ**。

```
venue_race_count_self           # 当該会場での自身の出走回数（信頼度の重み）
venue_win_rate_self             # 同・勝率（サンプル不足のためそのままでは使えない）

# ★類似バンクへの拡張
bank_cluster_id                 # 周長・カント・直線長でk-means（k=4〜6）
cluster_win_rate_self           # 同一クラスタのバンクでの成績（サンプルが数倍に増える）
cluster_win_rate_minus_overall  # 同 − 全体成績　＝そのバンク類型への適性
```

**なぜCか**：市場は「◯◯記念で強い」「あの選手は前橋が得意」といった個別会場の記憶で処理しており、**「バンク類型としての適性」という抽象化はしていない。** サンプル不足を類似度で補う発想は統計的な工夫であり、人間には実行不可能。

## II-7. 級班混走・格の非対称 ★見落とされがち

規程上、FIは「S級トーナメント＋A級1・2班トーナメント／L級」の組み合わせ、FIIは「A級1・2班／A級3班／L級」の組み合わせ、GIIは「S級トーナメントまたはS級A級混合競走」と定義されている。つまり**同一レース内に異なる級班の選手が混在する競走が制度的に存在する。**

級班が混ざると**競走得点の物差しが揃わない**（A級で稼いだ得点とS級で稼いだ得点は価値が違う）。ここは前回メモC-5（自前Eloによる対戦相手補正）が最も効く場面。

```
is_mixed_class_race             # 級班混走フラグ
class_diversity                 # レース内の級班の種類数
own_class_rank_in_race          # レース内での自身の級班順位
score_minus_class_mean          # 自身の得点 − 同級班の平均得点（級班内での相対位置）

# ★交互作用
is_mixed_class_race × elo_minus_displayed_score_z
                                # 混走レースでは表示得点の歪みが最大化するという仮説
                                # ＝自前Eloの優位性が最も出るセグメント
```

**この交互作用は前回メモC-5の測定を行う際の最優先セグメント**として扱うこと。仮説が正しければ、混走レースに限定した比が全体の比を大きく上回るはず。

## II-8. 開催時間帯・車立て数 ★層別が必須

```
race_time_category              # モーニング / 通常 / ナイター / ミッドナイト
n_starters                      # 7車立て / 9車立て
race_distance_m                 # 周回数×周長（ミッドナイトは周回数が少ない）
```

**既知の知見**：ミッドナイト競輪は7車立てで周回数が少なく走行距離が短いため、**先行選手の勝率が通常より高い**とされる。脚が残るため番手に抜かれにくい。つまり**脚質の価値が開催形態によって系統的に変わる。**

```
kyakushitsu × race_time_category
kyakushitsu × n_starters
kyakushitsu × race_distance_m   # 連続値版。距離が短い＝先行有利
car_no × is_midnight            # I-3の通り、ミッドナイトでは車番の情報量がゼロ
```

**7車立てと9車立てを混ぜて学習させるのも危険**。車番の意味（4/6/8の配置ルールは9車立ての運用）、ライン構成の自由度、単騎の発生確率がすべて変わる。**最低でも車立て数はモデルを分けるか、全特徴量に交互作用を張ることを検討すべき。**

# 測定時の追加注意（第I部・第II部共通）

前回メモの3ステップ（比の算出 → 1.333閾値 → TRAIN/TEST両窓一致）に加え、交互作用特徴量に固有の注意点。

1. **交互作用は多重比較の温床。** 変数A×変数Bの組み合わせは組み合わせ爆発するため、**事前に仮説と符号の方向を書き出してから測る。** 総当たりで探して有意なものを拾うと必ず偽陽性を掴む。本文書で各交互作用に「仮説」を明記しているのはこのため
2. **セグメントを切るとサンプルが指数的に減る。** 三重交互作用（II-1）は、二重で有意性を確認してからのみ進む
3. **単体で効かない変数の交互作用は解釈に注意。** 単体で効かないが交互作用で効く場合は本物の可能性があるが、**単体・交互作用の両方で効かないものを組み合わせ続けるのは探索空間の無駄**
4. **レース単位変数（II-2の構成変数など）は同一レース内の全選手に同じ値が入る。** これを選手単位のモデルに入れるとレース内で分散がゼロになり、レース内相対評価型のモデル（ランキング学習など）では効果が消える。**必ず「レース単位変数 × 選手単位変数」の交互作用として入れること**。これは見落としやすい
